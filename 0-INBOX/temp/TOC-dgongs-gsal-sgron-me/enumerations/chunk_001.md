Enumeration Block 1:
དང་པོ་ལ་གསུམ། མཚན་བསྒྱུར་བ་དང་། མཚན་བཤད་པ་དང་། མཚན་གྱི་དགོས་པའོ། །
Enumeration Block 2:
གསུམ་པ་གཞུང་གི་དོན་ལ་གཉིས། བསྟན་བཅོས་རྩོམ་པ་ལ་འཇུག་པའི་ཡན་ལག ། བརྩམ་པའི་བསྟན་བཅོས་ཀྱི་ལུས་དངོས་སོ། །དང་པོ་ལ་གསུམ། མཆོད་བརྗོད་སྔོན་དུ་འགྲོ་བས་རྩོམ་པར་དམ་བཅའ་བ་དང་། སྤྲོ་བ་སྔོན་དུ་འགྲོ་བས་མཚན་གྱི་དོན་བཤད་པ་དང་། དགོས་པ་སྔོན་དུ་འགྲོ་བས་སྟོན་པས་གསུངས་པར་བསྒྲུབ་པའོ། །དང་པོ་ལ་གཉིས། མཆོད་བརྗོད་དང་། རྩོམ་པར་དམ་བཅའ་བའོ། །
Enumeration Block 3:
དང་པོ་ལ། རང་དོན་སྤངས་རྟོགས་ཕུན་ཚོགས་དང་། གཞན་དོན་ཕྲིན་ལས་ཕུན་ཚོགས་དང་། དེ་སྒྲུབ་པའི་ཐབས་ཕུན་སུམ་ཚོགས་པའི་སྒོ་ནས་བསྟོད་པ་གསུམ་ལས།
Enumeration Block 4:
གཉིས་པ་སྤྲོ་བ་སྔོན་དུ་བཏང་ནས་མཚན་གྱི་དོན་བཤད་པ་ལ་གཉིས། ཆོས་མངོན་པ་བཤད་པ་དང་། མཛོད་བཤད་པའོ། །
Enumeration Block 5:
སྤྱིར་ཆོ༵ས་མངོ༵ན་པ་དེ་ལ་དབྱེ་ན་དོན་དམ་དང་། བརྡར་བཏགས་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་བརྩམ་པའི་བསྟན་བཅོས་ཀྱི་ལུས་དངོས་ལ་གཉིས། བརྗོད་བྱ་ངོས་གཟུང་བ་དང་། དེ་རྒྱས་པར་གཏན་ལ་དབབ་པའོ། །
Enumeration Block 7:
དེ་ནི་རྣམ་པ་གཉིས་སུ་འདུ་སྟེ། ཟ༵ག་པ་དང་བཅ༵ས་པ་དང་ཟ༵ག་པ་མེད༵་པའི་ཆོ༵ས་གཉིས་སུ་འདུ་བའི་ཕྱིར།
Enumeration Block 8:
རྣམ་པ་གསུམ་གང་ཞེ་ན། ནམ༵་མཁ༵འ་དང༵་ནི༵་སོ་སོར་བརྟགས་འགོ༵ག་དང་བརྟགས་པ༵་མ་ཡིན་པའི་འགོག་པ་གཉི༵ས་སོ། །
Enumeration Block 9:
གཉིས་པ་རྒྱས་པར་གཏན་ལ་དབབ་པ་ལ་གཉིས། འདུས་མ་བྱས་རྒྱས་པར་བཤད་པ། འདུས་བྱས་རྒྱས་པར་བཤད་པའོ། །
