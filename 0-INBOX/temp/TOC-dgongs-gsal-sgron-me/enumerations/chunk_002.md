Enumeration Block 1:
གཉིས་པ་རྒྱས་པར་གཏན་ལ་དབབ་པ་ལ་གཉིས། འདུས་མ་བྱས་རྒྱས་པར་བཤད་པ། འདུས་བྱས་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་འདུས་བྱས་རྒྱས་པར་བཤད་པ་ལ་གཉིས། སྤྱིིའི་དོན་དང་། གཞུང་གི་དོན་ནོ། ། དང་པོ་ལ་གསུམ། གནས་བརྒྱད་ཀྱི་རྣམ་པར་གཞག་པ། བརྒྱད་པོ་དེ་དག་གི་འབྲེལ་རྣམ་པར་གཞག་པ། གནས་གང་ན་བརྗོད་བྱ་གང་སྟོན་བསྟན་པའོ། །
Enumeration Block 3:
དེ་ཉིད་རྒྱས་པར་འཆད་པ་ལ་གནས་བརྒྱད་དེ།
Enumeration Block 4:
ཟག་བཅས་བྱེ་བྲག་ཏུ་སྟོན་པའི་དབང་དུ་བྱས་ནས་གནས་གསུམ་སྟེ། གང་ཀུན་ནས་ཉོན་མོངས་པ། གང་དུ་ཀུན་ནས་ཉོན་མོངས་པ། ཇི་ལྟར་ཀུན་ནས་ཉོན་མོངས་པ་གསུམ་རིམ་པ་ལྟར།
Enumeration Block 5:
ཟག་མེད་བྱེ་བྲག་ཏུ་སྟོན་པའི་དབང་དུ་མཛད་ནས་གནས་ཕྱི་མ་གསུམ་སྟེ། གང་རྣམ་པར་བྱང་བའི་གང་ཟག་དང་། གང་དུ་རྣམ་པར་བྱང་བའི་གནས་དང་། ཇི་ལྟར་རྣམ་པར་བྱང་བའི་མངོན་པར་རྟོགས་པའི་རིམ་པ་སྟོན་པ
Enumeration Block 6:
གཉིས་པ་གཞུང་གི་དོན་ལ་གནས་བརྒྱད་ཡོད་པ་ལས། དང་པོ་ཁམས་བསྟན་པའི་གནས་ལ་གསུམ། འདུས་བྱས་ཀྱི་ཕྱོགས། མིང་གི་རྣམ་གྲངས། ཕུང་ཁམས་སྐྱེ་མཆེད་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 7:
གཉིས་པ་མིང་གི་རྣམ་གྲངས་ལ་གཉིས། སྤྱིར་འདུས་བྱས་ཀྱི་མིང་གི་རྣམ་གྲངས་དང་། བྱེ་བྲག་ཏུ་ཟག་བཅས་ཀྱི་མིང་གི་རྣམ་གྲངས་སོ། །
Enumeration Block 8:
གསུམ་པ་ཕུང་ཁམས་སྐྱེ་མཆེད་རྒྱས་པར་བཤད་པ་ལ་གསུམ། ཕུང་ཁམས་སྐྱེ་མཆེད་ཀྱི་རང་བཞིན། ཆོས་གཞན་བསྡུ་བའི་ཚུལ། ཁམས་དང་ལྡན་པའི་རབ་དབྱེའོ། །
Enumeration Block 9:
དང་པོ་ལ་ལྔ། དངོས་དང། གསུམ་པོ་སོ་སོའི་སྒྲ་དོན་དགོས་པ་དང་བཅས་པ། ཚོར་འདུ་གཉིས་ཕུང་པོ་ལོགས་སུ་འཇོག་པའི་རྒྱུ་མཚན། ཕུང་ཁམས་སྐྱེ་མཆེད་ཀྱི་གོ་རིམ་ངེས་ཚུལ། སྐྱེ་མཆེད་གཉིས་ཀྱི་ངེས་པའོ། ། དང་པོ་ལ་བཞི། གཟུགས་ཕུང་གི་རྣམ་གཞག ། ཕུང་པོ་བར་པ་གསུམ་གྱི་རྣམ་གཞག རྣམ་ཤེས་ཀྱི་ཕུང་པོའི་རྣམ་གཞག ། རྫས་ཆོས་ལ་དོགས་པ་གཅད་པའོ། ། དང་པོ་ལ་གཉིས། དངོས་དང་། དེ་དག་ཁམས་དང་སྐྱེ་མཆེད་དུ་བྱ་བའོ། །དང་པོ་ལ་གཉིས། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 10:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། དབང་པོ་ལྔ་མཚན་ཉིད་ཀྱི་སྒོ་ནས་བསྟན་པ། དོན་ལྔ་མཚན་གཞིའི་སྒོ་ནས་བསྟན་པ། རིག་བྱེད་མ་ཡིན་པའི་གཟུགས་བཤད་པའོ། །
