Enumeration Block 1:
རྣམ༵་པ་གཉིས༵་སུ་འདུ་སྟེ། ཁ་དོག་གི་གཟུགས་དང༵་། དབྱིབས་ཀྱི་གཟུགས་གཉིས་སུ་འདུ་བའི་ཕྱིར། རྒྱས་པར་ཕྱེ་ན་རྣམ༵་པ་ཉི༵་ཤུར༵་ཡོད་དེ། ཁ་དོག་གི་གཟུགས་བཅུ་གཉིས། དབྱིབས་ཀྱི་གཟུགས་བརྒྱད་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
དབྱིབས་ཀྱི་གཟུགས་ནི་བརྒྱད་ཡོད་དེ། རིང་བ་དང་ཐུང་བ། མཐོ་བ་དང་དམའ་བ། ལྷམ་པ་དང་ཟླུམ་པ། ཕྱ་ལེ་བ་དང་ཕྱ་ལེ་བ་མ་ཡིན་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
སྒྲ༵་ནི༵་རྣམ༵་པ༵་བརྒྱད༵་ཡོད༵་དེ༵། །ཟིན་པའི་འབྱུང་བ་ལས་གྱུར་པའི་སྒྲ་དང་། མ་ཟིན་པའི་འབྱུང་བ་ལས་གྱུར་པའི་སྒྲ་གཉིས་ལས། དང་པོ་ལ་སེམས་ཅན་དུ་སྟོན་པ་དང་མི་སྟོན་པ་གཉིས། སེམས་ཅན་དུ་སྟོན་པ་ལ་སྙན་པ་ཆོས་སྟོན་པའི་སྒྲ་དང་མི་སྙན་པ་ཚིག་རྩུབ་སྨྲ་བའི་སྒྲ་ལྟ་བུ་གཉིས། སེམས་ཅན་དུ་མི་སྟོན་པ་ལ་སྙན་པ་ཕོག་རྡོག་པའི་སྒྲ་ལྟ་བུ་དང་མི་སྙན་པ་ཁུ་ཚུར་རྡེག་པའི་སྒྲ་ལྟ་བུ་གཉིས། མ་ཟིན་པའི་འབྱུང་བ་ལས་གྱུར་པའི་སྒྲ་ལ་སེམས་ཅན་དུ་སྟོན་མི་སྟོན་གཉིས་ལས། སེམས་ཅན་དུ་སྟོན་པ་ལ་སྙན་པ་སྤྲུལ་པའི་གང་ཟག་གིས་ཆོས་སྟོན་པའི་སྒྲ་ལྟ་བུ་དང་མི་སྙན་པ་སྤྲུལ་པའི་གང་ཟག་གིས་ཚིག་རྩུབ་སྨྲ་བའི་སྒྲ་ལྟ་བུ་གཉིས། དེ་འདྲའི་སེམས་ཅན་དུ་མི་སྟོན་པའི་སྒྲ་ལ་སྙན་པ་འཁར་རྔའི་སྒྲ་ལྟ་བུ་དང་མི་སྙན་པ་བྲག་རལ་བའི་སྒྲ་ལྟ་བུ་གཉིས་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
རོ༵་ནི༵་རྣམ༵་པ་དྲུག༵་ཡོད་དེ། མངར་བ་དང་སྐྱུར་བ་གཉིས། ཚ་བ་དང་ལན་ཚ་བ་གཉིས། སྐ་བ་དང་ཁ་བ་གཉིས་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
དྲི༵་ལ་རྣམ༵་པ་བཞི༵་ཡོད་དེ། དྲི་ཞིམ་པ་དང་མི་ཞིམ་པ། མཉམ་པ་དང་མི་མཉམ་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
རེག༵་བྱ༵་བཅུ༵་གཅི༵ག་ཡོད་དེ། རྒྱུའི་རེག་བྱ་འབྱུང་བ་བཞི། འབྲས་བུའི་རེག་བྱ་འཇམ་རྩུབ་གཉིས། ལྕི་ཡང་གཉིས། གྲང་བ་དང་བཀྲེས་སྐོམ་གཉིས་ཀྱི་བད༵ག་ཉིད་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
དེ་ནི་ཁྱད་པར་ལྔ་དང་ལྡན་པ་ཡིན་ཏེ།
Enumeration Block 8:
གཟུགས་དང་དེ་མ་ཡིན་པ་གཉིས་སུ་དངོས་པོར་ངེས་ལ། གཟུགས་མིན་པ་ལ་སེམས་དང་སེམས་མིན་པ་གཉིས་སུ་ངེས་ཤིང་། གཟུགས་དང་སེམས་མིན་པ་ནི་ཚོར་བ་ལ་སོགས་པའི་ཕུང་པོ་གསུམ་དུ་ངེས་པའི་ཕྱིར།
