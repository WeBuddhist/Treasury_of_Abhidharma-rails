Enumeration Block 1:
དྲུག་པ་དབང་པོའི་ལྡན་ཚུལ་ལ་གཉིས། ངེས་ལྡན་དང་། སྲིད་ལྡན་ནོ། །
Enumeration Block 2:
གཉིས་པ་འདུས་བྱས་ཀྱི་ཆོས་ཀྱི་སྐྱེ་ཚུལ་ལ་གཉིས། དངོས་དང་། ཞར་ལ་རྒྱུ་རྐྱེན་འབྲས་བུ་དང་བཅས་པ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། གཟུགས་ཅན་གྱི་ཆོས་ཀྱི་སྐྱེ་ཚུལ་དང་། གཟུགས་ཅན་མ་ཡིན་པའི་ཆོས་ཀྱི་སྐྱེ་ཚུལ་ལོ། །
Enumeration Block 3:
གཞན་རྣམས་ཀྱི་སྐྱེ་ཚུལ་ལ། གཟུགས་ཅན་གྱི་སྐྱེ་ཚུལ་དང་། གཟུགས་ཅན་མ་ཡིན་པའི་སྐྱེ་ཚུལ་གཉིས་སུ་ངེས་པས།
Enumeration Block 4:
གཉིས་པ་གཟུགས་ཅན་མ་ཡིན་པའི་སྐྱེ་ཚུལ་ལ་གཉིས། བསྟན། བཤད་དོ། །
Enumeration Block 5:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས། མཚུངས་ལྡན་གྱི་སྐྱེ་ཚུལ། མཚུངས་ལྡན་མ་ཡིན་པའི་སྐྱེ་ཚུལ་ལོ། །དང་པོ་ལ་བཞི། སྡེ་ཚན་དུ་ངེས་པའི་རབ་དབྱེ། མ་ངེས་པ་དང་བཅས་པའི་མཚུངས་ལྡན། འདྲ་བ་ལྟ་བུའི་ཁྱད་པར། ཐ་དད་ལྟ་བུའི་གཅིག་པའོ། །དང་པོ་ལ་གཉིས། བསྟན། བཤད་དོ། །
Enumeration Block 6:
གཉིས་པ་རྒྱས་བཤད་ལ་ལྔ་ལས།
Enumeration Block 7:
གཉིས་པ་མཚུངས་ལྡན་མ་ཡིན་པའི་སྐྱེ་ཚུལ་ལ་གསུམ། བསྟན། བཤད། དོན་བསྡུ་བའོ། །
Enumeration Block 8:
གཉིས་པ་རྒྱས་བཤད་ལ་བདུན། ཐོབ་མ་ཐོབ། སྐལ་མཉམ། འདུ་ཤེས་མེད་པ་བ། སྙོམས་འཇུག་གཉིས། སྲོག ། མཚན་ཉིད། རྗོད་བྱེད་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དངོས་དང་། དེའི་ཁྱད་ཆོས་བཤད་པའོ། །
Enumeration Block 9:
དེ་ལ་དབྱེ་ན། གསར་དུ་རྙེད་པ་དང་སྐད་ཅིག་གཉིས་པ་ཕན་ཆད་རྒྱུན་དང་ལྡན་པ་གཉིས་སོ། །
Enumeration Block 10:
དེ་ལའང་གཉིས་ཏེ། མ་རྙེད་པ་དང་། མི་ལྡན་པའོ། །དང་པོ་ལ། མ་ཐོབ་པ་ལས་མ་རྙེད་པ་དང་། ཉམས་ནས་མ་རྙེད་པའོ། །
Enumeration Block 11:
གཉིས་པ་དེའི་ཁྱད་ཆོས་ལ་གཉིས། ཐོབ་པའི་ཁྱད་ཆོས། མ་ཐོབ་པའི་ཁྱད་ཆོས་སོ། །
