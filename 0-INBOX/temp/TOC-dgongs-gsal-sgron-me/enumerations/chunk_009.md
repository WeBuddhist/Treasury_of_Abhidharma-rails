Enumeration Block 1:
གཉིས་པ་རྒྱས་བཤད་ལ་བདུན། ཐོབ་མ་ཐོབ། སྐལ་མཉམ། འདུ་ཤེས་མེད་པ་བ། སྙོམས་འཇུག་གཉིས། སྲོག ། མཚན་ཉིད། རྗོད་བྱེད་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དངོས་དང་། དེའི་ཁྱད་ཆོས་བཤད་པའོ། །
Enumeration Block 2:
དེ་ལ་དབྱེ་ན། གསར་དུ་རྙེད༵་པ་དང༵་སྐད་ཅིག་གཉིས་པ་ཕན་ཆད་རྒྱུན་དང་ལྡན༵་པ༵་གཉིས་སོ། །
Enumeration Block 3:
དེ་ལའང་གཉིས་ཏེ། མ་རྙེད་པ་དང་། མི་ལྡན་པའོ། །དང་པོ་ལ། མ་ཐོབ་པ་ལས་མ་རྙེད་པ་དང་། ཉམས་ནས་མ་རྙེད་པའོ། །
Enumeration Block 4:
གཉིས་པ་དེའི་ཁྱད་ཆོས་ལ་གཉིས། ཐོབ་པའི་ཁྱད་ཆོས། མ་ཐོབ་པའི་ཁྱད་ཆོས་སོ། །
Enumeration Block 5:
དབྱེ་ན་ཐ་དད་དང་། ཐ་དད་མིན་པ་གཉིས།
Enumeration Block 6:
བཞི་པ་སྙོམས་འཇུག་གཉིས་བཤད་པ་ལ་གསུམ། འདུ་ཤེས་མེད་པའི་སྙོམས་འཇུག་བཤད། འགོག་པའི་སྙོམས་འཇུག་བཤད། དེ་གཉིས་ཀྱི་རྟེན་ཐུན་མོང་དུ་བཤད་པའོ། །
