Enumeration Block 1:
གཉིས་པ་ཞར་ལ་རྒྱུ་རྐྱེན་འབྲས་བུ་དང་བཅས་པ་བཤད་པ་ལ་གཉིས་ལས། རྒྱུ་འབྲས་བུ་དང་བཅས་པ་བཤད་པ་དང་། རྐྱེན་བཤད་པའོ། །དང་པོ་ལ་གསུམ། རྒྱུ་བཤད་པ། འབྲས་བུ་བཤད་པ། དེ་གཉིས་ཀྱི་ཐུན་མོང་གི་ཆོས་བཤད་པའོ། །དང་པོ་ལ་གསུམ། བསྟན། བཤད། དོན་བསྡུ་བའོ། །
Enumeration Block 2:
རྒྱུ་དེ་ལ་དུ་ཡོད་ཅེ་ན། དྲུག་ཡོད་དེ། བྱེད༵་རྒྱུ༵་དང་། ལྷ྄༷ན་ཅིག༵་འབྱ྄ུ༷ང་བའི༵་རྒྱུ་དང༵་། སྐལ༵་མཉ༵མ་གྱི་རྒྱུ་དང་། མཚུང༵ས་པར༵་ལྡན༵་པའི༵་རྒྱུ་དང༵་། ཀུན༵་ཏུ་འགྲོ༵་བའི་རྒྱུ་དང༵་། རྣམ༵་སྨིན༵་གྱི་རྒྱུ་སྟེ། རྒྱུ༵་ནི༵་རྣམ༵་པ༵་དྲུག༵་ཏུ༵་འདོ༵ད་པའི་ཕྱིར། །
Enumeration Block 3:
གཉིས་པ་རྒྱས་བཤད་ལ་དྲུག་ལས།
Enumeration Block 4:
གཉིས་པ་ལྷན་ཅིག་འབྱུང་བའི་རྒྱུ་ལ་གཉིས། མཚན་ཉིད་དང་། མཚན་གཞིའོ། །
Enumeration Block 5:
གཉིས་པ་མཚན་གཞི་ལ་གཉིས། སྤྱིར་བསྟན་པ་དང་། སེམས་ཀྱི་རྗེས་འཇུག་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་འབྲས་བུ་བཤད་པ་ལ། བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 7:
གཉིས་པ་རྒྱས་བཤད་ལ། འབྲས་བུ་གང་རྒྱུ་གང་གི་ཡིན་པ། སོ་སོའི་མཚན་ཉིད་བཤད་པའོ། །
Enumeration Block 8:
སྐྱེས་བུའི་བྱེད་འབྲས་ལ་བསྐྱེད་པའི་སྐྱེས་བུའི་བྱེད་འབྲས་དང་། ཐོབ་པའི་སྐྱེས་བུའི་བྱེད་འབྲས་གཉིས།
