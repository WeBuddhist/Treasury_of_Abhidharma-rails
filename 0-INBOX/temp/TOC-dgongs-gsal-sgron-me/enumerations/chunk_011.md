Enumeration Block 1:
གཉིས་པ་འབྲས་བུ་བཤད་པ་ལ། བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 2:
སྐྱེས་བུའི་བྱེད་འབྲས་ལ་བསྐྱེད་པའི་སྐྱེས་བུའི་བྱེད་འབྲས་དང་། ཐོབ་པའི་སྐྱེས་བུའི་བྱེད་འབྲས་གཉིས།
Enumeration Block 3:
དབྱེ་ན་གསུམ།
Enumeration Block 4:
གསུམ་པ་དེ་གཉིས་ཀྱི་ཐུན་མོང་གི་ཆོས་བཤད་པ་ལ་གཉིས། འབྲས་བུ་འཛིན་འབྱིན་གྱི་དུས། དངོས་པོ་གང་རྒྱུ་དུས་སྐྱེད་པའོ། །
Enumeration Block 5:
སྤྱིར་འབྲས་བུ་ལ་མཚུངས་ལྡན་སེམས་ལས་སེམས་བྱུང་དང་དེ་མ་ཡིན་པ་གཉིས་སུ་ངེས་ཤིང་། དེ་ལས་ཀྱང་དང་པོ་མཚུངས་ལྡན་ལ་དབྱེ་ན། ཉོན༵་མོང༵ས་ཅ༵ན་དང༵་། རྣམ༵་སྨིན༵་སྐྱེས༵་དང་། དང་པོ་འཕགས་པ་མ་ཡིན་པའི་མཚུངས་ལྡན་འདུས་བྱས་ལྷག༵་མ་རྣམས་དང༵་། དང༵་པོ༵་འཕ྄༷གས་པ་སྟེ་ཟག་མེད་སྐད་ཅིག་དང་པོ་དང་བཞི་ཡོད་དོ། །
Enumeration Block 6:
གཉིས་པ་རྐྱེན་བཤད་པ་ལ། བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 7:
རྐྱེ༷ན་ནི༵་བཞི༵་པོ༵་དག༵་ཏུ༵་མདོ་ལས་གསུ༵ང༵ས་སོ། །གང་ཞེ་ན། རྒྱུའི་རྐྱེན་དང་། དེ་མ་ཐག་རྐྱེན་དང་། དམིགས་རྐྱེན་དང་། བདག་པོའི་རྐྱེན་ཉིད་དོ། །
Enumeration Block 8:
གཉིས་པ་རྒྱས་བཤད་ལ་བཞི། རྐྱེན་སོ་སོའི་མཚན་ཉིད། རྐྱེན་གང་འབྲས་བུ་དུས་གསུམ་པ་གང་ལ་བྱ་བ་བྱེད། དངོས་པོ་གང་རྐྱེན་དུས་སྐྱེད། དེ་མ་ཐག་པའི་རྐྱེན་རྒྱས་པས་བཤད་པའོ། །
Enumeration Block 9:
བཞི་པ་དེ་མ་ཐག་པའི་རྐྱེན་རྒྱས་པར་བཤད་པ་ལ་གསུམ། སེམས་བཅུ་གཉིས་སུ་དབྱེ་བ་དང་། ཉི་ཤུར་དབྱེ་བ་དང་། བཅུ་གཉིས་པོ་གང་ལས་གང་གསར་དུ་རྙེད་དཔྱད་པའོ། །དང་པོ་ལ། དངོས་དང་། རྐྱེན་དང་རྐྱེན་ཅན་སྦྱར་བའོ། །
Enumeration Block 10:
སེམས་དེ་ལ་བཅུ་གཉིས་ཡོད་དེ། འདོ༵ད་པ་ན་ཡི༵ད་དགེ༵་བ་དང༵་། མི༵་དགེ༵་བ་དང༵་། བསྒྲིབ༵ས་ལུང་མ་བསྟན་པ༵་དང༵་། མ༵་བསྒྲིབ༵ས་ལུང་མ་བསྟན་པ༵་བཞི་དང་། གཟུག༵ས་དང༵་གཟུག༵ས་མེད༵་པ༵་དག༵་ན༵་མི༵་དགེ༵་བ་ལས༵་གཞ༵ན་གསུམ་གསུམ་དང་། ཟག༵་མེད༵་ལ་སློབ་མི་སློབ་གཉི༵ས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 11:
ཚེ་བརྒྱད་ནི་རྒྱུན་གྱི་ཚེ། ས་མཚུངས་ཀྱི་ཚེ། ཉིང་མཚམས་སྦྱོར་བའི་ཚེ། སྙོམས་པར་འཇུག་པའི་ཚེ། སྙོམས་འཇུག་ལས་ལྡང་བའི་ཚེ། སྙོམས་འཇུག་ཉོན་མོངས་ཅན་གྱིས་གཟིར་བའི་ཚེ། སྤྲུལ་པ་ལ་འཇུག་པའི་ཚེ། སྤྲུལ་པ་ལས་ལྡང་བའི་ཚེའོ། །
