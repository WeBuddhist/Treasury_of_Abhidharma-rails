Enumeration Block 1:
གཉིས་པ་ཆོས་ཀྱི་ཁྱད་པར་ལ་བཞི། རྣམ་ཤེས་ཀྱི་གནས་པ་བདུན། སེམས་ཅན་གྱི་གནས་དགུ། རྣམ་ཤེས་གནས་པ་བཞི། བདུན་དང་བཞིའི་བསྡུ་བ་དཔྱད་པའོ། །
Enumeration Block 2:
གསུམ་པ་རང་བཞིན་རྒྱས་པར་བཤད་པ་ལ་གསུམ། དང་པོར་འཇུག་ཚུལ། བར་དུ་གནས་ཚུལ། མཐར་འགྲོ་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། གང་དུ་འཇུག་པའི་སྐྱེ་གནས། གང་གིས་འཇུག་པའི་བར་སྲིད་དོ། །
Enumeration Block 3:
གཉིས་པ་གང་གིས་འཇུག་པའི་བར་སྲིད་ལ་ལྔ། ངོ་བོ་དང་། སྒྲུབ་བྱེད། ཤ་ཚུགས། ཆོས་ཀྱི་ཁྱད་པར། སྐྱེ་གནས་སུ་འཇུག་ཚུལ་ལོ། །
Enumeration Block 4:
གཉིས་པ་སྒྲུབ་བྱེད་ལ་གཉིས། རིགས་པ་དང་། ལུང་གི་སྒྲུབ་བྱེད་དོ། །
Enumeration Block 5:
གཉིས་པ་བར་དུ་གནས་ཚུལ་ལ་གཉིས། གང་གནས་པ་སེམས་ཀྱི་རྟེན་འབྲེལ་དང་། གང་གིས་གནས་པ་ཟས་ཀྱི་རྟེན་འབྲེལ་ལོ། །དང་པོ་ལ་གསུམ། བསྟན། བཤད། བསྡུ་བའོ། །
Enumeration Block 6:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། གནས་སྐབས་པའི་རྟེན་འབྲེལ། སྐབས་སུ་བབ་པའི་ངོ་བོ། ཡན་ལག་གསུམ་དཔེ་དང་སྦྱར་བའོ། །དང་པོ་ལ་བཞི། རང་བཞིན། བསྡུ་བ་དཔྱད་པ། གྲངས་ངེས་པའི་རྒྱུ་མཚན། འབྱུང་བྱུང་གི་ཁྱད་པར་རོ། །དང་པོ་ལ་གསུམ། དབྱེ་བ། སོ་སོའི་མཚན་ཉིད། དེ་དག་གི་ངེས་པའོ། །
