Enumeration Block 1:
གསུམ་པ་ཚད་དེ་ཉིད་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གཉིས། རྩོམ་པའི་དང་པོ་མདོར་བསྟན། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་རྒྱས་བཤད་ལ། ཡུལ་གཟུགས་ཀྱི་ཚད་དང་། དུས་ཀྱི་ཚད་གཉིས།
Enumeration Block 3:
གཉིས་པ་རྒྱས་བཤད་ལ་བཞི། འཇིག ། འཆགས། གནས། བསྐལ་པ་ཆེན་པོའོ།
Enumeration Block 4:
གཉིས་པ་ཞར་ལས་བྱུང་བ་ལ་གཉིས། བསྐལ་ཆེན་གྱི་ཞར་བྱུང་། འཇིག་བསྐལ་གྱི་ཞར་བྱུང་ངོ་། །དང་པོ་ལ་གསུམ། སངས་རྒྱས། རང་རྒྱལ། འཁོར་ལོས་སྒྱུར་རྒྱལ་འབྱུང་ཚུལ་ལོ། །
Enumeration Block 5:
གཉིས་པ་འཇིག་བསྐལ་གྱི་ཞར་བྱུང་ལ་གསུམ། འཇིག་པའི་དབྱེ་བ། ལུས་པའི་རྩེ་མོ། འཇིག་པའོ་གོ་རིམ་མོ། །
Enumeration Block 6:
གསུམ་ཡོད་དེ། མེས༵་འཇིག་པ་དང༵་། ཆུས༵་འཇིག་པ་དང༵་། རླུང༵་གིས༵་འཇིག༵་པ༵་དག༵་ནི༵་ཡང༵་གསུ༵་ཡོད་པའི༵་ཕྱིར། །
Enumeration Block 7:
བཞི་པ་ལས་བསྟན་པའི་གནས་འཆད་པ་ལ་གཉིས། མཚམས་སྦྱར་བ། ལས་དངོས་བཤད་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལས་དངོས་བཤད་པ་ལ་གཉིས། ལས་ཀྱི་ངོ་བོ། །མདོ་ལས་བྱུང་བའི་མིང་གི་རྣམ་གྲངས་སོ། །དང་པོ་ལ་གཉིས། བསྟན། བཤད་དོ། །
Enumeration Block 9:
ལས་དེ༵་ནི༵་གཉིས་སུ་ཡོད་དེ། སེམས༵་པའི༵་ལས་དང༵་། སེམས་པ་དེས༵་བྱས༵་པ་སྟེ་ཀུན་ནས་སློང་བ་བསམ་པའི་ལས་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 10:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། ལས་ཀྱི་རང་བཞིན། ལས་གསུམ་སྤྱིའི་ཆོས་ཀྱི་ཁྱད་པར། རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་དབྱེ་བའོ། །དང་པོ་ལ་གཉིས། རྣམ་པར་རིག་བྱེད་དང་། རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའོ། །དང་པོ་ལ་གཉིས། ལུས་ཀྱི་རྣམ་པར་རིག་བྱེད་དང་། ངག་གི་རྣམ་པར་རིག་བྱེད་དོ། །
Enumeration Block 11:
གཉིས་པ་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་ལ་གསུམ། ལུང་གི་སྒྲུབ་བྱེད། རྒྱུ་འབྱུང་བའི་ཁྱད་པར། ཆོས་ཀྱི་ཁྱད་པར་རོ། །
