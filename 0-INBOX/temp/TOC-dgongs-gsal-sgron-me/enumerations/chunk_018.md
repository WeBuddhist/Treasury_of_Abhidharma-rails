Enumeration Block 1:
བཞི་པ་ལས་བསྟན་པའི་གནས་འཆད་པ་ལ་གཉིས། མཚམས་སྦྱར་བ། ལས་དངོས་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལས་དངོས་བཤད་པ་ལ་གཉིས། ལས་ཀྱི་ངོ་བོ། །མདོ་ལས་བྱུང་བའི་མིང་གི་རྣམ་གྲངས་སོ། །དང་པོ་ལ་གཉིས། བསྟན། བཤད་དོ། །
Enumeration Block 3:
ལས་དེ༵་ནི༵་གཉིས་སུ་ཡོད་དེ། སེམས༵་པའི༵་ལས་དང༵་། སེམས་པ་དེས༵་བྱས༵་པ་སྟེ་ཀུན་ནས་སློང་བ་བསམ་པའི་ལས་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
དེ༵་དག༵་ལ་དབྱེ་ན་རྣམ༵་པར་རིག༵་བྱེད་དང་རྣམ༵་པར་རིག༵་བྱེད་མིན༵་པ་གཉིས་གཉིས་ཡོད་དོ། །
Enumeration Block 5:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། ལས་ཀྱི་རང་བཞིན། ལས་གསུམ་སྤྱིའི་ཆོས་ཀྱི་ཁྱད་པར། རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་དབྱེ་བའོ། །དང་པོ་ལ་གཉིས། རྣམ་པར་རིག་བྱེད་དང་། རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའོ། །དང་པོ་ལ་གཉིས། ལུས་ཀྱི་རྣམ་པར་རིག་བྱེད་དང་། ངག་གི་རྣམ་པར་རིག་བྱེད་དོ། །
Enumeration Block 6:
གཉིས་པ་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་ལ་གསུམ། ལུང་གི་སྒྲུབ་བྱེད། རྒྱུ་འབྱུང་བའི་ཁྱད་པར། ཆོས་ཀྱི་ཁྱད་པར་རོ། །
Enumeration Block 7:
གཉིས་པ་ལས་གསུམ་སྤྱིའི་ཆོས་ཀྱི་ཁྱད་པར་ལ། དངོས་དང་། ཞར་བྱུང་གཉིས།
Enumeration Block 8:
གཉིས་པ་ཞར་བྱུང་ལ་གསུམ། དགེ་བ་ལ་སོགས་པའི་དབྱེ་བ། ཀུན་སློང་བཤད་པ། ཆོས་ཀྱི་ཁྱད་པར་རོ། །
Enumeration Block 9:
ཀུན༵་སློང༵་ནི་རྣམ༵་པ་གཉིས༵་ཏེ། རྒྱུའི༵་ཀུན་སློང་དང༵་ནི༵་བྱ་བ་དེ༵འི༵་དུས༵་ཀྱི༵་ཀུན་སློང༵་ཞེས༵་བྱའོ༵། །
Enumeration Block 10:
གསུམ་པ་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་དབྱེ་བ་ལ་གཉིས། བསྟན། བཤད་དོ། །
Enumeration Block 11:
རྣམ༵་པར་རིག༵་བྱེད་མིན༵་པ་ནི་རྣམ༵་པ་གསུ༵་དུ་ཤེས༵་པར་བྱ༵་སྟེ།
Enumeration Block 12:
གཉིས་པ་རྒྱས་བཤད་ལ་བཞི། སྡོམ་པ། ལྡན་ཚུལ། འཐོབ་གཏོང་། ལྡན་པའི་གང་ཟག་བཤད་པའོ། །དང་པོ་ལ་གཉིས། བསྟན། བཤད་དོ། །
Enumeration Block 13:
སྡོམ༵་པ༵་གསུམ་དུ་ཤེས་པར་བྱ་སྟེ། སོ༵་སོར༵་ཐར༵་པ་ཞེས༵་བྱ༵་བའི་སྡོམ་པ་དང་། དེ༵་བཞིན༵་དུ་ཟག༵་མེད༵་དང་བསམ༵་གཏན༵་ལས་སྐྱེས༵་པའི་སྡོམ་པ་གསུམ་དུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 14:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། སོ་ཐར་གྱི་སྡོམ་པ། བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པ། ཞར་བྱུང་ངོ། །དང་པོ་ལ་བཞི། དབྱེ་བ། ངོ་བོ། སྒྲ་དོན། ལྡན་པའི་གང་ཟག་གོ །
Enumeration Block 15:
སོ༵་སོར༵་ཐར༵་པ་ཞེས༵་བྱ༵་བའི་སྡོམ་པ་ལ་རྣམ༵་པ་བརྒྱད༵་ཡོད་དེ། དགེ་སློང་ཕ་མ་གཉིས། དགེ་སློབ་མ། དགེ་ཚུལ་ཕ་མ་གཉིས། དགེ་བསྙེན་ཕ་མ་གཉིས། བསྙེན་གནས་པའི་སྡོམ་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 16:
རྫས༵་སུ༵་བསྡུ་ན་རྣམ༵་པ༵་བཞི༵་ཡིན༵་ཏེ༵། དགེ་སློང་ཕ་མའི་སྡོམ་པ་རྫས་གཅིག ། དགེ་སློབ་མ་དང་དགེ་ཚུལ་ཕ་མའི་སྡོམ་པ་རྫས་གཅིག དགེ་བསྙེན་ཕ་མའི་སྡོམ་པ་རྫས་གཅིག ། བསྙེན་གནས་ཀྱི་སྡོམ་པ་རྫས་གཅིག་ཡིན་པའི་ཕྱིར་ཏེ།
Enumeration Block 17:
སོ༵་སོར༵་ཐར༵་པའི་སྡོམ་པ་དང༵་ལྡན༵་པའི༵་གང་ཟག་དེ་ལ་བརྒྱད༵་དུ་ཡོད་དེ། དགེ་སློང་ཕ་མ་གཉིས། དགེ་སློབ་མ། དགེ་ཚུལ་ཕ་མ་གཉིས། དགེ་བསྙེན་ཕ་མ་གཉིས། བསྙེན་གནས་པའི་གང་ཟག་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 18:
གཉིས་པ་ལྡན་ཚུལ་ལ་གསུམ། རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་ལྡན་ཚུལ་དང་། རྣམ་པར་རིག་བྱེད་ཀྱི་ལྡན་ཚུལ་དང་། ལྡན་པའི་མུ་བཞི་བཤད་པའོ། །
Enumeration Block 19:
གཉིས་པ་རྣམ་པར་རིག་བྱེད་ཀྱི་ལྡན་ཚུལ་ལ་གཉིས། དངོས་དང་། ཞར་བྱུང་ངོ་། །
Enumeration Block 20:
གསུམ་པ་འཐོབ་གཏོང་ལ་གཉིས། འཐོབ་ཚུལ་དང་། གཏོང་ཚུལ་ལོ། །དང་པོ་ལ་གསུམ། སྡོམ་པའི་འཐོབ་ཚུལ། སྡོམ་མིན་གྱི་འཐོབ་ཚུལ། བར་མའི་འཐོབ་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། ཇི་ལྟར་འཐོབ་པ་དང་། གང་ལས་འཐོབ་པའོ། །དང་པོ་ལ་གཉིས། བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པ་འཐོབ་ཚུལ། སོ་ཐར་གྱི་སྡོམ་པ་འཐོབ་ཚུལ་ལོ། །
Enumeration Block 21:
གཉིས་པ་སོ་ཐར་གྱི་སྡོམ་པ་འཐོབ་ཚུལ་ལ། དངོས་དང ་། ཞར་བྱུང་གཉིས།
Enumeration Block 22:
གཉིས་པ་ཞར་བྱུང་ལ་གསུམ། སྡོམ་པ་སྡོམ་མིན་གྱི་དུས་ཀྱི་ངེས་པ། བསྙེན་གནས་ཀྱི་སྡོམ་པའི་ཁྱད་པར། དགེ་བསྙེན་གྱི་སྡོམ་པའི་ཁྱད་པར་རོ། །
Enumeration Block 23:
གཉིས་པ་བསྙེན་གནས་ཀྱི་སྡོམ་པའི་ཁྱད་པར་ལ་གསུམ། ལེན་ཐབས། ཡན་ལག་གི་ངེས་པ། རྟེན་གྱི་ངེས་པའོ། །
