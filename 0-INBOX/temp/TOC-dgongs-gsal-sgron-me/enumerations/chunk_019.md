Enumeration Block 1:
གཉིས་པ་རྣམ་པར་རིག་བྱེད་ཀྱི་ལྡན་ཚུལ་ལ་གཉིས། དངོས་དང་། ཞར་བྱུང་ངོ་། །
Enumeration Block 2:
གསུམ་པ་འཐོབ་གཏོང་ལ་གཉིས། འཐོབ་ཚུལ་དང་། གཏོང་ཚུལ་ལོ། །དང་པོ་ལ་གསུམ། སྡོམ་པའི་འཐོབ་ཚུལ། སྡོམ་མིན་གྱི་འཐོབ་ཚུལ། བར་མའི་འཐོབ་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། ཇི་ལྟར་འཐོབ་པ་དང་། གང་ལས་འཐོབ་པའོ། །དང་པོ་ལ་གཉིས། བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པ་འཐོབ་ཚུལ། སོ་ཐར་གྱི་སྡོམ་པ་འཐོབ་ཚུལ་ལོ། །
Enumeration Block 3:
གཉིས་པ་སོ་ཐར་གྱི་སྡོམ་པ་འཐོབ་ཚུལ་ལ། དངོས་དང ་། ཞར་བྱུང་གཉིས།
Enumeration Block 4:
གཉིས་པ་ཞར་བྱུང་ལ་གསུམ། སྡོམ་པ་སྡོམ་མིན་གྱི་དུས་ཀྱི་ངེས་པ། བསྙེན་གནས་ཀྱི་སྡོམ་པའི་ཁྱད་པར། དགེ་བསྙེན་གྱི་སྡོམ་པའི་ཁྱད་པར་རོ། །
Enumeration Block 5:
གཉིས་པ་བསྙེན་གནས་ཀྱི་སྡོམ་པའི་ཁྱད་པར་ལ་གསུམ། ལེན་ཐབས། ཡན་ལག་གི་ངེས་པ། རྟེན་གྱི་ངེས་པའོ། །
Enumeration Block 6:
གསུམ་པ་དགེ་བསྙེན་གྱི་སྡོམ་པའི་ཁྱད་པར་ལ་གསུམ། དངོས་དང་། སྐྱབས་འགྲོའི་ཡུལ་བྱེ་བྲག་ཏུ་བཤད་པ། ཡན་ལག་གི་ངེས་པའོ། །
Enumeration Block 7:
གཉིས་པ་གཏོང་ཚུལ་ལ་གསུམ། སྡོམ་པའི། སྡོམ་མིན་གྱི། བར་མའི་གཏོང་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། སོ་ཐར་གྱི་སྡོམ་པའི། བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པའི་གཏོང་ཚུལ་ལོ། །
Enumeration Block 8:
གཉིས་པ་མདོ་ལས་འབྱུང་བའི་མིང་གི་རྣམ་གྲངས་ལ་བཅོ་ལྔ་ཡོད་པ་ལས།
Enumeration Block 9:
གཉིས་པ་འབྲས་བུའི་སྒོ་ནས་དབྱེ་བ་ལ་གཉིས། བསྟན། བཤད་དོ། །
Enumeration Block 10:
ལས་དེ་ལ་གསུམ་ཡོད་དེ། བསོད༵་ནམ༵ས་ཀྱི་ལས་དང་། བསོད༵་ནམ༵ས་མིན༵་པའི་ལས་དང་། མི༵་གཡོ༵་བའི་ལས་རྣམས་སུ་ཡོད་པའི་ཕྱིར། ཡང་ལས་དེ་ལ་གསུམ་ཡོད་དེ། བདེ༵་བ༵་མྱོང༵་བར༵་འགྱུར༵་བའི་ལས་ལ༵་སོགས༵་པ་གསུ༵་ཡོད་པའི་ཕྱིར། །
Enumeration Block 11:
གཉིས་པ་རྒྱས་པ་བཤད་ལ་གཉིས། བསོད་ནམས་སོགས་བཤད་པ་དང་། བདེ་སོགས་བཤད་པའོ། །
Enumeration Block 12:
གཉིས་པ་བདེ་སོགས་བཤད་པ་ལ་གསུམ། མྱོང་འགྱུར་གསུམ་པོ་སོ་སོའི་མཚན་གཞི། མྱོང་འགྱུར་གྱི་དབྱེ་བ། ལས་གང་གི་འབྲས་བུ་ཚོར་བ་གང་ཡིན་པའོ། །དང་པོ་ལ་གཉིས། རང་ལུགས་དང་། གཞན་ལུགས་སོ། །
Enumeration Block 13:
གཉིས་པ་མྱོང་འགྱུར་གྱི་དབྱེ་བ་ལ་གཉིས། ལྔར་དབྱེ་བ། རྣམ་སྨིན་མྱོང་འགྱུར་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 14:
མྱོང་བར་འགྱུར་བའི་ལས་རྣམ་པ་ལྔ་ཡོད་པ་ཡིན་ཏེ།
Enumeration Block 15:
གཉིས་པ་རྣམ་སྨིན་མྱོང་འགྱུར་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གཉིས། སྤྱིར་བསྟན། མྱོང་ངེས་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ལས་ཀྱི་དབྱེ་བ། ཁམས་དང་འགྲོ་བ་གང་ན་ལས་འཕན་པ་དུ་ཡོད་གཉིས། དང་པོ་ནི། རྣམ་སྨིན་མྱོང་འགྱུར་གྱི་ལས་དེ་ལ་བཞི་སྟེ། དེ༵་ལ་ཡང༵་ངེས༵་པ་དང༵་། མ༵་ངེས༵་པའི་ལས་གཉིས་ལས།
Enumeration Block 16:
མྱོང༵་བར་ངེས༵་པ་རྣམ༵་པ་གསུ༵་དང་། མ་ངེས་པ་སྟེ་བཞི་ཡིན་ནོ། །
