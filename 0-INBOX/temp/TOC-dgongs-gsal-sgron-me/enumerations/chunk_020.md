Enumeration Block 1:
གཉིས་པ་མྱོང་འགྱུར་གྱི་དབྱེ་བ་ལ་གཉིས། ལྔར་དབྱེ་བ། རྣམ་སྨིན་མྱོང་འགྱུར་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་རྣམ་སྨིན་མྱོང་འགྱུར་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གཉིས། སྤྱིར་བསྟན། མྱོང་ངེས་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ལས་ཀྱི་དབྱེ་བ། ཁམས་དང་འགྲོ་བ་གང་ན་ལས་འཕན་པ་དུ་ཡོད་གཉིས། དང་པོ་ནི། རྣམ་སྨིན་མྱོང་འགྱུར་གྱི་ལས་དེ་ལ་བཞི་སྟེ། དེ༵་ལ་ཡང༵་ངེས༵་པ་དང༵་། མ༵་ངེས༵་པའི་ལས་གཉིས་ལས། དང་པོ་ལ། མཐོང༵་བའི༵་ཆོས༵་སྐྱེ་བ་འདི་ཉིད་ལ༵་མྱོང་བ་དང་། སོག༵ས་པ༵་སྐྱེ་བ་ཕྱི་མར་མྱོང་བ་སྐྱེ་ནས་མྱོང་འགྱུར་དང་། དེ་ཕན་ཆད་ལ༵་མྱོང་བ་ལན་གྲངས་གཞན་མྱོང༵་འགྱུར༵་གསུམ་ཡོད་པའི་ཕྱིར༵་ན༵་མྱོང་བར་ངེས༵་པ་རྣམ༵་པ་གསུ༵་དང་། མ་ངེས་པ་སྟེ་བཞི་ཡིན་ནོ། །
Enumeration Block 3:
གསུམ་པ་ལས་གང་གི་འབྲས་བུ་ཚོར་བ་གང་ཡིན་པ་ལ་གཉིས། དངོས་དང་། གཡེང་བའིི་སེམས་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 4:
བཞི་པ་རྒྱུ་འབྲས་གཉིས་ཀའི་སྒོ་ནས་དབྱེ་བ་ལ། བསྟན། བཤད་གཉིས། 
Enumeration Block 5:
བདུན་པ་ལེགས་སྤྱད་དང་ཉེས་སྤྱད་བཤད་པ་ལ་གསུམ། ལས་ལམ་གྱི་རྣམ་གཞག ། ལོག་འཚོ་ལོགས་སུ་སྟོན་པའི་རྒྱུ་མཚན། ལས་གང་འབྲས་བུ་དུ་དང་བཅས་པའོ། །དང་པོ་ལ། བསྟན། བཤད་དོ། །
Enumeration Block 6:
གཉིས་པ་རྒྱས་བཤད་ལ་བདུན། རིག་བྱེད་དང་རིག་བྱེད་མ་ཡིན་པའི་ངེས་པ། ལས་ལམ་གསུམ་གསུམ་དུ་དབྱེ་བ། མི་དགེ་བའི་ལས་ལམ་བྱེ་བྲག་ཏུ་བཤད་པ། དགེ་རྩ་གཅོད་པ་དང་མཚམས་སྦྱོར་ཚུལ། སེམས་པ་ལས་ལམ་དུ་དང་ལྷན་ཅིག་འབྱུང་བ། ཁམས་དང་འགྲོ་བ་གང་ན་ལས་ལམ་དུ་ཡོད་པ། ལས་ལམ་གྱི་འབྲས་བུའོ། །
Enumeration Block 7:
གསུམ་པ་མི་དགེ་བའི་ལས་ལམ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གསུམ། མི་དགེ་བའི་ལས་ལམ་གྱི་བྱེད་པ། སོ་སོའི་མཚན་ཉིད། ལས་ལམ་གྱི་སྒྲ་དོན་ནོ། །
Enumeration Block 8:
གཉིས་པ་སོ་སོའི་མཚན་ཉིད་ལ་གསུམ། རྩ་བ་བཞི། ཐ་སྙད་བཞི། ཡན་ལག་དྲུག་བཤད་པའོ། །
