Enumeration Block 1:
རིག་བྱེད་དང་རིག་བྱེད་མིན་པ་རྣམ༵་པ་གཉིས༵་སོ༵། །
Enumeration Block 2:
ཚུལ་ཁྲིམས་དེའང་རྣམ༵་པར་དག༵་པའི་ཡོན༵་ཏན༵་བཞི༵་དང་ལྡན༵་པ་ཡིན་ནོ༵། །བཞི་གང་ཞེ་ན། འཆལ༵་བའི་ཚུལ་ཁྲིམ༵ས་ཀྱིས་འཕན་ཏེ་སྐྱོན་མ་བྱུང་བ་དང་། དེའི༵་རྒྱུ༵་རྩ་བ་དང་ཉེ་བའི་ཉོན་མོངས་པས་འཕན༵་མ༵་བྱུང༵་བ་དང་། འཆལ་བའི་ཚུལ་ཁྲིམས་དེའི༵་གཉེན༵་པོ་བྱེད་པའི་དྲན་པ་ཉེར་བཞག་ལ་བརྟེན་པ་དང༵་། ཐར་པར་བསྔོས་པ་ཡིན་པས་ཞི༵་བ་ལ༵་བརྟེན༵་པའོ། །
Enumeration Block 3:
བཅུ་བཞི་པ་ཆ་མཐུན་གསུམ་བཤད་པ་ནི། མདོ་ལས། བསོད་ནམས་དང་། ཐར་པ་དང་། ངེས་པར་འབྱེད་པའི་ཆ་དང་མཐུན་པའི་དགེ་བ་གསུམ་གསུངས་པ་ལས།
Enumeration Block 4:
ལྔ་པ་ཕྲ་རྒྱས་བསྟན་པའི་གནས་འཆད་པ་ལ་བཞི། མཚམས་སྦྱར་བ། ཕྲ་རྒྱས་དངོས། དེ་སྤོང་བའི་ཚུལ། སྤངས་པའི་འབྲས་བུ་ཡོངས་ཤེས་བསྟན་པའོ། །
Enumeration Block 5:
གཉིས་པ་ཕྲ་རྒྱས་དངོས་ལ་བདུན། ཕྲ་རྒྱས་ཀྱི་དབྱེ་བ། རྣམ་པའི་བྱེ་བྲག ། སེམས་ཕྲ་རྒྱས་དང་བཅས་པའི་ཚུལ། ཉོན་མོངས་སྐྱེ་ཚུལ། རྣམ་གྲངས། གང་དང་མཚུངས་ལྡན། སྒྲིབ་པ་ལྔ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དངོས་དང་། ཞར་བྱུང་ངོ་། །དང་པོ་ལ་གཉིས། རྩ་བའི་དབྱེ་བ་དང་། ཁྱད་པར་གྱི་དབྱེ་བའོ། །
Enumeration Block 6:
ཕྲ྄༷་རྒྱས༵་དྲུག༵་ཡོད་དེ། འདོད༵་ཆག༵ས་ཀྱི་ཕྲ་རྒྱས། དེ༵་བཞིན༵་དུ་ཁོང༵་ཁྲོ༵འི་ཕྲ་རྒྱས་དང༵་། ང༵་རྒྱལ༵་གྱི། མ༵་རིག༵་པའི། ལྟ྄༷་བའི༵་དང༵་། ཐེ༷་ཚོམ༵་གྱི་ཕྲ་རྒྱས་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
ཕྲ་རྒྱས་དེ༵་དྲུག༵་ཀྱང༵་འདོད༵་ཆག༵ས་ལ་འདོད་པའི་འདོད་ཆགས་དང་སྲིད་པའི་འདོད་ཆགས་གཉིས་སུ་དབྱེ༵་བ༵ས་བདུན༵་དུའང༵་བཤད༵་དོ། །
Enumeration Block 8:
ཡང་དེ་དག་བཅུར་ཡང་བཤད་དེ། ཇི་ལྟར་ཞེ་ན། ལྟ྄༷་བ༵་ལ༵་ལྔ༵་སྟེ༵། འཇིག༵་ཚོག༵ས་ལ་ལྟ་བ་དང༵་། སྐུར་འདེབས་ལོག༵་ལྟ་དང༵་། སྒྲོ་འདོགས་མཐར༵་འཛིན༵་པར་ལྟ྄༷་བ༵་དང༵་། ལྟ྄༷་བ༵་མཆོག་འཛིན་དང༵་ནི༵། ཚུལ༵་ཁྲིམ༵ས་དང༵་། བརྟུལ༵་ཞུག༵ས་མཆོག༵་ཏུ༵་འཛིན༵་པ་ལ་སྔར་གྱི་བསྣན་པ་དང༵་བཅུ༵་ཡིན་ནོ། །གཉིས་པ་ཁྱད་པར་གྱི་དབྱེ་བ་ནི། ཡང་ཕྲ་རྒྱས་དེ་ལ་རྣམ་པ་དང་། བྱེ་བྲག་དང་། ཁམས་ཀྱི་སྒོ་ནས་དབྱེ་ན་དགུ་བཅུ་རྩ་བརྒྱད་དུ་འདོད་དེ།
Enumeration Block 9:
གཉིས་པ་ཞར་བྱུང་ལ་ལྔ། སྤང་བྱ་ངེས་པ། ལྟ་བ་སོ་སོའི་མཚན་ཉིད། ལྟ་བ་ཐ་མ་དང་འབྲེལ་བའི་རྩོད་སྤང་། ཕྱིན་ཅི་ལོག་གི་རབ་དབྱེ། ང་རྒྱལ་གྱི་དབྱེ་བ་སྤྲོས་པ་དང་བཅས་པའོ། །
Enumeration Block 10:
ཕྱིན་ཅི་ལོག་བཞི་ཡོད་པའི་ཕྱིར་ཏེ། མི་རྟག་པ་ལ་རྟག་པར་ཕྱིན་ཅི་ལོག ། མི་གཙང་བ་ལ་གཙང་བར། སྡུག་བསྔལ་བ་ལ་བདེ་བར། བདག་མེད་པ་ལ་བདག་ཏུ་ཕྱིན་ཅི་ལོག་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 11:
ང་རྒྱལ་ལའང་བདུན་ཡོད་དེ། ང་རྒྱལ་དང་། ལྷག་པའི་ང་རྒྱལ་དང་། ང་རྒྱལ་ལས་ཀྱང་ང་རྒྱལ་དང་། ངའོ་སྙམ་པའི་ང་རྒྱལ་དང་། མངོན་པའི་ང་རྒྱལ་དང་། ཅུང་ཟད་སྙམ་པའི་ང་རྒྱལ་དང་། ལོག་པའི་ང༵་རྒྱལ༵་ཏེ་རྣམ་པ་བདུན༵་ཡོད་པའི་ཕྱིར།
Enumeration Block 12:
བསྟན་བཅོས་ཡེ་ཤེས་ལ་འཇུག་པ་ལས་དགུ་གསུངས་ཏེ། གཞན་ལ་ལྟོས་ཏེ་བདག་སྒྲུབ་པ་གསུམ། བདག་ལ་ལྟོས་ཏེ་གཞན་སྒྲུབ་པ་གསུམ། བདག་ལ་ལྟོས་ཏེ་གཞན་འགོག་པ་གསུམ་མོ། །དང་པོ་གསུམ་ཡོད་དེ། བདག་གཞན་ལས་ཁྱད་པར་དུ་འཕགས་སོ། །གཞན་དང་མཉམ་མོ། །གཞན་ལས་དམན་ནོ་ཞེས་པ་གསུམ་མོ། །གཉིས་པ་གསུམ་ཡོད་དེ། གཞན་བདག་ལས་ཁྱད་པར་དུ་འཕགས་སོ། །བདག་དང་མཉམ་མོ། །བདག་ལས་དམན་ནོ་ཞེས་པ་གསུམ་མོ། །གསུམ་པ་གསུམ་ཡོད་དེ། བདག་ལས་ཁྱད་པར་དུ་འཕགས་པ་མེད་དོ། །བདག་དང་མཉམ་པ་མེད་དོ། །བདག་ལས་དམན་པ་མེད་དོ་ཞེས་པ་གསུམ་མོ། །
Enumeration Block 13:
གཉིས་པ་རྣམ་པའི་བྱེ་བྲག་ལ་ལྔ། རྒྱུ་ལ་ལྟོས་པའི་རབ་དབྱེ། དམིགས་ཡུལ་ལ་ལྟོས་པའི་རབ་དབྱེ། ངོ་བོ་ལ་ལྟོས་པའི་རབ་དབྱེ། དུས་ལ་ལྟོས་པའི་ལྡན་ཚུལ། ཡུལ་ཡུལ་ཅན་གྱི་བྱེ་བྲག་གོ །
Enumeration Block 14:
གསུམ་པ་ངོ་བོ་ལ་ལྟོས་པའི་རབ་དབྱེ་ལ་གསུམ། དངོས་དང་། རྩ་བའི་བྱེ་བྲག ། དྲི་བ་ལུང་མ་བསྟན་གྱི་ཞར་བྱུང་ངོ་། །
Enumeration Block 15:
བཞི་ཡོད་དེ། མགོ༵་གཅིག༵་པ་དང༵་། རྣམ༵་པར་ཕྱེ༷་བ་དང༵་། དྲི༵་བ་དང༵་། གཞག༵་པར༵་ལུང༵་བསྟན༵་པ༵་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 16:
བཞི་པ་དུས་ལ་ལྟོས་པའི་ལྡན་ཚུལ་ལ་གསུམ། དངོས་དང་། ཞར་ལ་དུས་གསུམ་གྱི་རྣམ་གཞག་དཔྱད་པ། སྤངས་པ་དང་བྲལ་བའི་ཁྱད་པར་རོ། །
Enumeration Block 17:
སྤྱིར་ཉོན་མོངས་པ་ལ་ཉོན་མོངས་རང་གི་མཚན་ཉིད་པ་དང་། ཉོན་མོངས་སྤྱི་པ་གཉིས་ཡོད་ལ།
