Enumeration Block 1:
གཉིས་པ་རྒྱས་བཤད་ལ་བཞི། ཀུན་སྦྱོར། འཆིང་བ། ཉེ་ཉོན། ཀུན་དཀྲིས་སོ། །དང་པོ་ལ་གསུམ། ཀུན་སྦྱོར་དགུ། འོག་མའི་ཆ་མཐུན་ལྔ། གོང་མའི་ཆ་མཐུན་ལྔའོ། །
Enumeration Block 2:
ཀུན་སྦྱོར་དགུ་ཡོད་དེ། རྩ་ཉོན་འདོད་ཆགས། ཁོང་ཁྲོ། ང་རྒྱལ། མ་རིག ། ལྟ་བ། ཐེ་ཚོམ་དྲུག་དང་། མཆོག་ཏུ་འཛིན་པའི་ཀུན་སྦྱོར། ཕྲག་དོག་དང་སེར་སྣའི་ཀུན་སྦྱོར་རྣམས་སུ་ཡོད་པའི་ཕྱིར། །
Enumeration Block 3:
ཀུན་སྦྱོར་ཐ༵་མའི༵་ཆ྄༷་མཐུན༵་རྣམ༵་པ་ལྔ༵་ཡོད་དེ། འཇིག་ཚོགས་ལ་ལྟ་བ་དང་། ཚུལ་ཁྲིམས་དང་། བརྟུལ་ཞུགས་མཆོག་འཛིན་དང་། འདོད་པ་ལ་འདུན་པ་དང་། ཐེ་ཚོམ་དང་། གནོད་སེམས་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
བཞི་པ་ཀུན་དཀྲིས་ལ། དངོས་དང་། ཞར་བྱུང་གཉིས་ལས།
Enumeration Block 5:
གཉིས་པ་ཞར་བྱུང་ལ་གཉིས། དྲི་མ་དྲུག ། ཆོས་ཀྱི་ཁྱད་པར་རོ། །
Enumeration Block 6:
དྲི༵་མ༵འམ་ཉེ་ཉོན་ནི་དྲུག༵་ཡོད་དེ། སྒྱ྄ུ༷་དང༵་། གཡོ༵་དང༵་། རྒྱག༵ས་པ༵་དང༵་། དེ༵་བཞིན༵་དུ་འཚིག༵་པ་དང༵་། ཁོན༵་དུ་འཛིན༵་པ་དང༵་། རྣམ༵་འཚེ༵་རྣམས་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
དྲུག་པ་གང་དང་མཚུངས་པར་ལྡན་པ་ལ་གཉིས། རྣམ་ཤེས་གང་དང་མཚུངས་པར་ལྡན། ཚོར་བ་གང་དང་མཚུངས་པར་ལྡན་པའོ། །
Enumeration Block 8:
གསུམ་པ་དེ་སྤང་བའི་ཚུལ་ལ་གཉིས་ལས།
Enumeration Block 9:
དེ་ལ་གསུམ་སྟེ། དམིག༵ས་པ༵་ཡོང༵ས་སུ༵་ཤེས༵་པས་སྤོང་བ༵་དང༵་། དེ༵་ལ༵་དམིག༵ས་པ༵་ཡང༵་དག༵་པར༵་ཟད༵་པས་སྤོང་བ་དང༵་། དམིག༵ས་པ༵་སྤང༵ས་པས༵་སྤོང་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 10:
གཉེན༵་པོ༵་ནི་རྣམ༵་པ་བཞི༵་སྟེ།
Enumeration Block 11:
བཞི་པ་སྤངས་པའི་འབྲས་བུ་ཡོངས་ཤེས་བསྟན་པ་ལ་ལྔ། དབྱེ་བ། ལམ་གང་གི་འབྲས་བུ་གང་ཡིན་པ། གྲངས་ངེས། གང་ཟག་གང་ལ་ལྡན། འཐོབ་གཏོང་བཤད་པའོ། །
Enumeration Block 12:
འབྲས་བུ་ཡོང༵ས་སུ༵་ཤེས༵་པ་དགུ༵་ཡོད་དེ།
