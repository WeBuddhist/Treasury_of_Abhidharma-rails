Enumeration Block 1:
གཉིས་པ་ལྷག་མཐོང་བསྒོམ་པ་ལ་གསུམ། ཚོགས་ལམ། སྦྱོར་ལམ། བདེན་པ་མངོན་པར་རྟོགས་པའི་ལམ་མོ། །
Enumeration Block 2:
དེ་ལའང་སྤྱིར་རང་བཞིན་དང་། འབྲེལ་བ་དང་། དམིགས་པ་དྲན་པ་ཉེར་བཞག་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་སྦྱོར་ལམ་ལ་གསུམ། སྦྱོར་ལམ་གྱི་རང་བཞིན། ཆོས་ཀྱི་ཁྱད་པར། དོགས་གཅོད་གཞན་བསྟན་པའོ། །
Enumeration Block 4:
དེ་དག་བསྡུ་ན་རྣམ༵་པ་གསུ༵་སྟེ༵། མཐོང༵་བ་མངོན་རྟོགས། དམིག༵ས་པ་མངོན་རྟོགས། བྱ༵་བ༵་མངོན་རྟོགས་ཞེས༵་བྱ༵་བ་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གསུམ་པ་བདེན་པ་མངོན་རྟོགས་ལ་གནས་པའི་གང་ཟག་ལ་གཉིས། དབྱེ་བ་བསྡུས་ཏེ་བསྟན། མཇུག་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། ཆགས་བྲལ་སྔོན་སོང་། མཐར་གྱིས་པའོ། །དང་པོ་ལ། ཞུགས་གནས་གཉིས།
Enumeration Block 6:
གཉིས་པ་མཐར་གྱི ས་པ་ལ་གཉིས། རྒྱུ་མཚན་དང་། རྒྱུ་མཚན་ཅན་གྱི་གང་ཟག་གོ །
Enumeration Block 7:
གཉིས་པ་རྒྱུ་མཚན་ཅན་གྱི་གང་ཟག་ལ་བཞི། རྒྱུན་ཞུགས། ཕྱིར་འོང་། ཕྱིར་མི་འོང་། དགྲ་བཅོམ་མོ། །
Enumeration Block 8:
གཉིས་པ་ཕྱིར་འོང་ལ། ཞུགས་གནས་གཉིས།
Enumeration Block 9:
གསུམ་པ་ཕྱིར་མི་འོང་ལ། ཞུགས་གནས་གཉིས།
Enumeration Block 10:
གཉིས་པ་གནས་པ་ལ་གཉིས། སྤྱིར་བསྟན། བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 11:
གཉིས་པ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གསུམ། དབྱེ་བ། སྤེལ་མ་སྒོམ་པ། ལུས་མངོན་བྱེད་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དངོས་དང་། དོན་གྱི་ཁྱད་པར་རོ། །དང་པོ་ནི། ཕྱིར་མི་འོང་ལ་གཟུགས་སུ་ཉེར་འགྲོ་དང་། གཟུགས་མེད་ཉེར་འགྲོ་གཉིས་ལས།
Enumeration Block 12:
ཕྱིར་མི་འོང་གཟུགས་སུ་ཉེར་འགྲོ་དེ༵་ནི༵་ལྔ་ཡོད་དེ།
Enumeration Block 13:
བཤད་མ་ཐག་པའི་གོང་དུ་འཕོ་བ་དེ༵་ནི༵་ལྷག་མཐོང་ལ་དགའ་བ་དང་། ཞི་གནས་ལ་དགའ་བའི་རིགས་གཉིས་ལས།
Enumeration Block 14:
དེ༵་ལའང་འཕར༵་བ་དང་། ཕྱེད༵་དུ་འཕར༵་བ་དང་། གནས་ཐམ༵ས་ཅད༵་དུ་འཆི༵་འཕོ༵་བ་གསུམ་ཡོད་དེ།
Enumeration Block 15:
དེ་ལ་བར་སྲིད་མེད་པས་སྐྱེས་འདའ་བ་ནས་གོང་འཕོའི་བར་རྣམ༵་པ་བཞི༵་ཡིན་ནོ། །
Enumeration Block 16:
གཉིས་པ་དོན་གྱི་ཁྱད་པར་ནི། བར་དོར་འདའ་བ་དང་། སྐྱེས་འདའ་བ་དང་། གོང་འཕོ་སྟེ་གསུ༵་པོ་རེ་རེ་ལ༵་ཡང༵་རྣམ༵་པ་གསུ༵་གསུམ་དུ་ཕྱེ༷་ནས༵་གཟུག༵ས་སུ༵་ཉེར༵་འགྲོ༵འི་ཕྱིར་མི་འོང་དགུར༵་ཡང་བཤད༵དོ༵། །འབྱེད་ཚུལ་ནི་དང་པོ་ལ་ལྕགས་ཀྱི་ཚྭ་ཚྭའི་དཔེས་མྱུར་བ་དང་། མྱུར་བ་མ་ཡིན་པ་དང་། ཆེས་རིང་མོ་ནས་འདའ་བ་གསུམ་དང་། གཉིས་པ་ལ་སྐྱེས་མ་ཐག་པ་དང་། འདུ་བྱེད་དང་བཅས་པ་དང་། བྱེད་མིན་དུ་འདའ་བའོ། །གསུམ་པ་ལ་འཕར་བ། ཕྱེད་འཕར་བ། གནས་ཐམས་ཅད་དུ་འགྲོ་བའོ། །
