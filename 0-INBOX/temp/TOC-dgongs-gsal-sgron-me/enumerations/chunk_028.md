Enumeration Block 1:
གཉིས་པ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གསུམ། དབྱེ་བ། སྤེལ་མ་སྒོམ་པ། ལུས་མངོན་བྱེད་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དངོས་དང་། དོན་གྱི་ཁྱད་པར་རོ། །དང་པོ་ནི། ཕྱིར་མི་འོང་ལ་གཟུགས་སུ་ཉེར་འགྲོ་དང་། གཟུགས་མེད་ཉེར་འགྲོ་གཉིས་ལས། 
Enumeration Block 2:
ཕྱིར་མི་འོང་གཟུགས་སུ་ཉེར་འགྲོ་དེ༵་ནི༵་ལྔ་ཡོད་དེ།
Enumeration Block 3:
བཤད་མ་ཐག་པའི་གོང་དུ་འཕོ་བ་དེ༵་ནི༵་ལྷག་མཐོང་ལ་དགའ་བ་དང་། ཞི་གནས་ལ་དགའ་བའི་རིགས་གཉིས་ལས། 
Enumeration Block 4:
དེ༵་ལའང་འཕར༵་བ་དང་། ཕྱེད༵་དུ་འཕར༵་བ་དང་། གནས་ཐམ༵ས་ཅད༵་དུ་འཆི༵་འཕོ༵་བ་གསུམ་ཡོད་དེ།
Enumeration Block 5:
སྐྱེས་འདའ་བ་ནས་གོང་འཕོའི་བར་རྣམ༵་པ་བཞི༵་ཡིན་ནོ། །
Enumeration Block 6:
གཉིས་པ་དོན་གྱི་ཁྱད་པར་ནི། བར་དོར་འདའ་བ་དང་། སྐྱེས་འདའ་བ་དང་། གོང་འཕོ་སྟེ་གསུ༵་པོ་རེ་རེ་ལ༵་ཡང༵་རྣམ༵་པ་གསུ༵་གསུམ་དུ་ཕྱེ༷་ནས༵་གཟུག༵ས་སུ༵་ཉེར༵་འགྲོ༵འི་ཕྱིར་མི་འོང་དགུར༵་ཡང་བཤད༵དོ༵། །འབྱེད་ཚུལ་ནི་དང་པོ་ལ་ལྕགས་ཀྱི་ཚྭ་ཚྭའི་དཔེས་མྱུར་བ་དང་། མྱུར་བ་མ་ཡིན་པ་དང་། ཆེས་རིང་མོ་ནས་འདའ་བ་གསུམ་དང་། གཉིས་པ་ལ་སྐྱེས་མ་ཐག་པ་དང་། འདུ་བྱེད་དང་བཅས་པ་དང་། བྱེད་མིན་དུ་འདའ་བའོ། །གསུམ་པ་ལ་འཕར་བ། ཕྱེད་འཕར་བ། གནས་ཐམས་ཅད་དུ་འགྲོ་བའོ། །
Enumeration Block 7:
བཞི་པ་དགྲ་བཅོམ་ལ། ཞུགས་པ་དང་། གནས་པ་གཉིས། 
Enumeration Block 8:
གཉིས་པ་གནས་པ་ལ་བདུན། དངོས་དང་། ཞར་ལ་སྤང་བྱ་སྤོང་ཚུལ། ཤེས་པའི་འབྱུང་ཚུལ། དགེ་སྦྱོང་ཚུལ་གྱི་བསྡུ་བ། ཚངས་པའི་འཁོར་ལོ། དགེ་སྦྱོང་ཚུལ་གྱི་འབྲས་བུ་འཐོབ་ཚུལ། དགྲ་བཅོམ་གྱི་དབྱེ་བའོ། །
Enumeration Block 9:
གཉིས་པ་ཞར་ལ་སྤང་བྱ་སྤོང་ཚུལ་ལ་གསུམ། ལམ་གང་གིས་ས་གང་གི་སྤང་བྱ་སྤོང་། ས་གང་གིས་ས་གང་གི་སྤང་བྱ་སྤོང་། ཞར་ལ་འཇིག་རྟེན་པའི་ལམ་གྱིས་དམིགས་རྣམ་མོ། །དང་པོ་ནི། འཕགས་པ་དག་ས་དང་ས་ལས་འདོད་ཆགས་དང་བྲལ་ན་གཉེན་པོ་གང་གིས་ས་གང་ལས་འདོད་ཆགས་དང་བྲལ་ཞེ་ན། འདི་ལྟར་བསྒོམ་པའི་ལམ་ནི་འཇིག་རྟེན་དང་དེ་ལས་འདས་པ་གཉིས་ལས། 
Enumeration Block 10:
བདུན་པ་དགྲ་བཅོམ་གྱི་དབྱེ་བ་ལ་བཞི། དངོས་དང་། ཆོས་ཀྱི་ཁྱད་པར། ཉམས་པའི་དབྱེ་བ། དབང་པོའི་འཕོ་ཚུལ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 11:
ཉན་ཐོས་དགྲ྄༷་བཅོམ༵་པ་ནི་དྲུག༵་ཏུ༵་འདོད༵་དེ། རྐྱེན་ཆུང་ངུས་ཀྱང་རྟོགས་པ་ལས་ཡོངས་སུ་ཉམས་པའི་ཆོས་ཅན་དང་། ཉམས་པར་དོགས་པས་འཆི་བར་སེམས་པའི་ཆོས་ཅན་དང་། ཉམས་པར་དོགས་པས་རྗེས་སུ་བསྲུང་བའི་ཆོས་ཅན་དང་། རྐྱེན་ཆུང་ངུས་རྟོགས་པ་ལས་མི་བསྐྱོད་པའི་ཆོས་ཅན་དང ་། དབང་པོ་འཕོས་ཏེ་མི་གཡོ་བ་རྟོགས་པའི་སྐལ་པ་ཅན་དང་། དབང་པོ་རྣོ་བས་རྟོགས་པ་ལས་ཉམས་མི་སྲིད་པས་མི་གཡོ་བ་རྣམས་སོ། །
Enumeration Block 12:
ཡོང༵ས་སུ་ཉམ༵ས་པ་རྣམ༵་པ༵་གསུ༵་དུ་ཤེས༵་པར་བྱ༵་སྟེ། ཡོན་ཏན་ཐོབ་པ་ཤོར་བ་ཐོབ༵་པ་ལས་ཉམས་པ་དང༵་། ཐོབ་པར་བྱ་བ་མ༵་ཐོབ༵་པ་མ་ཐོབ་པ་ལས་ཉམས་པ་དང་། ཐོབ་པ་མངོན་དུ་མ་བྱས་པ་ཐོབ་པ་ཉེར༵་སྤྱད༵་ལས༵་ཉམས་པ་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 13:
གཉིས་པ་མཇུག་བསྡུ་བ་ནི། དགྲ་བཅོམ་པ་དེ་ལ་དགུ་ཡོད་དེ། སངས་རྒྱས་ལ་སང༵ས་རྒྱས༵་དང་རང་སངས་རྒྱས་གཉིས༵། མི་གཡོ་བའི་ཆོས་ཅན་ལ་རང་བཞིན་དུ་གནས་པ་དང༵་དབང་པོ་སྦྱངས་པ་གཉིས་སུ་ཕྱེ་བས་ཉན༵་ཐོས༵་དགྲ་བཅོམ་པ་ལ་བདུན༵་དུ་ཡོད་པའི་ཕྱིར། དགྲ་བཅོམ་པ་དགུར༵་ངེས་ཏེ། དབང༵་པོ༵་རྟུལ་འབྲིང་རྣོན་པོ་གསུམ་པོ་རེ་རེའང་གསུམ་གསུམ་དུ་དབྱེ་བས་རྣམ༵་པ་ད༵གུ༵་ཅན༵་ཡིན་པའི་ཕྱིར། 
Enumeration Block 14:
འཕགས་པའི་གང༵་ཟག༵་བདུན༵་ཡོད་དེ། དད་པ་དང་ཆོས་ཀྱི་རྗེས་འབྲང་གཉིས། དད་མོས་མཐོང་ཐོབ༵་གཉིས། ལུས་མངོན་བྱེད་དང་། ཤེས་རབ་ཀྱིས་རྣམ་པར་གྲོལ་བ་དང་། གཉིས་ཀའི་ཆ་ལས་རྣམ་པར་གྲོལ་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 15:
བཞི་པ་མངོན་རྟོགས་ཀྱི་ལམ་བསྟན་པ་ལ་གསུམ། སྦྱོར་སོགས་བཞི་བཤད་པ། གནས་དང་དབང་པོ་ཐམས་ཅད་པའི་ལམ་བཤད་པ། བྱང་ཆུབ་ཕྱོགས་མཐུན་གྱི་ལམ་བཤད་པའོ། །
Enumeration Block 16:
མདོར༵་ན༵་ཐར་པའི་ལམ༵་ནི༵་རྣམ༵་པ་བཞི༵་སྟེ༵། གང་གི་མཇུག་ཐོག་ཏུ་བར་ཆད་མེད་ལམ་སྐྱེ་བའི་སྦྱོར་བའི་ལམ་དང་། སྤང་བྱ་དངོས་སུ་སྤོང་བའི་བར་ཆད་མེད་ལམ་དང་། སྤང་བྱ་ལས་དང་པོར་གྲོལ་བའི་རྣམ༵་གྲོལ༵་ལམ༵་དང༵་། དེ་ཡན་ཆད་ཀྱི་ཁྱད༵་པར༵་ཅན༵་གྱི་ལམ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
