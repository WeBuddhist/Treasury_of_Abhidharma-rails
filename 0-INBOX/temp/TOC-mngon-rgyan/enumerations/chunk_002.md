Enumeration Block 1:
དེ་དག་གི་སྤྱིའི་དོན་ནི་གནས་བརྒྱད་ཀྱི་གྲངས་ངེས་པ་དང་རྣམ་བཞག་དང་། འབྲེལ་དང་། གོ་རིམ་ངེས་པ་དང་། གནས་གང་ནས་བརྗོད་བྱ་གང་སྟོན་པ་གསུམ་གྱིས་ངེས་པར་བྱ་བ་ལས།
Enumeration Block 2:
ཟག་བཅས་བྱེ་བྲག་ཏུ་སྟོན་པའི་དབང་དུ་མཛད་ནས་གནས་གསུམ་སྟེ། གང་ཀུན་ནས་ཉོན་མོངས་པ་སེམས་ཅན་གྱི་འཇིག་རྟེན་ཁམས་གསུམ་དང་འགྲོ་བ་ལྔ་དང་། གང་དུ་ཀུན་ནས་ཉོན་མོངས་པ་སྣོད་ཀྱི་འཇིག་རྟེན་དང་། ཇི་ལྟར་ཀུན་ནས་ཉོན་མོངས་པ་སྐྱེ་གནས་བཞི་དང་རྟེན་འབྲེལ་ཡན་ལག་བཅུ་གཉིས་སྟོན་པ་འཇིག་རྟེན་བསྟན་པའི་མཛོད་དང་། གང་གིས་ཀུན་ནས་ཉོན་མོངས་པར་བྱེད་པའི་དབང་དུ་མཛད་ནས་ལས་བསྟན་པ་དང་ཕྲ་རྒྱས་བསྟན་པའི་མཛོད་བསྟན་ཏོ། །
ཟག་མེད་བྱེ་བྲག་ཏུ་སྟོན་པའི་དབང་དུ་བྱས་ནས་གནས་ཕྱི་མ་གསུམ་སྟེ། གང་རྣམ་པར་བྱང་བའི་གང་ཟག་དང་། གང་དུ་རྣམ་པར་བྱང་བའི་ཁམས་གསུམ་དང་། ཇི་ལྟར་རྣམ་པར་བྱང་བའི་མངོན་པར་རྟོགས་པའི་རིམ་པ་སྟོན་པ་ལམ་དང་གང་ཟག་བསྟན་པའི་མཛོད་དང་། གང་གིས་རྣམ་པར་བྱང་བར་བྱེད་པ་ཡེ་ཤེས་བསྟན་པའི་མཛོད་དང་། ཡེ་ཤེས་ཀྱི་རྟེན་བསྟན་པའི་དབང་དུ་མཛད་ནས་སྙོམས་འཇུག་བསྟན་པའི་མཛོད་བསྟན་ཏོ་ཞེས་འཆད་དེ།
Enumeration Block 3:
སྔོན་གྱི་སློབ་དཔོན་ཁ་ཅིག་ནི་དམིགས་པ་དང་། སྤྱོད་པ་དང་། འབྲས་བུ་སྟོན་པའི་དབང་དུ་མཛད་ནས་གནས་བརྒྱད་དུ་བསྟན་ཏེ།
Enumeration Block 4:
གཞུང་གི་དོན་ལ་གནས་བརྒྱད་ལས་དང་པོ་ཁམས་བསྟན་པ་ལ་གསུམ་སྟེ། འདུས་བྱས་མདོར་བསྡུས་པའི་རབ་ཏུ་དབྱེ་བ་དང་། མིང་གི་རྣམ་གྲངས་དང་། ཕུང་པོ་ཁམས་དང་སྐྱེ་མཆེད་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 5:
གསུམ་པ་ཕུང་པོ་ཁམས་དང་སྐྱེ་མཆེད་རྒྱས་པར་བཤད་པ་ལ་དེ་དག་གི་རང་བཞིན་དང་། དེ་གསུམ་གཞན་ཡང་འདིར་བསྡུ་བ་དང་། ཁམས་ལ་རྣམ་པའི་རབ་དབྱེ་བཤད་པ་གསུམ་གྱི་དང་པོ་ལའང་མཚན་གཞིའི་དབྱེ་བ་དང་། མཚན་ཉིད་དང་། དགོས་པ་དང་། གྲངས་ངེས་པ་དང་། གོ་རིམ་ངེས་པ་ལྔའོ། །​དང་པོ་ལའང་ལྔ་ལས་གཟུགས་ཀྱི་ཕུང་པོ་ཁམས་དང་སྐྱེ་མཆེད་ཀྱི་དབྱེ་བ་ལ་ཕུང་པོ་དང་། ཁམས་དང་སྐྱེ་མཆེད་དུ་བསྟན་པ་གཉིས་ལས།
Enumeration Block 6:
འཕགས་པ་ཐོགས་མེད་ཀྱིས་ནི་གཟུགས་སུ་ཡོད་པ་གཉིས་བཤད་དེ། ཡུལ་དཔྱད་པ་དང་། རེག་པས་གཟུགས་སུ་ཡོད་པའོ། །
Enumeration Block 7:
རྒྱས་པར་བཤད་པ་ལ་གསུམ་ལས།
Enumeration Block 8:
དེ་དག་ལ་རབ་ཏུ་དབྱེ་བ་ནི་རྟེན་བཅས་དང་དེ་མཚུངས་གཉིས་གཉིས་སུ་དབྱེའོ། །
Enumeration Block 9:
གཉིས་པ་དོན་ལྔ་བཤད་པ་ལ་གཉིས་ལས།
Enumeration Block 10:
མིག་གི་སྤྱོད་ཡུལ་དུ་འགྱུར་བའི་གཟུགས་ནི་བསྡུས་ན་ཁ་དོག་དབྱིབས་རྣམ་པ་གཉིས་དང་། དེ་དག་ཀྱང་རྒྱས་པར་ཕྱེ་ན་རྣམ་པ་ཉི་ཤུར་རབ་ཏུ་བྱེད་པ་ལས་གསུངས་ཏེ། དེ་ལ་ཁ་དོག་ལ་ནི་རྩ་བའི་ཁ་དོག་སྔོན་པོ་དང་སེར་པོ་དང་དམར་པོ་དང་དཀར་པོ་བཞི་དང་། དེ་དག་གི་བྱེ་བྲག་སྤྲིན་དང་། དུ་བ་དང་། རྡུལ་དང་། ཁུག་རྣ་དང་། གྲིབ་མ་དང་། ཉི་མ་དང་། སྣང་བ་དང་། མུན་པ་སྟེ་ཡན་ལག་གི་ཁ་དོག་བརྒྱད་དེ་བཅུ་གཉིས་དང་། རིང་པོ་དང་། ཐུང་ངུ་དང་། ལྷམ་པ་དང་། ཟླུམ་པོ་དང་། མཐོན་པོ་དང་། དམའ་བ་དང་། ཕྱལ་ལེ་བ་དང་། ཕྱལ་ལེ་བ་མ་ཡིན་པ་སྟེ་དབྱིབས་བརྒྱད་དོ། །
Enumeration Block 11:
སྒྲ་ནི་རྣ་བའི་དབང་པོའི་ཡུལ་ཏེ་དེ་ནི་རྣམ་པ་བརྒྱད་ཡོད་དེ། འདི་ལྟར་དབང་པོ་ཐ་མི་དད་པར་འཇུག་པ་ཟིན་པའི་འབྱུང་བ་ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བ་དང་། མ་ཟིན་པའི་འབྱུང་བ་ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བའི་སྒྲ་གཉིས་སོ། །​དེ་དག་རེ་རེ་ལའང་སེམས་ཅན་དུ་སྟོན་པ་དོན་བརྗོད་པར་བྱེད་པ་དང་། །​དེ་ལས་བཟློག་པ་སེམས་ཅན་དུ་སྟོན་པ་མ་ཡིན་པ་དོན་བརྗོད་པར་བྱེད་པ་མ་ཡིན་པ་གཉིས་གཉིས་ཏེ་རྣམ་པ་བཞིའོ། །​དེ་རེ་རེ་ལའང་རྣ་བར་སྙན་པ་དང་མི་སྙན་པས་ཡིད་དུ་འོང་བ་དང་མི་འོང་བ་གཉིས་གཉིས་ཏེ་དེ་ལྟར་ན་བརྒྱད་དུ་འགྱུར་རོ། །
Enumeration Block 12:
རོ་ནི་ལྕེའི་དབང་པོའི་སྤྱོད་ཡུལ་ཏེ། དེ་ནི་རྣམ་པ་དྲུག་གོ ། ​མངར་བ་དང་། སྐྱུར་བ་དང་། ལན་ཚྭ་དང་། ཚ་བ་དང་། ཁ་བ་དང་། བསྐ་བའོ། །​དྲི་ནི་སྣའི་དབང་པོའི་ཡུལ་ཏེ། དེ་ནི་དྲི་ཞིམ་པ་དང་། ང་བ་གཉིས་ལས་རེ་རེ་ལའང་མཉམ་པ་དང་མི་མཉམ་པ་གཉིས་གཉིས་སུ་ཕྱེ་བས་རྣམ་པ་བཞིའོ། །
Enumeration Block 13:
ལུས་ཀྱི་དབང་པོའི་སྤྱོད་ཡུལ་ནི་རེག་བྱ་སྟེ། དེ་ནི་དབྱེ་ན་རྒྱུའི་རེག་བྱ་འབྱུང་བ་བཞི་དང་འབྲས་བུའི་རེག་བྱ་འཇམ་རྩུབ་ལྕི་ཡང་གྲང་བ་བཀྲེས་སྐོམ་བདུན་ཏེ་བཅུ་གཅིག་གི་བདག་ཉིད་དོ། །​དེ་གང་ཞེ་ན། རྒྱུའི་རེག་བྱ་སྲ་བ་ལ་སོགས་པ་འབྱུང་བ་བཞི་དང་། འབྲས་བུའི་རེག་བྱ་འཇམ་པ་དང་རྩུབ་པ་དང་ལྕི་བ་དང་ཡང་བ་དང་། གྲང་བ་དང་བཀྲེས་པ་དང་སྐོམ་པ་སྟེ་བདུན་ནོ། །
Enumeration Block 14:
དེ་ལ་གཉིས་པ་ཆོས་ཀྱི་ཁྱད་པར་ལ་བཞི་ལས།
Enumeration Block 15:
ད་ནི་གསུམ་པ་རིག་བྱེད་མ་ཡིན་པ་འཆད་པ་ལ་གཉིས་ལས་དང་པོ་ལའང་གསུམ་ལས།
Enumeration Block 16:

Enumeration Block 17:
