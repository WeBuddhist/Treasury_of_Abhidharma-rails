Enumeration Block 1:
ད་ནི་འདུས་བྱས་ཀྱི་སྐྱེ་ཚུལ་རྒྱས་པར་བཤད་པ་ལ་དོན་དངོས་དང་། ཞར་ལ་རྒྱུ་དང་རྐྱེན་འབྲས་བུ་དང་བཅས་པ་བཤད་པ་གཉིས་ཀྱི་
Enumeration Block 2:
ཤེས་བྱ་ཐམས་ཅད་གཞི་ལྔས་བསྡུས་པ་ཡིན་ཏེ། གཟུགས་དང་། སེམས་དང་། སེམས་ལས་བྱུང་བ་དང་། མི་ལྡན་པའི་འདུ་བྱེད་དང་འདུས་མ་བྱས་སོ། །
Enumeration Block 3:
གཉིས་པ་གཟུགས་ཅན་མ་ཡིན་པའི་ལྷན་ཅིག་སྐྱེ་བའི་ཚུལ་ལ་གཉིས་ལས།
Enumeration Block 4:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་མཚུངས་ལྡན་དང་། མཚུངས་ལྡན་མ་ཡིན་པ་རྒྱས་པར་བཤད་པ་གཉིས་ལས།
Enumeration Block 5:
སེམས་ལས་བྱུང་བ་ངེས་པ་རྣམས་ནི་སྡེ་ཚན་རྣམ་པ་ལྔ་སྟེ། སེམས་ཀྱིས་མང་པོ་པ་དང་། སོགས་པའི་སྒྲས་གཟུང་བ་དགེ་བའི་ས་མང་པོ་པ་རྣམས་དང་། ཉོན་མོངས་པའི་ས་མང་པོ་པ་རྣམས་དང་། མི་དགེ་བའི་ས་མང་པོ་པ་རྣམས་དང་། ཉོན་མོངས་པ་ཆུང་ངུའི་ས་པ་ཞེས་བྱ་བར།
Enumeration Block 6:
དེ་དག་གི་སྤྱིའི་དོན་ནི་མཚན་ཉིད་དང་རྫས་དང་བཏགས་པའི་ཁྱད་པར་དང་། ཁམས་དང་སའི་རྣམ་པར་བཞག་པ་དང་། རྣམ་ཤེས་གང་གི་འཁོར་དུ་གང་འབྱུང་བ་དང་། སྒྲའི་དོན་ལྔ་ལས།
Enumeration Block 7:
གཉིས་པ་གཞུང་གི་དོན་ལ་ངེས་པའི་སེམས་བྱུང་གི་རབ་ཏུ་དབྱེ་བ་དང་། ཞར་ལ་མ་ངེས་པ་བཤད་པ་དང་། སེམས་གང་གི་འཁོར་དུ་སེམས་བྱུང་དུ་འབྱུང་བ་བཤད་པ་དང་། འདྲ་བ་ལྟ་བུའི་སེམས་བྱུང་རྣམས་ཀྱི་ཁྱད་པར་བཤད་པ་དང་། སེམས་དང་སེམས་བྱུང་གི་མིང་གི་རྣམ་གྲངས་བཤད་པ་ལྔའི་
