Enumeration Block 1:
དེ་དག་གི་སྤྱིའི་དོན་ནི་མཚན་ཉིད་དང་རྫས་དང་བཏགས་པའི་ཁྱད་པར་དང་། ཁམས་དང་སའི་རྣམ་པར་བཞག་པ་དང་། རྣམ་ཤེས་གང་གི་འཁོར་དུ་གང་འབྱུང་བ་དང་། སྒྲའི་དོན་ལྔ་ལས་
Enumeration Block 2:
གཉིས་པ་གཞུང་གི་དོན་ལ་ངེས་པའི་སེམས་བྱུང་གི་རབ་ཏུ་དབྱེ་བ་དང་། ཞར་ལ་མ་ངེས་པ་བཤད་པ་དང་། སེམས་གང་གི་འཁོར་དུ་སེམས་བྱུང་དུ་འབྱུང་བ་བཤད་པ་དང་། འདྲ་བ་ལྟ་བུའི་སེམས་བྱུང་རྣམས་ཀྱི་ཁྱད་པར་བཤད་པ་དང་། སེམས་དང་སེམས་བྱུང་གི་མིང་གི་རྣམ་གྲངས་བཤད་པ་ལྔའི་དང་པོ་ལའང་ལྔ་ལས་
Enumeration Block 3:
གཉིས་པ་མཚུངས་ལྡན་མ་ཡིན་པ་བཤད་པ་ལ་གསུམ་ལས་
Enumeration Block 4:
གཉིས་པ་སོ་སོའི་རང་བཞིན་བཤད་པ་ལ་དགུ་ལས་དང་པོ་ཐོབ་པ་བཤད་པ་ལ།
Enumeration Block 5:
དང་པོ་ཐོབ་པ་ལ་སྒྲུབ་བྱེད་དང་། དེས་བསྒྲུབས་པའི་ཐོབ་པ་བསྟན་པ་གཉིས་ལས། དང་པོ་ལ་ལུང་རིགས་གཉིས་ལས།
Enumeration Block 6:
གཉིས་པ། དེ་ལའང་གཉིས་ཏེ། གསར་དུ་རྙེད་པ་དང་། སྐད་ཅིག་གཉིས་པ་ཕན་ཆད་རྒྱུན་ལྡན་པའོ།
