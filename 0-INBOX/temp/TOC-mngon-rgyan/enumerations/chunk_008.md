Enumeration Block 1:
ཆོས་འདས་པ་དང་མ་སྐྱེས་པ་མ་འོངས་པ་རྣམས་ཀྱི་མ་ཐོབ་པ་དེ་ནི་རྣམ་པ་གསུམ་ཡིན་ཏེ།
Enumeration Block 2:
སྐལ་མཉམ་ཡང་གཉིས་ཏེ། སྤྱིའི་སྐལ་མཉམ་སེམས་ཅན་ཐམས་ཅད་ཀྱི་སྤྱི་དང་། བྱེ་བྲག་གི་སྐལ་མཉམ་མི་དང་ལྷ་ལ་སོགས་པའི་སྤྱི་ལྟ་བུའོ།
Enumeration Block 3:
འཆི་འཕོ་ཞིང་སྐྱེ་ལ་སྐལ་མཉམ་མི་འདོར་བ་ཡོད་དམ་ཞེ་ན་མུ་བཞི་སྟེ།
Enumeration Block 4:
སྙོམས་འཇུག་འདི་གཉིས་ཀྱི་རྟེན་ལ་མུ་བཞི་སྟེ།
Enumeration Block 5:
ལུས་ཐོབ་པ་ནི་བཞི་སྟེ།
