Enumeration Block 1:
དེ་དག་ནི་མིང་དང་ངག་དང་ཡི་གེའི་ཚོགས་གསུམ་མོ། །
Enumeration Block 2:
གཉིས་པ་ཞར་ལ་རྒྱུ་རྐྱེན་འབྲས་བུ་དང་བཅས་པ་བཤད་པ་ལ་རྒྱུ་དང་འབྲས་བུ་དང་རྐྱེན་བཤད་པ་གསུམ་གྱི་དང་པོ་ལའང་གསུམ་ལས་མདོར་བསྟན་པ་ནི
Enumeration Block 3:
བྱེད་པའི་རྒྱུ་དང་། ལྷན་ཅིག་འབྱུང་བའི་རྒྱུ་དང་། སྐལ་བ་མཉམ་པའི་རྒྱུ་དང་། མཚུངས་པར་ལྡན་པའི་རྒྱུ་དང་། ཀུན་ཏུ་འགྲོ་བའི་རྒྱུ་དང་། རྣམ་པར་སྨིན་པའི་རྒྱུ་ཞེས་བྱ་བའོ། །
Enumeration Block 4:
སོ་སོའི་རང་བཞིན་བཤད་པ་ལ་དྲུག་ལས།
Enumeration Block 5:
བྱེད་རྒྱུ་ནི་ནུས་བཅས་དང་ནུས་མེད་གཉིས་ལས
Enumeration Block 6:
གཉིས་པ་འབྲས་བུ་བཤད་པ་ནི་འདུས་བྱས་ལ་རྣམ་སྨིན་དང་རྒྱུ་མཐུན་དང་བདག་པོ་དང་སྐྱེད་པའི་སྐྱེས་བུ་བྱེད་འབྲས་ཏེ་ཕྱེད་དང་བཞི་དང་། འདུས་མ་བྱས་ལ། ཐོབ་པའི་སྐྱེས་བུ་བྱེད་འབྲས་དང་ཟག་བཅས་གཉེན་པོས་བྲལ་འབྲས་སོ་སོར་བརྟགས་འགོག་དང་བཅས་པ་ཕྱེད་དང་གཉིས་སུ་ཕྱེ་བ་ནི་འབྲས་བུ་ཡིན་ཏེ།
Enumeration Block 7:
དགེ་བའི་སྐལ་མཉམ་གྱི་རྒྱུ་འབྲས་བུ་འཛིན་ལ་མ་འབྱིན་པ་ཡོད་དམ་ཞེ་ན་མུ་བཞི་སྟེ།
Enumeration Block 8:
འབྲས་བུ་རྣམས་ནི་མཚུངས་ལྡན་སེམས་དང་སེམས་བྱུང་དང་། དེ་མ་ཡིན་པ་གཉིས་སུ་ངེས་སོ། །​དེ་དག་ཀྱང་རྣམ་པ་བཞི་བཞིར་ངེས་ཏེ། ཉོན་མོངས་ཅན་དང་། རྣམ་སྨིན་སྐྱེས་དང་། ཟག་མེད་དང་པོ་དང་། དེ་དག་གི་ལྷག་མའོ། །
Enumeration Block 9:
གསུམ་པ་རྐྱེན་བཤད་པ་ལ་ལྔ་ལས་མདོར་བསྟན་པ་ནི་རྐྱེན་ནི་བཞི་པོ་དག་ཏུ་གསུངས་སོ་ཞེས་བྱ་སྟེ།
Enumeration Block 10:
སེམས་ཀྱི་མཚུངས་པ་དེ་མ་ཐག་པ་ཅན་དང་སེམས་ཀྱི་དེ་མ་ཐག་པ་ཅན་གྱི་མུ་བཞི་དང་། སེམས་ཀྱི་མཚུངས་པ་དེ་མ་ཐག་པ་ཅན་དང་སྙོམས་འཇུག་གཉིས་ཀྱི་དེ་མ་ཐག་པ་ཅན་གྱི་མུ་བཞི་གཉིས་བཤད་དོ། །
Enumeration Block 11:
ཆོས་གང་དག་སེམས་ཀྱི་མཚུངས་པ་དེ་མ་ཐག་པ་ཅན་ཡིན་པ་དེ་དག་སེམས་ཀྱི་དེ་མ་ཐག་པ་ཅན་ཡང་ཡིན་ནམ་ཞེ་ན། མུ་བཞི་སྟེ།
Enumeration Block 12:
ཆོས་གང་དག་སེམས་ཀྱི་མཚུངས་པ་དེ་མ་ཐག་པ་ཅན་ཡིན་པ་དེ་དག་སྙོམས་འཇུག་གཉིས་ཀྱི་དེ་མ་ཐག་པ་ཅན་ཡང་ཡིན་ནམ་ཞེ་ན། འདི་ལའང་མུ་བཞི་ལས
Enumeration Block 13:
དེ་རྣམས་ཀྱང་བསྡུ་ན་མ་སྐྱེས་པ་བསྐྱེད་པ་དང་། སྐྱེས་ཟིན་གནས་པ་དང་། གནས་པ་འཕེལ་བར་བྱེད་པའི་རྒྱུ་གསུམ་དུ་འགྱུར་རོ། །
Enumeration Block 14:
འདི་ལ་ནི་ཚེ་དྲུག་གམ་བརྒྱད་ཀྱི་རྣམ་པར་དབྱེ་བ་ཤེས་པར་བྱ་སྟེ། རྒྱུན་གྱི་ཚེ་དང་། ས་མཚུངས་པ་དང་། སྙོམས་པར་འཇུག་པ་དང་། སྙོམས་འཇུག ། ​ལས་ལྡང་བ་དང་། ཉིང་མཚམས་སྦྱོར་བ་དང་། སྙོམས་འཇུག་ཉོན་མོངས་ཅན་གྱིས་གཟིར་བའི་ཚེ་དྲུག་ལས
