Enumeration Block 1:
སེམས་ཉི་ཤུ་བཤད་པ་ལ་གསུམ་ལས་དང་པོ་ནི།
Enumeration Block 2:
སྡུག་བདེན་འཆད་པའི་མཚན་གཞི་ནི་གང་སྐྱེ་བ་སེམས་ཅན་དང་གང་དུ་སྐྱེ་བ་སྣོད་ཀྱི་འཇིག་རྟེན་དང་གཉིས་ཏེ།
Enumeration Block 3:
དེ་ལའང་སེམས་ཅན་གྱི་འཇིག་རྟེན་དང་། སྣོད་ཀྱི་འཇིག་རྟེན་གཉིས་ལས་དང་པོ་ལའང་ལས་གསོག་པ་པོ་སེམས་ཅན་བཤད་པ་ལ་སེམས་ཅན་གྱི་དབྱེ་བ་དང་། ཁྱད་པར་གྱི་ཆོས་དང་། རྣམ་གཞག་གིས་རྒྱས་པར་བཤད་པ་གསུམ་ལས་དང་པོ་ལའང་
Enumeration Block 4:
ཁྱད་པར་གྱི་ཆོས་ལ་གཉིས་ལས་དང་པོས་ནི་
Enumeration Block 5:
ད་ནི་དེ་རྣམ་གཞག་གིས་རྒྱས་པར་བཤད་པ་ལ་སེམས་ཅན་གྱི་སྐྱེ་བ་དང་། གནས་པ་དང་། འཆི་བ་བཤད་པ་གསུམ་ལས་དང་པོ་ལའང་
Enumeration Block 6:
ད་ནི་གང་གིས་འཇུག་པའི་བར་སྲིད་ལའང་གསུམ་ལས་དང་པོ་ངོ་བོ་ནི་
