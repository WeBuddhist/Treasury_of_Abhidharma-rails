Enumeration Block 1:
གསུམ་པ་དེ་དག་གི་ཁྱད་པར་ལའང་ངོ་བོ་དང་སའི་ཁྱད་པར་དང་། དགེ་བ་དང་མི་དགེ་བ་དང་ལུང་མ་བསྟན་གྱི་དབྱེ་བ་དང་། རིག་བྱེད་མ་ཡིན་པ་རྒྱས་པར་དབྱེ་བ་དང་། ལྡན་པའི་ཚུལ་དང་། འཐོབ་པའི་ཚུལ་དང་། གཏོང་བའི་ཚུལ་དང་། རྟེན་གྱི་ཁྱད་པར་བདུན་ལས་
Enumeration Block 2:
འདིར་དགེ་བ་ནི་དོན་དམ་པ་དང་། ངོ་བོ་ཉིད་དང་། མཚུངས་ལྡན་དང་། ཀུན་སློང་གིས་དགེ་བ་བཞི་ལས་
Enumeration Block 3:
མི་དགེ་བ་རྣམ་པ་བཞི་ཡིན་ཏེ།
Enumeration Block 4:
ལུང་མ་བསྟན་རྣམ་པ་བཞི་ལས་
Enumeration Block 5:
ཀུན་ནས་སློང་བ་ནི་རྣམ་པ་གཉིས་ཏེ། རྒྱུའི་ཀུན་སློང་དང་བྱ་བ་དེའི་དུས་ཀྱི་ཀུན་སློང་ཞེས་བྱའོ། །
Enumeration Block 6:
རབ་ཏུ་འཇུག་བྱེད་དང་རྗེས་སུ་འཇུག་བྱེད་ལ་མུ་བཞི་སྟེ། མཐོང་སྤང་གི་སེམས་ནི་རབ་ཏུ་འཇིག་བྱེད་ཁོ་ན་དང་། སྒོ་ལྔའི་རྣམ་ཤེས་ནི་རྗེས་སུ་འཇུག་བྱེད་ཁོ་ན་དང་། ཡིད་ཤེས་སྒོམ་སྤང་ནི་གཉིས་ཀ་དང་། ཟག་མེད་ནི་གཉིས་ཀ་མིན་པའི་མུའོ།
Enumeration Block 7:
རྣམ་པ་གསུམ་དུ་ཤེས་པར་བྱ་སྟེ། གང་ཞེ་ན།
Enumeration Block 8:
རྒྱས་པར་བཤད་པ་ལ་སྡོམ་པའི་དབྱེ་བ་དང་། སོ་སོ་ཐར་པའི་སྡོམ་པའི་ཁྱད་པར་དང་། བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པའི་ཁྱད་པར་གསུམ་ལས། དང་པོ་སྡོམ་པ་ལ་དབྱེ་ན་སོ་སོ་ཐར་པའི་སྡོམ་པ་ཞེས་བྱ་བ་དང་། དེ་བཞིན་དུ་ཟག་མེད་དང་བསམ་གཏན་ལས་སྐྱེས་པའི་སྡོམ་པ་གཉིས་ཏེ་གསུམ་ཡིན་ནོ། །
Enumeration Block 9:
སོ་སོ་ཐ་ར་པ་ཞེས་བྱ་བའི་སྡོམ་པ་ནི་གང་ཟག་གིས་ཕྱེ་ན་རྣམ་པ་བརྒྱད་དེ། དགེ་སློང་ཕ་མ་དང་། དགེ་སློབ་མ་དང་། དགེ་ཚུལ་ཕ་མ་དང་། དགེ་བསྙེན་ཕ་མ་དང་། བསྙེན་གནས་པའི་སྡོམ་པའོ། །
Enumeration Block 10:
སྡོམ་པའི་རྫས་སུ་ནི་རྣམ་པ་བཞི་ཡིན་ཏེ།
Enumeration Block 11:
སོ་སོ་ཐར་པའི་སྡོམ་པ་དང་ལྡན་པའི་གང་ཟག་ནི་བརྒྱད་དེ་དགེ་སློང་ལ་སོགས་པའོ། །
Enumeration Block 12:
དེས་ན་འདིར་རིག་བྱེད་དང་ལྡན་ལ་རིག་བྱེད་མ་ཡིན་པ་དང་མི་ལྡན་པའང་ཡོད་ཅེས་པ་མུ་བཞི་སྟེ།
Enumeration Block 13:
དུས་ཀྱི་མཐའ་ནི་སྲོག་གི་མཐའ་དང་ཉིན་ཞག་གི་མཐའ་གཉིས་ལས།
