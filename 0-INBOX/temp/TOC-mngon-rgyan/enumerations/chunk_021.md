Enumeration Block 1:
གསུམ་པ་དཀར་ནག་ལ་སོགས་པ་བཞིར་དབྱེ་བ་ནི་མདོ་ལས། ལས་གནག་ལ་རྣམ་པར་སྨིན་པ་གནག་པའི་ལས་དང་། ལས་དཀར་ལ་རྣམ་པར་སྨིན་པ་དཀར་བའི་ལས་དང་། སོགས་པའི་སྒྲས་བཟུང་བ་ལས་དཀར་ནག་འདྲེན་མ་ལ་རྣམ་པར་སྨིན་པ་ཡང་དཀར་གནག་འདྲེན་མ་དང་། ལས་མི་དཀར་མི་གནག་ཅིང་རྣམ་པར་སྨིན་པ་མེད་ལ་ལས་ཟད་པར་བྱེད་པའི་བྱེ་བྲག་གི་ལས་ནི་རྣམ་པ་བཞི་ཡིན་པར་གསུངས་པ་ཡིན་ནོ། །
Enumeration Block 2:
སློབ་དཔོན་གང་སྤེལ་གྱིས་ཀྱང་དཀར་བ་ནི་རྣམ་པ་གཉིས་ཏེ། རང་བཞིན་གྱིས་དཀར་བ་དང་། རྣམ་པར་སྨིན་པས་དཀར་བའོ། །
Enumeration Block 3:
བཞི་པ་ཐུབ་པ་གསུམ་ལ་སོགས་པར་དབྱེ་བ་ནི་མདོ་ལས། ཐུབ་པའི་གསུམ་སྟེ། ཐུབ་པའི་ལུས་དང་ཐུབ་པའི་ངག་དང་ཐུབ་པའི་ཡིད་དོ། །
Enumeration Block 4:
རྒྱས་པར་བཤད་པ་ལ་རིག་བྱེད་དང་རིག་བྱེད་མ་ཡིན་པ་དང་། ཀུན་སློང་དང་། གཞི་དང་། ངོ་བོ་དང་། ལས་ཀྱི་ལམ་དུ་དང་སེམས་པ་ལྷན་ཅིག་ཏུ་འབྱུང་བ་དང་། ལྡན་པའི་ཚུལ་དང་། འབྲས་བུ་བཤད་པ་བདུན་ལས།
Enumeration Block 5:
འདོད་པས་ལོག་པར་གཡེམ་པ་རྣམ་པ་བཞི་སྟེ། བགྲོད་པར་བྱ་བ་མ་ཡིན་པ་དང་། ཡན་ལག་མ་ཡིན་པ་དང་། ཡུལ་མ་ཡིན་པ་དང་། དུས་མ་ཡིན་པར་བགྲོད་པའོ། །
Enumeration Block 6:
ལོག་པ་ཉིད་དུ་ངེས་པ་ལ་མུ་བཞི་ལས།
