Enumeration Block 1:
དེའི་ཕྱིར་སྦྱིན་པ་ལས་བྱུང་བ་ལ་ནི་བསོད་ནམས་གཉིས་ཏེ། ལོངས་སྤྱད་པ་ལས་བྱུང་བ་དང་། བཏང་བའི་རྒྱུ་ལས་བྱུང་བའོ། །
Enumeration Block 2:
ཚུལ་ཁྲིམས་དེ་ཡང་སྤངས་བྱ་རིག་བྱེད་དང་རིག་བྱེད་མ་ཡིན་པ་གཉིས་ཀྱི་གཉེན་པོ་ཡིན་པས་རིག་བྱེད་དང་རིག་བྱེད་མ་ཡིན་པ་རྣམ་པ་གཉིས་སོ། །
Enumeration Block 3:
དེ་ལ་གསུམ་ལས་དང་པོ་གསུང་རབ་ཡན་ལག་བཅུ་གཉིས་སུ་དབྱེ་བ་ནི།
Enumeration Block 4:
གཉིས་པ་དེ་དག་སྡེ་སྣོད་གསུམ་དང་གཉིས་སུ་བསྡུ་བ་ལ་གསུམ་དུ་བསྡུ་བ་དང་གཉིས་སུ་བསྡུ་བ་དང་། ངེས་ཚིག་གསུམ་ལས་དང་པོ་ལའང་གཉིས་ལས་དང་པོ་གསུམ་དུ་བསྡུ་བ་དངོས་ནི།
Enumeration Block 5:
གཉིས་པ་སྡེ་སྣོད་གསུམ་དུ་བསྟན་པའི་དགོས་པ་ནི་རྒྱུ་དགུས་གཞག་སྟེ། དེ་ལ་གསུམ་མཚན་གསུམ་ལས་དང་པོ།
Enumeration Block 6:
བཅུ་བཞི་པ་ཆ་མཐུན་གྱི་དགེ་བ་གསུམ་བཤད་པ་ནི་མདོ་ལས། བསོད་ནམས་ཀྱི་ཆ་དང་མཐུན་པ་དང་། ཐར་པའི་ཆ་དང་མཐུན་པ་དང་། ངེས་པར་འབྱེད་པའི་ཆ་དང་མཐུན་པའི་དགེ་བ་གསུམ་གསུངས་པ་ལ།
Enumeration Block 7:
བཅོ་ལྔ་པ་འཇིག་རྟེན་པའི་ལས་གསུམ་གྱི་རྣམ་གྲངས་བསྟན་པ་ནི།
Enumeration Block 8:
ད་ནི་གནས་ལྔ་པ་ཕྲ་རྒྱས་བསྟན་པ་འཆད་པ་ལ་ཕྲ་རྒྱས་ཀྱི་རང་བཞིན་དང་། དེ་ཇི་ལྟར་སྤོང་བའི་ཚུལ་དང་། སྤངས་པའི་འབྲས་བུ་ཡོངས་ཤེས་བཤད་པ་གསུམ་ལས། དང་པོ་ལའང་ཕྲ་རྒྱས་ཀྱི་དབྱེ་བ་དང་། རྣམ་པའི་རབ་དབྱེ་བཤད་པ་གཉིས་ཀྱི་དང་པོ་ན།
Enumeration Block 9:
ཕྲ་རྒྱས་དེ་ཡང་དབྱེ་ན་རེ་ཞིག་རྣམ་པ་དྲུག་སྟེ། གང་ཞེ་ན། འདོད་ཆགས་དང་དེ་བཞིན་དུ་ཁོང་ཁྲོ་དང་ང་རྒྱལ་དང་མ་རིག་པ་དང་ལྟ་བ་དང་ཐེ་ཚོམ་ཡིན་ཏེ།
Enumeration Block 10:
མདོ་ལས་འདོད་ཆགས་ལ་འདོད་པའི་འདོད་ཆགས་ཀྱི་ཕྲ་རྒྱས་དང་། སྲིད་པའི་འདོད་ཆགས་ཀྱི་ཕྲ་རྒྱས་ཞེས་གཉིས་སུ་དབྱེ་བ་བྱས་ནས་སོ། །
Enumeration Block 11:
ཡང་ཕྲ་རྒྱས་དྲུག་པོ་དེ་དག་ཆོས་མངོན་པ་ལས་བཅུར་ཡང་བཤད་དོ་ཞེས་སྦྲེལ་ལོ། །ཇི་ལྟར་ཞེ་ན་ལྟ་བ་ལ་འཇིག་ཚོགས་ལ་ལྟ་བ་དང་། སྐུར་པ་འདེབས་པ། ལོག་པར་ལྟ་བ་དང་། ཁྱད་པར་དུ་སྒྲོ་འདོགས་པ་མཐར་འཛིན་པར་ལྟ་བ་དང་། ལྟ་བ་མཆོག་ཏུ་འཛིན་པ་དང་། ཚུལ་ཁྲིམས་དང་བརྟུལ་ཞུགས་མཆོག་ཏུ་འཛིན་པ་དང་ལྔར་ཕྱེ་སྟེ།
Enumeration Block 12:
ཕྲ་རྒྱས་བཅུ་པོ་དེ་དག་དགུ་བཅུ་རྩ་བརྒྱད་དུའང་འཆད་དེ།
