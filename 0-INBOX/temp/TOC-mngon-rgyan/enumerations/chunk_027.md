Enumeration Block 1:
གང་དག་དུས་གསུམ་རྫས་སུ་ཡོད་པར་འདོད་པའི་ཐམས་ཅད་ཡོད་པར་སྨྲ་བ་དེ་དག་ཀྱང་དབྱེ་ན་རྣམ་པ་བཞི་ཡིན་ཏེ། དངོས་པོ་གཞན་དུ་འགྱུར་བ་དང་། མཚན་ཉིད་གཞན་དུ་འགྱུར་བ་དང་། གནས་སྐབས་གཞན་དུ་འགྱུར་བ་དང་། གཞན་དང་གཞན་དུ་འགྱུར་བ་ཞེས་བྱ་བའོ། །
Enumeration Block 2:
ཡུལ་ཆོས་ཐམས་ཅད་ནི་རྣམ་པ་བཅུ་དྲུག་ཏུ་འདུས་ཏེ། ཁམས་གསུམ་ན་སྤང་བྱ་རིས་ལྔ་ལྔ་དང་། ཟག་པ་མེད་པའོ། །
Enumeration Block 3:
ཡུལ་དེ་ཆོས་གང་དུ་གཏོགས་པ་དང་། དེ་སེམས་དུའི་ཡུལ་དུ་འགྱུར་བ་དང་། ཡུལ་ཅན་གྱི་སེམས་དེ་ཕྲ་རྒྱས་ཡིན་མིན་དང་། ཕྲ་རྒྱས་ཡིན་པ་དེ་ཡུལ་དེ་ལ་རྒྱས་མི་རྒྱས་དཔྱད་པ་བཞིས་
Enumeration Block 4:

Enumeration Block 5:

Enumeration Block 6:
མདོ་ལས་གསུངས་པའི་ཟག་པ་ལ་སོགས་པའི་དབྱེ་བ་བསྟན་པ་ལ་ཟག་པ་དང་། ཆུ་བོ་དང་། སྦྱོར་བ་དང་། ཉེར་ལེན་དང་། ཕྲ་རྒྱས་ལ་སོགས་པའི་མིང་དོན་དང་། ཀུན་སྦྱོར་དང་། འཆིང་བ་དང་། ཉེ་བའི་ཉོན་མོངས་དང་། ཀུན་དཀྲིས་དང་། དྲི་མ་དང་། དེ་དག་གི་རྣམ་པའི་རབ་དབྱེ་དང་། སྒྲིབ་པ་ལྔ་བཤད་པ་དང་བཅུ་གཅིག་ལས་
Enumeration Block 7:
འདོད་པའི་ཟག་པ་དང་། སྲིད་པའི་ཟག་པ་དང་། མ་རིག་པའི་ཟག་པའོ་ཞེས་ཟག་པ་གསུམ་དུ་གསུངས་པ་ལས་
Enumeration Block 8:
ཆུ་བོ་ནི་བཞི་སྟེ། འདོད་པའི་ཆུ་བོ་དང་། སྲིད་པའི་ཆུ་བོ་དང་། ལྟ་བའི་ཆུ་བོ་དང་། མ་རིག་པའི་ཆུ་བོའོ་
Enumeration Block 9:

Enumeration Block 10:

Enumeration Block 11:
ཕྲ་རྒྱས་དེ་དག་ཉིད་ཀུན་ཏུ་སྦྱོར་བ་དང་། སོགས་པས་གཟུང་བ་འཆིང་བ་དང་། ཕྲ་རྒྱས་དང་། ཉེ་བའི་ཉོན་མོངས་པ་དང་། ཀུན་ནས་དཀྲིས་པ་རྣམས་ཀྱི་དབྱེ་བས་ཡང་རྣམ་པ་ལྔར་མདོ་དང་། ཆོས་མངོན་པ་ལས་ཕྱེ་ནས་བཤད་དོ། །
Enumeration Block 12:
ཀུན་ཏུ་སྦྱོར་བ་ནི་དགུ་སྟེ། རྗེས་སུ་ཆགས་པ་དང་། ཁོང་ཁྲོ་བ་དང་། ང་རྒྱལ་དང་། མ་རིག་པ་དང་། ལྟ་བ་དང་། མཆོག་ཏུ་འཛིན་པ་དང་། ཐེ་ཚོམ་དང་། ཕྲག་དོག་དང་། སེར་སྣའི་ཀུན་ཏུ་སྦྱོར་བ་རྣམས་སོ་
Enumeration Block 13:
ཐ་མའི་ཆ་དང་མཐུན་པའི་ཀུན་ཏུ་སྦྱོར་བ་ལྔ་སྤངས་པའི་ཕྱིར་འཕགས་པ་ཕྱིར་མི་འོང་བ་ཡིན་ཏེ། འདི་ལྟ་སྟེ་འཇིག་ཚོགས་ལ་ལྟ་བ་དང་། ཚུལ་ཁྲིམས་དང་བརྟུལ་ཞུགས་མཆོག་ཏུ་འཛིན་པ་དང་། ཐེ་ཚོམ་དང་། འདོད་པ་ལ་འདུན་པ་དང་། གནོད་སེམས་སོ་
Enumeration Block 14:
གོང་མའི་ཆ་དང་མཐུན་པ་ལྔ་ཉིད་དུ་གསུངས་པ་ནི་གཟུགས་དང་གཟུགས་མེད་པའི་ཁམས་ལས་སྐྱེས་པའི་འདོད་ཆགས་གཉིས་དང་རྒོད་པ་དང་ང་རྒྱལ་དང་ཀུན་དུ་རྨོངས་པ་རྣམས་ཡིན་ནོ། །
Enumeration Block 15:
འཆིང་བ་ནི་གསུམ་སྟེ། འཆིང་བ་འདོད་ཆགས་ཐམས་ཅད་དང་། ཞེ་སྡང་ཐམས་ཅད་དང་། གཏི་མུག་ཐམས་ཅད་དོ
Enumeration Block 16:
དེ་དག་ཀྱང་ཀུན་ནས་དཀྲིས་པ་དང་། དྲི་མ་དང་། གཞི་ཕྲན་ཚེགས་ལས་འབྱུང་བ་མི་དགའ་བ་དང་། གླལ་བྱེད་པ་དང་། སེམས་ཞུམ་པ་ཉིད་དང་། སྨྱོ་བ་དང་། ཟས་ཀྱི་དྲོད་མི་ཟིན་པ་ཉིད་དང་། ཐ་དད་པའི་འདུ་ཤེས་དང་། ཡིད་ལ་མི་བྱེད་པ་དང་། ལུས་ཀྱི་གནས་ངན་ལེན་དང་། རུ་གདུག་དང་། འཕྱ་སྨོད་དང་། གནམ་པ་ཉིད་དང་། མི་གནམ་པ་ཉིད་དང་། རང་བཞིན་དུ་མི་འདུག་པ་ཉིད་དང་། འདོད་པའི་རྣམ་པར་རྟོག་པ་དང་། འཚེ་བའི་རྣམ་པར་རྟོག་པ་དང་། ཉེ་དུའི་རྣམ་པར་རྟོག་པ་དང་། ཡུལ་མིའི་རྣམ་པར་རྟོག་པ་དང་། མི་འཆི་བའི་རྣམ་པར་རྟོག་པ་དང་། བརྙས་པ་དང་ལྡན་པའི་རྣམ་པར་རྟོག་པ་དང་། རིགས་སྙེམས་པ་དང་ལྡན་པའི་རྣམ་པར་རྟོག་པ་དང་། མྱ་ངན་དང་། སྡུག་བསྔལ་བ་དང་། ཡིད་མི་བདེ་བ་དང་། འཁྲུག་པ་ཞེས་བྱ་བ་ཉེར་བཞི་པོ་དག་སྟེ།
