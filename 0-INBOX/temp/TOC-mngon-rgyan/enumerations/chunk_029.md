Enumeration Block 1:
གསུམ་པ་མངོན་པར་རྟོགས་པའི་རིམ་པ་ལ་གཉིས་ལས
Enumeration Block 2:
རྒྱས་པར་བཤད་པ་ལ་ཚོགས་ལམ་དང་། སྦྱོར་ལམ་དང་། མཐོང་ལམ་གསུམ་ལས
Enumeration Block 3:
ཞི་གནས་སེམས་གནས་པའི་ཐབས་དགུ་ནི་སེམས་མི་གནས་པ་གནས་པའི་ཐབས་གསུམ་གནས་པར་བརྟན་པར་བྱེད་པའི་ཐབས་གསུམ་བརྟན་པའི་འབྲས་བུ་ལ་དབང་བསྒྱུར་བའི་ཐབས་གསུམ་མོ།
Enumeration Block 4:
དེ་ལ་དང་པོའི་གསུམ་ནི་སེམས་འཇོག་པ་དང་། རྒྱུན་དུ་འཇོག་པ་དང་། ངེས་པར་འཇོག་པ་སྟེ།
Enumeration Block 5:
གཉིས་པའི་གསུམ་ནི་ཉེ་བར་འཇོག་པ་དང་། འདུལ་བར་བྱེད་པ་དང་། ཞི་བར་བྱེད་པ་སྟེ།
Enumeration Block 6:
གསུམ་པའི་གསུམ་ནི་ཉེ་བར་ཞི་བར་བྱེད་པ་དང་། རྒྱུད་གཅིག་ཏུ་བྱེད་པ་དང་། མཉམ་པར་འཇོག་པར་བྱེད་པ་སྟེ།
Enumeration Block 7:
དེ་ལ་དྲན་པ་ཉེར་གཞག་ནི་དབྱེ་ན་རང་བཞིན་དང་། འབྲེལ་བ་དང་། དམིགས་པའི་དྲན་པ་ཉེར་གཞག་གསུམ་ལས
Enumeration Block 8:
དེ་ལ་འདིར་ལམ་གྱི་སྤྱིའི་དོན་རྣམ་པར་བཞག་པ་ལ་ལམ་སྤྱིའི་རྣམ་པར་བཞག་པ་དང་། ཚོགས་ལམ་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས་ལས
Enumeration Block 9:
དབྱེ་བ་གཉིས་ལས་དང་པོ་ནི་ཚོགས་ལམ་ནས་མི་སློབ་པའི་ལམ་གྱི་བར་ལྔའོ།
Enumeration Block 10:
གཉིས་པ་ཚོགས་ལམ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གསུམ་ལས
Enumeration Block 11:
མཚན་གཞི་ནི་ཁྱད་པར་ཅན་དང་། ཕལ་པ་གཉིས་ལས
Enumeration Block 12:
ཁྱད་པར་གྱི་ཆོས་ལ་ལྔ་ལས
Enumeration Block 13:
བཟོད་པ་ལའང་གསུམ་ཡོད་པ་ལས
