Enumeration Block 1:
དབྱེ་བ་གཉིས་ལས་
Enumeration Block 2:
གཉིས་པ་ཚོགས་ལམ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གསུམ་ལས་
Enumeration Block 3:
མཚན་གཞི་ནི་ཁྱད་པར་ཅན་དང་། ཕལ་པ་གཉིས་ལས་
Enumeration Block 4:
ཁྱད་པར་གྱི་ཆོས་ལ་ལྔ་ལས་
Enumeration Block 5:
སྤྱིའི་དོན་ནི་གསུམ་ཡིན་ཏེ། མཐོང་ལམ་གྱི་རྟེན་དང་། ལམ་དང་། འབྲས་བུའོ། །
Enumeration Block 6:
རྒྱུན་ཞུགས་ཀྱི་དབྱེ་བ་ལ་ཞུགས་གནས་གཉིས་ལས།
Enumeration Block 7:
དེ་ལ་རྒྱུན་ཞུགས་དང་། ལན་ཅིག་ཕྱིར་འོང་དང་། ཕྱིར་མི་འོང་དང་། དགྲ་བཅོམ་པ་ལ་ཞུགས་པ་དང་གནས་པ་བཤད་པ་བཞི་ལས་
