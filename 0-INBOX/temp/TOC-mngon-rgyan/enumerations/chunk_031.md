Enumeration Block 1:
རྒྱུན་ཞུགས་ཀྱི་དབྱེ་བ་ལ་ཞུགས་གནས་གཉིས་ལས། ཞུགས་པ་ནི་ལམ་གྱིས་ཕྱེ་ན་མཐོང་ལམ་སྐད་ཅིག་བཅོ་ལྔ་ལ་གནས་པས་བཅོ་ལྔའོ། །​དེ་རེ་རེའང་འདོད་ཆགས་དང་བྲལ་བས་དྲུག་སྟེ། སྒོམ་སྤང་མ་སྤངས་པ་ནས་ལྔ་པ་སྤངས་པའི་བར་རོ། །​དེ་རེ་རེ་ཡང་གཉིས་གཉིས་ཏེ་དད་པའི་རྗེས་འབྲང་ནི་རིགས་ཀྱིས་ལྔ་སྟེ། ཉམས་པའི་ཆོས་ཅན་ནས་རྟོགས་པའི་སྐལ་བ་ཅན་གྱི་བར་རོ། །​དེ་རེ་རེའང་དབང་པོས་གསུམ་མོ། །​དེ་རེ་རེ་ཡང་རྟེན་གྱིས་དགུ་དགུ་སྟེ་གླིང་གསུམ་དང་ལྷ་དྲུག་གོ །
Enumeration Block 2:
ཆགས་བྲལ་སྔོན་འགྲོའི་ཕྱིར་འོང་ལ་ཞུགས་གནས་གཉིས་ལས། ཞུགས་པ་ལའང་གཉིས་ལས་དད་པས་རྗེས་འབྲང་ནི་གཞན་རྒྱུན་ཞུགས་དང་འདྲ་ལ། འདོད་ཆགས་དང་བྲལ་བས་གསུམ་སྟེ།
Enumeration Block 3:
ཆགས་བྲལ་སྔོན་འགྲོའི་ཕྱིར་མི་འོང་ལ་ཞུགས་གནས་གཉིས་ལས།
Enumeration Block 4:
དེ་ལ་རྒྱུན་ཞུགས་དང་། ལན་ཅིག་ཕྱིར་འོང་དང་། ཕྱིར་མི་འོང་དང་། དགྲ་བཅོམ་པ་ལ་ཞུགས་པ་དང་གནས་པ་བཤད་པ་བཞི་ལས
Enumeration Block 5:
ཕྱིར་མི་འོང་གི་འབྲས་བུ་ལ་གནས་པ་དེ་ཉིད་ནི་གསུམ་དུ་དབྱེ་སྟེ། གཟུགས་སུ་ཉེ་བར་འགྲོ་བ་དང་། གཟུགས་མེད་པར་ཉེ་བར་འགྲོ་བ་དང་། ཚེ་འདི་ལ་མྱ་ངན་ལས་འདའ་བའོ། །
Enumeration Block 6:
དེ་ལ་གཟུགས་སུ་ཉེ་བར་འགྲོ་བ་དེ་ནི་རྣམ་པ་ལྔ་སྟེ། བར་མ་དོར་མྱ་ངན་ལས་འདའ་བ་དང་། སྐྱེས་ནས་མྱ་ངན་ལས་འདའ་བ་དང་། མངོན་པར་འདུ་བྱེད་པ་དང་བཅས་པ་དང་། མངོན་པར་འདུ་བྱེད་པ་མེད་པར་ཡོངས་སུ་མྱ་ངན་ལས་འདའ་བ་དང་། གོང་དུ་འཕོ་བ་རྣམས་སོ། །
Enumeration Block 7:
ཤེས་རབ་ལ་དགའ་བས་ལྷག་མཐོང་སྤྱད་པ་བསམ་གཏན་སྤེལ་བ་དང་། ཏིང་ངེ་འཛིན་ལ་དགའ་བས་ཞི་གནས་སྤྱད་པ་བསམ་གཏན་མ་སྤེལ་བ་གཉིས་ལས
Enumeration Block 8:
དེ་ཡང་དབྱེ་ན་འཕར་བ་དང་ཕྱེད་དུ་འཕར་བ་དང་གནས་ཐམས་ཅད་དུ་འཆི་འཕོ་བ་གསུམ་ལས
Enumeration Block 9:
སྤེལ་བའི་དགོས་པ་ནི་གསུམ་སྟེ།
Enumeration Block 10:
ཁྱིམ་བདག་ཡོན་གནས་ནི་གཉིས་ཏེ། སློབ་པ་དང་མི་སློབ་པའོ། །
Enumeration Block 11:
བཞི་པ་དགྲ་བཅོམ་པ་འཆད་པ་ལ་ཞུགས་པ་དང་། གནས་པ་གཉིས་ལས
Enumeration Block 12:
རྡོ་རྗེ་ལྟ་བུའི་ཏིང་ངེ་འཛིན་དེ་ཡང་སའི་སྒོ་ནས་དབྱེ་ན་དགུ་སྟེ། བསམ་གཏན་གྱི་ས་དྲུག་དང་། གཟུགས་མེད་དང་པོ་གསུམ
Enumeration Block 13:
དམིགས་པའི་སྒོ་ནས་དབྱེ་ན་བཞི་སྟེ།
Enumeration Block 14:
རྣམ་པའི་སྒོ་ནས་དབྱེ་ན་བཅུ་དྲུག་སྟེ།
Enumeration Block 15:
གསུམ་པ་ཁྱད་པར་གྱི་ཆོས་འཆད་པ་ན་ས་དང་ལམ་གྱི་ཁྱད་པར་དང་། ཟད་པ་དང་མི་སྐྱེ་བ་ཤེས་པའི་ཁྱད་པར་དང་། འབྲས་བུའི་རྣམ་པར་བཞག་པའི་ཁྱད་པར་དང་། ཆོས་ཀྱི་འཁོར་ལོའི་ཁྱད་པར་དང་། ཁམས་དང་དབྱེ་བའི་ཁྱད་པར་དང་། རིགས་དང་ཉམས་པའི་ཁྱད་པར་དང་། དབང་པོ་འཕོ་བའི་ཁྱད་པར་བདུན་ལས
Enumeration Block 16:
སྒོམ་པའི་ལམ་ནི་འཇིག་རྟེན་དང་དེ་ལས་འདས་པ་གཉིས་ལས
Enumeration Block 17:
འབྲས་བུ་ནི་འདུས་བྱས་དང་འདུས་མ་བྱས་གཉིས་ཡིན་ཏེ
