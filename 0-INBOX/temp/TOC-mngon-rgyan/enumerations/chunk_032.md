Enumeration Block 1:
ཡོངས་སུ་ཉམས་པ་ནི་རྣམ་པ་གསུམ་དུ་ཤེས་པར་བྱའོ་ཞེས་སྦྱར་རོ། །གང་ཡིན་ཞེ་ན། ཡོན་ཏན་ཐོབ་པ་ལས་ཉམས་པ་དང་མ་ཐོབ་པ་ལས་ཉམས་པ་དང་ཐོབ་པ་ཉེ་བར་སྤྱད་པ་ལས་ཉམས་པའོ། །
Enumeration Block 2:
ཡང་དགྲ་བཅོམ་པ་དེ་དག་ནི་རྣམ་པ་དགུར་དབྱེ་སྟེ། སངས་རྒྱས་དང་རང་སངས་རྒྱས་གཉིས་དང་། ཉན་ཐོས་ཡོངས་སུ་ཉམས་པའི་ཆོས་ཅན་ལ་སོགས་པ་ལྔ་དང་། མི་གཡོ་བ་ལ་སྦྱངས་པ་ལས་གྱུར་པ་དང་། དང་པོ་ནས་མི་གཡོ་བའི་ཆོས་ཅན་ཏེ་མི་གཡོ་བ་གཉིས་ཏེ་བདུན་ནོ། །
Enumeration Block 3:
གཉིས་པ་གང་ཟག་བདུན་དུ་བསྡུ་བ་ནི་འཕགས་པའི་གང་ཟག་ནི་བདུན་ཏེ། དད་པས་རྗེས་འབྲང་དང་། ཆོས་ཀྱི་རྗེས་འབྲང་དང་། དད་པས་མོས་པ་དང་། མཐོང་བས་ཐོབ་པ་དང་། ལུས་ཀྱིས་མངོན་སུམ་དུ་བྱེད་པ་དང་། ཤེས་རབ་ཀྱིས་རྣམ་པར་གྲོལ་བ་དང་། སངས་རྒྱས་གཉིས་ཀྱང་འདིར་འདུས་སོ་གཉིས་ཀའི་ཆ་ལས་རྣམ་པར་གྲོལ་བའོ། །
Enumeration Block 4:
ལྔ་པ་མངོན་པར་རྟོགས་པའི་ལམ་སྟོན་པ་ནི་ལམ་གྱི་དབྱེ་བ་དང་། བྱང་ཆུབ་ཀྱི་ཕྱོགས་དང་མཐུན་པའི་ལམ་བཤད་པ་གཉིས་ལས།
Enumeration Block 5:
ལམ་ཐམས་ཅད་ནི་འཆད་པ་ན་འདོན་པ་བསྒྱུར་ཏེ། སྦྱོར་དང་བར་ཆད་མེད་པ་དང་། །རྣམ་གྲོལ་ཁྱད་པར་ཅན་ཞེས་བྱ་བ་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ།
Enumeration Block 6:
གཉིས་པ་ལ་རྫས་ཡོད་དང་བརྟགས་ཡོད་ཀྱི་ཁྱད་པར་དང་། གོ་རིམ་གྱི་ཁྱད་པར་དང་། ངོ་བོ་དང་སའི་ཁྱད་པར་དང་། ཤེས་ནས་དད་པའི་ཁྱད་པར་དང་། མི་སློབ་པའི་ཆོས་བཅུའི་ཁྱད་པར་བཤད་པ་ལྔ་ལས།
