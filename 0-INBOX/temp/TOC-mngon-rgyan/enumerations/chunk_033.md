Enumeration Block 1:
དེ་དག་ལས་གཞན་དྲན་པ་ཉེར་གཞག་ནས་སྟོབས་ཀྱི་བར་དག་ནི་གནས་སྐབས་ཁྱད་པར་ཅན་དང་ཁྱད་པར་ཅན་མ་ཡིན་པའི་སྒོ་ནས་ཟག་བཅས་དང་ཟག་མེད་རྣམ་པ་གཉིས་ཡིན་ཏེ།
Enumeration Block 2:
རྣམ་པར་གྲོལ་བ་དེ་ཡང་འདུས་བྱས་དང་འདུས་མ་བྱས་རྣམ་པ་གཉིས་ཡོད་པ་ལས།
Enumeration Block 3:
ཡིད་འབྱུང་བ་དང་འདོད་ཆགས་དང་བྲལ་བ་ལ་མུ་བཞི་སྲིད་དེ།
Enumeration Block 4:
ད་ནི་གནས་བདུན་པ་འཆད་པ་ན་བཟོད་པ་དང་ཤེས་པ་དང་ལྟ་བའི་ཁྱད་པར་བཤད་པ་དང་། ཤེས་པ་བྱེ་བྲག་ཏུ་བཤད་པ་དང་། དེ་དག་གི་ཡོན་ཏན་བཤད་པ་གསུམ་ལས།
Enumeration Block 5:
ཤེས་པ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་ཤེས་པའི་ངོ་བོའི་དབྱེ་བ་དང་། གྲངས་ངེས་པ་དང་། རྣམ་པ་དང་། ས་དང་བརྟེན་པ་དང་། དྲན་པ་ཉེར་གཞག་ཏུ་བཞག་པ་དང་། དམིགས་པ་དང་། ལྡན་པའི་ཚུལ་དང་། ཐོབ་པའི་ཚུལ་བརྒྱད་ཡོད་པ་ལས།
Enumeration Block 6:
ཤེས་པ་ནི་བཅུ་སྟེ། ཆོས་དང་རྫས་དང་ཀུན་རྫོབ་དང་། གཞན་གྱི་སེམས་དང་སྡུག་བསྔལ་དང་། ཀུན་འབྱུང་བ་དང་འགོག་པ་དང་། ལམ་དང་ཟད་དང་མི་སྐྱེ་ཞེས། ཞེས་པ་བསྡུ་ཚིག་གོ་འདི་ལྟ་སྟེ། ཆོས་ཤེས་པ་དང་། རྗེས་སུ་ཤེས་པ་དང་། ཀུན་རྫོབ་ཤེས་པ་དང་། ཕ་རོལ་གྱི་སེམས་ཤེས་པ་དང་། སྡུག་བསྔལ་ཤེས་པ་དང་། ཀུན་འབྱུང་ཤེས་པ་དང་། འགོག་པ་ཤེས་པ་དང་། ལམ་ཤེས་པ་དང་། ཟད་པ་ཤེས་པ་དང་། མི་སྐྱེ་བ་ཤེས་པའོ།
Enumeration Block 7:
ཤེས་པ་ཐམས་ཅད་རྣམ་པ་གཉིས་སུ་འདུས་ཏེ་ཟག་པ་དང་བཅས་པ་དང་ཟག་པ་མེད་པའོ། །
