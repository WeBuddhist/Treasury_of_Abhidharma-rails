Enumeration Block 1:
རྫུ་འཕྲུལ་གྱིས་འགྲོ་བ་ནི་རྣམ་པ་གསུམ་ཏེ། བྱ་བཞིན་དུ་རིམ་གྱིས་ལུས་ཀྱིས་མགྱོགས་པོར་ཕྱིན་པར་བྱེད་པ་ལུས་ཕྱིན་བྱེད་དང་། ལམ་ཐག་རིང་པོའང་ཐུང་ངུར་མོས་པ་བྱས་པས་མྱུར་དུ་སླེབ་པ་མོས་པ་ལས་བྱུང་བ་དང་། ཡིད་ཀྱིས་བསམས་པ་ཙམ་གྱིས་དེར་སླེབས་པའི་ཡིད་མགྱོགས་སོ། །
Enumeration Block 2:
སྤྲུལ་པ་ནི་རྟེན་འདོད་གཟུགས་ཀྱི་སྤྲུལ་པ་གཉིས་ལས་དང་པོ་ལ་ཡང་གཉིས་ལས།
Enumeration Block 3:
དེ་ལའང་བསམ་གཏན་དང་གཟུགས་མེད་བཤད་པ་དང་། དེ་ལ་བརྟེན་པའི་ཡོན་ཏན་བཤད་པ་གཉིས་ལས། དང་པོ་ལའང་ངོ་བོ་དང་། དབྱེ་བ་དང་། ཡན་ལག་རྣམ་པར་བཞག་པ་དང་། འཐོབ་པའི་ཚུལ་དང་། ཁྱད་པར་གྱི་ཆོས་དང་། ཉེར་བསྡོགས་དང་། ཏིང་ངེ་འཛིན་གྱི་དབྱེ་བ་བཤད་པ་བདུན་ལས།
Enumeration Block 4:
བསམ་གཏན་དག་ནི་མདོར་བསྡུས་ན་འབྲས་བུ་སྐྱེ་བ་དང་། རྒྱུ་སོམས་པར་འཇུག་པ་རྣམ་པ་གཉིས་ཡིན་ལ།
Enumeration Block 5:
བསམ་གཏན་བཞི་དང་གཟུགས་མེད་བཞི་སྟེ་སྙོམས་པར་འཇུག་པའི་དངོས་གཞིའི་རྫས་ནི་རྣམ་པ་བརྒྱད་ཡིན་ལ།
Enumeration Block 6:
བརྒྱད་པོ་དེ་དག་ལས་སྲིད་རྩེ་མ་གཏོགས་པ་བདུན་ནི་རྣམ་པ་གསུམ་གསུམ་ཡིན་ཏེ། རོ་མྱང་བ་དང་མཚུངས་པར་ལྡན་པ་དང་། དག་པ་པ་དང་། ཟད་པ་མེད་པ་རྣམས་སོ། །
Enumeration Block 7:
བརྒྱད་པ་སྲིད་རྩེ་ནི་རོ་མྱང་ལྡན་དང་དག་པ་པ་རྣམ་པ་གཉིས་ཡིན་གྱི།
Enumeration Block 8:
གསུམ་པ་ཡན་ལག་རྣམ་པར་བཞག་པ་ལ་གཉིས་ལས་སྤྱིའི་དོན་ལ་གསུམ་གྱི།
Enumeration Block 9:
འདིའི་ལག་ལ་གཞན་ལུགས་དང་། རང་ལུགས་གཉིས་ལས།
