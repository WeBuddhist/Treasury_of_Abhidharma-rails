Enumeration Block 1:
ཆོས་མངོན་པ་མཛོད་ཀྱི་མདོ་དོན་འཆད་པའི་ཐབས་ཡན་ལག་ལྔ་ལས།
Enumeration Block 2:
འཁོར་བར་འཇུག་པ་ལ། གང་ལ་བརྟེན་ནས་འཇུག་པ། གང་གིས་གང་དུ་འཇུག་པ། གང་གི་དབང་གིས་འཇུག་པ་གསུམ་ལས།
Enumeration Block 3:
དང་པོ་ལ། མཆོད་བརྗོད་དང༌། རྩོམ་པར་དམ་བཅའ་བ་གཉིས།
Enumeration Block 4:
དགོས་དོན། བསྡུས་དོན། ཚིག་དོན་གསུམ་ལས།
Enumeration Block 5:
གསུམ་པ་ལ་དངོས་དང༌། མཐའ་དཔྱད་པ་གཉིས་ལས།
Enumeration Block 6:
སྤྱི་དོན་དང༌། གཞུང་དོན་གཉིས་ལས།
Enumeration Block 7:
སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་གཉིས་ལས།
Enumeration Block 8:
ཟག་བཅས་ཟག་པ་མེད་ཆོས་རྣམས། །ཞེས་པའི་སྐབས་སུ་གཉིས་ལས།
Enumeration Block 9:
གཉིས་པ་ལ། མདོར་བསྟན་དང༌། རྒྱས་བཤད་གཉིས་ལས། དང་པོ་ནི། ཟག་བཅས་མདོར་བསྟན་པ་དང༌། ཟག་མེད་མདོར་བསྟན་པའོ། །
Enumeration Block 10:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། །འདུས་མ་བྱས་རྒྱས་པར་བཤད་པ། འདུས་བྱས་རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 11:
སྐབས་འདིར་སྤྱི་དོན་དང་གཞུང་དོན་གཉིས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། རྣམ་གྲངས། སྒྲ་བཤད་པ། ཕུང་པོ་ལྔ་རྫས་གཅིག་དང་རྫས་ཐ་དད་ལ་དཔྱད་པའོ། །
Enumeration Block 12:
སྤྱི་དོན། གཞུང་དོན་གཉིས་ལས།
Enumeration Block 13:
གཡེངས་དང་སེམས་མེད་པ་ཡི་ཡང༌། །ཞེས་སོགས་རྐང་བ་བཞིའི་སྐབས་སུ། གཉིས་ལས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། སྒྲུབ་བྱེད་ཀྱི་རིགས་པ། ཆོས་ཀྱི་ཁྱད་པར། རྩོད་པ་སྤོང་བའོ། །
