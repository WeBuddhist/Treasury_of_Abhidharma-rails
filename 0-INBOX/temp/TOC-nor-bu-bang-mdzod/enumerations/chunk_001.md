Enumeration Block 1:
གཉིས་པ་འདུས་བྱས་རྒྱས་པར་བཤད་པ་ལ། སྤྱིར་བསྟན་པ་དང༌། སོ་སོར་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གནས་བརྒྱད་ཡོད་པའི་ནང་ནས། དང་པོ་ཁམས་སྟོན་པའི་གནས་དེ་འཆད་པ་ལ། འདུས་བྱས་ཕྱོགས་ཀྱི་མིང་གི་རྣམ་གྲངས། ཕུང་ཁམས་སྐྱེ་མཆེད་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 3:
སྤྱི་དོན་དང་གཞུང་དོན་གཉིས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། རྣམ་གྲངས། སྒྲ་བཤད་པ། ཕུང་པོ་ལྔ་རྫས་གཅིག་དང་རྫས་ཐ་དད་ལ་དཔྱད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་སྤྱིར་འདུས་བྱས་ཀྱི་མིང་གི་རྣམ་གྲངས་དང༌། བྱེ་བྲག་ཏུ་ཟག་བཅས་ཀྱི་མིང་གི་རྣམ་གྲངས་སོ། །
Enumeration Block 5:
གསུམ་པ་ལ། ཕུང་ཁམས་སྐྱེ་མཆེད་ཀྱི་རང་བཞིན། །ཆོས་གཞན་སྐྱེས་ཚུལ། ཁམས་ཀྱི་རྣམ་པའི་རབ་དབྱེ། དང་པོ་ལ། རང་བཞིན་དངོས། གསུམ་པོ་སོ་སོའི་སྒྲ་དོན། དགོས་པ་དང་བཅས་པ། དེ་དག་ངེས་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 6:
རྐང་པ་གཉིས་ཀྱི་སྐབས་སུ། སྤྱི་དོན། གཞུང་དོན་ནོ། །
