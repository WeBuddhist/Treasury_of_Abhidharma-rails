Enumeration Block 1:
དབྱེ་ན་བརྒྱད་ཡོད་དེ། ཟིན་པའི་འབྱུང་བ་ལས་གྱུར་བའི་སྒྲ། མ་ཟིན་པའི་འབྱུང་བ་ལས་གྱུར་པའི་སྒྲ་གཉིས་ལས། དང་པོ་ལ་བཞི། དེ་ལྟ་བུའི་སེམས་ཅན་དུ་སྟོན་པའི་སྙན་པའི་སྒྲ། མི་སྙན་པའི་སྒྲ་དང་གཉིས། སེམས་ཅན་དུ་མི་སྟོན་པའི་སྒྲ་སྙན་མི་སྙན་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལའང་བཞི། དེ་ལྟ་བུའི་སེམས་ཅན་དུ་སྟོན་པའི་སྙན་མི་སྙན་གཉིས། སེམས་ཅན་དུ་མི་སྟོན་པའི་དེ་གཉིས་སོ། །
Enumeration Block 3:
སྐབས་སུ། གཉིས་ལས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། སྒྲུབ་བྱེད་ཀྱི་རིགས་པ། ཆོས་ཀྱི་ཁྱད་པར། རྩོད་པ་སྤོང་བའོ། །
Enumeration Block 4:
ཁྱད་ཆོས་ལྔ་དང་ལྡན་ཏེ། གནས་སྐབས་ཀྱི་ཁྱད་པར། ངོ་བོའི་ཁྱད་པར། དུས་ཀྱི་ཁྱད་པར། རྒྱུའི་ཁྱད་པར། ངེས་ཚིག་གི་ཁྱད་པར་དང་ལྡན་པའི་ཕྱིར།
Enumeration Block 5:
སྡོམ་པ། སྡོམ་མིན། བར་མའི་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་གཟུགས་གསུམ་ཡོད་དེ།
Enumeration Block 6:

Enumeration Block 7:

Enumeration Block 8:
དེ་ལྟར་བསྟན་པ་ལ་དགོས་པ་ཡོད་དེ། རྨོངས་པ་རྣམ་པ་གསུམ་ཟློག་པའི་ཕྱིར་དང༌། དབང་པོ་རྣོ་འབྲིང་རྟུལ་གསུམ་རྗེས་སུ་གཟུང་བའི་ཕྱིར་དང༌། ཚིག་གི་སྤྲོས་པ་མདོར་བསྡུས་དང༌། འབྲིང་དང༌། རྒྱས་པ་འདོད་པ་རྗེས་སུ་གཟུང་བའི་ཆེད་དུ་དེ་ལྟར་བསྟན་པའི་ཕྱིར།
Enumeration Block 9:
ནམ་མཁའི་ཁམས་ལ་བཞི་ཡོད་དེ། རྒྱན་ནམ་མཁའ། མངོན་པར་སྐབས་ཡོད་ཀྱི་ནམ་མཁའ། བུ་ག་ནམ་མཁའ། འདུས་བྱས་ཀྱི་ནམ་མཁའ་དང་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 10:
ཁམས་ཀྱི་རྣམ་པའི་རབ་དབྱེ་ལ་བདུན། ངོ་བོ་ལ་ལྟོས་པའི་རབ་དབྱེ། གྲོགས་ལ་ལྟོས་པའི། །རྒྱུ་འབྲས་ལ་ལྟོས་པའི། མོང་དོན་ལ་ལྟོས་པའི། སྤང་བྱ་ལ་ལྟོས་པའི། བྱེད་པ་ལ་ལྟོས་པའི། རབ་དབྱེ་གཞན་བསྟན་པ། དང་པོ་ལ་བསྟན་ཡོད་བསྟན་མེད་ཀྱི་ཁྱད་པར། ཐོགས་བཅས་ཐོགས་མེད་ཀྱི་ཁྱད་པར། དགེ་མི་དགེ་ལུང་མ་བསྟན་གསུམ་གྱི་ཁྱད་པར། ཁམས་གསུམ་གང་རུང་དུ་གཏོགས་པ་དུ་ཡོད་ཀྱི་ཁྱད་པར་དང་བཞི་ཡོད་དེ།
Enumeration Block 11:
གཉིས་པ་གྲོགས་ལ་ལྟོས་བའི་རབ་དབྱེ་ལ། ཟག་བཅས་ཟག་མེད་ཀྱི་ཁྱད་པར། རྟོག་དཔྱོད་དང་བཅས་མ་བཅས་ཀྱི། དམིགས་བཅས་དམིགས་མེད་ཀྱི། ཟིན་མ་ཟིན་གྱི། འབྱུང་བ་འབྱུང་འགྱུར་གྱི། བསགས་མ་བསགས་ཀྱི། གཅོད་བྱེད་གཅད་བྱའི་ཁྱད་པར་ཏེ་བདུན་ཡོད་དེ།
Enumeration Block 12:
གསུམ་པ་ལ། བྱུང་བ་གསུམ་གྱི་ཁྱད་པར། བཏགས་རྫས་ཡིན་མིན་གྱི། ཐོབ་པའི་ཁྱད་པར་ཏེ་གསུམ་ཡོད་དེ།
Enumeration Block 13:
བཞི་པ་ལ། ཕྱི་ནང་གི་ཁྱད་པར། རྟེན་བཅས་དེ་མཚུངས་ཀྱི་ཁྱད་པར་གཉིས་ཡོད་དེ།
Enumeration Block 14:

Enumeration Block 15:
དྲུག་པ་ལ། ལྟ་བ་དང་ལྟ་མིན་གྱི་ཁྱད་པར། དབང་པོས་ཡུལ་འཛིན་ཚུལ་གྱི་ཁྱད་པར། རྟེན་གྱི་ཡུལ་ངེས་པ། དབང་པོ་རྟེན་དུ་འཇོག་ཚུལ། དབང་པོ་ལྔ་ལ་རང་མིང་གི་འདོགས་པའི་རྒྱུ་མཚན། ཡུལ་དབང་རྟེན་གསུམ་གྱི་མཚུངས་པ་རྩི་བ་དང་དྲུག་ཡོད།
Enumeration Block 16:
བདུན་པ་ནི། རྣམ་པར་ཤེས་པ་གང་གིས་ཤེས་པར་བྱ་བ། རྟག་མི་རྟག་གི་ཁྱད་པར། དབང་པོ་དང་དབང་པོ་མ་ཡིན་པའི་ཁྱད་པར་དང་གསུམ་ཡོད་དེ།
Enumeration Block 17:
གཉིས་པ་དབང་པོ་སྟོན་པའི་གནས་བཤད་པ་ལ། དབང་པོའི་རྣམ་གཞགའདུས་བྱས་ཀྱི་སྐྱེ་ཚུལ། རྒྱུ་རྐྱེན་འབྲས་གསུམ་བཤད་པའོ། །དང་པོ་ལ། དབང་པོའི་རང་བཞིན། སྐབས་སུ་བབས་པའི་དབང་པོའི་ངོ་བོ། རྣམ་པའི་རབ་དབྱེ། རྙེད་གཏོང༌། དགེ་སྦྱོང་ཚུལ་གྱི་འབྲས་བུ་དབང་པོ་དུས་ཐོབ་པ། དབང་པོའི་ལྡན་ཚུལ་ལོ། །
Enumeration Block 18:

Enumeration Block 19:
དོན་བཞི་ལ་དབང་བྱེད་དེ། རྟེན་མཛེས་པར་བྱེད། ལུས་སྲུང་བར་བྱེད། རང་གི་རྣམ་ཤེས་མཚུངས་ལྡན་དང་བཅས་པར་སྐྱེད་བར་བྱེད། རང་རང་གི་ཡུལ་འཛིན་པའི་ཐ་སྙད་ཐུན་མོང་མ་ཡིན་པ་བཞི་ལ་དབང་བྱེད་པའི་ཕྱིར།
Enumeration Block 20:
དོན་གཉིས་གཉིས་ལ་ལྷག་པར་དབང་བྱེད་དེ། ཡིད་དབང་གིས་ཡང་སྲིད་དུ་ཉིང་མཚམས་སྦྱོར་བ་དང༌། ཡིད་དབང་གི་ངོ་བོ་དང་མཐུན་པར་དབང་བྱེད། སྲོག་གི་དབང་པོས། རིས་མཐུན་ཉིང་མཚམས་སྦྱར་བ་དང་རིས་མཐུན་གནས་པ་གཉིས་ལ་དབང་བྱེད། ཕོ་མོའི་དབང་པོས་སེམས་ཅན་གྱི་བྱེ་བྲག་འབྱེད་པ་དང༌། ཁྱད་པར་འབྱེད་པ་གཉིས་ལ་དབང་བྱེད་པའི་ཕྱིར།
