Enumeration Block 1:
རྣམ་པར་ཤེས་པ་གང་གིས་ཤེས་པར་བྱ་བ། རྟག་མི་རྟག་གི་ཁྱད་པར། དབང་པོ་དང་དབང་པོ་མ་ཡིན་པའི་ཁྱད་པར་དང་གསུམ་ཡོད་དེ།
Enumeration Block 2:
དབང་པོ་སྟོན་པའི་གནས་བཤད་པ་ལ། དབང་པོའི་རྣམ་གཞགའདུས་བྱས་ཀྱི་སྐྱེ་ཚུལ། རྒྱུ་རྐྱེན་འབྲས་གསུམ་བཤད་པའོ། །དང་པོ་ལ། དབང་པོའི་རང་བཞིན། སྐབས་སུ་བབས་པའི་དབང་པོའི་ངོ་བོ། རྣམ་པའི་རབ་དབྱེ། རྙེད་གཏོང༌། དགེ་སྦྱོང་ཚུལ་གྱི་འབྲས་བུ་དབང་པོ་དུས་ཐོབ་པ། དབང་པོའི་ལྡན་ཚུལ་ལོ། །
Enumeration Block 3:
སྤྱི་དོན། གཞུང་དོན་གཉིས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། ངེས་ཚིགགང་གིས་གང་ལ་དབང་བྱེད་པ། གཞུང་དོན་དང་སྦྱར་ཏེ་བཤད་པའོ། །
Enumeration Block 4:
ཉེར་གཉིས་ཡོད་དེ། མིག་སོགས་དབང་པོ་དྲུག་སྲོག་གི་དབང་པོ། ཕོ་མོའི་དབང་པོ་གཉིས། ཚོར་བའི་དབང་པོ་ལྔ། དད་སོགས་དབང་པོ་ལྔ། ཟག་མེད་ཀྱི་དབང་པོ་གསུམ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
དབང་པོ་ལ་ཉེར་གཉིས་སུ་གྲངས་ངེས་ཏེ། ཀུན་ནས་ཉོན་མོངས་ཀྱི་ཕྱོགས་ལ་དང་པོ་བཅུ་བཞི། རྣམ་བྱང་གི་ཕྱོགས་ལ་ཕྱི་མ་བརྒྱད་དུ་གྲངས་ངེས་པའི་ཕྱིར།
Enumeration Block 6:
ལུས་ཚོར་སིམ་པ་མ་ཡིན་གང༌། །ཞེས་སོགས་ཤོ་ལོ་ཀ་གཅིག་གིས་སྐབས་སུ་གཉིས་ལས།
Enumeration Block 7:
རྣམ་བྱང་གི་དབང་པོ་རྒྱས་པར་བཤད་པ་ནི། མཐོང་སྒོམ་མི་སློབ་ལམ་ལ་དགུ། གསུམ་ཡིན། ཞེས་པའི་སྐབས་སུ་གཉིས་ལས།
Enumeration Block 8:
དབང་པོའི་རབ་དབྱེ་ལ་གྲོགས་ལ་ལྟོས་བའི་རབ་དབྱེ། རྒྱུ་འབྲས་ལ་ལྟོས་བའི། ངོ་བོ་ལ་ལྟོས་པའི། སྤང་བྱ་ལ་ལྟོས་པའི་རབ་དབྱེ་དང་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 9:
དབང་པོའི་ལྡན་ཚུལ་ལ། ངེས་ལྡན། སྲིད་ལྡན་གཉིས། དང་པོ་ལ། གསུམ། བཞི། ལྔ། བདུན། བཅུ་གཅིག བཅུ་གསུམ་ལྡན་ཏེ་རིམ་བཞིན་དུ་སྟོན་པ་ལ།
Enumeration Block 10:
སྲིད་ལྡན་ལ་ཉུང་ལྡན་མང་ལྡན་གཉིས།
Enumeration Block 11:
འདུས་བྱས་ཀྱི་སྐྱེ་ཚུལ་ལ། གཟུགས་ཅན་གྱི་སྐྱེ་ཚུལ་དང༌། གཟུགས་ཅན་མ་ཡིན་པའི་སྐྱེ་ཚུལ་གཉིས།
Enumeration Block 12:
འདོད་ན་དབང་པོ་མེད་པ་དང༌། ཞེས་སོགས་རྐང་བ་བཞིའི་སྐབས་སུ། །གཉིས་ལས།
Enumeration Block 13:
གཞན་རྣམས་ཀྱི་སྐྱེ་ཚུལ་ལ། རྡུལ་ལ་རྫས་ཀྱི་རྡུལ་དང༌། བསགས་པའི་རྡུལ་གཉིས་ལས།
Enumeration Block 14:
གཟུགས་ཅན་མ་ཡིན་པའི་སྐྱེ་ཚུལ་ལ། བསྟན། བཤད་གཉིས་ལས། དང་པོ་ནི། སེམས་དང་སེམས་བྱུང་ངེས་ལྷན་ཅིག ཞེས་སོགས་རྐང་པ་ཕྱེད་དང་གསུམ་གྱི་སྐབས་སུ། གཉིས་ལས།
Enumeration Block 15:
སེམས་བྱུང་ལ་དབྱེ་ན། སྡེ་ཚན་དུ་ངེས་པའི་སེམས་བྱུང༌། སྡེ་ཚན་དུ་མ་ངེས་པའི་སེམས་བྱུང་གཉིས། དང་པོ་ལ། སེམས་ཀྱི་ས་མང༌། དགེ་བའི་ས་མང༌། ཉོན་མོངས་ཆེན་པོའི་ས་མང༌། མི་དགེ་བའི་ས་མང༌། ཉོན་མོངས་ཆུང་ངུའི་ས་མང་རྣམས་སུ་ཡོད།
Enumeration Block 16:
སྡེ་ཚན་དུ་མ་ངེས་པའི་སེམས་བྱུང་ལ་བརྒྱད་ཡོད་དེ།
Enumeration Block 17:
ས་མང་རྒྱས་པར་བཤད་པ་ལ། །མཚུངས་ལྡན་གྱི་འདུ་བྱེད་དང༌། མཚུངས་ལྡན་མ་ཡིན་པའི་འདུ་བྱེད་བཤད་པའོ། །
Enumeration Block 18:
སེམས་དང་ཡིད་དང་རྣམ་ཤེས་ནི། །ཞེས་སོགས་རྐང་པ་བཞིའི་སྐབས་སུ། གཉིས་ལས།
