Enumeration Block 1:
གཉིས་པ་ལ་གནས་བརྒྱད་ཡོད་པའི་ནང་ནས། དང་པོ་ཁམས་སྟོན་པའི་གནས་དེ་འཆད་པ་ལ། འདུས་བྱས་ཕྱོགས་ཀྱི་མིང་གི་རྣམ་གྲངས། ཕུང་ཁམས་སྐྱེ་མཆེད་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 2:
སྐབས་འདིར་སྤྱི་དོན་དང་གཞུང་དོན་གཉིས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། རྣམ་གྲངས། སྒྲ་བཤད་པ། ཕུང་པོ་ལྔ་རྫས་གཅིག་དང་རྫས་ཐ་དད་ལ་དཔྱད་པའོ། །
Enumeration Block 3:
དབྱེ་ན། གཟུགས་སོགས་དོན་ལྔ། མིག་སོགས་དབང་པོ་ལྔ། རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་གཟུགས་ཏེ་བཅུ་གཅིག་གོ། །
Enumeration Block 4:
གཟུགས་བཅུ་གཅིག་ཡོད་དེ། དབང་པོ་ལྔ། དོན་ལྔ། རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་གཟུགས་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
དབྱེ་ན། མིག་གི་དབང་པོ་གཟུགས་ཅན་པ་ནས། ལུས་ཀྱི་དེའི་བར་ལྔ།
Enumeration Block 6:
དབྱེ་ན། རེ་རེ་ལ་རྟེན་བཅས་དང་དེ་མཚུངས་ཀྱི་རེ་རེ་སྟེ་གཉིས་གཉིས་ཡོད།
Enumeration Block 7:
རྐང་པ་བཞིའི་སྐབས་སུ། སྤྱི་དོན། གཞུང་དོན་གཉིས་ལས།
Enumeration Block 8:
རྒྱས་པར་དབྱེ་ན་ཉི་ཤུ་ཡོད་དེ། ཁ་དོག་གི་གཟུགས་བཅུ་གཉིས། དབྱིབས་ཀྱི་གཟུགས་བརྒྱད་ཡོད་པའི་ཕྱིར།
Enumeration Block 9:
ཉི་ཤུ་པོ་དེ་ལ་ཡང་མུ་གསུམ་ཡོད་དེ། ཁ་དོག་ཁོ་ན་ཡིན་ལ། དབྱིབས་ཁོ་ན་ཡིན་པ། གཉིས་ཀ་ཡིན་པ་གསུམ་ཡོད་པའི་ཕྱིར་ཏེ།
Enumeration Block 10:
དབྱེ་ན་བརྒྱད་ཡོད་དེ། ཟིན་པའི་འབྱུང་བ་ལས་གྱུར་བའི་སྒྲ། མ་ཟིན་པའི་འབྱུང་བ་ལས་གྱུར་པའི་སྒྲ་གཉིས་ལས། དང་པོ་ལ་བཞི། དེ་ལྟ་བུའི་སེམས་ཅན་དུ་སྟོན་པའི་སྙན་པའི་སྒྲ། མི་སྙན་པའི་སྒྲ་དང་གཉིས། སེམས་ཅན་དུ་མི་སྟོན་པའི་སྒྲ་སྙན་མི་སྙན་གཉིས།
Enumeration Block 11:
གཉིས་པ་ལའང་བཞི། དེ་ལྟ་བུའི་སེམས་ཅན་དུ་སྟོན་པའི་སྙན་མི་སྙན་གཉིས། སེམས་ཅན་དུ་མི་སྟོན་པའི་དེ་གཉིས་སོ། །
Enumeration Block 12:
དབྱེ་ན་དྲུག་ཡོད་དེ། མངར་སྐྱུར་གཉིས། ཚ་བ་ལན་ཚ་བ་གཉིས་ཁ་བ་བསྐ་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 13:
དབྱེ་ན་བཞི་ཡོད་དེ། དྲི་ཞིམ་མི་ཞིམ། མཉམ་མི་མཉམ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 14:
དབྱེ་ན་བཅུ་གཅིག་ཡོད་དེ། འབྱུང་བ་བཞིའི་རེག་བྱ་བཞི། འབྱུང་འགྱུར་བཞིའི་རེག་བྱ་བདུན་ཡོད་པའི་ཕྱིར།
Enumeration Block 15:
དོན་ལྔ་སོ་སོའི་དབྱེ་བ་བཞག་ཏུ་ཡོད་དེ། གཟུགས་ལ་རྣམ་པ་ཉི་ཤུ། སྒྲ་ལ་བརྒྱད། རོ་ལ་དྲུག དྲི་ལ་བཞི། རེག་བྱ་ལ་བཅུ་གཅིག་ཡོད་པའི་ཕྱིར།
Enumeration Block 16:
རྐང་བ་བཞིའི་སྐབས་སུ། གཉིས་ལས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། སྒྲུབ་བྱེད་ཀྱི་རིགས་པ། ཆོས་ཀྱི་ཁྱད་པར། རྩོད་པ་སྤོང་བའོ། །
Enumeration Block 17:
སྡོམ་པ། སྡོམ་མིན། བར་མའི་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་གཟུགས་གསུམ་ཡོད་དེ།
Enumeration Block 18:
འདིའི་སྐབས་སུ། གཉིས་ལས།
