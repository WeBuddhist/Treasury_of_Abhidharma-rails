Enumeration Block 1:
དབྱེ་ན་བཅུ་བཞི་ཡོད་དེ། ཐོབ་པ། མ་ཐོབ་པ། སྐལ་མཉམ། འདུ་ཤེས་མེད་པ། འདུ་ཤེས་མེད་པའི་སྙོམས་འཇུགའགོག་པའི་སྙོམས་འཇུག སྲོག་དང་མཚན་ཉིད་བཞི། ཚོགས་གསུམ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
དང་པོ་ལ། ཐོབ་པ་བཤད་པ་དང༌། མ་ཐོབ་པ་བཤད་པ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་ལས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། དེའི་ཁྱད་པར་གྱི་ཆོས།
Enumeration Block 4:
ཐོབ་པ་ལ་དབྱེ་ན་གསར་དུ་ཐོབ་པ། ཐོབ་པའི་ཐོབ་པ་གཉིས་ལས། རྙེད་པ་ལ་དབྱེ་ན། གསར་དུ་རྙེད་པ། ཉམས་པ་ལས་རྙེད་པ་གཉིས། ལྡན་པ་ལ་དབྱེ་ན། ཉམས་པ་ལས་ལྡན་པ། ཐོབ་ནས་ལྡན་པའི་ལྡན་པ་གཉིས། གསུམ་པ་ལ། ཐོབ་པ་རྫས་ཡོད་དུ་བཤད་པ། ཐོབ་པ་ཐོབ་པའི་ཐོབ་པ། ཐོབ་བྱའི་ཆོས་གསུམ་གྱི་ཁྱད་པར་བཤད་པ། རྒྱུད་ཀྱིས་བསྡུས་མ་བསྡུས་ཀྱི་ཁྱད་པར། དུས་གསུམ་གྱི་ཁྱད་པར། དགེ་སོགས་གསུམ་གྱི་ཁྱད་པར། ཁམས་གསུམ་གྱི་ཁྱད་པར། སློབ་མི་སློབ་ཀྱི་ཁྱད་པར། སྤང་བྱ་ཡིན་མ་ཡིན་གྱི་ཁྱད་པར། དམིགས་བསལ་བཤད་པ་དང་དགུ།
Enumeration Block 5:
གཉིས་ལས། དང་པོ་ནི། མཚན་ཉིད། དབྱེ་བ། ཁྱད་པར་གྱི་ཆོས་གསུམ།
Enumeration Block 6:
དེ་ལ་རྙེད་པའི་མ་ཐོབ་པ་མ་རྙེད་པའི་མ་ཐོབ་པ། མི་ལྡན་པའི་མ་ཐོབ་པ་གསུམ་ཡོད།
Enumeration Block 7:
མཚན་ཉིད། དབྱེ་བ། དྭོགས་པར་གཅོད་པ་གསུམ།
Enumeration Block 8:
གཉིས་པ་ནི། ཐ་དད་མ་ཡིན་པའི་སྐལ་མཉམ་དང་ཐ་དད་པའི་སྐལ་མཉམ་གཉིས།
Enumeration Block 9:
དེ་ལ་གཟུགས་ཅན་དུ་གྱུར་པའི་སྲོགཤེས་པར་གྱུར་པའི་སྲོག་ལྡན་མིན་འདུ་བྱེད་དུ་གྱུར་པའི་སྲོག་གསུམ་ཡོད།
Enumeration Block 10:
གསུམ་པ་རྒྱུ་རྐྱེན་འབྲས་བུ་གསུམ་བཤད་པ་ལ། རྒྱུ་བཤད་པ། འབྲས་བུ་བཤད་པ། རྐྱེན་བཤད་པའོ། །
Enumeration Block 11:
སྤྱི་དོན་དང༌། གཞུང་དོན་གཉིས།
Enumeration Block 12:
བྱེད་རྒྱུ། ལྷན་ཅིག་འབྱུང་བའི་རྒྱུ། སྐལ་མཉམ་གྱི་རྒྱུ། མཚུངས་ལྡན་གྱི་རྒྱུ། ཀུན་འགྲོའི་རྒྱུ། རྣམ་སྨིན་གྱི་རྒྱུ་རྣམས་སུ་ཡོད་དོ། །
Enumeration Block 13:
གཉིས་ལས། དང་པོ་ནི། འབྲས་བུའི་མཚན་ཉིད། དབྱེ་བ། སོ་སོའི་རང་བཞིན། འབྲས་བུ་གང་རྒྱུ་གང་གི་འབྲས་བུ་ཡིན་པ། དེ་དག་ལ་དྭོགས་པ་གཅོད་པ་དང་ལྔ།
Enumeration Block 14:
དེ་ལ་ལྔ་ཡོད་དེ་རྣམ་སྨིན་གྱི་འབྲས་བུ། རྒྱུ་མཐུན་གྱི་འབྲས་བུ། བྲལ་བའི་འབྲས་བུ། སྐྱེས་བུ་བྱེད་པའི་འབྲས་བུ། བདག་འབྲས་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 15:
དབྱེ་ན། སྐྱེད་པའི་སྐྱེས་བུའི་བྱེད་འབྲས། ཐོབ་པའི་སྐྱེས་བུའི་བྱེད་འབྲས་གཉིས་ཡོད།
Enumeration Block 16:
གསུམ་པ་རྐྱེན་བཤད་པ་ལ། བསྟན་བཤད་གཉིས།
Enumeration Block 17:
གཉིས་ལས། དང་པོ་ལ། རྐྱེན་ལ་མཚན་ཉིད། དབྱེ་བ། སོ་སོའི་རང་བཞིན། རྐྱེན་གང་གི་དུས་གང་ལ་བྱ་བ་བྱེད་པ། དངོས་པོ་གང་རྐྱེན་དུས་སྐྱེད་པའོ། །
Enumeration Block 18:
དེ་ལ་རྒྱུ་རྐྱེན། དེ་མ་ཐག་རྐྱེན། དམིགས་རྐྱེན། བདག་རྐྱེན་དང་བཞི་ཡོད།
Enumeration Block 19:
གཉིས་ལས། དང་པོ་ནི། སྤྱིར་སེམས་ཀྱི་དབྱེ་བ་བཤད་པ། དེ་མ་ཐག་རྐྱེན་དང་སྦྱར་བ། ཁམས་གསུམ་གྱི་ཉོན་མོངས་ཅན་གྱི་སེམས་གང་མངོན་དུ་གྱུར་པ་ན་གསར་དུ་དུ་རྙེད་དཔྱད་པའོ། །དང་པོ་ལ། སེམས་བཅུ་གཉིས་སུ་དབྱེ་བ། ཉི་ཤུར་དབྱེ་བ། དེ་གཉིས་གང་ཁྱབ་ཆེ་བཤད་པའོ། །
Enumeration Block 20:
སེམས་ལ་བཅུ་གཉིས་ཡོད་དེ། འདོད་བའི་སས་བསྡུས་ཀྱི་དགེ་སེམས། །མི་དགེའི་སེམས། སྒྲིབ་ལུང་མ་བསྟན་གྱི་སེམས། མ་སྒྲིབ་ལུང་མ་བསྟན་གྱི་སེམས་ཏེ་བཞི། ཁམས་གོང་མ་གཉིས་ན་མི་དགེ་བ་གཉིས་དོར་བའི་གསུམ་གསུམ། སློབ་པའི་ཟག་མེད་ཀྱི་སེམས་མི་སློབ་པའི་ཟག་མེད་ཀྱི་སེམས་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 21:
སེམས་ཉི་ཤུ་ཡོད་དེ། ཁམས་གསུམ་གྱི་དགེ་སེམས་ལ་སྐྱེས་ཐོབ་དང་སྦྱོར་བྱུང་གི་དགེ་བ་གཉིས་གཉིས་སུ་ཕྱེ་བས་དྲུག། འདོད་པའི་མ་སྒྲིབ་ལུང་མ་བསྟན་གྱི་སེམས་ལ་རྣམ་སྨིན་སྐྱེས་གྱི། སྤྱོད་ལམ་པའི། བཟོ་གནས་པའི། སྤྲུལ་པའི་སེམས་ཏེ་བཞི། གཟུགས་ཀྱི་མ་སྒྲིབ་ལུང་མ་བསྟན་གྱི་སེམས་ལ། བཟོ་གནས་མ་གཏོགས་པའི་གསུམ། གཟུགས་མེད་ན་རྣམ་སྨིན་སྐྱེས་ཀྱི་སེམས་གཅིག་པུ་སྟེ། དེ་ལྟར་དགེ་སེམས་དྲུག་མ་སྒྲིབ་ལུང་མ་བསྟན་གྱི་སེམས་བརྒྱད། སྒྲིབ་ལུང་མ་བསྟན་གྱི་སེམས་གསུམ། མི་དགེའི་སེམས་གཅིག ཟག་མེད་ཀྱི་སེམས་གཉིས་རྣམས་སུ་ཡོད་པའི་ཕྱིར་ཏེ།
Enumeration Block 22:
ཚེའམ་གནས་སྐབས་བརྒྱད་ཀྱིས་ཤེས་པར་བྱ་སྟེ། རྒྱུན་ལྡན་གྱི་ཚེ། ས་མཚུངས་ཀྱི་ཚེ། ཉིང་མཚམས་སྦྱོར་བའི་ཚེ། སྙོམས་པར་འཇུག་པའི་ཚེ། སྙོམས་པར་འཇུག་པ་ལས་ལྡང་བའི་ཚེ། སྙོམས་འཇུག་ཉོན་མོངས་ཅན་གྱིས་གཟིར་བའི་ཚེ། སྤྲུལ་པ་ལ་འཇུག་པའི། སྤྲུལ་པ་ལས་ལྡང་པའི་ཚེ་རྣམས་སོ། །
