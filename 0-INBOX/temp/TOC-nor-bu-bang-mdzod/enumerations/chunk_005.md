Enumeration Block 1:
དབང་པོ་ལ་ཉེར་གཉིས་སུ་གྲངས་ངེས་ཏེ། ཀུན་ནས་ཉོན་མོངས་ཀྱི་ཕྱོགས་ལ་དང་པོ་བཅུ་བཞི། རྣམ་བྱང་གི་ཕྱོགས་ལ་ཕྱི་མ་བརྒྱད་དུ་གྲངས་ངེས་པའི་ཕྱིར།
Enumeration Block 2:
འདིར་ཚོར་བའི་དབང་པོ་ལྔའི་ངོ་བོ་འཆད་པ་ལ། ལུས་ཚོར་སིམ་པ་མ་ཡིན་གང༌། །ཞེས་སོགས་ཤོ་ལོ་ཀ་གཅིག་གིས་སྐབས་སུ་གཉིས་ལས།
Enumeration Block 3:
རྣམ་བྱང་གི་དབང་པོ་རྒྱས་པར་བཤད་པ་ནི། མཐོང་སྒོམ་མི་སློབ་ལམ་ལ་དགུ། གསུམ་ཡིན། ཞེས་པའི་སྐབས་སུ་གཉིས་ལས།
Enumeration Block 4:
གསུམ་པ་དབང་པོའི་རབ་དབྱེ་ལ་གྲོགས་ལ་ལྟོས་བའི་རབ་དབྱེ། རྒྱུ་འབྲས་ལ་ལྟོས་བའི། ངོ་བོ་ལ་ལྟོས་པའི། སྤང་བྱ་ལ་ལྟོས་པའི་རབ་དབྱེ་དང་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
དྲུག་པ་དབང་པོའི་ལྡན་ཚུལ་ལ། ངེས་ལྡན། སྲིད་ལྡན་གཉིས། དང་པོ་ལ། གསུམ། བཞི། ལྔ། བདུན། བཅུ་གཅིག བཅུ་གསུམ་ལྡན་ཏེ་རིམ་བཞིན་དུ་སྟོན་པ་ལ།
Enumeration Block 6:
གཉིས་པ་སྲིད་ལྡན་ལ་ཉུང་ལྡན་མང་ལྡན་གཉིས།
Enumeration Block 7:
གཉིས་པ་འདུས་བྱས་ཀྱི་སྐྱེ་ཚུལ་ལ། གཟུགས་ཅན་གྱི་སྐྱེ་ཚུལ་དང༌། གཟུགས་ཅན་མ་ཡིན་པའི་སྐྱེ་ཚུལ་གཉིས། དང་པོ་ནི། འདོད་ན་དབང་པོ་མེད་པ་དང༌། ཞེས་སོགས་རྐང་བ་བཞིའི་སྐབས་སུ། །གཉིས་ལས།
Enumeration Block 8:
རྡུལ་ལ་རྫས་ཀྱི་རྡུལ་དང༌། བསགས་པའི་རྡུལ་གཉིས་ལས།
Enumeration Block 9:
གཉིས་པ་གཟུགས་ཅན་མ་ཡིན་པའི་སྐྱེ་ཚུལ་ལ། བསྟན། བཤད་གཉིས་ལས། དང་པོ་ནི། སེམས་དང་སེམས་བྱུང་ངེས་ལྷན་ཅིག ཞེས་སོགས་རྐང་པ་ཕྱེད་དང་གསུམ་གྱི་སྐབས་སུ། གཉིས་ལས།
Enumeration Block 10:
སེམས་བྱུང་ལ་དབྱེ་ན། སྡེ་ཚན་དུ་ངེས་པའི་སེམས་བྱུང༌། སྡེ་ཚན་དུ་མ་ངེས་པའི་སེམས་བྱུང་གཉིས། དང་པོ་ལ། སེམས་ཀྱི་ས་མང༌། དགེ་བའི་ས་མང༌། ཉོན་མོངས་ཆེན་པོའི་ས་མང༌། མི་དགེ་བའི་ས་མང༌། ཉོན་མོངས་ཆུང་ངུའི་ས་མང་རྣམས་སུ་ཡོད།
