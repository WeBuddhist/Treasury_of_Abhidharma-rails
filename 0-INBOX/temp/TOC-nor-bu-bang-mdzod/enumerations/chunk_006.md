Enumeration Block 1:
རྡུལ་ལ་རྫས་ཀྱི་རྡུལ་དང༌། བསགས་པའི་རྡུལ་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་གཟུགས་ཅན་མ་ཡིན་པའི་སྐྱེ་ཚུལ་ལ། བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 3:
སེམས་དང་སེམས་བྱུང་ངེས་ལྷན་ཅིག ཞེས་སོགས་རྐང་པ་ཕྱེད་དང་གསུམ་གྱི་སྐབས་སུ། གཉིས་ལས།
Enumeration Block 4:
སེམས་བྱུང་ལ་དབྱེ་ན། སྡེ་ཚན་དུ་ངེས་པའི་སེམས་བྱུང༌། སྡེ་ཚན་དུ་མ་ངེས་པའི་སེམས་བྱུང་གཉིས། དང་པོ་ལ། སེམས་ཀྱི་ས་མང༌། དགེ་བའི་ས་མང༌། ཉོན་མོངས་ཆེན་པོའི་ས་མང༌། མི་དགེ་བའི་ས་མང༌། ཉོན་མོངས་ཆུང་ངུའི་ས་མང་རྣམས་སུ་ཡོད།
Enumeration Block 5:
གཉིས་པ་སྡེ་ཚན་དུ་མ་ངེས་པའི་སེམས་བྱུང་ལ་བརྒྱད་ཡོད་དེ།
Enumeration Block 6:
སེམས་དང་ཡིད་དང་རྣམ་ཤེས་ནི། །ཞེས་སོགས་རྐང་པ་བཞིའི་སྐབས་སུ། གཉིས་ལས།
Enumeration Block 7:
མི་ལྡན་པ་ཡི་འདུ་བྱེད་རྣམས། །ཞེས་སོགས་རྐང་པ་ལྔའི་སྐབས་སུ། གཉིས་ལས།
Enumeration Block 8:
དབྱེ་ན་བཅུ་བཞི་ཡོད་དེ། ཐོབ་པ། མ་ཐོབ་པ། སྐལ་མཉམ། འདུ་ཤེས་མེད་པ། འདུ་ཤེས་མེད་པའི་སྙོམས་འཇུགའགོག་པའི་སྙོམས་འཇུག སྲོག་དང་མཚན་ཉིད་བཞི། ཚོགས་གསུམ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 9:
བཅུ་བཞི་ཡོད་དེ། ཐོབ་པ་སོགས་དེར་ཡོད་པའི་ཕྱིར།
Enumeration Block 10:
དང་པོ་ལ། ཐོབ་པ་བཤད་པ་དང༌། མ་ཐོབ་པ་བཤད་པ་གཉིས་ལས།
Enumeration Block 11:
ཐོབ་པ་རྙེད་དང་ལྡན་པའོ། །ཞེས་པའི་སྐབས་སུ། གཉིས་ལས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། དེའི་ཁྱད་པར་གྱི་ཆོས།
Enumeration Block 12:
ཐོབ་པ་ལ་དབྱེ་ན་གསར་དུ་ཐོབ་པ། ཐོབ་པའི་ཐོབ་པ་གཉིས་ལས། རྙེད་པ་ལ་དབྱེ་ན། གསར་དུ་རྙེད་པ། ཉམས་པ་ལས་རྙེད་པ་གཉིས། ལྡན་པ་ལ་དབྱེ་ན། ཉམས་པ་ལས་ལྡན་པ། ཐོབ་ནས་ལྡན་པའི་ལྡན་པ་གཉིས། གསུམ་པ་ལ། ཐོབ་པ་རྫས་ཡོད་དུ་བཤད་པ། ཐོབ་པ་ཐོབ་པའི་ཐོབ་པ། ཐོབ་བྱའི་ཆོས་གསུམ་གྱི་ཁྱད་པར་བཤད་པ། རྒྱུད་ཀྱིས་བསྡུས་མ་བསྡུས་ཀྱི་ཁྱད་པར། དུས་གསུམ་གྱི་ཁྱད་པར། དགེ་སོགས་གསུམ་གྱི་ཁྱད་པར། ཁམས་གསུམ་གྱི་ཁྱད་པར། སློབ་མི་སློབ་ཀྱི་ཁྱད་པར། སྤང་བྱ་ཡིན་མ་ཡིན་གྱི་ཁྱད་པར། དམིགས་བསལ་བཤད་པ་དང་དགུ།
