Enumeration Block 1:
གསུམ་པ་སེམས་ཅན་གྱི་སྣོད་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། དངོས་དང༌། དེ་དག་གི་སྤྲོས་པའོ། །དང་པོ་ལ། ངན་སོང་བའི་གནས་དང༌། མཐོ་རིས་ཀྱི་གནས་སོ། །
Enumeration Block 2:
གཉིས་པ་མཐོ་རིས་ཀྱི་གནས་བཤད་པ་ལ། མིའི་གནས་བཤད་ཟིན། ལྷ་གནས་བཤད་པ། ལས་དང་འབྲེལ་བའི་ལྷ་གནས་དང་མ་འབྲེལ་བའི་ལྷ་གནས་གཉིས་ལས། དང་པོ་ལ། རྒྱལ་ཆེན་བཞིའི་གནས། སུམ་ཅུ་རྩ་གསུམ་པའི་གནས་དང་པོ་ལ་གཞལ་མེད་ཁང་ལ་བརྟེན་པ་དང༌། རི་རབ་ལ་བརྟེན་པ་གཉིས་ལས། དང་པོ་ནི། ཉི་ཟླ་ལྷུན་པོའི་ཕྱེད་ནའོ། །ཞེས་སོགས་རྐང་པ་གཉིས་ཀྱི་སྐབས་སུ་སྤྱི་དོན་དང༌། གཞུང་དོན་གཉིས་ལས། དང་པོ་ལ། ཉི་ཟླ་ཇི་ཙམ་ནས་འཆར་བ། ཉི་ཟླའི་དཀྱིལ་འཁོར་གྱི་ཚད། ཁྱད་ཆོས་རྒྱས་པར་བཤད་པ། ཞར་ལ་སྐར་མིའི་ཚད་བསྟན་པའོ། །
Enumeration Block 3:
དེ་སྟོན་པ་ནི། ནམ་ཕྱེད་ཉི་མ་ནུབ་པ་དང༌། །ཞེས་སོགས་རྐང་པ་གཉིས་ཀྱི་སྐབས་སུ། གཉིས་ལས། དང་པོ་ལ་དགག་གཞག་གཉིས།
Enumeration Block 4:
དབྱར་གྱི་ཟླ་བ་གཉིས་པ་ཡི། །ཞེས་སོགས་རྐང་པ་བཞིའི་སྐབས་སུ་གཉིས་ལས། དང་པོ་ལ། དུས་ཀྱི་རྣམ་གཞག་སྤྱིར་བསྟན་པ། དེ་ལ་བརྟེན་ནས་འདུལ་བའི་ལུགས་གྱི་གཞི་གསུམ་གྱི་རྣམ་གཞག་བསྡུས་ཏེ་བསྟན་པ། གཞུང་འདིའི་སྐབས་དོན་དང་སྦྱར་ཏེ་མངོན་པའི་ལུགས་ཀྱི་དབྱར་དགུན་གྱི་ཉི་མའི་ལྡོག་དུས་བཤད་པའོ། །
Enumeration Block 5:
དང་པོ་ལ་དུས་ཀྱི་ཕྱི་མོ་ལོ། དེ་ལས་ཕྱེ་བའི་དུས་ཚིགས་ཀྱི་རྣམ་གཞགདེ་ལ་བརྟེན་ནས་ཞག་མི་ཐུབ་འདོར་བའི་ཚུལ་རྒྱུ་མཚན་དང་བཅས་པའོ། །དང་པོ་ལ། ཡོད་ཙམ་གྱི་སྒོ་ནས་དབྱེ་ན། ཚེས་ཞག་ལ་ལྟོས་པའི་ལོ། ཉི་ཞག་ལ་ལྟོས་པའི་ལོ། ཁྱིམ་ཞག་ལ་ལྟོས་པའི་ལོ་གསུམ་ཡོད།
Enumeration Block 6:
གཉིས་པ་ལ་དངོས་དང༌། དུས་བཞི་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ་གསུམ་དུ་དབྱེ་བ། བཞིར་དབྱེ་བ། ལྔར་དབྱེ་བ། དྲུག་དུ་དབྱེ་བ་རྣམས་ཏེ།
Enumeration Block 7:
གཉིས་པ་ལ་ཉི་མའི་བགྲོད་པའི་དབང་གིས་ལོ་གཅིག་ལ་དུས་བཞིར་འབྱུང་ཚུལ། ཟླ་བའི་བགྲོད་པའི་དབང་གིས་དུས་བཞི་ལ་ཟླ་བ་བཅུ་གཉིས་འབྱུང་ཚུལ། ལོ་དང་དུས་ཀྱི་འགོ་འཛིན་ཚུལ་དངོས་སོ། །
Enumeration Block 8:
གསུམ་པ་ལ་དགག་གཞག་གཉིས་ལས།
Enumeration Block 9:
བཞི་པ་དེ་ལ་བརྟེན་ནས་ཞག་མི་ཐུབ་པ་དང་ཤོལ་དོར་ཚུལ་བཤད་པ་ལ། ཞག་མི་ཐུབ་དོར་བའི་ཚུལ། གསོ་སྦྱོང་བཅུ་བཞི་པའི་དུས་ངོས་བཟུང་བ། ཟླ་ཤོལ་འདོར་བའི་རྒྱུ་མཚན་དང་བཅས་པའོ། །
