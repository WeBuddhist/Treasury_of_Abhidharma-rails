Enumeration Block 1:
གསུམ་པ་གཞུང་འདིའི་སྐབས་དོན་དང་སྦྱར་ཏེ་མངོན་པའི་ལུགས་ཀྱི་དབྱར་དགུན་གྱི་ཉི་མའི་ལྡོག་དུས་བཤད་པ་ལ། དགག་བཞག་གཉིས།
Enumeration Block 2:
གཉིས་པ་ཞར་ལ་སེམས་ཅན་གྱི་ཚད་བཤད་པ་ལ། ལུས་ཚད། ཚེ་ཚད་གཉིས།
Enumeration Block 3:
བསྐལ་པ་ལ་ལྔ་ཡོད་དེ། འཇིག་པའི། ཞིག་ནས་འདུག་པའི། ཆགས་པའི། གནས་པའི། བསྐལ་ཆེན་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
སྤྱི་དོན་གཞུང་དོན་གཉིས། དང་པོ་ལ། བསྐལ་པ་དང་པོའི་མིའི་གནས་ཚུལ། དེ་འགྲིབ་ཚུལ། མི་རིགས་བཞི་པོ་ཇི་ལྟར་བྱུང་ཚུལ། འགྲིབ་པའི་མཐར་ཇི་ལྟ་བུ་བྱུང་ཚུལ་ལོ། །
Enumeration Block 5:
གནས་བཞི་པ་ལས་བསྟན་པའི་གནས་བཤད་པ་ལ། མཚམས་སྦྱར་བ་དང༌། ལས་དངོས་བཤད་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ་ངོ་བོ་དང༌། མདོ་ལས་བྱུང་བའི་རྣམ་གྲངས་སོ། །དང་པོ་ལ། བསྟན་བཤད་གཉིས།
Enumeration Block 7:
ཞེས་སོགས་རྐང་པ་གསུམ་གྱི་སྐབས་སུ་གཉིས་ལས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། རྣམ་གྲངས། ཁྱད་པར་གྱི་ཆོས་སོ། །
