Enumeration Block 1:
གསུམ་པ་རྒྱུ་རྐྱེན་འབྲས་བུ་གསུམ་བཤད་པ་ལ། རྒྱུ་བཤད་པ། འབྲས་བུ་བཤད་པ། རྐྱེན་བཤད་པའོ། །དང་པོ་ནི། བྱེད་རྒྱུ་ལྷན་ཅིག་འབྱུང་བ་དང༌། །ཞེས་སོགས་ཀྱི་སྐབས་སུ། སྤྱི་དོན་དང༌། གཞུང་དོན་གཉིས། དང་པོ་ནི། རྒྱུ་ལ་མཚན་ཉིད། དབྱེ་བ། བསྡུ་བ། སོ་སོའི་རང་བཞིན། རྒྱུ་དྲུག་གྲུབ་མཐའ་སྨྲ་བ་གང་གིས་འདོད་པ། རྒྱུ་དྲུག་འགལ་མི་འགལ་ལ་དཔྱད་པའོ། །
Enumeration Block 2:
བསྡུ་ན། གཉིས་སུ་འདུ་སྟེ། ཐུན་མོང་མ་ཡིན་པའི་རྒྱུ་གཉིས་སུ་འདུ་བའི་ཕྱིར།
Enumeration Block 3:
གཉིས་པ་ཡང་གཉིས་སུ་འདུ་སྟེ། དུས་མཉམ་པའི་རྒྱུ། མི་མཉམ་བའི་རྒྱུ་གཉིས་སུ་འདུ་བའི་ཕྱིར་ཏེ།
Enumeration Block 4:
རྒྱུ་ལ་དྲུག་ཏུ་ཡོད་དེ། བྱེད་རྒྱུ་སོགས་དྲུག་ཡོད་པའི་ཕྱིར། །གཉིས་པ་འབྲས་བུ་བཤད་པ་ནི། འདུས་བྱས་བྲལ་བཅས་འབྲས་བུ་ཡིན། །ཞེས་སོགས་ཀྱི་སྐབས་སུ། གཉིས་ལས། དང་པོ་ནི། འབྲས་བུའི་མཚན་ཉིད། དབྱེ་བ། སོ་སོའི་རང་བཞིན། འབྲས་བུ་གང་རྒྱུ་གང་གི་འབྲས་བུ་ཡིན་པ། དེ་དག་ལ་དྭོགས་པ་གཅོད་པ་དང་ལྔ།
Enumeration Block 5:
དེ་ལ་ལྔ་ཡོད་དེ་རྣམ་སྨིན་གྱི་འབྲས་བུ། རྒྱུ་མཐུན་གྱི་འབྲས་བུ། བྲལ་བའི་འབྲས་བུ། སྐྱེས་བུ་བྱེད་པའི་འབྲས་བུ། བདག་འབྲས་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
སྐྱེད་པའི་སྐྱེས་བུའི་བྱེད་འབྲས། ཐོབ་པའི་སྐྱེས་བུའི་བྱེད་འབྲས་གཉིས་ཡོད།
Enumeration Block 7:
གསུམ་པ་རྐྱེན་བཤད་པ་ལ། བསྟན་བཤད་གཉིས། དང་པོ་ནི། རྐྱེན་ནི་བཞི་པོ་དག་ཏུ་གསུངས། །ཞེས་སོགས་ཀྱི་སྐབས་སུ། གཉིས་ལས། དང་པོ་ལ། རྐྱེན་ལ་མཚན་ཉིད། དབྱེ་བ། སོ་སོའི་རང་བཞིན། རྐྱེན་གང་གི་དུས་གང་ལ་བྱ་བ་བྱེད་པ། དངོས་པོ་གང་རྐྱེན་དུས་སྐྱེད་པའོ། །
Enumeration Block 8:
དེ་ལ་རྒྱུ་རྐྱེན། དེ་མ་ཐག་རྐྱེན། དམིགས་རྐྱེན། བདག་རྐྱེན་དང་བཞི་ཡོད།
Enumeration Block 9:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། དེ་མ་ཐག་རྐྱེན་བྱེ་བྲག་ཏུ་བཤད་པ་ནི། འདོད་ཡིད་དགེ་དང་མི་དགེ་དང༌། །ཞེས་སོགས་ཀྱི་སྐབས་སུ། གཉིས་ལས། དང་པོ་ནི། སྤྱིར་སེམས་ཀྱི་དབྱེ་བ་བཤད་པ། དེ་མ་ཐག་རྐྱེན་དང་སྦྱར་བ། ཁམས་གསུམ་གྱི་ཉོན་མོངས་ཅན་གྱི་སེམས་གང་མངོན་དུ་གྱུར་པ་ན་གསར་དུ་དུ་རྙེད་དཔྱད་པའོ། །དང་པོ་ལ། སེམས་བཅུ་གཉིས་སུ་དབྱེ་བ། ཉི་ཤུར་དབྱེ་བ། དེ་གཉིས་གང་ཁྱབ་ཆེ་བཤད་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ་དུས་ནམ་གྱི་ཚེ་རྐྱེན་དང་རྐྱེན་ཅན་དུ་འགྱུར་བ། སེམས་བཅུ་གཉིས་ཀྱི་རྐྱེན་དང་རྐྱེན་དུ་སྦྱར་བ། སེམས་ཉི་ཤུའི་རྐྱེན་དང་རྐྱེན་ཅན་དུ་སྦྱར་བའོ། །དང་པོ་ནི། ཚེའམ་གནས་སྐབས་བརྒྱད་ཀྱིས་ཤེས་པར་བྱ་སྟེ། རྒྱུན་ལྡན་གྱི་ཚེ། ས་མཚུངས་ཀྱི་ཚེ། ཉིང་མཚམས་སྦྱོར་བའི་ཚེ། སྙོམས་པར་འཇུག་པའི་ཚེ། སྙོམས་པར་འཇུག་པ་ལས་ལྡང་བའི་ཚེ། སྙོམས་འཇུག་ཉོན་མོངས་ཅན་གྱིས་གཟིར་བའི་ཚེ། སྤྲུལ་པ་ལ་འཇུག་པའི། སྤྲུལ་པ་ལས་ལྡང་པའི་ཚེ་རྣམས་སོ། །
Enumeration Block 11:
ཚེ་ལྔར་ཤེས་པར་བྱ་སྟེ། ཁམས་གོང་མ་ནས་འོག་མར་སྐྱེ་པའི་ཚེ་དང༌། ཟག་བཅས་ཟག་མེད་ལ་སྙོམས་པར་འཇུག་པའི་ཚེ། ས་དང་ས་ལ་འདོད་ཆགས་དང་བྲལ་བའི་ཚེ། དེ་དག་ལས་ཡོངས་སུ་ཉམས་པའི་ཚེ། སླར་ཡང་དགེ་བས་ཉིང་མཚམས་སྦྱོར་བའི་ཚེ་སྟེ་ལྔའོ། །
