Enumeration Block 1:
མཚམས་སྦྱར་བ་དང༌། ལས་དངོས་བཤད་པ་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལ་ངོ་བོ་དང༌། མདོ་ལས་བྱུང་བའི་རྣམ་གྲངས་སོ། །དང་པོ་ལ། བསྟན་བཤད་གཉིས།
Enumeration Block 3:
གཉིས་ལས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། རྣམ་གྲངས། ཁྱད་པར་གྱི་ཆོས་སོ། །
Enumeration Block 4:
བཞི་པ་ལ། ལས་ངེས་པའི་ཚུལ། ལས་འཕེལ་ཆེ་བ། ལས་མ་བྱས་པ་དང་མི་ཕྲད་པ། བྱས་པ་ཆུད་མི་ཟ་བ། ལས་ཀྱི་རྣམ་སྨིན་གྱི་འབྲས་བུ་འབྱིན་ཚུལ་ལོ། །
Enumeration Block 5:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་གསུམ། ལས་ཀྱི་རང་བཞིན། ལས་གསུམ་སྤྱིའི་ཆོས་ཀྱི་ཁྱད་པར། རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་དབྱེ་བའོ། །
Enumeration Block 6:
རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་དབྱེ་བ་སྟོན་པ་ལ། བསྟན་བཤད་གཉིས།
Enumeration Block 7:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། སྡོམ་པ་ལྡན་ཚུལ། ཐོབ་གཏོང༌། ལྡན་པའི་གང་ཟག་བཤད་པའོ། །
Enumeration Block 8:
དང་པོ་ནི། བསྟན་བཤད་གཉིས།
Enumeration Block 9:
གསུམ་པ་ཐོབ་གཏོང་བཤད་པ་ལ། ཐོབ་ཚུལ་དང་གཏོང་ཚུལ་གཉིས། དང་པོ་ལ་སྡོམ་པའི་ཐོབ་ཚུལ། སྡོམ་མིན་གྱི་ཐོབ་ཚུལ། བར་མའི་ཐོབ་ཚུལ་ལོ། །དང་པོ་ལ། ཇི་ལྟར་ཐོབ་པ། གང་ཐོབ་པའོ། །དང་པོ་ལ། བསམ་གཏན་གྱི་སྡོམ་པའི། ཟག་མེད་ཀྱི་སྡོམ་པའི་སོ་ཐར་གྱི་སྡོམ་པའི་ཐོབ་ཚུལ་ལོ། །
