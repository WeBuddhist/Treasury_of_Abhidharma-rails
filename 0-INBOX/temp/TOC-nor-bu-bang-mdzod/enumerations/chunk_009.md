Enumeration Block 1:
གསུམ་པ་ཐོབ་གཏོང་བཤད་པ་ལ། ཐོབ་ཚུལ་དང་གཏོང་ཚུལ་གཉིས། དང་པོ་ལ་སྡོམ་པའི་ཐོབ་ཚུལ། སྡོམ་མིན་གྱི་ཐོབ་ཚུལ། བར་མའི་ཐོབ་ཚུལ་ལོ། །དང་པོ་ལ། ཇི་ལྟར་ཐོབ་པ། གང་ཐོབ་པའོ། །དང་པོ་ལ། བསམ་གཏན་གྱི་སྡོམ་པའི། ཟག་མེད་ཀྱི་སྡོམ་པའི་སོ་ཐར་གྱི་སྡོམ་པའི་ཐོབ་ཚུལ་ལོ། །
Enumeration Block 2:
སྤྱི་དོན། གཞུང་དོན་ནོ། །དང་པོ་ནི། སྐྱབས་ཡུལ་དཀོན་མཆོག་གསུམ་ངེས་བཟུང་བ། དེ་གྲོལ་བ་དོན་གཉེར་གྱི་སྐྱབས་སུ་འོས་པའི་རྒྱུ་མཚན། རྒྱུ་གང་ལ་བརྟེན་ནས་ཚུལ་ཇི་ལྟར་དུ་སྐྱབས་སུ་འགྲོ་བ། སྐྱབས་སུ་སོང་པའི་ཕན་ཡོན། སྐྱབས་འགྲོའི་བསླབ་བྱ་བཤད་པའོ། །
Enumeration Block 3:
སྐྱབས་འགྲོ་ལ་དབྱེ་ན། །སྐྱེས་བུ་ཆུང་དུ། འབྲིང༌། ཆེན་པོའི་སྐྱབས་འགྲོ། རྒྱུ་དང་འབྲས་བུའི་སྐྱབས་འགྲོ་སོགས་དུ་མ་ཡོད། །
Enumeration Block 4:
གཉིས་པ་མདོར་བསྡུས་པའི་རྣམ་གྲངས་བཤད་པ་ལ། མཚན་ཉིད་དང༌། མཚན་གཞིའི་དབྱེ་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་ཡང༌། རྒྱུ་འབྲས་ཀྱི་སྒོ་ནས་དབྱེ་བ། རྟེན་གྱི་སྒོ་ནས། འབྲས་བུའི་སྒོ་ནས། ངོ་བོའི་སྒོ་ནས། བྱེད་ལས་ཀྱི་སྒོ་ནས་དབྱེ་བའོ། །
Enumeration Block 6:
ལྔ་པ་བྱེ་བྲག་གི་སྒོ་ནས་དབྱེ་བ་ལ། སྤང་བྱ་སྒྲིབ་པ་གཉིས་བཤད་པ། རྟེན་བྱ་བསོད་ནམས་བྱ་བའི་གཞི་བཤད་པ། ཆ་མཐུན་གྱི་དགེ་རྩ་གསུམ་བཤད་པ། རྣམ་གྲངས་གཞན་བསྟན་པའོ། །
Enumeration Block 7:
སྤྱི་དོན། གཞུང་དོན། དང་པོ་ནི། མཚམས་མེད་གྱི་སྒྲིབ་པ། ཉོན་མོངས་པའི་སྒྲིབ་པ། རྣམ་སྨིན་གྱི་སྒྲིབ་པ་བཤད་པའོ། །
Enumeration Block 8:
དབྱེ་ན་མཚམས་མེད་ལྔ་དང༌། ཉེ་བའི་མཚམས་མེད་ལྔ།
