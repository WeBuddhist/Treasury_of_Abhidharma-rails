Enumeration Block 1:
ལྔ་པ་བྱེ་བྲག་གི་སྒོ་ནས་དབྱེ་བ་ལ། སྤང་བྱ་སྒྲིབ་པ་གཉིས་བཤད་པ། རྟེན་བྱ་བསོད་ནམས་བྱ་བའི་གཞི་བཤད་པ། ཆ་མཐུན་གྱི་དགེ་རྩ་གསུམ་བཤད་པ། རྣམ་གྲངས་གཞན་བསྟན་པའོ། །
Enumeration Block 2:
སྤྱི་དོན། གཞུང་དོན། དང་པོ་ནི། མཚམས་མེད་གྱི་སྒྲིབ་པ། ཉོན་མོངས་པའི་སྒྲིབ་པ། རྣམ་སྨིན་གྱི་སྒྲིབ་པ་བཤད་པའོ། །
Enumeration Block 3:

Enumeration Block 4:

Enumeration Block 5:
གསུམ་པ་བསོད་ནམས་བྱ་བ་དང༌། །ཞེས་སོགས་ཀྱི་སྐབས་སུ་གཉིས་ལས། དང་པོ་ནི། སྦྱིན་པ་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་གཞི། ཚུལ་ཁྲིམས་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་གཞི། སྒོམ་པ་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་གཞི་བཤད་པའོ། །དང་པོ་ནི། སྦྱིན་པའི་མཚན་ཉིད། དབྱེ་བ། སྦྱིན་པ་གཏོང་ཚུལ། །
Enumeration Block 6:
གསུམ་པ་སྦྱིན་པ་གཏོང་ཚུལ་ལ་གསུམ། སྦྱིན་བདག་གི་ཁྱད་པར། དངོས་པོའི་ཁྱད་པར། ཞིང་གི་ཁྱད་པར་ལས་སྦྱིན་པ་ཁྱད་པར་དུ་འགྱུར་ཚུལ་ལོ། །
Enumeration Block 7:
གཉིས་པ་ཚུལ་ཁྲིམས་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་གཞི་ལ། དེའི་མི་མཐུན་ཕྱོགས་བཤད་པ། ཚུལ་ཁྲིམས་དང༌། དེའི་ཡོན་ཏན་བཤད་པའོ། །

Enumeration Block 9:
