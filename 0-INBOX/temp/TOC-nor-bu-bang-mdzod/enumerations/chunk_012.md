Enumeration Block 1:
གཞི་ཐམས་ཅད་ཡོད་པར་སྨྲ་བའི་སྡེ་པ་ལ་བཞི་ཡོད་དེ། དངོས་པོ་གཞན་དུ་འགྱུར་བར་སྨྲ་བ། མཚན་ཉིད་གཞན་དུ་འགྱུར་བར་སྨྲ་བ། གནས་སྐབས་གཞན་དུ་འགྱུར་བར་སྨྲ་བ། གཞན་གཞན་དུ་འགྱུར་བར་སྨྲ་བ་སྟེ་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
ཟག་པ་ལ་ནི་འདོད་པའི་ཟག་པ་དང༌། སྲིད་པའི་ཟག་པ། མ་རིག་པའི་ཟག་པ་དང་གསུམ།
Enumeration Block 3:
ཀུན་སྦྱོར། འཆིང་བ། ཕྲ་རྒྱུས། ཉེ་ཉོན། ཀུན་དཀྲིས་ཞེས་ལྔ་གསུངས་ཏེ།
Enumeration Block 4:
ཀུན་སྦྱོར་ལ་དགུ་ཡོད་དེ། རྩ་ཉོན་དྲུག་གི་ཀུན་སྦྱོར། མཆོག་འཛིན་གཉིས་ཀྱི་ཀུན་སྦྱོར། ཕྲག་དོག་སེར་སྣའི་ཀུན་སྦྱོར་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
དང་པོ་ལ། འཇིག་ལྟ་ཀུན་སྦྱོར། ཚུལ་ཁྲིམས་མཆོག་འཛིན། ཐེ་ཚོམ་སྟེ་གསུམ་ཡོད།
Enumeration Block 6:
ཐ་མའི་ཀུན་སྦྱོར་ལ་ལྔ་ཡོད་དེ། གསུམ་པོ་དེའི་སྟེང་དུ་འདོད་པ་ལ་འདུན་པ། གནོད་སེམས་གཉིས་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
གོང་མའི་ཀུན་སྦྱོར་ལ་ལྔ་ཡོད་དེ། གཟུགས་གཟུགས་མེད་ཀྱི་འདོད་ཆགས་གཉིས། རྒོད་པ། ང་རྒྱལ། མ་རིག་པ་གསུམ་སྟེ།
Enumeration Block 8:
གཉིས་པ་འཆིང་བ་ལ་གསུམ་ཡོད། དུག་གསུམ་གྱི་འཆིང་བ་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 9:
ཀུན་བཀྲིས་ལ་བརྒྱད་ཡོད་དེ། ཚུལ་ཁྲིམས་ཀྱི་མི་མཐུན་ཕྱོགས་ངོ་ཚ་མེད་དང་ཁྲེལ་མེད། གཞན་ལ་ཕན་འདོགས་པའི་མི་མཐུན་ཕྱོགས་ཕྲག་དོག་སེར་སྣ། ཤེས་རབ་ཀྱི་མི་མཐུན་ཕྱོགས་རྒོད་འགྱོད། ཏིང་ངེ་འཛིན་གྱི་མི་མཐུན་ཕྱོགས་གཉིད་རྨུགས་རྣམས་སུ་ཡོད་པའི་ཕྱིར་ཏེ།
