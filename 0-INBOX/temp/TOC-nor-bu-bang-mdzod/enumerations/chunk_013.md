Enumeration Block 1:
གཉིས་ལས། དང་པོ་ལ་དགག་གཞག་གཉིས།
Enumeration Block 2:
གཉིས་ལས། དང་པོ་ལ། དུས་ཀྱི་རྣམ་གཞག་སྤྱིར་བསྟན་པ། དེ་ལ་བརྟེན་ནས་འདུལ་བའི་ལུགས་གྱི་གཞི་གསུམ་གྱི་རྣམ་གཞག་བསྡུས་ཏེ་བསྟན་པ། གཞུང་འདིའི་སྐབས་དོན་དང་སྦྱར་ཏེ་མངོན་པའི་ལུགས་ཀྱི་དབྱར་དགུན་གྱི་ཉི་མའི་ལྡོག་དུས་བཤད་པའོ། །
Enumeration Block 3:
དང་པོ་ལ་དུས་ཀྱི་ཕྱི་མོ་ལོ། དེ་ལས་ཕྱེ་བའི་དུས་ཚིགས་ཀྱི་རྣམ་གཞགདེ་ལ་བརྟེན་ནས་ཞག་མི་ཐུབ་འདོར་བའི་ཚུལ་རྒྱུ་མཚན་དང་བཅས་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་དངོས་དང༌། དུས་བཞི་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ་གསུམ་དུ་དབྱེ་བ། བཞིར་དབྱེ་བ། ལྔར་དབྱེ་བ། དྲུག་དུ་དབྱེ་བ་རྣམས་ཏེ།
Enumeration Block 5:
གཉིས་པ་ལ་ཉི་མའི་བགྲོད་པའི་དབང་གིས་ལོ་གཅིག་ལ་དུས་བཞིར་འབྱུང་ཚུལ། ཟླ་བའི་བགྲོད་པའི་དབང་གིས་དུས་བཞི་ལ་ཟླ་བ་བཅུ་གཉིས་འབྱུང་ཚུལ། ལོ་དང་དུས་ཀྱི་འགོ་འཛིན་ཚུལ་དངོས་སོ། །
Enumeration Block 6:
གསུམ་པ་ལ་དགག་གཞག་གཉིས་ལས།
Enumeration Block 7:
བཞི་པ་དེ་ལ་བརྟེན་ནས་ཞག་མི་ཐུབ་པ་དང་ཤོལ་དོར་ཚུལ་བཤད་པ་ལ། ཞག་མི་ཐུབ་དོར་བའི་ཚུལ། གསོ་སྦྱོང་བཅུ་བཞི་པའི་དུས་ངོས་བཟུང་བ། ཟླ་ཤོལ་འདོར་བའི་རྒྱུ་མཚན་དང་བཅས་པའོ། །
