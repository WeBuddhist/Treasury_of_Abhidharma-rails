Enumeration Block 1:
ཁྱོད་ལ་དབྱེ་ན། གཟུགས་སུ་ཉེར་འགྲོའི་ཕྱིར་མི་འོང༌། གཟུགས་མེད་ཉེར་འགྲོ་གཉིས། དང་པོ་ལ་བར་མདའ་བ་གསུམ། སྐྱེ་འདའ་བ་གསུམ། གོང་འཕོ་ལ་འདོད་རྟེན་ལ་བསམ་གཏན་སྤེལ་སྒོམ་བྱས་མ་བྱས་ཀྱི་བྱེ་བྲག་གིས་འོག་མིན་འགྲོ། འཕར་བ། ཕྱེད་འཕར། གནས་ཐམས་ཅད་དུ་འཆི་འཕོའི་ཕྱིར་མི་འོང་གསུམ།
Enumeration Block 2:
དེ་ལ་དབྱེ་ན་དྲུག་ཡོད་དེ། ཡོངས་སུ་ཉམས་པའི་ཆོས་ཅན། འཆི་བར་སེམས་པའི་ཆོས་ཅན། རྗེས་སུ་སྲུང་པའི་ཆོས་ཅན། གནས་པ་ལས་མི་བསྐྱོད་པའི་ཆོས་ཅན། རྟོགས་པའི་འོས་སུ་གྱུར་པའི་ཆོས་ཅན། མི་གཡོ་བའི་ཆོས་ཅན་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
སྤྱིར་ཉམས་པ་ལ་གསུམ་ཡོད་དེ། ཡོན་ཏན་ཐོབ་པ་ལས་ཉམས་པ། ཐོབ་བྱའི་ཡོན་ཏན་མ་ཐོབ་པ་ལས་ཉམས་པ། ཐོབ་ཀྱང་མངོན་དུ་མི་བྱེད་པ་སྟེ་ཉེར་སྤྱད་ལས་ཉམས་པ་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
བཞི་པ་མངོན་པར་རྟོགས་པའི་ལམ་གཞན་བསྟན་པ་ནི། མདོར་ན་ལམ་ནི་རྣམ་བཞི་སྟེ། །ཞེས་སོགས་རྐང་པ་གསུམ་གྱི་སྐབས་སུ། སྤྱི་དོན་དང༌། གཞུང་དོན་གཉིས།
Enumeration Block 5:
དབྱེ་ན་མཐོང་ལམ་སྒོམ་ལམ་གཉིས་ཀྱི་བར་ཆད་མེད་ལམ་གཉིས་དང༌། དེ་ཡང་དང་པོ་ལ་བརྒྱད། ཕྱི་མ་ལ་དགུ
Enumeration Block 6:
དབྱེ་ན་མཐོང་ལམ་སྒོམ་ལམ་མི་སློབ་ལམ་གྱི་རྣམ་གྲོལ་ལམ་གསུམ།
Enumeration Block 7:
ཐར་ལམ་ལ་དབྱེ་ན་བཞི་ཡོད་དེ།
Enumeration Block 8:
ཟད་དང་མི་སྐྱེ་ཤེས་པ་ནི། །ཞེས་སོགས་ཀྱི་སྐབས་སུ་གཉིས་ལས། དང་པོ་ལ། ངེས་ཚིགདབྱེ་བ། བསྡུ་བ། གྲངས་ངེས། གོ་རིམ། ཟག་བཅས་ཟག་མེད་ཀྱི་ཁྱད་པར། ལམ་དང་སའི་ཁྱད་པར་རོ། །
Enumeration Block 9:
སོ་བདུན་པོ་དེ་ལ་རྗེས་ཀྱི་སྒོ་ནས་བསྡུ་ན་བཅུར་འདུས་ཏེ། རྫས་སུ་བཅུ།
Enumeration Block 10:
གནས་བདུན་པ་ཡེ་ཤེས་བསྟན་པའི་གནས་བཤད་པ་ལ། ཤེས་པ། ལྡན་པ། ཐོབ་པ། ཡོན་ཏན་བཤད་པའོ། །
Enumeration Block 11:
སྐབས་འདིར་བསྟན་ཤེས་པ་ལ་དབྱེ་ན་བཅུ་ཡོད་དེ། ཆོས་ཤེས། རྗེས་ཤེས། ཀུན་རྫོབ་ཤེས་པ། གཞན་སེམས་ཤེས་པ། བདེན་བཞི་ཤེས་པ། ཟད་པ་ཤེས་པ། མི་སྐྱེ་བ་ཤེས་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར་ཏེ།
Enumeration Block 12:
བཅུ་པོ་དེ་བསྡུ་ན་གཉིས་སུ་འདུ་སྟེ། ཟག་བཅས་ཀྱི་ཤེས་པ་དང༌། ཟག་མེད་ཀྱི་ཤེས་པ་གཉིས་སུ་འདུ་བའི་ཕྱིར།
Enumeration Block 13:
གཉིས་པ་ལའང་གཉིས་སུ་འདུ་སྟེ། ཆོས་ཤེས་དང་རྗེས་ཤེས་གཉིས་སུ་འདུ་བའི་ཕྱིར།
Enumeration Block 14:
བཞི་པ་ཤེས་པས་བསྡུས་བའི་ཡོན་ཏན་ལ། ཐུན་མོང་མ་ཡིན་པའི་ཡོན་ཏན་དང༌། ཐུན་མོང་བའི་ཡོན་ཏན་གཉིས་ལས།
Enumeration Block 15:
སངས་རྒྱས་ཆོས་ནི་མ་འདྲེས་པ། །ཞེས་སོགས་རྐང་པ་གཉིས་ཀྱི་སྐབས་སུ། སྤྱི་དོན་དང༌། གཞུང་དོན་གཉིས། དང་པོ་ལ། སངས་རྒྱས་ཀྱི་ཆོས་མ་འདྲེས་པའི་ཡོན་ཏན་གྱི་མཚན་ཉིད། དབྱེ་བ། སོ་སོའི་རང་བཞིན་ནོ། །
Enumeration Block 16:
གཉིས་པ་ནི། སྟོབས་བཅུ། མི་འཇིགས་པ་བཞི། དྲན་པ་ཉེར་གཞག་གསུམ། ཐུགས་རྗེ་ཆེན་པོ་རྣམས་སུ་ཡོད་དེ།
Enumeration Block 17:
དབྱེ་ན། རང་དོན་སྤངས་རྟོགས་དམ་པ་ལ་མི་འཇིགས་པ་གཉིས། གཞན་དོན་སྤང་གཉེན་དམ་པ་ལ་མི་འཇིགས་པ་གཉིས་ཏེ་བཞི་ཡོད་དེ།
Enumeration Block 18:
དབྱེ་ན། འཁོར་གུས་པར་ཆོས་ཉན་པ་ལ་རྗེས་སུ་ཆགས་པ་སྤངས་བའི་དྲན་པ། མ་གུས་པར་ཆོས་ཉན་པ་ལ་ཁོང་ཁྲོ་སྤངས་པའི་དྲན་པ། གུས་མ་གུས་འདྲེས་མ་ལ་དེ་གཉིས་ཀར་མི་འགྱུར་བ་དྲན་ཤེས་བཞིན་བཏང་སྙོམས་སུ་གནས་པའི་དྲན་པ་གསུམ་སྟེ།
Enumeration Block 19:
གཉིས་པ་ནི། ཐུན་མོང་མ་ཡིན་པའི་སངས་རྒྱས་ཀྱི་ཡོན་ཏན་འཕགས་པ་འོག་མ་དང་མ་འདྲེས་པ་ལ་བཅོ་བརྒྱད་ཡོད་དེ། སྟོབས་བཅུ་མི་འཇིགས་པ་བཞི། དྲན་པ་ཉེར་གཞག་གསུམ། ཐུགས་རྗེ་ཆེན་པོ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 20:
དབྱེ་ན་ཆོས། དོན། ངེས་ཚིག་སྤོབས་པ་སོ་སོ་ཡང་དག་པར་རིག་པ་བཞི་ཡོད།
Enumeration Block 21:
མངོན་ཤེས་ལ་དྲུག་ཡོད་དེ། རྫུ་འཕྲུལ་ཡུལ་ཤེས་ཀྱི་མངོན་ཤེས་སོགས་དྲུག་ཡོད་པའི་ཕྱིར།
Enumeration Block 22:
དེའི་ཡུལ་ལ་སྤྲུལ་པ་དང་འགྲོ་བ་གཉིས་ཡོད་ཅིང༌། འགྲོ་བ་ལ་གསུམ་ཡོད་དེ། འདབ་ཆགས་བྱ་བཞིན་ལུས་ཕྱིན་བྱེད་ཀྱི་འགྲོ་བ། ཐག་རིང་པོ་ཡང་ཐུང་ངུར་མོས་པས་མྱུར་དུ་འགྲོ་མོས་པ་ལས་བྱུང་བའི་འགྲོ་བ་ཡིད་ལྟར་མགྱོགས་པའི་འགྲོ་བ་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 23:
སྤྲུལ་པ་ལ་གཉིས་ཡོད་དེ། འདོད་པར་གཏོགས་པའི་སྤྲུལ་པ། གཟུགས་ཁམས་སུ་གཏོགས་པའི་སྤྲུལ་པ་གཉིས་ཡོད་པའི་ཕྱིར།
Enumeration Block 24:
སྤྲུལ་པ་ཐམས་ཅད་བསྡུ་ན་གཉིས་སུ་འདུས་ཏེ། རང་ཉིད་སེང་གེ་སོགས་སུ་སྤྲུལ་པ་རང་གི་ལུས་དང་འབྲེལ་བ་དང༌། །ཕྱི་རོལ་ཏུ་སེང་གེ་སོགས་སྤྲུལ་པ་ལྟ་བུ་གཞན་གྱི་ལུས་དང་འབྲེལ་བ་གཉིས་སུ་འདུས་པའི་ཕྱིར།
Enumeration Block 25:
རྫུ་འཕྲུལ་ལ་དབྱེ་ན་ལྔ་ཡོད་དེ། སྒོམ་བྱུང་གི་རྫུ་འཕྲུལ། སྐྱེས་ཐོབ་ཀྱི། གསང་སྔགས་ཀྱིས་ནམ་མཁའ་ལ་འགྲོ་ནུས་པ་ལྟ་བུ་གསང་སྔགས་ཀྱི། རྨ་བྱའི་མདོངས་དང་རུས་སྦལ་གྱི་ཟེ་བ་ལ་སོགས་པའི་སྨན་དག་དང༌། རྒྱལ་པོ་ང་ལས་ནུས་དང་བར་སྲིད་པ་ལྟ་བུ་ལས་ལས་སྐྱེས་པའི་རྫུ་འཕྲུལ་དང་ལྔ་ཡོད་པའི་ཕྱིར།
Enumeration Block 26:
གནས་བརྒྱད་པ་སྙོམས་འཇུག་བསྟན་པའི་གནས་བཤད་པ་ལ། སྙོམས་འཇུག་དངོས་དང༌། དེ་ལ་བརྟེན་པའི་ཡོན་ཏན་ནོ། །
Enumeration Block 27:
བསམ་གཏན་དག་ནི་རྣམ་གཉིས་བཞི། །ཞེས་སོགས་ཀྱི་སྐབས་སུ་སྤྱི་དོན། གཞུང་དོན་གཉིས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། བསྡུ་བ། སོ་སོའི་རང་བཞིན། བྱེ་བྲག་ཏུ་བསམ་གཏན་གྱི་ཡན་ལག་གི་དབྱེ་བསྡུ། ཉོན་མོངས་ཅན་ལ་ཡན་ལག་རྣམ་པར་མི་འཇོག་པའི་རྒྱུ་མཚན། ཁྱད་ཆོས་བཤད་པའོ། །
Enumeration Block 28:
