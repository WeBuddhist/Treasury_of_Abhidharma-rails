Enumeration Block 1:
གནས་བརྒྱད་པ་སྙོམས་འཇུག་བསྟན་པའི་གནས་བཤད་པ་ལ། སྙོམས་འཇུག་དངོས་དང༌། དེ་ལ་བརྟེན་པའི་ཡོན་ཏན་ནོ། །
Enumeration Block 2:
གཞུང་དོན་གཉིས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། བསྡུ་བ། སོ་སོའི་རང་བཞིན། བྱེ་བྲག་ཏུ་བསམ་གཏན་གྱི་ཡན་ལག་གི་དབྱེ་བསྡུ། ཉོན་མོངས་ཅན་ལ་ཡན་ལག་རྣམ་པར་མི་འཇོག་པའི་རྒྱུ་མཚན། ཁྱད་ཆོས་བཤད་པའོ། །
Enumeration Block 3:
གཉིས་པ་དེ་ལ་བརྟེན་པའི་ཡོན་ཏན་ལ། ཚད་མེད། རྣམ་ཐར། ཟིལ་གནོན། ཟད་པར་དེ་དག་གི་སྤྲོས་པའོ། །
Enumeration Block 4:
གཞུང་དོན་གཉིས། དང་པོ་ལ། ཆོས་འཁོར་ལ་མཚན་ཉིད། དབྱེ་བ། བསྟན་པའི་གནས་ཚད་དོ། །
Enumeration Block 5:
འདིའི་དོན་ལ། མདོ་ཕྱོགས་ནས་བསྟན་པའི་གནས་ཚད་མི་འདྲ་བ་གསུངས་པ་འགོད་པ། དེ་དང་ཕྱོགས་གཞན་ནས་གསུངས་པ་མཐུན་མི་མཐུན་དཔྱད་པ། བསྟན་པ་སྔ་དང་ཕྱི་དར་གྱི་རྣམ་གཞག་ལ་དཔྱད་པའོ། །
Enumeration Block 6:
འདི་ལ་ས་སྐྱ་ཕ་ཁུ་དབོན་གྱི་རྩི་ཚུལ། ཇོ་བོ་ཆེན་པོ་ཡབ་སྲས་ཀྱི་རྩི་ཚུལ། གང་གི་རྗེས་སུ་འབྲང་བའོ། །
