Enumeration Block 1:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་གསུམ། ལས་ཀྱི་རང་བཞིན། ལས་གསུམ་སྤྱིའི་ཆོས་ཀྱི་ཁྱད་པར། རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་དབྱེ་བའོ། །
Enumeration Block 2:
དབྱེ་ན། དོན་དམ་པའི་དགེ་བ། ངོ་བོ་ཉིད་ཀྱི་དགེ་བ། མཚུངས་ལྡན་གྱི་དགེ་བ། ཀུན་སློང་གི་དགེ་བ་བཞི་གསུངས་པའི།
Enumeration Block 3:
དབྱེ་ན། དོན་དམ་པའི། ངོ་བོ་ཉིད་ཀྱི། མཚུངས་ལྡན་གྱི། ཀུན་སློང་གི་མི་དགེ་བ་བཞི་གསུངས་པའི།
Enumeration Block 4:
དབྱེ་ན་བཞི་ལས།
Enumeration Block 5:
གསུམ་པ་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་དབྱེ་བ་སྟོན་པ་ལ། བསྟན་བཤད་གཉིས།
Enumeration Block 6:
དེ་ལ་གསུམ་སྟེ། སྡོམ་པ། སྡོམ་མིན་བར་མ་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
དབྱེ་ན། སོ་ཐར། བསམ་གཏན། ཟག་མེད་ཀྱི་སྡོམ་པ་གསུམ།
Enumeration Block 8:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། སྡོམ་པ་ལྡན་ཚུལ། ཐོབ་གཏོང༌། ལྡན་པའི་གང་ཟག་བཤད་པའོ། །
Enumeration Block 9:
དང་པོ་ནི། བསྟན་བཤད་གཉིས།
Enumeration Block 10:
སྡོམ་པ་ལ་གསུམ་ཡོད་དེ། སོ་ཐར་བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 11:
དབྱེ་ན་སོ་ཐར་རིགས་བརྒྱད། བསྡུ་ན་རྟེན་གྱི་སྒོ་ནས། ཁྱིམ་པའི་སོ་ཐར་གྱི་སྡོམ་པ། རབ་བྱུང་གི་སོ་ཐར་གྱི་སྡོམ་པ་གཉིས་སུ་འདུ། རྫས་རིགས་ཀྱི་སྒོ་ནས། དགེ་སློང༌། དགེ་ཚུལ། དགེ་བསྙེན། བསྙེན་གནས་ཀྱི་སྡོམ་པ་བཞིར་འདུ་སྟེ།
Enumeration Block 12:
དབྱེ་ན་དངོས་གཞིའི་སས་བསྡུས་ཀྱི་སྡོམ་པ། ཉེར་བསྡོགས་ཀྱིས་བསྡུས་པའི་སྡོམ་པ། རྟེན་གྱི་སྒོ་ནས་སོ་སྐྱེ་དང༌། འཕགས་པའི་རྒྱུད་ཀྱི་བསམ་གཏན་གྱི་སྡོམ་པ་གཉིས།
Enumeration Block 13:
དབྱེ་ན། འདོད་པའི་རྟེན་ལ་ཡོད་པ། གཟུགས་ཀྱི་རྟེན་ལ་ཡོད་པ། གཟུགས་མེད་ཀྱི་རྟེན་ལ་ཡོད་པའི་ཟག་མེད་ཀྱི་སྡོམ་པ་སྟེ་གསུམ་ཡོད།
Enumeration Block 14:
དེ་ལ་དབྱེ་ན། དགེ་སློང་ཕ་མའི་སྡོམ་པ་གཉིས།
Enumeration Block 15:
གསུམ་པ་ཐོབ་གཏོང་བཤད་པ་ལ། ཐོབ་ཚུལ་དང་གཏོང་ཚུལ་གཉིས། དང་པོ་ལ་སྡོམ་པའི་ཐོབ་ཚུལ། སྡོམ་མིན་གྱི་ཐོབ་ཚུལ། བར་མའི་ཐོབ་ཚུལ་ལོ། །དང་པོ་ལ། ཇི་ལྟར་ཐོབ་པ། གང་ཐོབ་པའོ། །དང་པོ་ལ། བསམ་གཏན་གྱི་སྡོམ་པའི། ཟག་མེད་ཀྱི་སྡོམ་པའི་སོ་ཐར་གྱི་སྡོམ་པའི་ཐོབ་ཚུལ་ལོ། །
