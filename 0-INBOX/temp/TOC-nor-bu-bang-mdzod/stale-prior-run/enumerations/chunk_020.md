Enumeration Block 2:

Enumeration Block 3:
བརྟེན་བསོད་ནམས་བྱ་བའི་གཞི་གསུམ་བཤད་པ་ནི། གསུམ་པ་བསོད་ནམས་བྱ་བ་དང༌། །ཞེས་སོགས་ཀྱི་སྐབས་སུ་གཉིས་ལས། དང་པོ་ནི། སྦྱིན་པ་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་གཞི། ཚུལ་ཁྲིམས་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་གཞི། སྒོམ་པ་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་གཞི་བཤད་པའོ། །
Enumeration Block 4:
གསུམ་པ་སྦྱིན་པ་གཏོང་ཚུལ་ལ་གསུམ། སྦྱིན་བདག་གི་ཁྱད་པར། དངོས་པོའི་ཁྱད་པར། ཞིང་གི་ཁྱད་པར་ལས་སྦྱིན་པ་ཁྱད་པར་དུ་འགྱུར་ཚུལ་ལོ། །

Enumeration Block 6:
