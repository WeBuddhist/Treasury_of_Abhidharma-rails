Enumeration Block 1:
གསུམ་པ་སྒོམ་པ་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་གཞི་ལ། དངོས་དང༌། གཞི་གསུམ་གྱི་འབྲས་བུ་བཤད་པའོ། །
Enumeration Block 2:
གནས་ལྔ་པ་ཕྲ་རྒྱས་བསྟན་པ་འཆད་པ་ལ། མཚམས་སྦྱར། ཕྲ་རྒྱས་དངོས། དེ་ཇི་ལྟར་སྤོང་ཚུལ། སྤངས་པའི་འབྲས་བུ་ཡོངས་ཤེས་སོ། །
གནས་འདིའི་སྤྱི་དོན་ཐུན་མོང་དུ་སྟོན་པའི་ཉོན་མོངས་པ་ལ་མཚན་ཉིད། དབྱེ་བ། རྣམ་པའི་བྱེ་བྲག་སྟེ། སེམས་ཕྲ་རྒྱས་དང་བཅས་ཚུལ། ཉོན་མོངས་སྐྱེ་ཚུལ། རྣམ་གྲངས། །གང་དང་མཚུངས་པར་ལྡན་པ། སྒྲིབ་པ་ལྔ་བྱེ་བྲག་ཏུ་བཤད་པ། སྤངས་པའི་འབྲས་བུ་ཡོངས་ཤེས་སོ། །
Enumeration Block 3:
གཉིས་པ་ལ། རྩ་བའི་དབྱེ་བ། ཁྱད་པར་གྱི་དབྱེ་བ། ཞར་བྱུང་ངོ་། །
Enumeration Block 4:
གཉིས་པ་ལ་དབང་པོའི་སྒོ་ནས་བདུན་དུ་དབྱེ་བ། ལྟ་བའི་སྒོ་ནས་བཅུར་དབྱེ་བ། ཁམས་ཀྱི་སྒོ་ནས་གོ་བརྒྱད་དུ་དབྱེ་བའོ། །
Enumeration Block 5:
གསུམ་པ་ཞར་བྱུང་ལ་ལྔ། སྤང་བྱ་གཉིས་ཀྱི་ངེས་པ། ལྟ་བ་ལྔ་སོ་སོའི་མཚན་ཉིད། ལྟ་བ་ཐ་མ་དང་འབྲེལ་པའི་རྩོད་སྤང༌། ཕྱིན་ཅི་ལོག་གི་རབ་དབྱེ། ང་རྒྱལ་གྱི་དབྱེ་བ་སྤྲོས་པ་དང་བཅས་པའོ། །
Enumeration Block 6:
ལྔ་པ་ལ། ང་རྒྱལ་གྱི་དབྱེ་བ། བསྡུ་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། གསུམ་དུ་བསྡུ་བ། སྤང་བྱ་གཉིས་སུ་བསྡུ་བའོ། །
Enumeration Block 8:
གསུམ་པ་རྣམ་པའི་བྱེ་བྲག་བཤད་པ་ལ། རྒྱུ་ལ་ལྟོས་པའི་རབ་དབྱེ། དམིགས་ཡུལ་ལ་ལྟོས་པའི། ངོ་བོ་ལ་ལྟོས་པའི། དུས་ལ་ལྟོས་པའི། ལྡན་ཚུལ། ཡུལ་ཅན་གྱི་བྱེ་བྲག་གོ
Enumeration Block 9:
གསུམ་པ་ལ་དངོས་དང༌། རྩ་བའི་དབྱེ་བ། དྲི་བ་ལུང་མ་བསྟན་གྱི་ཞར་བྱུང་ངོ༌། །
Enumeration Block 10:
བཞི་པ་དུས་ལ་ལྟོས་པའི་ལྡན་ཚུལ་ལ། དངོས་དང༌། ཞར་ལ་དུས་ཀྱི་རྣམ་གཞག་ལ་དཔྱད་པ། སྤང་བ་དང་བྲལ་བའི་ཁྱད་པར་བཤད་པའོ། །
