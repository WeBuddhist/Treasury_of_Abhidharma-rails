Enumeration Block 1:
ཕྲ་རྒྱས་གོ་བརྒྱད་པོ་དེ་ལ། སྐལ་མཉམ་གྱི་ཀུན་འགྲོ། སྐལ་པ་མི་མཉམ་གྱི་ཀུན་འགྲོ། དེ་ལས་གཞན་པའི་ཀུན་འགྲོ་དང་གསུམ་ཡོད་དེ།
Enumeration Block 2:
ཕྲ་རྒྱས་གོ་བརྒྱད་པོ་ལ་ཟག་བཅས་ལ་དམིགས་པ་ཟག་མེད་ལ་དམིགས་པ་གཉིས་ཡོད་དེ།
Enumeration Block 3:
སྤྱིར་དྲི་བ་བཞི་ཡོད་དེ། མགོ་གཅིག་པའི་དྲི་བ། རྣམ་པར་ཕྱེ་སྟེ་ལན་བཏབ་པའི་དྲི་བ། དྲིས་ནས་ལན་བཏབ་པའི་དྲི་བ། བཞག་པར་ལུང་མ་བསྟན་པའི་དྲི་བ་དང་བཞི་ཡོད་པའི་ཕྱིར་ཏེ།
Enumeration Block 4:
ཉོན་མོངས་ལ་རང་གི་མཚན་ཉིད་པའི་ཉོན་མོངས་དང༌། ཉོན་མོངས་སྤྱི་པ་ཞེས་བྱ་བ་གཉིས་ལས།
Enumeration Block 5:
ཁྱད་པར་དུ་འདས་མ་འོངས་རྫས་སུ་ལུང་རིགས་གཉིས་ཀྱིས་གྲུབ།
Enumeration Block 6:
གཞི་ཐམས་ཅད་ཡོད་པར་སྨྲ་བའི་སྡེ་པ་ལ་བཞི་ཡོད་དེ། དངོས་པོ་གཞན་དུ་འགྱུར་བར་སྨྲ་བ། མཚན་ཉིད་གཞན་དུ་འགྱུར་བར་སྨྲ་བ། གནས་སྐབས་གཞན་དུ་འགྱུར་བར་སྨྲ་བ། གཞན་གཞན་དུ་འགྱུར་བར་སྨྲ་བ་སྟེ་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
ལྔ་པ་ཉོན་མོངས་སྐྱེ་ཚུལ་ལ། སྐྱེ་བའི་གོ་རིམ་དང༌། སྐྱེ་བའི་རྒྱུ་གཉིས།
Enumeration Block 8:
ཟག་པ་ལ་ནི་འདོད་པའི་ཟག་པ་དང༌། སྲིད་པའི་ཟག་པ། མ་རིག་པའི་ཟག་པ་དང་གསུམ།
Enumeration Block 9:
ཉེར་ལེན་ལའང་ལྟ་བ་ཉེར་ལེན། འདོད་པ་ཉེར་ལེན། བདག་ཏུ་ལྟ་བ་ཉེ་བར་ལེན་པ། ཚུལ་ཁྲིམས་མཆོག་ཏུ་འཛིན་པ་ཉེ་བར་ལེན་པ་བཞི་ཡོད།
Enumeration Block 10:
ཀུན་སྦྱོར། འཆིང་བ། ཕྲ་རྒྱུས། ཉེ་ཉོན། ཀུན་དཀྲིས་ཞེས་ལྔ་གསུངས་ཏེ།
Enumeration Block 11:
ཀུན་སྦྱོར་ལ་དགུ་ཡོད་དེ། རྩ་ཉོན་དྲུག་གི་ཀུན་སྦྱོར། མཆོག་འཛིན་གཉིས་ཀྱི་ཀུན་སྦྱོར། ཕྲག་དོག་སེར་སྣའི་ཀུན་སྦྱོར་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 12:
དང་པོ་ལ། འཇིག་ལྟ་ཀུན་སྦྱོར། ཚུལ་ཁྲིམས་མཆོག་འཛིན། ཐེ་ཚོམ་སྟེ་གསུམ་ཡོད།
Enumeration Block 13:
ཐ་མའི་ཀུན་སྦྱོར་ལ་ལྔ་ཡོད་དེ།
