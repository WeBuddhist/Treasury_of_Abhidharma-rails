Enumeration Block 1:
འདི་ལ་གསུམ། ཀླད་ཀྱི་དོན་དང༌། གཞུང་གི་དོན་དང༌། མཇུག་གི་དོན་བཤད་པའོ། །དང་པོ་ལ། མཚན་གྱི་དོན་དང༌། འགྱུར་གྱི་ཕྱག་བཤད་པ་གཉིས། དང་པོ་ལ། བསྟན་བཅོས་འདིའི་རྒྱ་སྐད་གྱི་མཚན་དང༌། དེ་བོད་ཀྱི་སྐད་དུ་བསྒྱུར་བ་གཉིས།
Enumeration Block 2:
གཉིས་པ་འགྱུར་གྱི་ཕྱག་ལ། གཞུང་དགོད་པ་དང༌། དོན་བཤད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། བསྟན་བཅོས་ལ་འཇུག་པའི་ཡན་ལག་དང༌། གཞུང་གི་དོན་དངོས་དང༌། བཤད་པ་མཐར་ཕྱིན་པའི་ཚུལ་གསུམ། དང་པོ་ལ། མཆོད་པར་བརྗོད་པ། བརྩམ་པར་དམ་བཅའ་བ། མངོན་པའི་མཚན་དོན། བརྩམས་པའི་དགོས་པ་བཤད་པ་བཞི། དང་པོ་ལ་གཞུང་དགོད་པ་དང༌། དེའི་དོན་བཤད་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ་ཚིག་དོན་དང༌། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 5:
གསུམ་པ་ལ། དོན་དམ་པའི་ཆོས་མངོན་པའི་དོན་དང༌། བརྡར་བཏགས་པའི་ཆོས་མངོན་པའི་དོན་དང༌། མཛོད་ཀྱི་མཚན་དོན་བཤད་པ་གསུམ།
Enumeration Block 6:
འདི་ལ་ཚིག་དོན་དང༌། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 7:
འདི་ལ་ཚིག་དོན་དང༌། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 8:
འདི་ལ་ཚིག་དོན་དང༌། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 9:
འདི་ལ་ཚིག་དོན་དང༌། མཐའ་དཔྱད་པ་གཉིས།
