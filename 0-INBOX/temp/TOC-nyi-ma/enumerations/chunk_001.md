Enumeration Block 1:
འདི་ལ་ཚིག་དོན་དང༌། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 2:
གཉིས་པ་གཞུང་དོན་དངོས་ལ། ལུས་ཀྱི་སྒོ་ནས་མདོར་བསྟན་པ་དང༌། ཡན་ལག་གི་སྒོ་ནས་རྒྱས་པར་བཤད་པ་གཉིས། དང་པོ་ལ་གཉིས། བརྗོད་བྱའི་དོན་བསྡུས་ཏེ་བསྟན་པ་དང༌། ཅུང་ཟད་ཕྱེ་སྟེ་བཤད་པ་གཉིས།
Enumeration Block 3:

Enumeration Block 4:

Enumeration Block 5:
གཉིས་པ་ཡན་ལག་གི་སྒོ་ནས་རྒྱས་པར་བཤད་པ་ལ། གང་ལ་མཁས་པར་བྱ་དགོས་པའི་གནས་ངོས་བཟུང་བ་དང༌། དེ་ལྟར་མཁས་པར་བྱས་པའི་ཡོན་ཏན་བསྟན་པ་གཉིས། དང་པོ་ལ། མཁས་བྱའི་གནས་དང༌། དེ་ཉིད་ངེས་པར་བྱེད་པའི་ཚུལ་གཉིས། དང་པོ་ལ། ཡུལ་ཕུང་ཁམས་སྐྱེ་མཆེད་ཀྱི་རྣམ་གཞག་དང༌། ཡུལ་ཅན་དབང་པོའི་རབ་དབྱེ་བཤད་པ་གཉིས། དང་པོ་ལ། འདུས་བྱས་སྤྱིའི་མཚན་ཉིད་དང༌། ཆོས་གསུམ་གྱི་རྣམ་གཞག་དང༌། ཁམས་ཀྱི་རྣམ་པ་རབ་དབྱེ་དང་གསུམ། དང་པོ་ལ། མཚན་ཉིད་ཀྱི་སྒོ་ནས་དབྱེ་བ་དང༌། རྣམ་གྲངས་ཀྱི་དབྱེ་བ་གཉིས།
Enumeration Block 6:
