Enumeration Block 1:
འདི་ལ་གཉིས། ཚིག་དོན་དང༌། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 2:
འདི་ལ་ཚིག་དོན་དང༌། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་གཟུགས་སེམས་གཉིས་ལས་གཞན་པའི་ཆོས་ལ། ངོ་བོ་དང༌། དེ་ལས་ཁམས་དང་སྐྱེ་མཆེད་འཇོག་ཚུལ་གཉིས།
Enumeration Block 4:
འདི་ལ་ཚིག་དོན་དང༌། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 5:
གསུམ་པ་སེམས་ཀྱིས་བསྡུས་པའི་ཆོས་གསུམ་ལ། ཆོས་གསུམ་གྱི་རང་བཞིན། ཆོས་གསུམ་གྱི་གཙོ་བོ་ངོས་བཟུང་བ། ཞར་ལ་ཁམས་ཀྱི་གྲངས་ངེས་ལ་རྩོད་པ་སྤང་བ་གསུམ།
Enumeration Block 6:
འདི་ལས། ཚིག་དོན་དང༌། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ་ཆོས་གསུམ་གྱི་ཁྱད་ཆོས་ལ། ཆོས་གསུམ་གྱི་སྒྲ་དོན། ཆོས་གསུམ་གསུངས་པའི་དགོས་པ། ཆོས་གསུམ་གྱི་གོ་རིམ་གསུམ།
Enumeration Block 8:
འདི་ལ་ཚིག་དོན་དང༌། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 9:
གཉིས་པ་ལ། ཆོས་གསུམ་བསྟན་པའི་དགོས་པ་དང༌། དོགས་གཅོད་གཉིས།
Enumeration Block 10:
གསུམ་པ་གོ་རིམ་ལ། ཕུང་པོའི་གོ་རིམ། ཁམས་དང་སྐྱེ་མཆེད་ཀྱི་གོ་རིམ། ཞར་བྱུང་དང་གསུམ།
