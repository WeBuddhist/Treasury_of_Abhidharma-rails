Enumeration Block 1:
གསུམ་པ་གོ་རིམ་ལ། ཕུང་པོའི་གོ་རིམ། ཁམས་དང་སྐྱེ་མཆེད་ཀྱི་གོ་རིམ། ཞར་བྱུང་དང་གསུམ།
Enumeration Block 2:
གསུམ་པ་ཆོས་གསུམ་གྱིས་གཞན་བསྡུས་ཚུལ་ལ། ཆོས་ཕུང་གིས་བསྡུས་ཚུལ་དང༌། ཕུང་ཁམས་གཞན་བསྡུས་ཚུལ་གཉིས།དང་པོ་ལ། དངོས་དང༌། ཞར་བྱུང་གཉིས།
Enumeration Block 3:
གསུམ་པ་ཁམས་ཀྱི་རྣམ་པ་ཤར་བ་དབྱེ་བཤད་པ་ལ། མཚན་ཉིད་ཀྱི་སྒོ་ནས་བཤད་པ། སུམ་ཚན་གྱི་སྒོ་ནས། བཅས་མ་བཅས་ཀྱི་སྒོ་ནས། གྲུབ་པ་སོགས་ཀྱི་སྒོ་ནས། བྱུང་སོགས་ཀྱི་སྒོ་ནས། ལྟ་སོགས་ཀྱི་དབྱེ་བ་དྲུག །
Enumeration Block 4:
གཉིས་པ་ལ། དགེ་སོགས་གསུམ་དུ་དབྱེ་བ་ཁམས་གསུམ་གྱི་སྒོ་ནས་དབྱིབས་གཉིས།
Enumeration Block 5:
གསུམ་པ་ལ། ཟག་པ་དང་བཅས་མ་བཅས། རྟོག་པ་དང་བཅས་མ་བཅས། དམིགས་པ་དང་བཅས་མ་བཅས་གསུམ།
Enumeration Block 6:
གཉིས་པ་ལ་དངོས་དང༌། རྩོད་སྤོང་གཉིས།
Enumeration Block 7:
བཞི་པ་ལ། ཟིན་མ་ཟིན་གྱི་སྒོ་ནས་དབྱེ་བ། འབྱུང་བ་དང་འབྱུང་གྱུར་གྱི་སྒོ་ནས་དབྱེ་བ། བསགས་མ་བསགས་ཀྱི་སྒོ་ནས་དབྱེ་བ། གཅད་བྱ་གཅོད་བྱེད་ཀྱི་སྒོ་ནས་དབྱེ་བ་བཞི།
Enumeration Block 8:
འདི་ལ་ཚིག་དོན་དང༌། མཐའ་དཔྱད་པ་གཉིས།
