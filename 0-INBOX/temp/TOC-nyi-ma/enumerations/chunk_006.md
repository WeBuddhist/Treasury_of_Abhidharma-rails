Enumeration Block 1:
གཉིས་པ་ཡུལ་ཅན་དབང་པོའི་རབ་དབྱེ་བཤད་པ་ལ། དབང་པོ་ཉེར་གཉིས་ཀྱི་རང་བཞིན། འདུས་བྱས་ཀྱི་ཆོས་རྣམས་ཀྱི་སྐྱེ་ཚུལ། རྒྱུ་རྐྱེན་འབྲས་བུའི་འབྱུང་ཚུལ་གྱི་སྒོ་ནས་བཤད་པ་དང་གསུམ། དང་པོ་ལ། དབང་པོར་འཇོག་པའི་རྒྱུ་མཚན། དབང་པོའི་གྲངས་ངེས། ངོ་བོ།རབ་དབྱེ་དང་བཞི། དང་པོ་ལ། བྱེ་བྲག་ཏུ་སྨྲ་བའི་ལུགས་དང་། མདོ་སྡེ་པའི་ལུགས་གཉིས།
Enumeration Block 2:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་གྲངས་ངེས་ལ། བྱེ་བྲག་སྨྲ་བ་དང་། མདོ་སྡེ་པའི་ལུགས་གཉིས།
Enumeration Block 4:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 5:
གསུམ་པ་ངོ་བོ་ལ། ཚོར་བའི་དབང་པོ་ལྔ་བཤད་པ་དང་། དྲི་མེད་ཀྱི་དབང་པོ་གསུམ་བཤད་པ་གཉིས།
Enumeration Block 6:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 7:
བཞི་པ་དབང་པོའི་དབྱེ་བ་ལ། དབང་པོའི་དབྱེ་བ་དངོས། དེ་རྙེད་གཏོང་གི་ཚུལ། དགེ་སྦྱོང་ཚུལ་གྱི་འབྲས་བུ་དབང་པོ་དུས་འཐོབ་ཚུལ། དབང་པོ་ལྡན་ཚུལ་བཞི། དང་པོ་ལ། གཉིས་ཚན་དང་། གསུམ་ཚན་གྱི་དབྱེ་བ་གཉིས། དང་པོ་ལ། ཟག་པ་དང་བཅས་མ་བཅས་ཀྱི་སྒོ་ནས་དབྱེ་བ། རྣམ་སྨིན་ཡིན་མིན་གྱི་སྒོ་ནས། རྣམ་སྨིན་དང་བཅས་མ་བཅས་ཀྱི་སྒོ་ནས་དབྱེ་བ་གསུམ།
Enumeration Block 8:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
