Enumeration Block 1:
བཞི་པ་དབང་པོའི་དབྱེ་བ་ལ། དབང་པོའི་དབྱེ་བ་དངོས། དེ་རྙེད་གཏོང་གི་ཚུལ། དགེ་སྦྱོང་ཚུལ་གྱི་འབྲས་བུ་དབང་པོ་དུས་འཐོབ་ཚུལ། དབང་པོ་ལྡན་ཚུལ་བཞི། དང་པོ་ལ། གཉིས་ཚན་དང་། གསུམ་ཚན་གྱི་དབྱེ་བ་གཉིས། དང་པོ་ལ། ཟག་པ་དང་བཅས་མ་བཅས་ཀྱི་སྒོ་ནས་དབྱེ་བ། རྣམ་སྨིན་ཡིན་མིན་གྱི་སྒོ་ནས། རྣམ་སྨིན་དང་བཅས་མ་བཅས་ཀྱི་སྒོ་ནས་དབྱེ་བ་གསུམ།
Enumeration Block 2:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། དགེ་སོགས་གསུམ་དང་། ཁམས་གསུམ་དང་། མཐོང་སྤང་སོགས་གསུམ་གྱི་སྒོ་ནས་དབྱེ་བ་གསུམ།
Enumeration Block 4:
གཉིས་པ་རྙེད་གཏོང་གི་ཚུལ་ལ། རྙེད་པའི་ཚུལ་དང་། གཏོང་བའི་ཚུལ་གཉིས། དང་པོ་ལ། འདོད་པ་དང་། གོང་མའི་དབང་དུ་བྱས་པ་གཉིས། དང་པོ་ལ། མངལ་སྐྱེས་དང་།རྫུས་སྐྱེས་ཀྱི་དབང་དུ་བྱས་པ་གཉིས་ཏེ།
Enumeration Block 5:
གཉིས་པ་ལ། ཉོན་མོངས་ཅན་ལུང་མ་བསྟན་གྱི་གཏོང་ཚུལ་དང་། དགེ་སེམས་ཅན་གྱི་གཏོང་ཚུལ་གཉིས། དང་པོ་ལ། ཁམས་གོང་མ་དང་། འདོད་ཁམས་ཀྱི་གཏོང་ཚུལ་གཉིས།
Enumeration Block 6:
བཞི་པ་ལྡན་ཚུལ་ལ། ངེས་ལྡན་དང་། སྲིད་ལྡན་གཉིས། དང་པོ་ལ། ཕན་ཚུན་ངེས་ལྡན་དང་། དབང་པོ་གཞན་ངེས་ལྡན་གྱི་ཚུལ་གཉིས།
Enumeration Block 7:
གཉིས་པ་སྲིད་ལྡན་ལ། ཉུང་ལྡན་དང་། མང་ལྡན་གཉིས།
Enumeration Block 8:
གཉིས་པ་འདུས་བྱས་སྐྱེ་ཚུལ་ལ། གཟུགས་ཅན་སྐྱེ་ཚུལ་དང་། དེ་མིན་པའི་སྐྱེ་ཚུལ་གཉིས།
Enumeration Block 9:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
