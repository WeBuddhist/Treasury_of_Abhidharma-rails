Enumeration Block 1:
གཉིས་པ་འདུས་བྱས་སྐྱེ་ཚུལ་ལ། གཟུགས་ཅན་སྐྱེ་ཚུལ་དང་། དེ་མིན་པའི་སྐྱེ་ཚུལ་གཉིས།
Enumeration Block 2:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། མཚུངས་ལྡན་འདུ་བྱེད་དང་། ལྡན་མིན་འདུ་བྱེད་གཉིས། དང་པོ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། སེམས་བྱུང་སྤྱིའི་རྣམ་གཞག །གཙོ་སེམས་གང་གི་འཁོར་དུ་སེམས་བྱུང་དུ་འགྲོ་བ། ཞར་ལ་སེམས་བྱུང་འགའ་ཞིག་གི་ཁྱད་པར་བཤད་པ་གསུམ། དང་པོ་ལ། ངེས་པའི་མཚུངས་ལྡན་འདུ་བྱེད་དང་། མ་ངེས་པའི་མཚུངས་ལྡན་འདུ་བྱེད་གཉིས། དང་པོ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ། འདོད་པ་དང་། ཁམས་གོང་མའི་དབང་དུ་བྱས་པ་གཉིས། དང་པོ་ལ། དགེ་བ་དང་། མི་དགེ་བ་དང་། ལུང་མ་བསྟན་གྱི་དབང་དུ་བྱས་པ་གསུམ།
Enumeration Block 6:
གཉིས་པ་ལམ་འདྲེས་པ་དང་། འདྲེས་པ་གཉིས་
Enumeration Block 7:
གསུམ་པ་སེམས་བྱུང་འགའ་ཞིག་གི་ཁྱད་པར་ལ། སེམས་བྱུང་བརྒྱད་ཀྱི་ཁྱད་པར་དང་། སེམས་སེམས་བྱུང་གི་མིང་གི་རྣམ་གྲངས་གཉིས།
