Enumeration Block 1:
གསུམ་པ་སེམས་བྱུང་འགའ་ཞིག་གི་ཁྱད་པར་ལ། སེམས་བྱུང་བརྒྱད་ཀྱི་ཁྱད་པར་དང་། སེམས་སེམས་བྱུང་གི་མིང་གི་རྣམ་གྲངས་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལྡན་མིན་འདུ་བྱེད་ལ། དབྱེ་བ་མདོར་བསྟན་པ་དང་། རང་བཞིན་རྒྱས་པར་བཤད་པ་དང་། ཁྱད་པར་གཞན་བསྟན་པའི་སྒོ་ནས་དོན་བསྡུ་བ་གསུམ།
Enumeration Block 3:
གཉིས་པ་ལ། ཐོབ་པ་སོགས་གསུམ་བཤད་པ་དང་། འདུ་ཤེས་མེད་པ་སོགས་གསུམ་བཤད་པ་དང་། སྲོག་སོགས་ལྔ་བཤད་པ་དང་། མིང་ཚིག་སོགས་གསུམ་བཤད་པ་དང་བཞི། དང་པོ་ལ། ཐོབ་མ་ཐོབ་དང་། སྐལ་མཉམ་བཤད་པ་གཉིས། དང་པོ་ལ། ཐོབ་མ་ཐོབ་ཀྱི་ངོ་བོ་དང་། ཁྱད་ཆོས་གཉིས།
Enumeration Block 4:
གཉིས་པ་ཁྱད་ཆོས་སོ་སོར་བཤད་པ་ལ། ཐོབ་པའི་ཁྱད་ཆོས་དང་། མ་ཐོབ་པའི་ཁྱད་ཆོས་གཉིས། དང་པོ་ལ། སྤྱིར་བསྟན་པ་དང་། དམིགས་བསལ་གཉིས།
Enumeration Block 5:
འདི་ལ་གཉིས། ཚིག་དོན་དང་། མཐའ་དཔྱད་པའོ། །
Enumeration Block 6:
གཉིས་པ་མ་ཐོབ་པའི་ཁྱད་ཆོས་ལ། སྤྱིར་བསྟན་པ་དང་། གཏོང་ཚུལ་གཉིས།
Enumeration Block 7:
གཉིས་པ་འདུ་ཤེས་མེད་པ་སོགས་གསུམ་ལ། འདུ་ཤེས་མེད་པ་དང་། དེའི་སྙོམས་འཇུག་དང་། འགོག་པའི་སྙོམས་འཇུག་གསུམ།
