Enumeration Block 1:
གསུམ་པ་སྲོག་སོགས་ལྔ་བཤད་པ་ལ། སྲོག་དབང་བཤད་པ་དང་། འདུས་བྱས་ཀྱི་མཚན་ཉིད་བཤད་པ་གཉིས།
Enumeration Block 2:
གསུམ་པ་རྒྱུ་རྐྱེན་འབྲས་བུའི་རྣམ་གཞག་ལ། རྒྱུ་འབྲས་སྤྱིར་བསྟན་པ་དང་། རྐྱེན་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས། དང་པོ་ལ། རྒྱུ་དང་འབྲས་བུ་བཤད་པ་གཉིས་དང་། དེ་གཉིས་ཀྱི་ཐུན་མོང་གི་ཆོས་བཤད་པ་གསུམ། དང་པོ་ལ། དབྱེ་བ་མདོར་བསྟན་པ་དང་།རང་བཞིན་རྒྱས་པར་བཤད་པ་དང་། དོན་བསྡུ་བ་གསུམ།
Enumeration Block 3:
གཉིས་པ་ལ་དྲུག་ལས།
Enumeration Block 4:
འདི་ལ་མཚན་ཉིད། མཚན་གཞི། སེམས་ཀྱི་རྗེས་འཇུག་ངོས་བཟུང་། དེ་རྗེས་སུ་འཇུག་ཚུལ་བཞི།
Enumeration Block 5:
གསུམ་པ་སྐལ་མཉམ་གྱི་རྒྱུ་ལ། ངོ་བོ་སྤྱིར་བསྟན་པ་དང་། ནང་ཚན་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ། ཉོན་མོངས་ཅན་དང་། ཉོན་མོངས་ཅན་མ་ཡིན་པ་གཉིས་ལས།
