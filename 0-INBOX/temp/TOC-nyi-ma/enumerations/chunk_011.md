Enumeration Block 1:
གསུམ་པ་སྐལ་མཉམ་གྱི་རྒྱུ་ལ། ངོ་བོ་སྤྱིར་བསྟན་པ་དང་། ནང་ཚན་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལ། ཉོན་མོངས་ཅན་དང་། ཉོན་མོངས་ཅན་མ་ཡིན་པ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་འབྲས་བུ་ལ། མཚན་གཞི། འབྲས་བུ་གང་རྒྱུ་ལས་སྐྱེས་པ། འབྲས་བུ་སོ་སོའི་ངོ་བོ་དང་གསུམ།
Enumeration Block 4:
གསུམ་པ་རྒྱུ་འབྲས་གཉིས་ཀའི་ཐུན་མོང་གི་ཆོས་ལ། འབྲས་བུ་འཛིན་འབྱིན་གྱི་ཁྱད་པར་དང་། འབྲས་བུ་གང་རྒྱུ་དུ་ཞིག་གིས་སྐྱེད་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ། མཚུངས་ལྡན་རྒྱུ་དུ་ལས་བྱུང་བ་དང་། མཚུངས་ལྡན་མིན་པ་རྒྱུ་དུ་ལས་བྱུང་བ་གཉིས།
Enumeration Block 6:
གཉིས་པ་རྐྱེན་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། སྤྱིར་བསྟན་པ་དང་། དེ་མ་ཐག་རྐྱེན་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས། དང་པོ་ལ། དབྱེ་བ་མདོར་བསྟན་པ་དང་། སོ་སོའི་རང་བཞིན་རྒྱས་པར་བཤད་པ། དེ་དག་གི་ཁྱད་ཆོས་གཞན་བཤད་པ་གསུམ།
Enumeration Block 7:
གསུམ་པ་ལ། རྐྱེན་གང་གིས་འབྲས་བུ་གང་ལ་བྱ་བ་བྱེད་ཚུལ། འབྲས་བུ་གང་རྐྱེན་གང་ལས་བྱུང་ཚུལ། འབྱུང་བ་དང་འབྱུང་འགྱུར་གཉིས་རྐྱེན་དང་རྐྱེན་ཅན་དུ་འགྱུར་ཚུལ་གསུམ།
