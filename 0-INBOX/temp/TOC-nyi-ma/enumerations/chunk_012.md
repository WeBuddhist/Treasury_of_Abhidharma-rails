Enumeration Block 1:
གསུམ་པ་ལ། རྐྱེན་གང་གིས་འབྲས་བུ་གང་ལ་བྱ་བ་བྱེད་ཚུལ། འབྲས་བུ་གང་རྐྱེན་གང་ལས་བྱུང་ཚུལ། འབྱུང་བ་དང་འབྱུང་འགྱུར་གཉིས་རྐྱེན་དང་རྐྱེན་ཅན་དུ་འགྱུར་ཚུལ་གསུམ།
Enumeration Block 2:
གསུམ་པ་ལ། འབྱུང་བ་རྒྱུར་བྱས་པ་དང་། འབྱུང་གྱུར་རྒྱུར་བྱས་པ་གཉིས། དང་པོ་ལ། འབྱུང་བ་སྐྱེད་པ་དང་། འབྱུང་གྱུར་སྐྱེད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ནི། འབྱུང་གྱུར་ལས་རང་ཉིད་སྐྱེ་བ་དང་། དེ་ལས་འབྱུང་བ་བསྐྱེད་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་དེ་མ་ཐག་རྐྱེན་ལ། བཅུ་གཉིས་སུ་དབྱེ་བ། ཉི་ཤུར་དབྱེ་བ། བཅུ་གཉིས་པོ་གང་ལས་གང་གསར་དུ་རྙེད་ཚུལ་གསུམ། དང་པོ་ལ། དབྱེ་བ་དངོས་དང་། དེ་མ་ཐག་པའི་རྐྱེན་དང་རྐྱེན་ཅན་སྦྱར་བ་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ། འདོད་པ་དང་། གཟུགས་དང་། གཟུགས་མེད་དང་། ཟག་མེད་ཀྱི་དབང་དུ་བྱས་པ་བཞི།
Enumeration Block 6:
གཉིས་པ་དེ་ཉིད་ངེས་པར་བྱེད་པའི་ཚུལ་ལ། ཤེས་བྱ་སྡུག་བསྔལ་གྱི་བདེན་པ་གཏན་ལ་དབབ་པ། སྤང་བྱ་ཀུན་འབྱུང་གི་བདེན་པ་གཏན་ལ་དབབ་པ། ཐོབ་བྱ་འགོག་ལམ་གྱི་བདེན་པ་གཏན་ལ་དབབ་པ་གསུམ། དང་པོ་ལ། ནང་བཅུད་ཀྱི་འཇིག་རྟེན་གྱི་རྣམ་གཞག་དང་། ཕྱི་སྣོད་ཀྱི་འཇིག་རྟེན་གྱི་རྣམ་གཞག་གཉིས། དང་པོ་ལ། དབྱེ་བ་སྤྱིར་སྟན་པ་དང་། རྟེན་འབྲེས་བྱེ་བྲག་ཏུ་བཤད་པ། སྐྱེ་བ་གནས་པའི་ཐབས། གནས་པ་འཆི་བའི་འཕོ་སེམས། སེམས་ཀྱི་ཚོགས་གསུམ་དུ་སྡུད་པ་ལྔ། དང་པོ་ལ། ཁམས་གསུམ་དུ་དབྱེ་བ། འགྲོ་བ་རིགས་ལྔར་དབྱེ་བ། སྐྱེ་གནས་བཞིར་དབྱེ་བ་གསུམ། དང་པོ་ལ། འདོད་ཁམས། གཟུགས་ཁམས། གཟུགས་མེད་ཁམས་བཤད་པ་དང་གསུམ།
