Enumeration Block 1:
གཉིས་པ་དེ་ཉིད་ངེས་པར་བྱེད་པའི་ཚུལ་ལ། ཤེས་བྱ་སྡུག་བསྔལ་གྱི་བདེན་པ་གཏན་ལ་དབབ་པ། སྤང་བྱ་ཀུན་འབྱུང་གི་བདེན་པ་གཏན་ལ་དབབ་པ། ཐོབ་བྱ་འགོག་ལམ་གྱི་བདེན་པ་གཏན་ལ་དབབ་པ་གསུམ། དང་པོ་ལ། ནང་བཅུད་ཀྱི་འཇིག་རྟེན་གྱི་རྣམ་གཞག་དང་། ཕྱི་སྣོད་ཀྱི་འཇིག་རྟེན་གྱི་རྣམ་གཞག་གཉིས། དང་པོ་ལ། དབྱེ་བ་སྤྱིར་སྟན་པ་དང་། རྟེན་འབྲེས་བྱེ་བྲག་ཏུ་བཤད་པ། སྐྱེ་བ་གནས་པའི་ཐབས། གནས་པ་འཆི་བའི་འཕོ་སེམས། སེམས་ཀྱི་ཚོགས་གསུམ་དུ་སྡུད་པ་ལྔ། དང་པོ་ལ། ཁམས་གསུམ་དུ་དབྱེ་བ། འགྲོ་བ་རིགས་ལྔར་དབྱེ་བ། སྐྱེ་གནས་བཞིར་དབྱེ་བ་གསུམ། དང་པོ་ལ། འདོད་ཁམས། གཟུགས་ཁམས། གཟུགས་མེད་ཁམས་བཤད་པ་དང་གསུམ།
Enumeration Block 2:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། དངོས་དང་། དོགས་དཔྱོད་དང་བཅས་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། སེམས་ཀྱིས་གནས་པ་བདུན་བཤད་པ། སེམས་ཅན་གྱི་གནས་དགུ་བཤད་པ། སེམས་ཀྱི་གནས་པ་བཞི་བཤད་པ་གསུམ།
Enumeration Block 5:
གསུམ་པ་སྐྱེ་གནས་བཞིར་དབྱེ་བ་ལ། གང་དུ་འཇུག་པ་སྐྱེ་གནས་ཀྱི་དབྱེ་བ། གང་འཇུག་པ་བར་སྲིད་ཀྱི་རང་བཞིན། དེ་སྐྱེ་གནས་སུ་འཇུག་ཚུལ་གསུམ།
Enumeration Block 6:
གཉིས་པ་བར་སྲིད་ལ། ངོ་བོ། སྒྲུབ་བྱེད། ཁྱད་ཆོས་གསུམ།
Enumeration Block 7:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 8:
གཉིས་པ་སྒྲུབ་བྱེད་ལ། རིགས་པ་དང་། ལུང་གཉིས།
