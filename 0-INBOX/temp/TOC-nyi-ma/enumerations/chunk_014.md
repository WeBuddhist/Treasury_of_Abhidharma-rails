Enumeration Block 1:
གཉིས་པ་སྒྲུབ་བྱེད་ལ། རིགས་པ་དང་། ལུང་གཉིས།
Enumeration Block 2:
གསུམ་པ་སྐྱེ་གནས་སུ་བགྲོད་པའི་ཚུལ་ལ། དངོས་དང་། དབྱེ་བ་གཉིས་ལས་
Enumeration Block 3:
གཉིས་པ་སྐྱེ་ཚུལ་རྟེན་འབྲེལ་གྱི་རང་བཞིན་ལ། དངོས་དང་། ཞར་བྱུང་སྲིད་པ་བཞིའི་ཁྱད་པར་གཉིས། དང་པོ་ལ། འཁོར་བར་འཇུག་ཚུལ་གྱི་སྒོ་ནས་མདོར་བསྟན་པ། གྲུབ་པའི་འཁོར་བ་རྒྱས་པར་བཤད་པ། ཉོན་མོངས་པས་དཔེ་གསུམ་མཚོན་ཚུལ་གྱི་སྒོ་ནས་དོན་བསྡུ་བ་གསུམ། དང་པོ་ལ། འཁོར་བར་འཇུག་ཚུལ་དངོས་དང་། སྲིད་རྒྱུན་ཐོག་མེད་དུ་བསྟན་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ་བྱེ་བྲག་སྨྲ་བའི་ལུགས་དང་། མདོ་སྡེ་པའི་ལུགས་གཉིས། དང་པོ་ལ། རྫོགས་ཚུལ། བསྡུ་བ། འཁོར་ཚུལ་གསུམ། དང་པོ་ལ། མདོར་བསྟན་པ། རྒྱས་དང་བཤད་པ། དོན་བསྡུ་པ་གསུམ།
Enumeration Block 5:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ། ཉོན་མོངས་པ་གསུམ་དུ་བསྡུ་བ་དང་། རྒྱུ་འབྲས་གཉིས་སུ་བསྡུ་བ་གཉིས།
