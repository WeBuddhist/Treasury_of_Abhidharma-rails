Enumeration Block 1:
གཉིས་པ་ལ། ཉོན་མོངས་པ་གསུམ་དུ་བསྡུ་བ་དང་། རྒྱུ་འབྲས་གཉིས་སུ་བསྡུ་བ་གཉིས།
Enumeration Block 2:
གཉིས་པ་མདོ་སྡེ་པའི་ལུགས་ལ། རྟེན་འབྲེལ་གྱི་རང་བཞིན་དང་། ལྷག་མ་འཆད་འགྱུར་ལ་ལྟོས་པར་བསྟན་པ་གཉིས། དང་པོ་ལ། མ་རིག་པ་དང་མིང་དང་རེག་པ་དང་ཚོར་བའི་རྟེན་འབྲེལ་བཞི།
Enumeration Block 3:
བཞི་པ་ལ། སྤྱིར་བསྟན་པ་དང་། ཡིད་ཚོར་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། གྲངས་ཀྱི་སྒོ་ནས་མདོར་བསྟན་པ། ཡུལ་ལ་འཇུག་ཚུལ་གྱི་སྒོ་ནས་རྒྱས་པར་བཤད་པ། ངོ་བོའི་སྒོ་ནས་དོན་བསྡུ་བ་གསུམ།
Enumeration Block 5:
གཉིས་པ་ལ་འདོད་པ་དང་། གཟུགས་དང་། གཟུགས་མེད་ཀྱི་དབང་དུ་བྱས་པ་གསུམ།
Enumeration Block 6:
གཉིས་པ་ལ་བསམ་གཏན་དང་པོ་གཉིས་དང་། ཕྱི་མ་གཉིས་ཀྱི་དབང་དུ་བྱས་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ་ཉོན་མོངས་དཔེས་མཚོན་ཚུལ་ལ། ཉོན་མོངས་པའི་ཉོན་མོངས་དཔེ་ལྔ་དང་། ལས་ཀྱི་ཀུན་ནས་ཉོན་མོངས་དཔེ་གསུམ་དང་། གཞིའི་ཀུན་ནས་ཉོན་མོངས་དཔེ་གཅིག་གིས་མཚོན་ཚུལ་གསུམ།
