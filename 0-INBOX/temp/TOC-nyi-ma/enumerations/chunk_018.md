Enumeration Block 1:
བཞི་པ་ཉི་ཟླའི་འཆར་ཚུལ་ལ། དངོས་དང་། དུས་ཚིགས་ཀྱི་རྣམ་གཞག་གཉིས།
Enumeration Block 2:
འདི་ལ་ཚིག་དོན་དང་། སྤྱི་དོན་དང་། མཐའ་དཔྱད་པ་གསུམ།
Enumeration Block 3:
གཉིས་པ་སྤྱི་དོན་ལ། དུས་ཚིགས་གང་ལས་བྱུང་བ་དང་། བྱེད་པ་པོ་ཡོད་མེད་དང་། དུས་ཚིགས་སོ་སོར་བཤད་པ་དང་གསུམ།
Enumeration Block 4:
ལྔ་པ་ལྷ་རྣམས་ཀྱི་གནས་བཤད་པ་ལ། ས་དང་འབྲེལ་བའི་གནས་དང་། མ་འབྲེལ་པའི་གནས། སེམས་ཅན་གྱི་ཁྱད་ཆོས།གོང་འོག་གི་བར་གྱི་ཐག་ཚད་དང་བཞི། དང་པོ་ལ། རྒྱལ་ཆེན་བཞི་པ་དང་། སུམ་ཅུ་རྩ་གསུམ་པའི་གནས་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ་མདོར་བསྟན་པ། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། གནས་དང་ཚལ་དང་ས་གཞི་དང་ཤིང་དང་འདུན་ས་དང་ལྔ།
