Enumeration Block 1:
གསུམ་པ་སེམས་ཅན་གྱི་ཁྱད་ཆོས་ལ། འདོད་པ་ལ་སྤྱོད་ཚུལ་དང་། ལྷའི་སྐྱེ་ཚུལ་དང་། བདེ་བའི་ཁྱད་པར་གསུམ།
Enumeration Block 2:
བདུན་པ་འགྲོ་བ་རྣམས་ཀྱི་ལུས་དང་ཚེ་ཚད་བཤད་པ་ལ། ལུས་ཚད་དང་ཚེ་ཚད་གཉིས།དང་པོ་ལ། མིའི་ལུས་ཚད་དང་། ལྷའི་ལུས་ཚད་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། འདོད་ལྷ་དང་གཟུགས་ཁམས་པའི་ལུས་ཚད་གཉིས།
Enumeration Block 4:
གཉིས་པ་ཆེ་ཚད་ལ། བདེ་འགྲོ་དང་ངན་འགྲོ་དང་མ་ངེས་པའི་འཆི་བ་ཡོད་མེད་གསུམ། དང་པོ་ལ་མི་དང་ལྷའི་ཚེ་ཚད་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ། འདོད་ལྷ་དང་གཟུགས་དང་གཟུགས་མེད་ཁམས་པའི་ཚེ་ཚད་གསུམ།
Enumeration Block 6:
གཉིས་པ་ངན་འགྲོའི་ཚེ་ཚད་ལ། ཚ་དམྱལ། དུད་འགྲོ། ཡི་དྭགས། གྲང་དམྱལ་གྱི་ཚེ་ཚད་དང་བཞི།
