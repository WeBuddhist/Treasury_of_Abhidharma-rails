Enumeration Block 1:
གཉིས་པ་ངན་འགྲོའི་ཚེ་ཚད་ལ། ཚ་དམྱལ། དུད་འགྲོ། ཡི་དྭགས། གྲང་དམྱལ་གྱི་ཚེ་ཚད་དང་བཞི།
Enumeration Block 2:
བརྒྱད་པ་ཚད་དེ་གཞལ་ཐབས་ལ། དེ་རྩོམ་བྱེད་ཀྱི་གཞི་དང་། བརྩམས་པའི་འཇལ་བྱེད་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། ཡུལ་གྱི་ཚད་དང་། དུས་ཀྱི་ཚད་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། ལོ་དང་བསྐལ་པ་བཤད་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ་མདོར་བསྟན་པ་དང་རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ། འཇིག་བསྐལ། འཆགས་བསྐལ། གནས་བསྐལ། སྟོང་བསྐལ། བསྐལ་ཆེན་དང་ལྔ།
Enumeration Block 7:
གསུམ་པ་ལ། གནས་བསྐལ་གྱི་ཡ་ཐོག་དང་བར་བསྐལ་དང་པོ་བཤད་པ། བར་གྱི་ཁུག་པ་བཅོ་བརྒྱད་བཤད་པ། མཐའི་མ་ཐོག་དང་ཡར་འཕེལ་བཅུ་དགུའི་མཚམས་བསྟན་ལ། ཡར་འཕེལ་གྱི་ཚད་བཤད་པ། དེ་རྣམས་གནས་བསྐལ་དུ་བསྟན་པ་ལ།
