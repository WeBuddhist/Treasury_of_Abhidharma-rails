Enumeration Block 1:
གཉིས་པ་འཇིག་བསྐལ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། འཇིག་རྐྱེན། འཇིག་བྱ། འཇིག་པའི་རྒྱུ་མཚན། ཇི་ལྟར་འཇིག་ཚུལ་དང་བཞི།
Enumeration Block 2:
གཉིས་པ་སྤང་བྱ་ཀུན་འབྱུང་བདེན་པ་གཏན་ལ་དབབ་པ་ལ།ལས་ཀྱི་ཀུན་འབྱུང་དང་། ཉོན་མོངས་པའི་ཀུན་འབྱུང་གཉིས། དང་པོ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པ་བཤད་པ་དང་། ལས་ཀྱི་རྣམ་གྲངས་བསྟན་པའི་དོན་བསྡུ་བ་གསུམ།
Enumeration Block 3:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། བསྟན་བཅོས་ནས་བཤད་པ་དང་། མདོ་ནས་བཤད་པའི་ཚུལ་གཉིས།དང་པོ་ལ། སྤྱིར་བསྟན་པ་དང་། རིག་བྱེད་མིན་པ་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས། དང་པོ་ལ་སེམས་པ་དང་བསམ་པའི་ལས་ངོས་བཟུང་བ། རིག་བྱེད་དང་དེ་མིན་པ་ངོས་བཟུང་བ། དེ་དག་ལ་དགེ་སོགས་འཇོག་ཚུལ་གསུམ།
Enumeration Block 5:
འདི་ལ་ཚིག་དོན། སྤྱི་དོན། མཐའ་དཔྱད་པ་གསུམ།
Enumeration Block 6:
གཉིས་པ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ་ལ། རིག་བྱེད་དང་རིག་བྱེད་མ་ཡིན་པ་གཉིས། དང་པོ་ལ། ལུས་དང་ངག་གི་རིག་བྱེད་གཉིས། དང་པོ་ལ། བྱེ་བྲག་སྨྲ་བའི་ལུགས་བཞག །གནས་མ་བུ་པའི་ལུགས་དགག །མདོ་སྡེ་པའི་ལུགས་བརྗོད་པ་གསུམ།
Enumeration Block 8:
གཉིས་པ་རིག་བྱེད་མ་ཡིན་པའི་གཟུགས་བཤད་པ་ལ། དབྱེ་བ། སྒྲུབ་བྱེད། ཁྱད་ཆོས་གསུམ།
Enumeration Block 9:
གསུམ་པ་ཁྱད་ཆོས་ལ། རྒྱུ་དང་ས་དང་ངོ་བོ་དང་རྒྱུའི་ཁྱད་ཆོས་གཞན་བཤད་པ་བཞི།
