Enumeration Block 1:
གསུམ་པ་ཁྱད་ཆོས་ལ། རྒྱུ་དང་ས་དང་ངོ་བོ་དང་རྒྱུའི་ཁྱད་ཆོས་གཞན་བཤད་པ་བཞི།
Enumeration Block 2:
གསུམ་པ་ལ། དངོས་དང་། དགེ་སོགས་གསུམ་གྱི་དབྱེ་བ། ཀུན་སློང་བྱེ་བྲག་ཏུ་བཤད་པ་གསུམ།
Enumeration Block 3:
གསུམ་པ་ལ། ཀུན་སློང་གི་དབྱེ་བ་དང་། མུ་བཞིའི་སྒོ་ནས་རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། མུ་བཞི་དང་། དགེ་སོགས་དགུར་བཤད་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་རིག་བྱེད་མ་ཡིན་པ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ། སྡོམ་པ་བཤད་པ་དང་། གསུམ་ཀ་ཐུན་མོང་དུ་བཤད་པ་གཉིས། དང་པོ་ལ། མདོར་བསྟན་པ་དང་རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ་ལ། སོ་ཐར་དང་། བསམ་གཏན་དང་ཟག་མེད། སྡོམ་པའི་རྣམ་གྲངས་གཞན་བཤད་པ་དང་གསུམ། དང་པོ་ལ། དབྱེ་བ། བསྡུ་བ། ལྡན་ཚུལ། ངོ་བོ། རྣམ་གྲངས། སྒྲ་བཤད། རྟེན་གྱི་གང་ཟག་བཤད་པ་དང་བདུན།
