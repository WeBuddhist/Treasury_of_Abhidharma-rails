Enumeration Block 1:
གཉིས་པ་ཐོབ་ཚུལ་ལ། རྒྱུ་གང་ལ་བརྟེན་པ་དང་། གཞི་གང་ལ་བརྟེན་པ་གཉིས། དང་པོ་ལ། བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པ་དང་། སོ་ཐར་རྒྱུ་གང་ལ་བརྟེན་ནས་ཐོབ་པ་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལ། སྤྱིར་བསྟན་པ་དང་། བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། དུས་ཀྱི་དང་། བསྙེན་གནས། དགེ་བསྙེན། ཆེ་ཆུང་གི་དབྱེ་བ།རྟེན་སྐྱབས་འགྲོ། བསླབ་བྱའི་ཁྱད་པར་དྲུག །
Enumeration Block 4:
གཉིས་པ་ལ། ལེན་ཚུལ། བསླབ་བྱ། ལེན་པའི་གང་ཟག་ལ་དཔྱད་པ་དང་གསུམ།
Enumeration Block 5:
གཉིས་པ་གཞི་གང་ལ་བརྟེན་ནས་འཐོབ་པ་ལ། སྡོམ་པ་དང་། སྡོམ་མིན་དང་། བར་མ་གསུམ། དང་པོ་ལ། སོ་ཐར་དང་། བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པ་གཉིས།
Enumeration Block 6:
གསུམ་པ་གཏོང་ཚུལ་ལ། སྡོམ་པ་དང་སྡོམ་མིན་དང་བར་མ་དང་ཞར་ལ་གཟུགས་ཅན་མིན་པ་གཞན་གཏོང་ཚུལ་དང་བཞི། དང་པོ་ལ། སོ་ཐར་དང་། བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པའི་གཏོང་རྒྱུ་གཉིས།
