Enumeration Block 1:
གསུམ་པ་གཏོང་ཚུལ་ལ། སྡོམ་པ་དང་སྡོམ་མིན་དང་བར་མ་དང་ཞར་ལ་གཟུགས་ཅན་མིན་པ་གཞན་གཏོང་ཚུལ་དང་བཞི། དང་པོ་ལ། སོ་ཐར་དང་། བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པའི་གཏོང་རྒྱུ་གཉིས།
Enumeration Block 2:
བཞི་པ་ལྡན་པའི་གང་ཟག་ལ་སྡོམ་མིན་དང་། སྡོམ་པ་ལྡན་པའི་གང་ཟག་གཉིས།
Enumeration Block 3:
གཉིས་པ་མདོ་ལས་གསུངས་པའི་ལས་ཀྱི་རྣམ་གྲངས་ལ། ཐུན་མོང་དུ་བཤད་པ་དང་། སོ་སོར་བཤད་པ་གཉིས། དང་པོ་ལ། རྒྱུ་འབྲས་ཀྱི་སྒོ་ནས་དབྱེ་བ། ལས་ཀྱི་རྣམ་གྲངས་དུ་མ་བསྟན་པ། ལས་གང་གིས་འབྲས་བུ་གང་འགྲུབ་ཚུལ། ལས་ཀྱི་རྣམ་གྲངས་གཞན་བཤད་པ་བཞི། དང་པོ་ལ། འབྲས་བུའི་སྒོ་ནས་དབྱེ་བ། རྒྱུའི་སྒོ་ནས་དབྱེ་བ། གཉིས་ཀའི་སྒོ་ནས་དབྱེ་བ་གསུམ། དང་པོ་ལ། དགེ་སོགས་གསུམ་དུ་དབྱེ་བ། བསོད་ནམས་སོགས་གསུམ་དུ་དབྱེ་བ། མྱོང་འགྱུར་གྱི་ལས་ཀྱི་ཁྱད་པར་བསྟན་པ་གསུམ།
Enumeration Block 4:
གཉིས་པ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 5:
གསུམ་པ་ལ། མྱོང་འགྱུར་གསུམ་དུ་དབྱེ་བ། ལྔར་དབྱེ་བ། ལས་ངེས་མ་ངེས་ཀྱི་ཁྱད་པར་བཤད་པ་གསུམ། དང་པོ་ལ། རང་ལུགས་དང་གཞན་གྱི་འདོད་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ། མདོར་བསྟན་པ་དང་རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ་ལ། དབྱེ་བ་སྤྱིར་བསྟན་པ། ཁྱད་ཆོས་སོ་སོར་བཤད་པ། མྱོང་ངེས་བྱེ་བྲག་ཏུ་བཤད་པ་དང་གསུམ། དང་པོ་ལ། དངོས་དང་། སྡེ་པ་གཞན་གྱི་འདོད་ཚུལ་གཉིས།
