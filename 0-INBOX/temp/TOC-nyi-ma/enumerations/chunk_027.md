Enumeration Block 1:
གཉིས་པ་ལ། དབྱེ་བ་སྤྱིར་བསྟན་པ། ཁྱད་ཆོས་སོ་སོར་བཤད་པ། མྱོང་ངེས་བྱེ་བྲག་ཏུ་བཤད་པ་དང་གསུམ། དང་པོ་ལ།དངོས་དང་། སྡེ་པ་གཞན་གྱི་འདོད་ཚུལ་གཉིས།
Enumeration Block 2:
གསུམ་པ་ལ། མྱོང་ངེས་སྤྱིར་བསྟན་པ། མཐོང་ཆོས་ལ་མྱོང་ངེས་བྱེ་བྲག་ཏུ་བཤད་པ། ཞར་བྱུང་གི་དོན་དང་གསུམ།
Enumeration Block 3:
གསུམ་པ་ལ། ལས་གང་གི་འབྲས་བུ་དང་། གཡེང་བའི་སེམས་ངོས་བཟུང་བ་གཉིས།
Enumeration Block 4:
གསུམ་པ་རྒྱུ་འབྲས་གཉིས་ཀའི་སྒོ་ནས་དབྱེ་བ་ལ། མདོར་བསྟན་པ་དང་རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ། སོ་སོའི་ངོ་བོ་སྤྱིར་བསྟན་པ། ཟག་མེད་ཀྱི་ལས་བྱེ་བྲག་ཏུ་བཤད་པ། གཞན་གྱི་འདོད་པ་བརྗོད་པ་དང་གསུམ།
Enumeration Block 6:
གཉིས་པ་ལས་ཀྱི་རྣམ་གྲངས་དུ་མ་བསྟན་པ་ལ། དབྱེ་བ་སྤྱིར་བསྟན་པ་དང་། ལས་ལམ་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 8:
འདི་ལ་གཉིས། ཚིག་དོན་དང་། མཐའ་དཔྱད་པའོ། །
