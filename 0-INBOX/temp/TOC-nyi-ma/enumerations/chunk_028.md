Enumeration Block 1:
གཉིས་པ་ལས་ཀྱི་རྣམ་གྲངས་དུ་མ་བསྟན་པ་ལ། དབྱེ་བ་སྤྱིར་བསྟན་པ་དང་། ལས་ལམ་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 3:
འདི་ལ་གཉིས། ཚིག་དོན་དང་། མཐའ་དཔྱད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། རིག་བྱེད་དང་རིག་བྱེད་ཡིན་པ་ངོས་བཟུང་བ། རྩ་བ་གསུམ་དུ་བསྟན་པ། རྫོགས་བྱེད་གསུམ་དུ་བསྟན་པ། སོ་སོའི་ངོ་བོ་ཞར་བྱུང་དང་བཅས་པ་བཞི། དང་པོ་ལ། དངོས་གཞི་ལ་དོགས་གཅོད་དང་། སྦྱོར་མཇུག་ལ་དོགས་གཅོད་གཉིས།
Enumeration Block 5:
གསུམ་པ་རྫོགས་བྱེད་གསུམ་དུ་བསྟན་པ་ལ། དངོས་དང་གཞི་གང་ལ་བརྟེན་པ་གཉིས།
Enumeration Block 6:
བཞི་པ་སོ་སོའི་ངོ་བོ་ཞར་བྱུང་དང་བཅས་པ་ལ། ལས་ལམ་སོ་སོའི་ངོ་བོ། སེམས་པ་གང་ལས་ལམ་དུ་དང་ལྷན་ཅིག་འབྱུང་བ། འགྲོ་བ་གང་ན་ལས་ལམ་དུ་ཡོད། ལས་ཀྱི་འབྲས་བུ་ཞར་བྱུང་དང་བཅས་པ་བཞི། དང་པོ་ལ། ལུས་དང་ངག་དང་ཡིད་ཀྱི་ལས་བཤད་པ་གསུམ། དང་པོ་ལ། སྲོག་གཅོད་མ་བྱིན་ལེན་ལོག་གཡེམ་གསུམ།
Enumeration Block 7:
གཉིས་པ་ལ། རྫུན་ཕྲ་མ་ཚིག་རྩུབ་ངག་ཀྱལ་བཞི་ལས། དང་པོ་ལ། དངོས་དང་ཞར་བྱུང་གཉིས།
Enumeration Block 8:
གསུམ་པ་ལ། བརྣབ་སེམས་གནོད་སེམས་ལོག་ལྟ་གསུམ་ལས།
