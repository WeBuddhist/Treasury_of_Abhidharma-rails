Enumeration Block 1:
གསུམ་པ་ལ། བརྣབ་སེམས་གནོད་སེམས་ལོག་ལྟ་གསུམ་ལས།
Enumeration Block 2:
གསུམ་པ་ལ། དངོས་དང་། ཞར་བྱུང་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། གཅོད་ཚུལ་དང་། འཚམས་སྦྱར་ཚུལ་གཉིས།
Enumeration Block 4:
གཉིས་པ་སེམས་པ་གང་ལས་ལམ་དུ་དང་ལྷན་ཅིག་འབྱུང་དཔྱད་པ་ལ། མི་དགེ་བ་དང་དགེ་བའི་དབང་དུ་བྱས་པ་གཉིས།
Enumeration Block 5:
གསུམ་པ་འགྲོ་བ་གང་ན་ལས་ལམ་དུ་ཡོད་དཔྱད་པ་ལ། མི་དགེ་བ་དང་དགེ་བ་གཉིས།
Enumeration Block 6:
བཞི་པ་ལས་ཀྱི་འབྲས་བུ་ཞར་བྱུང་དང་བཅས་པ་ལ། འབྲས་བུ་དང་ཞར་བྱུང་གཉིས།
Enumeration Block 7:
གསུམ་པ་ལས་གང་གིས་འབྲས་བུ་གང་འགྲུབ་ཚུལ་ལ། མདོར་བསྟན་པ་དང་རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 8:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། དགེ་སོགས་གསུམ་དུ་བཤད་པ། དུས་གསུམ་དུ་བཤད་པ། ཁམས་གསུམ་དུ་བཤད་པ། སློབ་སོགས་གསུམ་དུ་བཤད་པ། མཐོང་སྤང་སོགས་གསུམ་དུ་འབྲས་བུ་དུ་དང་བཅས་པ་དང་ལྔ།
Enumeration Block 9:
གཉིས་པ་ལ། འདས་ད་ལྟར་མ་འོངས་པ་གསུམ་ལས།
