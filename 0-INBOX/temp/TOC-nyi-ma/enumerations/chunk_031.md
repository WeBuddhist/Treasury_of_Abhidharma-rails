Enumeration Block 1:
གཉིས་པ་ལ། ཉེ་བའི་འཚམས་མེད་དངོས་དང་། ལས་ལམ་གྱི་གེགས་ངོས་བཟུང་བ་དང་། བྱང་སེམས་ངེས་གནས་བཤད་པ་གསུམ།
Enumeration Block 2:
གསུམ་པ་ལ། བྱང་སེམས་ངེས་གནས་ཀྱི་ཁྱད་ཆོས་དང་། སྔོན་བྱུང་སྟོན་པའི་རྣམ་ཐར་བཤད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། བསོད་ནམས་བསགས་ཚུལ་དང་། ཕར་ཕྱིན་རྫོགས་ཚུལ་གཉིས།
Enumeration Block 4:
གཉིས་པ་བསྟེན་བྱ་བསོད་ནམས་ཀྱི་གཞི་གསུམ་ལ། མདོར་བསྟན། རྒྱས་བཤད། ཞར་བྱུང་གསུམ།
Enumeration Block 5:
གཉིས་པ་ལ། སྦྱིན་པ་དང་ཚུལ་ཁྲིམས་དང་བསྒོམས་པ་ལས་བྱུང་བའི་གཞི་གསུམ། དང་པོ་ལ། ངོ་བོ་དང་དབྱེ་བ་དང་ཁྱད་ཆོས་དང་ཞར་བྱུང་དང་བཞི།
Enumeration Block 6:
གསུམ་པ་ལ། མདོར་བསྟན་དང་རྒྱས་བཤད་གཉིས།
Enumeration Block 7:
གཉིས་པ་ལ། སྦྱིན་བདག །དངོས་པོ་ཞིང་གི་ཁྱད་པར་གསུམ།
