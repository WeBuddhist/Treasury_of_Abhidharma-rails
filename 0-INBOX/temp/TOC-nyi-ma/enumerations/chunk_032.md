Enumeration Block 1:
བཞི་པ་ཞར་བྱུང་ལ། ལས་ཆེ་ཆུང་གི་ཁྱད་པར། བསགས་མ་བསགས་ཀྱི་ཁྱད་པར། ལས་ཀྱི་འབྲས་བུ་ལ་དོགས་པ་དཔྱད་པ་གསུམ།
Enumeration Block 2:
བཞི་པ་ཞར་བྱུང་ལ། ཚངས་པའི་བསོད་ནམས་དང་། ཆོས་ཀྱི་སྦྱིན་པ་གཉིས།
Enumeration Block 3:
གསུམ་པ་ལས་ཀྱི་རྣམ་གྲངས་གཞན་བསྟན་པའི་སྒོ་ནས་དོན་བསྡུ་བ་ལ། འཇིག་རྟེན་པའི་ལས་ཀྱི་རྣམ་གྲངས་དངོས་དང་། ཆོས་ཀྱི་རྣམ་གྲངས་གཞན་བསྟན་ནས་མཇུག་བསྡུ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ཉོན་མོངས་པའི་ཀུན་འབྱུང་བཤད་པ་ལ། སྤང་བྱ་ཕྲ་རྒྱས་ཉོན་མོངས་བཤད་པ། དེ་ཇི་ལྟར་སྤོང་ཚུལ་བཤད་པ། སྤངས་པའི་འབྲས་བུ་ཡོངས་ཤེས་བཤད་པ་དང་གསུམ། དང་པོ་ལ། དབྱེ་བ། སྐྱེ་ཚུལ། རྣམ་གྲངས་དང་གསུམ། དང་པོ་ལ།ངོ་བོའི་སྒོ་ནས། རྣམ་པའི་སྒོ་ནས། བཅས་མ་བཅས་ཀྱི་སྒོ་ནས་དབྱེ་བ་དང་གསུམ། དང་པོ་ལ། སྤྱིར་བསྟན་པ་དང་། ལྟ་བ་དང་ང་རྒྱལ་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས། དང་པོ་ལ། རྩ་བ་དང་། ནང་ཚན་དང་། གཉེན་པོའི་སྒོ་ནས་དབྱེ་བ་གསུམ། དང་པོ་ལ། ཚིག་དོན། སྤྱི་དོན། མཐའ་དཔྱད་པ་དང་གསུམ།
Enumeration Block 5:
གཉིས་པ་ལ། ཉོན་མོངས་ཀྱི་མཚན་ཉིད། སྒྲ་བཤད། བྱེད་ལས། དབྱེ་བ་དང་བཞི།
