Enumeration Block 1:
གཉིས་པ་ལ། ཉོན་མོངས་ཀྱི་མཚན་ཉིད། སྒྲ་བཤད། བྱེད་ལས། དབྱེ་བ་དང་བཞི།
Enumeration Block 2:
གསུམ་པ་ལ། དངོས་དང་། གཉེན་པོས་སྤང་བྱ་སྤོང་ཚུལ་གཉིས། དང་པོ་ལ། འདོད་པ་དང་། གཟུགས་དང་གཟུགས་མེད་ཀྱི་དེ་གཉིས། དང་པོ་ལ། མཐོང་ལམ་དང་སྒོམ་ལམ་གྱི་སྤང་བྱ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། ལྟ་བ་དང་ང་རྒྱལ་བཤད་པ་གཉིས། དང་པོ་ལ། དངོས་དང་། དོགས་གཅོད་གཉིས།
Enumeration Block 4:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་ང་རྒྱལ་ལ། དབྱེ་བ་དང་། སྤོང་ཚུལ་དོགས་གཅོད་དང་བཅས་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་རྣམ་པའི་སྒོ་ནས་དབྱེ་བ་ལ། ཀུན་འགྲོ་ཡིན་མིན་གྱི་སྒོ་ནས། ཟག་མེད་ལ་དམིགས་མ་དམིགས་ཀྱི་སྒོ་ནས། དམིགས་པ་དང་མཚུངས་ལྡན་གྱི་སྒོ་ནས། མི་དགེ་བ་དང་ལུང་མ་བསྟན་གྱི་སྒོ་ནས། དུས་གསུམ་ལ་ཕྲ་རྒྱས་ཀྱི་སྒོ་ནས་དབྱེ་བ་དང་ལྔ།
Enumeration Block 7:
གཉིས་པ་ལ། ཟག་མེད་ལ་དམིགས་པ་དང་། དེ་ལ་མ་དམིགས་པ་གཉིས།
