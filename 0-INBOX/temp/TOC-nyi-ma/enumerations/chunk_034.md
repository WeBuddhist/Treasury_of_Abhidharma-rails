Enumeration Block 1:
གཉིས་པ་ལ། ཟག་མེད་ལ་དམིགས་པ་དང་། དེ་ལ་མ་དམིགས་པ་གཉིས།
Enumeration Block 2:
བཞི་པ་ལ། དབྱེ་བ་སྤྱིར་བསྟན་པ། དེ་དག་ཏུ་འཇོག་པའི་རྩ་བ་ངོས་བཟུང་བ། དྲི་བ་དང་ལན་གྱིས་གཏན་ལ་དབབ་པ་དང་གསུམ།
Enumeration Block 3:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། འདོད་པའི་ཉོན་མོངས་མི་དགེ་བ་དང་། ཁམས་གོང་གི་ཉོན་མོངས་ལུང་མ་བསྟན་དུ་འཇོག་པའི་རྩ་བ་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ། ཁ་ཆེ་བའི་ལུགས་དང་། འོག་པའི་ལུགས་གཉིས།
Enumeration Block 6:
ལྔ་པ་དུས་གསུམ་ལ་ཕྲ་རྒྱས་ལྡན་ཚུལ་གྱི་སྒོ་ནས་དབྱེ་བ་ལ། ཕྲ་རྒྱས་ཀྱི་དམིགས་ཡུལ། དུས་གསུམ་ལྡན་ཚུལ་ལམ་དེའི་རྣམ་གཞག་བསྟན་ལ། སྤང་བྲལ་གྱི་ཁྱད་པར་བཤད་པ། སེམས་ཀྱི་དམིགས་པ་བྱེ་བྲག་ཏུ་བཤད་པ་དང་བཞི། དང་པོ་ལ། དམིགས་ཡུལ་ངེས་ཅན་གྱི་ཉོན་མོངས་དང་། ངེས་མེད་ཀྱི་ཉོན་མོངས་གཉིས།
Enumeration Block 7:
གསུམ་པ་ལ། དུས་གསུམ་རྫས་ཡོད་དུ་གྲུབ་ཚུལ། དུས་གསུམ་གྱི་འཇོག་ཚུལ། དེ་ལ་མདོ་སྡེ་པས་གནོད་བྱེད་བརྗོད་པ། བྱེ་བྲག་སྨྲ་བས་ལན་བཏབ་ཚུལ་དང་བཞི། དང་པོ་ལ། ལུང་དང་རིགས་པའི་སྒྲུབ་བྱེད་གཉིས།
