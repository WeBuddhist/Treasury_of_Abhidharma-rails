Enumeration Block 1:
གཉིས་པ་བསྟན་བཅོས་ལས་བཤད་པའི་རྣམ་གྲངས་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལ། ཀུན་སྦྱོར། འཆིང་བ། ཉེ་ཉོན། ཀུན་དཀྲིས་དང་བཞི། དང་པོ་ལ། དངོས་དང་། ཞར་བྱུང་གཉིས།
Enumeration Block 3:
གཉིས་པ་ཞར་བྱུང་ལ། ཐ་མའི་ཆ་མཐུན་ལྔ། ཀུན་སྦྱོར་གསུམ། གོང་མའི་ཆ་མཐུན་ལྔ་བཤད་པ་དང་གསུམ།
Enumeration Block 4:
གཉིས་པ་ལ། བྱེ་སྨྲ་དང་མདོ་སྡེ་པའི་ལན་གཉིས།
Enumeration Block 5:
བཞི་པ་ཀུན་དཀྲིས་ལ། དངོས་དང་། ཞར་བྱུང་དྲི་མ་དྲུག་བཤད་པ་དང་། ཁྱད་ཆོས་བཤད་པ་གསུམ། དང་པོ་ལ། དབྱེ་བ་དང་། རྒྱུ་གང་ལས་བྱུང་བ་གཉིས། དང་པོ་ལ། བསྟན་བཅས་རབ་ཏུ་བྱེད་པ་ནས་བཤད་ཚུལ་དང་། བྱེ་བྲག་སྨྲ་བའི་ལུགས་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ། དབྱེ་བ་དང་། རྒྱུ་གཉིས།
Enumeration Block 7:
གསུམ་པ་ཁྱད་ཆོས་ལ། མཐོང་སྒོམ་གྱི་སྤང་བྱའི་ཁྱད་པར། དགེ་བ་དང་ལུང་མ་བསྟན་གྱི་ཁྱད་པར། ཁམས་དང་སའི་ཁྱད་པར་དང་གསུམ།
Enumeration Block 8:
གསུམ་པ་མཚུངས་ལྡན་ལ།གཙོ་སེམས་གང་དུ་མཚུངས་པར་ལྡན་ཚུལ་དང་མཚུངས་བར་ལྡན་པ་གཉིས།
Enumeration Block 9:
གཉིས་པ་ལ། རྩ་ཉོན་ཚོར་བ་གང་དང་། ཉེ་ཉོན་ཚོར་བ་གང་དང་མཚུངས་པར་ལྡན་ཚུལ་གཉིས། དང་པོ་ལ། འདོད་པ་དང་། ཁམས་གོང་མའི་མཚུངས་པར་ལྡན་ཚུལ་གཉིས།
