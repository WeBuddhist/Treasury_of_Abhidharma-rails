Enumeration Block 1:
གསུམ་པ་ཐོབ་བྱ་འགོག་ལམ་གྱི་བདེན་པ་གཏན་ལ་དབབ་པ་ལ། ལམ་གྱི་རྣམ་གཞག །རྟེན་གང་ཟག་གི་རྣམ་གཞག །ལམ་གྱི་ཁྱད་ཆོས་གཞན་བཤད་པ་དང་གསུམ། དང་པོ་ལ། ལམ་གྱི་ངོ་བོ། །དམིགས་པ། སྒོམ་ཚུལ་དང་གསུམ།
Enumeration Block 2:
འདི་ལ་ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། བདེན་བཞི་དང་། བདེན་གཉིས་བཤད་པ་གཉིས། དང་པོ་ལ། དངོས་དང་། ཟག་བཅས་རྣམས་སྡུག་བདེན་དུ་བཤད་པ་གཉིས།
Enumeration Block 4:
གསུམ་པ་ལམ་སྒོམ་ཚུལ་ལ། ལམ་ལ་འཇུག་ཚུལ་གྱི་སྒོ་ནས་མདོར་བསྟན་པ་དང་། ལམ་སྒོམ་ཚུལ་གྱི་སྒོ་ནས་རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ། ལམ་སྒོམ་པའི་གང་ཟག །སྒོམ་པའི་ཚུལ་དང་གཉིས། དང་པོ་ལ། གང་ཟག་གི་ངོ་བོ་མི་མཐུན་ཕྱོགས་དང་བཅས་པ། དེ་ལ་ལྡན་པའི་ཡོན་ཏན། དེ་རིགས་སུ་འཇོག་ཚུལ་དང་གསུམ།
Enumeration Block 6:
གཉིས་པ་སྒོམ་ཚུལ་དངོས་ལ། ཞི་གནས་དང་། ལྷག་མཐོང་སྒོམ་ཚུལ་གཉིས། དང་པོ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 7:
འདི་ལ་ཚིག་དོན་དང་། སྤྱི་དོན་གཉིས།
Enumeration Block 8:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། མི་སྡུག་པ་སྒོམ་ཚུལ་དང་།དབུགས་རྔུབ་འབྱུང་དྲན་པ་སྒོམ་ཚུལ་གཉིས། དང་པོ་ལ། དེ་སྒོམ་ཚུལ་དང་། དེའི་རྣམ་གཞག་གཉིས།
