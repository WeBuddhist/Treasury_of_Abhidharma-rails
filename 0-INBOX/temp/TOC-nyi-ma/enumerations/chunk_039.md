Enumeration Block 1:
གཉིས་པ་སྒོམ་ཚུལ་དངོས་ལ། ཞི་གནས་དང་། ལྷག་མཐོང་སྒོམ་ཚུལ་གཉིས། དང་པོ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 2:
འདི་ལ་ཚིག་དོན་དང་། སྤྱི་དོན་གཉིས།
Enumeration Block 3:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། མི་སྡུག་པ་སྒོམ་ཚུལ་དང་།དབུགས་རྔུབ་འབྱུང་དྲན་པ་སྒོམ་ཚུལ་གཉིས། དང་པོ་ལ། དེ་སྒོམ་ཚུལ་དང་། དེའི་རྣམ་གཞག་གཉིས།
Enumeration Block 4:
གསུམ་པ་དབུགས་རྔུབ་འབྱུང་དྲན་པ་སྒོམ་པ་ལ། དེའི་རྣམ་གཞག་དང་། སྒོམ་ཚུལ་དྲུག་བཤད་པ་དང་། དེའི་ཡུལ་བཤད་པ་དང་གསུམ།
Enumeration Block 5:
གཉིས་པ་ལྷག་མཐོང་སྒོམ་ཚུལ་ལ། ཐོག་མར་དྲན་པ་ཉེར་གཞག །དེ་ནས་དྲོད་སོགས་བཞི། དེ་ནས་བདེན་པ་མངོན་རྟོགས་བཅུ་དྲུག་སྒོམ་ཚུལ་དང་གསུམ།
Enumeration Block 6:
དང་པོ་ལ་སྤྱིར་བསྟན་པ་དང་། ཆོས་དྲན་པ་ཉེར་གཞག་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ་ལ། སྦྱོར་ལམ་སྐབས་ཀྱི་སྒོམ་ཚུལ། དྲོད་སོགས་སྐྱེ་རིམ་གྱི་སྒོམ་ཚུལ་དང་ཁྱད་ཆོས། ཞར་ལ་ཐེག་པ་གསུམ་གྱི་ལམ་བགྲོད་ཚུལ་དང་གསུམ། དང་པོ་ལ། སྐྱེ་རིམ་གྱི་ཚུལ་དང་། ཕུང་པོ་དུ་ཡོད་དང་། ངེས་ཚིག་གསུམ།
Enumeration Block 8:
གཉིས་པ་ལ། ངོ་བོའི་ཁྱད་པར། རྟེན་གྱི་དང་། བྲལ་ཐོབ་ཀྱི་དང་། དེ་ལྡན་པའི་ཡོན་ཏན་དང་། ལམ་གཞན་དུ་འཇུག་ཚུལ་ལྔ།
Enumeration Block 9:
གཉིས་པ་ལ། སེམས་རྟེན་དང་། ལུས་རྟེན་གཉིས།
