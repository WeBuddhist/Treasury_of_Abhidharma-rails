Enumeration Block 1:
གཉིས་པ་ལ། སེམས་རྟེན་དང་། ལུས་རྟེན་གཉིས།
Enumeration Block 2:
གསུམ་པ་བདེན་པ་མངོན་རྟོགས་བཅུ་དྲུག་སྒོམ་ཚུལ་ལ། སྐྱེ་རིམ། གྲངས་ངེས། ས་གང་ལ་བརྟེན་པ། སྤོང་གཉེན་གྱི་ལམ་གང་ཡིན་བཤད་པ་དང་བཞི།
Enumeration Block 3:
གཉིས་པ་གང་ཟག་གི་རྣམ་གཞག་ལ། ཞུགས་གནས་ཀྱི་རྣམ་གཞག་སྤྱིར་བསྟན་པ། ནང་ཚན་གྱི་སྒོ་ནས་བདུན་དུ་དབྱེ་བ། གང་ཟག་གི་རིགས་བསྡུས་པ་དང་གསུམ། དང་པོ་ལ། རྒྱུན་ཞུགས་དང་ཆགས་བྲལ་སྔོན་སོང་གི་རྣམ་གཞག་དང་། འབྲས་བུ་རིམ་གྱིས་པའི་རྣམ་གཞག་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ་སྤང་བྱ་སྤང་ཚུལ་དང་། ཞུགས་གནས་ཀྱི་རྣམ་གཞག་དངོས་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ། རྒྱུན་ཞུགས་ཞུགས་འབྲས། ཕྱིར་འོང་། ཕྱིར་མི་འོང་། དགྲ་བཅོམ་ཞུགས་གནས་དང་བཞི། དང་པོ་ལ་གཉིས་ཀྱི་ཞུགས་པ་བཤད་ཟིན་ཅིང་། འབྲས་གནས་ལ། ཙམ་པོ་བ་དང་། ཁྱད་པར་ཅན་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ། ཕྱིར་འོང་ཞུགས་པ་དང་འབྲས་གནས་གཉིས།
Enumeration Block 7:
གཉིས་པ་ལ། ཙམ་པོ་བ་དང་། ཁྱད་པར་ཅན་གཉིས།
