Enumeration Block 1:
དེ་ལ་ཡང་ངེས་མ་ངེས་གཉིས་ཡོད།
Enumeration Block 2:
གཉིས་པ་ལ། ཕྱིར་འོང་ཞུགས་པ་དང་འབྲས་གནས་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། ཙམ་པོ་བ་དང་། ཁྱད་པར་ཅན་གཉིས།
Enumeration Block 4:
གསུམ་པ་ལ། ཞུགས་པ་དང་། འབྲས་གནས་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ། གཟུགས་ཉེར་འགྲོ་།གཟུགས་མེད་ཉེར་འགྲོ་།མཐོང་ཆོས་ཞི། ཉེར་འགྲོ་དགུར་དབྱེ་བ། ཚེ་ཡོངས་གྱུར། ལུས་མངོན་བྱེད་དང་དྲུག །དང་པོ་ལ། རྩ་བའི་སྒོ་ནས་ལྔ་ང་དབྱེ་བ་དང་། གོང་འཕོ་བྱེ་ཕྲག་ཏུ་བཤད་པ་གཉིས།
Enumeration Block 7:
བཞི་པ་ལ། དགུར་བཤད་པ་དང་། དེའི་ཁྱད་པར་དང་།དམ་པའི་འགྲོ་བ་བདུན་དང་གསུམ།
Enumeration Block 8:
ལྔ་པ་ཚེ་ཡོངས་གྱུར་ལ། དངོས་དང་། ཞར་བྱུང་གཉིས།
Enumeration Block 9:
བཞི་པ་དགྲ་བཅོམ་ཞུགས་འབྲས་ལ། ཞུགས་པ་དང་། འབྲས་གནས་གཉིས།
Enumeration Block 10:
གཉིས་པ་འབྲས་གནས་ལ། དངོས་དང་། ཁྱད་ཆོས་དང་། དབྱེ་བ་གསུམ།
Enumeration Block 11:
གཉིས་པ་ལ། ཆགས་བྲལ་གྱི་རྣམ་གཞག་དང་། དགེ་སྦྱོང་ཚུལ་གྱི་རྣམ་གཞག་གཉིས། དང་པོ་ལ། གང་གིས་ཆགས་པ་དང་བྲལ་བའི་ལམ་དང་། བྲལ་ཐོབ་སྐྱེ་ཚུལ། ས་གང་གི་གང་ལ་ཆགས་པ་དང་བྲལ་བ། འཇིག་རྟེན་པའི་ལམ་གྱི་དམིགས་རྣམ་བཤད་པ་བཞི།
