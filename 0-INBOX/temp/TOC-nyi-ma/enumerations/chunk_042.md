Enumeration Block 1:
གཉིས་པ་འབྲས་གནས་ལ། དངོས་དང་། ཁྱད་ཆོས་དང་། དབྱེ་བ་གསུམ།
Enumeration Block 2:
གཉིས་པ་ལ། ཆགས་བྲལ་གྱི་རྣམ་གཞག་དང་། དགེ་སྦྱོང་ཚུལ་གྱི་རྣམ་གཞག་གཉིས། དང་པོ་ལ། གང་གིས་ཆགས་པ་དང་བྲལ་བའི་ལམ་དང་། བྲལ་ཐོབ་སྐྱེ་ཚུལ། ས་གང་གི་གང་ལ་ཆགས་པ་དང་བྲལ་བ། འཇིག་རྟེན་པའི་ལམ་གྱི་དམིགས་རྣམ་བཤད་པ་བཞི།
Enumeration Block 3:
བཞི་པ་དམིགས་རྣམ་ལ། འཇིག་རྟེན་པའི་ལམ་གྱི་དམིགས་རྣམ་དང་། འཇིག་རྟེན་ལས་འདས་པའི་མཐར་གྲོལ་ལམ་སྐྱེ་ཚུལ་གཉིས།
Enumeration Block 4:
གཉིས་པ་དགེ་སྦྱོང་ཚུལ་གྱི་འབྲས་བུ་ལ། ངོ་བོ་དབྱེ་བ་དང་བཅས་པ་དང་། མདོ་དང་འགལ་བའི་རྩོད་པ་སྤང་པ་དང་། དོགས་གཅོད་དང་། འཐོབ་པའི་ཚུལ་བཞི།
Enumeration Block 5:
གསུམ་པ་དགྲ་བཅོམ་འབྲས་གནས་གྱི་དབྱེ་བ་ལ། མཚན་གཞིའི་སྒོ་ནས་དྲུག་ཏུ་དབྱེ་བ། གཉིས་སུ་བསྡུ་བ། རིགས་དང་འབྲས་བུ་གང་ལས་ཉམས་པ། རིགས་ཀྱི་དབྱེ་བ་དེ་གཞན་ལ་སྦྱར་བ། ཉམས་པའི་དབྱེ་བ། དབང་པོ་འཕོ་ཚུལ། དགྲ་བཅོམ་དགུར་དབྱེ་བ་དང་བདུན།
Enumeration Block 6:
བཞི་པ་ལ། དངོས་དང་། ལམ་གང་ལས་དབང་པོ་འཕོ་བ་གཉིས།
