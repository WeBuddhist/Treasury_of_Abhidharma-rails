Enumeration Block 1:
གསུམ་པ་ལམ་གྱིས་ཐོབ་པའི་རྣམ་གྲོལ་ལམ་ལ། རྣམ་གྲོལ་ལམ་གྱི་དབྱེ་བ། ཐོབ་ཚུལ། འདུས་མ་བྱས་ཀྱི་རྣམ་གྲོལ་བྱེ་བྲག་ཏུ་བཤད་པ། ཡིད་འབྱུང་དང་ཆགས་བྲལ་གྱི་ཁྱད་པར་དང་བཞི།
Enumeration Block 2:
གཉིས་པ་ལ། སེམས་གང་རྣམ་པར་གྲོལ་བ་དང་། ལམ་གང་གིས་རྣམ་པར་གྲོལ་བ་གཉིས།
Enumeration Block 3:
གཉིས་པ་མཁས་པར་བྱ་བའི་ཡོན་ཏན་གཏན་ལ་དབབ་པ་ལ། ཤེས་པའི་ཡོན་ཏན་གཏན་ལ་དབབ་པ་དང་། སྙོམས་འཇུག་གི་ཡོན་ཏན་གཏན་ལ་དབབ་པ་གཉིས། དང་པོ་ལ། ཡེ་ཤེས་ཀྱི་རང་བཞིན་དང་ལྡན་ཚུལ་དང་ཐོབ་ཚུལ་དང་ཁྱད་པར་གྱི་ཆོས་དང་བཞི། དང་པོ་ལ། བཟོད་ཤེས་དང་ལྟ་བའི་ཁྱད་པར། ཤེས་པ་བཅུའི་རྣམ་གཞག །དེ་དག་གི་ཁྱད་ཆོས་དང་གསུམ།
Enumeration Block 4:
གཉིས་པ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ། སྤྱིར་བསྟན་པ་དང་། བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ། ཕ་རོལ་གྱི་སེམས་ཤེས་པ་དང་། ཟད་དང་མི་སྐྱེ་བ་ཤེས་པ་གཉིས། དང་པོ་ལ། ཆོས་ཤེས་ཀྱི་དབྱེ་བ་དང་། ཕ་རོལ་གྱི་སེམས་ཤེས་པ་གཉིས། དང་པོ་ལ། གཉིས་ལས་བརྒྱད་དུ་དབྱེ་བ་དང་། བཞི་ལས་བཅུ་གཉིས་སུ་དབྱེ་བ་གཉིས།
