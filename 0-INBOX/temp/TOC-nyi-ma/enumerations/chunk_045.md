Enumeration Block 1:
གསུམ་པ་ཁྱད་ཆོས་ལ། ཤེས་པ་བཅུར་འཇོག་པའི་རྒྱུ་མཚན། གཉེན་པོའི་ཁྱད་པར། རྣམ་པའི་ཁྱད་པར་དང་གསུམ།
Enumeration Block 2:
གསུམ་པ་ཤེས་བཅུའི་རྣམ་པའི་ཁྱད་པར་ལ། ཤེས་པ་སོ་སོའི་རྣམ་པ་དང་། རྣམ་པའི་གྲངས་ངེས། དེ་དག་གི་ཁྱད་པར། ཆོས་གཞན་བཤད་པ་དང་བཞི།
Enumeration Block 3:
བཞི་པ་ལ། ངོ་བོ་དང་རྟེན་དང་དྲན་པ་ཉེར་གཞག་དང་དམིགས་པའི་ཁྱད་པར་དང་བཞི།
Enumeration Block 4:
གཉིས་པ་ལ་སེམས་དང་ལུས་རྟེན་གཉིས།
Enumeration Block 5:
བཞི་པ་དམིགས་པའི་ཁྱད་པར་ལ། ཤེས་པ་ནང་ཕན་ཚུན་ཡུལ་དུ་འགྱུར་ཚུལ། ཆོས་བཅུ་དང་ཤེས་བཅུ་ཡུལ་ཡུལ་ཅན་དུ་སྦྱར་བ། ཆོས་གང་རིག་པ་དང་གསུམ།
Enumeration Block 6:
གསུམ་པ་ཐོབ་ཚུལ་ལ། ལམ་གྱི་གནས་སྐབས་གང་དུ་ཤེས་པ་དུ་ཐོབ་པ་དང་། ས་གང་དུ་ཤེས་པ་དུ་ཐོབ་པ་དང་། ཐོབ་པའི་དབྱེ་བ་གསུམ། དང་པོ་ལ། མཐོང་ལམ་དུ་དང་། སྒོམ་ལམ་དུ་དང་། བཤད་པའི་ལྷག་མ་དུ་ཐོབ་པ་གསུམ།
