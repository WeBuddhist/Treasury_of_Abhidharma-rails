Enumeration Block 1:
གཉིས་པ་ལ། མཚན་ཉིད། དབྱེ་བ། སྒྲ་དོན། ས་མཚམས་དང་བཞི།
Enumeration Block 2:
གཉིས་པ་དེ་ལ་དབྱེ་ན་གཉིས་ཡོད་དེ། དེར་གྱུར་པའི་ཉེར་བསྡོགས་དང་དངོས་གཞི་གཉིས་ཡོད་པའི་ཕྱིར། དང་པོ་ལ་བཞི་ཡོད་དེ། དང་པོའི་ཉེར་བསྡོགས་སོགས་བཞི་ཡོད་པའི་ཕྱིར། དང་པོའི་ཉེར་བསྡོགས་ལ་གཉིས་ཡོད་དེ། ཞི་གནས་སྐབས་ཀྱི་ཉེར་བསྡོགས་དང་ལྷག་མཐོང་སྐབས་ཀྱི་ཉེར་བསྡོགས་གཉིས་ཡོད་པའི་ཕྱིར། ཕྱི་མ་ལ་དྲུག་ཡོད་དེ། མཚན་ཉིད་སོ་སོ་རིག་པ་དང་། མོས་པ་ཡིད་བྱེད་དང་། རབ་ཏུ་དབེན་པ་ཡིད་བྱེད། དགའ་བ་སྡུད་པའི་ཡིད་བྱེད། དཔྱོད་པ་ཡིད་བྱེད། སྦྱོར་བ་མཐའི་ཡིད་བྱེད་དང་དྲུག་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
ཡང་ངོ་བོའི་སྒོ་ནས་གཉིས་ཡོད་དེ། དག་པ་དང་ཉམས་པ་ཆ་མཐུན་གཉིས་ཡོད་ཅིང་།
Enumeration Block 4:
གཉིས་པ་ལ། དབྱེ་བ། ཐོབ་ཚུལ། དམིགས་པའི་ཁྱད་པར། སོ་སོའི་ངོ་བོ་དང་བཞི།
Enumeration Block 5:
གསུམ་པ་ཡན་ལག་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། དབྱེ་བ་དང་བསྡུ་བ་དང་ཉོན་མོངས་ཅན་ཡན་ལག་ལྡན་ཚུལ་དང་ཞར་བྱུང་བཤད་པ་དང་བཞི།
Enumeration Block 6:
གཉིས་པ་ལ། དངོས་དང་། དོགས་གཅོད་གཉིས།
Enumeration Block 7:
བཞི་པ་ལ། བསམ་གཏན་བཞི་པ་མི་གཡོ་བའི་རྒྱུ་མཚན་དང་། འབྲས་བུ་སྐྱེ་བས་ཐོབ་པའི་བསམ་གཏན་ལ་ཚོར་བའི་ལྡན་ཚུལ། བསམ་གཏན་གཉིས་པར་འོག་མའི་སེམས་མངོན་དུ་བྱེད་ཚུལ་གསུམ།
Enumeration Block 8:
གཉིས་པ་དེ་དག་གི་ཁྱད་ཆོས་ལ། ཐོབ་ཚུལ། ཐོབ་ཟིན་མངོན་དུ་བྱེད་ཚུལ། དམིགས་པའི་ཁྱད་པར། སྤང་བྱ་སྤོང་ཚུལ་ཉེར་བསྡོགས་དང་བཅས་པ་བཞི། དང་པོ་ལ། དངོས་དང་། སྙོམས་འཇུག་གང་གི་མཇུག་ཏུ་སྙོམས་འཇུག་དུ་འབྱུང་ལ་དཔྱད་པ། དག་པ་བའི་དབྱེ་བ། ཞར་བྱུང་ཐོད་རྒལ་གྱི་རྣམ་གཞག་དང་བཞི།
