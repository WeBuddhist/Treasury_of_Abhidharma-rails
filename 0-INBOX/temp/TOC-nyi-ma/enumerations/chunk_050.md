Enumeration Block 1:
གཉིས་པ་དེ་དག་གི་ཁྱད་ཆོས་ལ། ཐོབ་ཚུལ། ཐོབ་ཟིན་མངོན་དུ་བྱེད་ཚུལ། དམིགས་པའི་ཁྱད་པར། སྤང་བྱ་སྤོང་ཚུལ་ཉེར་བསྡོགས་དང་བཅས་པ་བཞི། དང་པོ་ལ། དངོས་དང་། སྙོམས་འཇུག་གང་གི་མཇུག་ཏུ་སྙོམས་འཇུག་དུ་འབྱུང་ལ་དཔྱད་པ། དག་པ་བའི་དབྱེ་བ། ཞར་བྱུང་ཐོད་རྒལ་གྱི་རྣམ་གཞག་དང་བཞི།
Enumeration Block 2:
འདི་ལ་ཐོད་རྒལ་གྱི་སྦྱོར་བ། དངོས་གཞི། སྒྲ་བཤད། རྟེན་དང་བཞི། དང་པོ་ལ། རིང་སྦྱོར་དང་ཉེ་སྦྱོར་གཉིས་ལས།
Enumeration Block 3:
བཞི་བ་སྤང་བྱ་སྤོང་ཚུལ་ཉེར་བསྡོགས་དང་བཅས་པ་ལ། སྤང་བྱ་སྤོང་ཚུལ། ཉེར་བསྡོགས་ཀྱི་དབྱེ་བ། བསམ་གཏན་གྱི་སྙོམས་འཇུག་ཁྱད་པར་ཅན་བཤད་པ་དང་གསུམ།
Enumeration Block 4:
གསུམ་པ་ཏིང་ངེ་འཛིན་གྱི་དབྱེ་བ་ལས། ཁམས་གསུམ་གྱི་སྒོ་ནས་རྟོག་བཅས་སོགས་གསུམ། ལམ་གྱི་སྒོ་ནས་རྣམ་ཐར་སྒོ་གསུམ། ལམ་སུན་པའི་སྒོ་ནས་གསུམ། བྱེད་པའི་སྒོ་ནས་བཞིར་བཤད་པ་དང་བཞི།
Enumeration Block 5:
བཞི་པ་དེ་ལ་བརྟེན་པའི་ཡོན་ཏན་ལ། ཚད་མེད་དང་། རྣམ་ཐར་དང་ཟིལ་གནོན་དང་ཟད་པར་དང་དེ་དག་གི་ཐོབ་ཚུལ་རྟེན་དང་བཅས་པ་ལྔ།
