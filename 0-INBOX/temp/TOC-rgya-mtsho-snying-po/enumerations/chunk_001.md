Enumeration Block 1:
གནས་བརྒྱད་ལས་དང་པོ་ཁམས་བསྟན་པའི་གནས་ཀྱི་དོན་ལ་གཉིས། གནས་ཀྱི་གཞུང་བཤད་པ་དང༌། གནས་ཀྱི་མཚན་བསྟན་པའོ། །དང་པོ་ལ་བཞི། འདུས་བྱས་ཀྱི་རྣམ་གཞག ཕུང་ཁམས་སྐྱེ་མཆེད་ཀྱི་རྣམ་གཞག ཆོས་གསུམ་གྱིས་ཐམས་ཅད་བསྡུས་པར་བསྟན་པ། ཁམས་ཀྱི་རྣམ་པའི་རབ་དབྱེའོ། །དང་པོ་ལ་གསུམ། འདུས་བྱས་ཀྱི་མཚན་གཞི། མིང་གི་རྣམ་གྲངས། ཟག་བཅས་ཀྱི་རྣམ་གྲངས་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ཕུང་ཁམས་སྐྱེ་མཆེད་ཀྱི་རྣམ་གཞག་ལ་བཞི། ཕུང་ཁམས་སྐྱེ་མཆེད་སོ་སོའི་རང་བཞིན། སྒྲ་འཇུག་པའི་རྒྱུ་མཚན། ཆོས་གསུམ་བསྟན་པའི་དགོས་པ། ཆོས་གསུམ་གྱི་གོ་རིམ་མོ། །དང་པོ་ལ་གསུམ། རྒྱས་པར་བཤད། བསྡུས་ཏེ་བསྟན། དོགས་པ་བཅད་པའོ། །དང་པོ་ལ་གསུམ། གཟུགས་ཀྱི་ཕུང་ཁམས་སྐྱེ་མཆེད་བཤད། ཚོར་སོགས་གསུམ་གྱི། རྣམ་ཤེས་ཀྱི་དེ་བཤད་པའོ། །དང་པོ་ལ་གསུམ། བསྟན་པ་དང༌། བཤད་པ་དང༌། ཁམས་དང་སྐྱེ་མཆེད་དུ་བཞག་ཚུལ་ལོ། །
Enumeration Block 3:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་གསུམ། དབང་པོ་ལྔ་བཤད། དོན་ལྔ་བཤད། རིག་བྱེད་མ་ཡིན་པའི་གཟུགས་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་དོན་ལྔ་བཤད་པ་ལ་ལྔ་ལས།
Enumeration Block 5:
གསུམ་པ་རིག་བྱེད་མིན་པའི་གཟུགས་བཤད་པ་ལ། དངོས་དང༌། དེའི་རྒྱུ་འབྱུང་བ་བཤད་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ཚོར་སོགས་གསུམ་གྱི་ཕུང་ཁམས་སྐྱེ་མཆེད་བཤད་པ་ལ་བཞི། ཚོར་བ། འདུ་ཤེས། འདུ་བྱེད། ཆོས་ཀྱི་སྐྱེ་མཆེད་དང་ཁམས་སུ་བསྟན་པའོ། །
