Enumeration Block 1:
གསུམ་པ་ཆོས་གསུམ་གྱིས་ཐམས་ཅད་བསྡུས་པར་བསྟན་པ་ལ། ཆོས་ཀྱི་ཕུང་པོ་བསྡུ་བ། ཕུང་ཁམས་སྐྱེ་མཆེད་གཞན་བསྡུ་བ། ཞར་ལ་ཁམས་གཉིས་ཀྱི་ངོ་བོ་བསྟན་པའོ། །དང་པོ་ལ། དངོས་དང༌། ཆོས་ཕུང་གི་ཚད་དོ། །
Enumeration Block 2:
གཉིས་པ་ཆོས་ཕུང་གི་ཚད་ལ། གཞན་ལུགས་དགག རང་ལུགས་བཞག་པའོ། །
Enumeration Block 3:
གསུམ་པ་ཞར་ལ་ཁམས་གཉིས་ཀྱི་ངོ་བོ་བསྟན་པ་ལ། ནམ་མཁའ་དང༌། རྣམ་ཤེས་གཉིས་ལས།
Enumeration Block 4:
བཞི་པ་ཁམས་ཀྱི་རྣམ་པའི་རབ་དབྱེ་ལ་བདུན། གཉིས་ཚན་གྱི་དབྱེ་བ་དང༌། གསུམ་ཚན། བཅས་མ་བཅས། གཟུགས་ཅན་གྱི་དབྱེ་བ། བྱུང་བ་གསུམ་དང༌། ཐོབ་པའི་ཁྱད་པར། ཕྱི་ནང་ལ་སོགས་པའི་དབྱེ་བའོ། །དང་པོ་ལ། བསྟན་དུ་ཡོད་མེད་དང༌། ཐོགས་བཅས་ཐོགས་མེད་ཀྱི་རྣམ་པའོ། །
Enumeration Block 5:
གཉིས་པ་གསུམ་ཚན་གྱི་རྣམ་པ་ལ། དགེ་སོགས་གསུམ་གྱི་རྣམ་པ་དང༌། ཁམས་གསུམ་དུ་གཏོགས་པའི་རྣམ་པའོ། །
Enumeration Block 6:
གསུམ་པ་བཅས་མ་བཅས་ཀྱི་རྣམ་པ་ལ། ཟག་པ་དང་བཅས་མ་བཅས། རྟོག་དཔྱོད་དང་བཅས་མ་བཅས། དམིགས་པ་དང་བཅས་མ་བཅས་སོ། །
Enumeration Block 7:
བཞི་པ་གཟུགས་ཅན་གྱི་དབྱེ་བ་ལ། ཟིན་མ་ཟིན་གྱི་དབྱེ་བ། འབྱུང་འབྱུང་གྱུར་གྱི་དབྱེ་བ། བསགས་མ་བསགས་ཀྱི་དབྱེ་བ། གཅད་བྱ་གཅོད་བྱེད་ཀྱི་དབྱེ་བ། སྲེག་འཇལ་གྱི་དབྱེ་བའོ། །
Enumeration Block 8:
ལྔ་པ་བྱུང་བ་གསུམ་ལ། སྤྱིར་བཏང་བ་དང༌། དམིགས་ཀྱིས་བསལ་བའོ། །
Enumeration Block 9:
བདུན་པ་ཕྱི་ནང་ལ་སོགས་པའི་དབྱེ་བ་ལ། ཕྱི་ནང་གི་རྣམ་པ། རྟེན་བཅས་དེ་མཚུངས་ཀྱི། མཐོང་སྤང་སོགས་ཀྱི། ལྟ་བ་ཡིན་མིན་གྱི། རྣམ་ཤེས་གང་གི་ཡུལ་ཡིན་པ། རྟག་མི་རྟག་གི ། དབང་པོ་ཡིན་མིན་གྱི་རྣམ་པའོ། །
Enumeration Block 10:
གཉིས་པ་རྟེན་བཅས་དེ་མཚུངས་ཀྱི་རྣམ་པ་ལ། དངོས་དང༌། དེ་མཚུངས་ཀྱི་དོན་ཏོ། །
Enumeration Block 11:
གསུམ་པ་མཐོང་སྤང་སོགས་ཀྱི་རྣམ་པ་ལ། དངོས་དང༌། གནས་མ་བུའི་འདོད་པ་དགག་པའོ། །
Enumeration Block 12:
བཞི་པ་ལྟ་བ་ཡིན་མིན་གྱི་རྣམ་པ་ལ། དངོས་དང༌། དེ་ལས་འཕྲོས་པའི་དོན་ཏོ། །
Enumeration Block 13:
གཉིས་པ་དེ་ལས་འཕྲོས་པའི་དོན་ལ། དབང་པོའི་ཤེས་རབ་ལྟ་བ་ཡིན་པ་དགག མིག་ལྟ་བ་ཡིན་པར་སྒྲུབ། །དབང་པོས་ཡུལ་འཛིན་པའི་ཁྱད་པར། རྟེན་གྱི་དུས་ངེས་པ། རྟེན་དང་བརྟེན་པའི་རྒྱུ་མཚན། དབང་ཡུལ་རྣམ་ཤེས་དང་རྟེན་གྱི་ས་པའི་ངེས་པའོ། །
Enumeration Block 14:
གཉིས་པ་མིག་ལྟ་བ་ཡིན་པར་སྒྲུབ་པ་ལ། དངོས་དང༌། དོགས་པ་གཅོད་པའོ། །
Enumeration Block 15:
གཉིས་པ་དོགས་གཅོད་ལ། ཐམས་ཅད་ཀྱིས་མཐོང་མི་མཐོང་དཔྱད། མིག་དང་མིག་ཤེས་གང་གིས་མཐོང་དཔྱད། མིག་གཉིས་ཀས་མཐོང་མི་མཐོང་དཔྱད་པའོ། །
Enumeration Block 16:
གསུམ་པ་དབང་པོས་ཡུལ་འཛིན་པའི་ཁྱད་པར་ལ། ཕྲད་མ་ཕྲད་དང༌། མཉམ་མི་མཉམ་མོ། །
Enumeration Block 17:
ལྔ་པ་རྟེན་དང་བརྟེན་པའི་རྒྱུ་མཚན་ལ། རྟེན་ཉིད་དུ་འཇོག་པའི་རྒྱུ་མཚན་དང༌། རྣམ་ཤེས་རྟེན་གྱིས་ཁྱད་པར་དུ་བྱེད་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 18:
དྲུག་པ་དབང་ཡུལ་རྣམ་ཤེས་དང་རྟེན་གྱི་ས་པའི་ངེས་པ་ལ། མིག་ལ་དངོས་སུ་སྦྱར་བ། རྣ་བ་དེ་དང་མཚུངས་པར་བསྟན་པ། སྣ་ལྕེ་ལུས་གསུམ་གྱི་ངེས་པ། ཡིད་ངེས་མེད་དུ་བསྟན་པའོ། །
