Enumeration Block 1:
གཉིས་པ་དེ་ལས་འཕྲོས་པའི་དོན་ལ། དབང་པོའི་ཤེས་རབ་ལྟ་བ་ཡིན་པ་དགག མིག་ལྟ་བ་ཡིན་པར་སྒྲུབ། །དབང་པོས་ཡུལ་འཛིན་པའི་ཁྱད་པར། རྟེན་གྱི་དུས་ངེས་པ། རྟེན་དང་བརྟེན་པའི་རྒྱུ་མཚན། དབང་ཡུལ་རྣམ་ཤེས་དང་རྟེན་གྱི་ས་པའི་ངེས་པའོ། །
Enumeration Block 2:
གཉིས་པ་མིག་ལྟ་བ་ཡིན་པར་སྒྲུབ་པ་ལ། དངོས་དང༌། དོགས་པ་གཅོད་པའོ། །
Enumeration Block 3:
གཉིས་པ་དོགས་གཅོད་ལ། ཐམས་ཅད་ཀྱིས་མཐོང་མི་མཐོང་དཔྱད། མིག་དང་མིག་ཤེས་གང་གིས་མཐོང་དཔྱད། མིག་གཉིས་ཀས་མཐོང་མི་མཐོང་དཔྱད་པའོ། །
Enumeration Block 4:
གསུམ་པ་དབང་པོས་ཡུལ་འཛིན་པའི་ཁྱད་པར་ལ། ཕྲད་མ་ཕྲད་དང༌། མཉམ་མི་མཉམ་མོ། །
Enumeration Block 5:
ལྔ་པ་རྟེན་དང་བརྟེན་པའི་རྒྱུ་མཚན་ལ། རྟེན་ཉིད་དུ་འཇོག་པའི་རྒྱུ་མཚན་དང༌། རྣམ་ཤེས་རྟེན་གྱིས་ཁྱད་པར་དུ་བྱེད་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 6:
དྲུག་པ་དབང་ཡུལ་རྣམ་ཤེས་དང་རྟེན་གྱི་ས་པའི་ངེས་པ་ལ། མིག་ལ་དངོས་སུ་སྦྱར་བ། རྣ་བ་དེ་དང་མཚུངས་པར་བསྟན་པ། སྣ་ལྕེ་ལུས་གསུམ་གྱི་ངེས་པ། ཡིད་ངེས་མེད་དུ་བསྟན་པའོ། །
Enumeration Block 7:
གསུམ་པ་སྣ་ལྕེ་ལུས་གསུམ་གྱི་ངེས་པ་ལ། སྤྱིར་བཏང་བ་དང༌། དམིགས་ཀྱིས་བསལ་བ་ལས།
Enumeration Block 8:
ད་ནི་གནས་གཉིས་པ་དབང་པོ་བསྟན་པའི་གནས་ཀྱི་དོན་ལ། གནས་ཀྱི་གཞུང་བསྟན་པ་དང༌། གནས་ཀྱི་མཚན་བསྟན་པའོ། །དང་པོ་ལ་དབང་པོའི་རང་བཞིན། འདུས་བྱས་ཀྱི་སྐྱེ་ཚུལ། རྒྱུ་རྐྱེན་འབྲས་བུ་དང་བཅས་པ་བཤད་པའོ། །དང་པོ་ལ། དབང་པོ་སོ་སོར་ངོས་བཟུང་བ་དང༌། དབང་པོའི་རྣམ་པའི་རང་བཞིན་གཏན་ལ་དབབ་པའོ། །དང་པོ་ལ། དབང་པོ་སོ་སོའི་སྒྲ་དོན། གྲངས་ངེས། སོ་སོའི་མཚན་ཉིད་དོ། །དང་པོ་ལ། བྱེ་མདོའི་ལུགས་གཉིས་ལས།
Enumeration Block 9:
གཉིས་པ་གྲངས་ངེས། བྱེ་མདོ་གཉིས་ཀྱི་ལུགས་གཉིས་ལས།
Enumeration Block 10:
གསུམ་སོ་སོའི་མཚན་ཉིད་ལ། ཚོར་དབང་ལྔའི་མཚན་ཉིད་དང༌། དྲི་མེད་ཀྱི་དབང་པོ་གསུམ་གྱི་མཚན་ཉིད་བཤད་པའོ། །དང་པོ་ལ། ལུས་ཚོར་བདེ་སྡུག སེམས་ཚོར་བདེ་སྡུག བཏང་སྙོམས་སོ། །དང་པོ་ལ། སྡུག་བསྔལ་དང༌། བདེ་བའོ། །
Enumeration Block 11:
གཉིས་པ་སེམས་ཚོར་བདེ་སྡུག་ལ། ཡིད་བདེ་དང༌། ཡིད་མི་བདེའོ། །
Enumeration Block 12:
གསུམ་པ་བཏང་སྙོམས་ཀྱི་དབང་པོ་ལ། མཚན་ཉིད་དང༌། ལུས་སེམས་ཀྱི་དེ་གཉིས་སོ་སོར་མི་འདྲེན་པའི་དོན་ཏོ། །
Enumeration Block 13:
གཉིས་པ་དབང་པོའི་རྣམ་པའི་རང་བཞིན་གཏན་ལ་དབབ་པ་ལ། རྣམ་པའི་རབ་དབྱེ་བསྟན་པ། ཇི་ལྟར་རྙེད་པའི་ཚུལ། འབྲས་བུ་དབང་པོ་དུས་ཐོབ་པ། དབང་པོ་ལྡན་ཚུལ་ལོ། །དང་པོ་ལ། ཟག་བཅས་ཟག་མེད་ཀྱི་རྣམ་པ། རྣམ་སྨིན་ཡིན་མིན། རྣམ་སྨིན་དང་བཅས་མ་བཅས། དགེ་སོགས་གསུམ་གྱི་རྣམ་པ། ཁམས་གང་དུ་གཏོགས་པའི་རྣམ་པ། སྤང་བྱ་ཡིན་མིན་གྱི་རྣམ་པའོ། །
