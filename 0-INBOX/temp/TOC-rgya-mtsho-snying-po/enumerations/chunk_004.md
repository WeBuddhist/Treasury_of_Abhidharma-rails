Enumeration Block 1:
གཉིས་པ་ཇི་ལྟར་རྙེད་པའི་ཚུལ་ལ། རྙེད་ཚུལ་དངོས་དང༌། ཞར་བྱུང་འགག་པའི་ཚུལ་ལོ། །དང་པོ་ལ། འདོད་ཁམས། གཟུགས་ཁམས། གཟུགས་མེད་ཁམས་སུ་རྙེད་པའོ། །དང་པོ་ལ། སྤྱིར་བཏང༌། དམིགས་བསལ་ལས།
Enumeration Block 2:
གཉིས་པ་ཞར་བྱུང་འགག་པའི་ཚུལ་ལ། སྤྱིར་བཏང་དང༌། དགེ་སེམས་དང་ལྡན་པའི་དམིགས་བསལ་ལོ། །དང་པོ་ལ། གཟུགས་མེད། གཟུགས། འདོད་པར་འགག་ཚུལ་ལོ། །
Enumeration Block 3:
གསུམ་པ་འདོད་པར་འགག་ཚུལ་ལ། རྫུས་སྐྱེས་དང༌། མངལ་སྐྱེས་ཀྱི་འགག་ཚུལ་ལོ། །
Enumeration Block 4:
གསུམ་པ་འབྲས་བུ་དབང་པོ་དུས་ཐོབ་པ་ལ། འབྲས་བུ་ཐོག་མཐའ་གཉིས་དུས་ཐོབ་པ། བར་པ་གཉིས་དུས་ཐོབ་པ། དེ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 5:
བཞི་པ་དབང་པོའི་ལྡན་ཚུལ་ལ། །ངེས་ལྡན། ཉུང་ལྡན། མང་ལྡན་ནོ། །དང་པོ་ལ། གསུམ་གྱི་ངེས་ལྡན། བཞིའི་ངེས་ལྡན། ལྔ་ལྡན། བདུན་ལྡན། བརྒྱད་ལྡན། བཅུ་གཅིག་ལྡན། བཅུ་གསུམ་ངེས་པར་ལྡན་པའོ། །
Enumeration Block 6:
གཉིས་པ་ཉུང་ལྡན་ལ། དགེ་བ་མེད་པའི་ཉུང་ལྡན་དང༌། གཟུགས་མེད་བྱིས་པའི་ཉུང་ལྡན་ནོ། །
Enumeration Block 7:
གསུམ་པ་མང་ལྡན་ལ། སོ་སྐྱེ་དང༌། འཕགས་པའི་མང་ལྡན་ནོ། །
Enumeration Block 8:
གཉིས་པ་འདུས་བྱས་ཀྱི་སྐྱེ་ཚུལ་ལ། གཟུགས་ཅན་དང༌། གཟུགས་ཅན་མིན་པའི་སྐྱེ་ཚུལ་ལོ། །དང་པོ་ལ། རྫས་བརྒྱད་དང་ལྡན་པར་སྐྱེ་བ། དགུ་དང་ལྡན་པར་སྐྱེ་བ། བཅུ་དང་ལྡན་པར་སྐྱེ་བའོ། །
Enumeration Block 9:
གཉིས་པ་གཟུགས་ཅན་མ་ཡིན་པའི་སྐྱེ་ཚུལ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 10:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། སེམས་དང་མཚུངས་ལྡན་རྒྱས་པར་བཤད། མི་ལྡན་འདུ་བྱེད་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 11:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། ས་མང་ལྔའི་དབྱེ་བ། སེམས་གང་གི་འཁོར་དུ་སེམས་བྱུང་གང་ཡོད་པ། འདྲ་མཚུངས་ཀྱི་ཁྱད་འབྱེད། མིང་གི་རྣམ་གྲངས་བསྟན་པའོ། །དང་པོ་ལ། སེམས་ཀྱི་ས་མང་པོ་བ། དགེ་བའི་ས་མང་པོ་བ། ཉོན་མོངས་པ་ཅན་གྱི་ས་མང་པོ་བ། མི་དགེ་བའི་ས་མང་པོ་བ། ཉེ་བའི་ཉོན་མོངས་པ་ཆུང་ངུའི་ས་པ་བཤད་པའོ། །
Enumeration Block 12:
གཉིས་པ་སེམས་གང་གི་འཁོར་དུ་སེམས་བྱུང་གང་ཡོད་པ་ལ། འདོད་སེམས་གང་གི་འཁོར་དུ་སེམས་བྱུང་གང་ཡོད་པ། ཁམས་གོང་ན་གང་ཡོད་པའོ། །དང་པོ་ལ། དགེ་བའི་སེམས་ཀྱི། མི་དགེ་བའི་སེམས་ཀྱི། ལུང་མ་བསྟན་གྱི་འཁོར་དུ་གང་ཡོད་པ། གཉིད་གསལ་བྱེད་དུ་སྦྱར་བའོ། །དང་པོ་ལ། སྤྱིར་བཏང༌། དམིགས་བསལ་ལོ། །
Enumeration Block 13:
གསུམ་པ་སེམས་ལུང་མ་བསྟན་གྱི་འཁོར་དུ་སེམས་བྱུང་གང་ཡོད་པ་ལ། བསྒྲིབས་ལུང་མ་བསྟན་གྱི་དང༌། མ་བསྒྲིབས་ལུང་མ་བསྟན་གྱི་འཁོར་དུ་གང་ཡོད་པའོ། །
