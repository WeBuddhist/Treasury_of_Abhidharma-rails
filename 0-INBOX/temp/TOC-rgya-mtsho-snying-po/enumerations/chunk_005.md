Enumeration Block 1:
གཉིས་པ་སེམས་གང་གི་འཁོར་དུ་སེམས་བྱུང་གང་ཡོད་པ་ལ། འདོད་སེམས་གང་གི་འཁོར་དུ་སེམས་བྱུང་གང་ཡོད་པ། ཁམས་གོང་ན་གང་ཡོད་པའོ། །དང་པོ་ལ། དགེ་བའི་སེམས་ཀྱི། མི་དགེ་བའི་སེམས་ཀྱི། ལུང་མ་བསྟན་གྱི་འཁོར་དུ་གང་ཡོད་པ། གཉིད་གསལ་བྱེད་དུ་སྦྱར་བའོ། །དང་པོ་ལ། སྤྱིར་བཏང་དང༌། དམིགས་བསལ་ལོ། །
Enumeration Block 2:
གསུམ་པ་སེམས་ལུང་མ་བསྟན་གྱི་འཁོར་དུ་སེམས་བྱུང་གང་ཡོད་པ་ལ། བསྒྲིབས་ལུང་མ་བསྟན་གྱི་དང༌། མ་བསྒྲིབས་ལུང་མ་བསྟན་གྱི་འཁོར་དུ་གང་ཡོད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ཁམས་གོང་མ་ན་སེམས་བྱུང་གང་ཡོད་པ་ལ། བསམ་གཏན་དང་པོ་ན་དང༌། གཉིས་པ་ཡན་ན་གང་ཡོད་པའོ། །དང་པོ་ལ། དངོས་གཞི་ཙམ་ཁྱད་གཉིས་ན་གང་ཡོད་པ་ལས།
Enumeration Block 4:
གསུམ་པ་འདྲ་མཚུངས་ཀྱི་ཁྱད་འབྱེད་ལ། ངོ་ཚ་མེད་པ་དང་ཁྲེལ་མེད་ཀྱི་ཁྱད་པར། དགའ་གུས་ཀྱི་ཁྱད་པར། རྟོག་དཔྱོད་ཀྱི་ཁྱད་པར། ང་རྒྱལ་དང་རྒྱགས་པའི་ཁྱད་པར་རོ། །
Enumeration Block 5:
གཉིས་པ་ལ། དངོས་དང༌། ཁམས་གང་ན་གང་ཡོད་པའོ། །
Enumeration Block 6:
བཞི་པ་མིང་གི་རྣམ་གྲངས་བསྟན་པ་ལ། སེམས་ཀྱི་རྣམ་གྲངས་དང༌། སེམས་བྱུང་གི་འདྲ་མཚུངས་སོ། །
Enumeration Block 7:
གཉིས་པ་མི་ལྡན་འདུ་བྱེད་ལ། བསྟན། བཤད། ཆོས་ཀྱི་ཁྱད་པར་གཞན་བསྟན་པས་མཇུག་བསྡུ་བའོ། །
Enumeration Block 8:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། ཐོབ་མ་ཐོབ། སྐལ་མཉམ། འདུ་ཤེས་མེད་པ། སྙོམས་འཇུག སྲོག མཚན་ཉིད། མིང་སོགས་རྒྱས་པར་བཤད་པ་དང་བདུན་ནོ། །དང་པོ་ལ། ངོ་བོ་ངོས་བཟུང་བ་དང༌། དེ་གང་གི་ཡིན་པ་དང༌། ཁྱད་པར་གྱི་ཆོས་སོ། །
Enumeration Block 9:
གཉིས་པ་དེ་གང་གི་ཡིན་པ་ལ། སྤྱིར་བཏང༌། དམིགས་བསལ་ལོ། །
Enumeration Block 10:
གསུམ་པ་ཁྱད་པར་གྱི་ཆོས་ལ། ཐོབ་པའི་ཁྱད་ཆོས། མ་ཐོབ་པའི་ཁྱད་ཆོས་སོ། །དང་པོ་ལ། དུས་ཀྱི་ཁྱད་པར། ངོ་བོའི་ཁྱད་པར། ཁམས་ཀྱི་ཁྱད་པར། སློབ་མི་སློབ་ཀྱི་ཁྱད་པར། སྤང་བྱ་ཡིན་མིན་གྱི་ཁྱད་པར། །དུས་ཀྱི་ཁྱད་པར་དམིགས་ཀྱི་བསལ་པའོ། །
Enumeration Block 11:
དྲུག་པ་དུས་ཀྱི་ཁྱད་པར་དམིགས་ཀྱིས་བསལ་བ་ལ། མ་བསྒྲིབས་ལུང་མ་བསྟན་གྱི་དམིགས་བསལ། བསྒྲིབས་ལུང་མ་བསྟན་གྱི། དགེ་མི་དགེའི་འོ། །
Enumeration Block 12:
གཉིས་པ་མ་ཐོབ་པའི་ཁྱད་པར་ལ། ངོ་བོའི་ཁྱད་པར། དུས་ཀྱི་ཁྱད་པར། ཁམས་ཀྱི་ཁྱད་པར། མ་ཐོབ་པ་ཟག་མེད་མེད་པ། ཉམས་ཚུལ་གྱི་ཁྱད་པར་རོ། །
Enumeration Block 13:
དབྱེ་ན་ཐ་དད་མ་ཡིན་པ་དང་ཐ་དད་པ་གཉིས་སོ། །
Enumeration Block 14:
གསུམ་པ་འདུ་ཤེས་མེད་པ་པ་བཤད་པ་ལ། མཚན་གཞི་ངོས་བཟུང་བ། འབྲས་བུ་བཞི་གང་ཡིན་པ། ས་གང་དུ་གཏོགས་པའོ། །
Enumeration Block 15:
བཞི་པ་སྙོམས་འཇུག་གཉིས་བཤད་པ་ལ། ངོ་བོ་སོ་སོར་བཤད། རྟེན་ཐུན་མོང་དུ་བསྟན་པའོ། །དང་པོ་ལ། འདུ་ཤེས་མེད་པའི་སྙོམས་འཇུག་གི་ངོ་བོ། འགོག་སྙོམས་ཀྱི་ངོ་བོའོ། །
Enumeration Block 16:
གཉིས་པ་འགོག་སྙོམས་ཀྱི་ངོ་བོ་ལ། དངོས་དང༌། ཐོབ་ཚུལ་གྱི་དམིགས་བསལ་དང༌། འཕྲོས་དོན་ཏོ། །
Enumeration Block 17:
དྲུག་པ་མཚན་ཉིད་བཤད་པ་ལ། དབྱེ་བ། དོགས་པ་བཅད་པའོ། །
Enumeration Block 18:
གཉིས་པ་དོགས་པ་བཅད་པ་ལ། མཚན་ཉིད་ལ་མཚན་ཉིད་ཡོད་པར་བསྟན། ཐུག་མེད་དུ་ཐལ་བ་སྤང༌། ཧ་ཅང་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 19:
བདུན་པ་མིང་ཚིག་ཡི་གེའི་ཚོགས་བཤད་པ་ལ། ངོ་བོ་དང༌། ཁྱད་ཆོས་སོ། །
Enumeration Block 20:
གཉིས་པ་ཁྱད་ཆོས་ལ། སའི་ཁྱད་པར། སྟོན་མི་སྟོན་གྱི་ཁྱད་པར། བྱུང་བའི་ཁྱད་པར། དགེ་སོགས་ཀྱི་ཁྱད་པར་རོ། །
