Enumeration Block 1:
དྲུག་པ་མཚན་ཉིད་བཤད་པ་ལ། དབྱེ་བ། དོགས་པ་བཅད་པའོ། །
Enumeration Block 2:
གཉིས་པ་དོགས་པ་བཅད་པ་ལ། མཚན་ཉིད་ལ་མཚན་ཉིད་ཡོད་པར་བསྟན། ཐུག་མེད་དུ་ཐལ་བ་སྤང༌། ཧ་ཅང་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 3:
བདུན་པ་མིང་ཚིག་ཡི་གེའི་ཚོགས་བཤད་པ་ལ། ངོ་བོ་དང༌། ཁྱད་ཆོས་སོ། །
Enumeration Block 4:
གཉིས་པ་ཁྱད་ཆོས་ལ། སའི་ཁྱད་པར། སྟོན་མི་སྟོན་གྱི་ཁྱད་པར། བྱུང་བའི་ཁྱད་པར། དགེ་སོགས་ཀྱི་ཁྱད་པར་རོ། །
Enumeration Block 5:
གསུམ་པ་རྒྱུ་རྐྱེན་འབྲས་བུ་དང་བཅས་པའི་རྣམ་གཞག་བཤད་པ་ལ། རྒྱུ་བཤད་པ། འབྲས་བུ་བཤད་པ། རྒྱུ་འབྲས་གཉིས་ཀྱི་ཐུན་མོང་གི་ཆོས་བཤད་པ། རྐྱེན་བཤད་པའོ། །དང་པོ་ལ། དབྱེ་བས་མདོར་བསྟན། སོ་སོའི་རང་བཞིན་རྒྱས་པར་བཤད། །དུས་ངེས་པས་མཇུག་བསྡུ་བའོ། །
Enumeration Block 6:
གཉིས་པ་སོ་སོའི་རང་བཞིན་རྒྱས་བཤད་ལ། བྱེད་རྒྱུ། ལྷན་ཅིག་བྱུང་བའི། སྐལ་མཉམ། མཚུངས་ལྡན། ཀུན་འགྲོ། རྣམ་སྨིན་གྱི་རྒྱུའོ། །
Enumeration Block 7:
གཉིས་པ་ལྷན་ཅིག་འབྱུང་བའི་རྒྱུ་ལ། ངོ་བོ་ངོས་བཟུང༌། མཚན་གཞི་དཔེར་བརྗོད། དེ་ལས་འཕྲོས་པའི་དོན་ཏོ། །
Enumeration Block 8:
གསུམ་པ་འཕྲོས་པའི་དོན་ལ། སེམས་ཀྱི་རྗེས་འཇུག་ངོས་བཟུང་བ་དང༌། དེ་སེམས་ཀྱི་རྗེས་སུ་ཇི་ལྟར་འཇུག་ཚུལ་ལོ། །
Enumeration Block 9:
གསུམ་སྐལ་མཉམ་གྱི་རྒྱུ་ལ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 10:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། ཟག་བཅས་ཀྱི་འདྲ་བ། དུས་ཀྱི་ཁྱད་པར། ཟག་མེད་བྱེ་བྲག་ཏུ་བཤད་པ། དེ་འཇིག་རྟེན་པའི་སྦྱོར་བྱུང་ལ་མཚུངས་པར་བསྟན་པའོ། །
Enumeration Block 11:
གཉིས་པ་འབྲས་བུ་བཤད་པ་ལ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 12:
གཉིས་པ་རྒྱས་བཤད་ལ། རྒྱུ་གང་གི་འབྲས་བུ་གང་ཡིན་པ་དང༌། འབྲས་བུ་ལྔའི་ངོ་བོའོ། །
Enumeration Block 13:
གཉིས་པ་འབྲས་བུ་ལྔའི་ངོ་བོ་ལ། རྣམ་སྨིན་གྱི། རྒྱུ་མཐུན་གྱི། བྲལ་བའི། སྐྱེས་བུའི་བྱེད་པའི། བདག་པོའི་འབྲས་བུའི་ངོ་བོའོ། །
Enumeration Block 14:
གསུམ་པ་རྒྱུ་འབྲས་གཉིས་ཀྱི་ཐུན་མོང་གི་ཆོས་བཤད་པ་ལ། རྒྱུ་འབྲས་འཛིན་འབྱིན་གྱི་དུས། འབྲས་བུ་གང་རྒྱུ་དུས་བསྐྱེད་པའོ། །དང་པོ་ལ། འཛིན་པའི་དུས་དང༌། འབྱིན་པའི་དུས་སོ། །
Enumeration Block 15:
གཉིས་པ་འབྲས་བུ་གང་རྒྱུ་དུས་སྐྱེད་པ་ལ། མཚུངས་ལྡན་དང༌། མཚུངས་ལྡན་མ་ཡིན་པའི་སྐྱེད་ཚུལ་ལོ། །དང་པོ་ལ། བཤད་པ་དང༌། བསྡུ་བའོ། །
Enumeration Block 16:
བཞི་པ་རྐྱེན་བཤད་པ་ལ། མདོར་བསྟན། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 17:
གཉིས་པ་རྒྱས་བཤད་ལ། རྐྱེན་བཞི་སོ་སོའི་རང་བཞིན། རྐྱེན་གང་དུས་གང་ལ་བྱ་བ་བྱེད་པ། དངོས་པོ་གང་རྐྱེན་དུ་ལས་སྐྱེ་བ། དེ་མ་ཐག་རྐྱེན་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ། རྒྱུའི་རྐྱེན། དེ་མ་ཐག་རྐྱེན། དམིགས་རྐྱེན། བདག་རྐྱེན་ནོ། །
Enumeration Block 18:
གཉིས་པ་རྐྱེན་གང་དུས་གང་ལ་བྱ་བ་བྱེད་པ་ལ། ལྷན་འབྱུང་དང་མཚུངས་ལྡན་གྱི་རྒྱུ་དུས་གང་ལ་དང༌། སྐལ་མཉམ་སོགས་གསུམ་དང༌། དེ་མ་ཐག་རྐྱེན་དང་དམིགས་རྐྱེན་དུས་གང་ལ་བྱ་བ་བྱེད་པའོ། །
Enumeration Block 19:
གསུམ་པ་དངོས་པོ་གང་རྐྱེན་དུ་ལས་སྐྱེ་བ་ལ། སྤྱིར་བསྟན་པ་དང༌། གཟུགས་ཅན་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ། རང་ལུགས་བཞག་པ་དང༌། གཞན་ལུགས་དགག་པའོ། །དང་པོ་ལ། རྐྱེན་བཞི་ལས། གསུམ་ལས། གཉིས་ལས་སྐྱེ་བའོ། །
Enumeration Block 20:
གཉིས་པ་གཟུགས་ཅན་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། འབྱུང་བས་འབྱུང་བའི་རྐྱེན་བྱེད་ཚུལ། འབྱུང་བས་འབྱུང་གྱུར་གྱི་རྐྱེན་བྱེད་ཚུལ། འབྱུང་གྱུར་ནང་ཕན་ཚུན་རྐྱེན་བྱེད་ཚུལ། འབྱུང་གྱུར་གྱིས་འབྱུང་བའི་རྐྱེན་བྱེད་ཚུལ་ལོ། །
Enumeration Block 21:
བཞི་པ་དེ་མ་ཐག་རྐྱེན་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། སེམས་བཅུ་གཉིས་སུ་དབྱེ་བ། བཅུ་གཉིས་པོ་གང་ལས་གང་རྙེད་པ། སེམས་ཉི་ཤུར་དབྱེ་བ། སེམས་ཉོན་མོངས་ཅན་གྱི་རྙེད་ཚུལ་ལོ། །
Enumeration Block 22:
གཉིས་པ་བཅུ་གཉིས་པོ་གང་ལས་གང་རྙེད་པ་ལ། འདོད་སེམས་ལ་སྦྱར་བ། གཟུགས་ཀྱི། གཟུགས་མེད་ཀྱི། སློབ་པའི། མི་སློབ་པའི་སེམས་ལ་སྦྱར་བའོ། །དང་པོ་ལ། དགེ་སེམས་ལ། མི་དགེ་བའི་སེམས་ལ། ལུང་མ་བསྟན་གྱི་སེམས་ལ་སྦྱར་བའོ། །དང་པོ་ལ། དགེ་སེམས་ཀྱི་མཇུག་ཐོགས་སུ་སེམས་དུ་འབྱུང་བ་དང༌། སེམས་དུའི་མཇུག་ཐོགས་སུ་དགེ་སེམས་འབྱུང་བའོ། །
Enumeration Block 23:
གཉིས་པ་མི་དགེ་བའི་སེམས་ལ་སྦྱར་བ་ལ། དུའི་མཇུག་ཏུ་དེ་འབྱུང་བ་དང༌། དེའི་མཇུག་ཏུ་དུ་འབྱུང་བའོ། །
Enumeration Block 24:
གསུམ་པ་ལུང་མ་བསྟན་ལ་སྦྱར་བ་ལ། བསྒྲིབས་ལ་ལུང་མ་བསྟན་དང༌། མ་བསྒྲིབས་ལ་ལུང་མ་བསྟན་ནོ། །
Enumeration Block 25:
གཉིས་པ་མ་བསྒྲིབས་ལུང་མ་བསྟན་ལ་སྦྱར་བ་ལ། དུ་ལས་དེ་འབྱུང་བ་དང༌། དེ་ལས་དུ་འབྱུང་བའོ། །
