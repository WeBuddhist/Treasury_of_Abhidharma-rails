Enumeration Block 1:
བཞི་པ་དེ་མ་ཐག་རྐྱེན་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། སེམས་བཅུ་གཉིས་སུ་དབྱེ་བ། བཅུ་གཉིས་པོ་གང་ལས་གང་རྙེད་པ། སེམས་ཉི་ཤུར་དབྱེ་བ། སེམས་ཉོན་མོངས་ཅན་གྱི་རྙེད་ཚུལ་ལོ། །
Enumeration Block 2:
གཉིས་པ་བཅུ་གཉིས་པོ་གང་ལས་གང་རྙེད་པ་ལ། འདོད་སེམས་ལ་སྦྱར་བ། གཟུགས་ཀྱི། གཟུགས་མེད་ཀྱི། སློབ་པའི། མི་སློབ་པའི་སེམས་ལ་སྦྱར་བའོ། །དང་པོ་ལ། དགེ་སེམས་ལ། མི་དགེ་བའི་སེམས་ལ། ལུང་མ་བསྟན་གྱི་སེམས་ལ་སྦྱར་བའོ། །དང་པོ་ལ། དགེ་སེམས་ཀྱི་མཇུག་ཐོགས་སུ་སེམས་དུ་འབྱུང་བ་དང༌། སེམས་དུའི་མཇུག་ཐོགས་སུ་དགེ་སེམས་འབྱུང་བའོ། །
Enumeration Block 3:
གཉིས་པ་མི་དགེ་བའི་སེམས་ལ་སྦྱར་བ་ལ། དུའི་མཇུག་ཏུ་དེ་འབྱུང་བ་དང༌། དེའི་མཇུག་ཏུ་དུ་འབྱུང་བའོ། །
Enumeration Block 4:
གསུམ་པ་ལུང་མ་བསྟན་ལ་སྦྱར་བ་ལ། བསྒྲིབས་ལ་ལུང་མ་བསྟན་དང༌། མ་བསྒྲིབས་ལ་ལུང་མ་བསྟན་ནོ། །
Enumeration Block 5:
གཉིས་པ་མ་བསྒྲིབས་ལུང་མ་བསྟན་ལ་སྦྱར་བ་ལ། དུ་ལས་དེ་འབྱུང་བ་དང༌། དེ་ལས་དུ་འབྱུང་བའོ། །
Enumeration Block 6:
གཉིས་པ་གཟུགས་ཀྱི་སེམས་ལ་སྦྱར་བ་ལ། དགེ་སེམས་དང༌། ལུང་མ་བསྟན་ཏོ། །དང་པོ་ལ། དེའི་མཇུག་ཐོགས་སུ་དུ་འབྱུང་བ་དང༌། དུའི་མཇུག་ཐོགས་སུ་དེ་འབྱུང་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལུང་མ་བསྟན་ལ་སྦྱར་བ་ལ་བསྒྲིབས་པ་དང༌། མ་བསྒྲིབས་པའོ། །དང་པོ་ལ་གཉིས་ཀྱི།
Enumeration Block 8:
གཉིས་པ་མ་བསྒྲིབས་པ་ལའང་གཉིས་ལས།
Enumeration Block 9:
གསུམ་པ་གཟུགས་མེད་ལ་སྦྱར་བ་ལ། མ་བསྒྲིབས་པ། དགེ་སེམས། བསྒྲིབས་པ་ལ་སྦྱར་བའོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས་ཀྱི།
Enumeration Block 11:
གསུམ་པ་བསྒྲིབས་པ་ལའང་གཉིས་ལས།
Enumeration Block 12:
བཞི་པ་སློབ་པའི་སེམས་ལ་སྦྱར་བ་ལ་གཉིས་ཀྱི།
Enumeration Block 13:
ལྔ་པ་མི་སློབ་པའི་སེམས་ལ་སྦྱར་བ་ལ་གཉིས་ཀྱི།
Enumeration Block 14:
བཞི་པ་སེམས་ཉོན་མོངས་ཅན་སོགས་ཀྱི་རྙེད་ཚུལ་ལ། སེམས་ཉོན་མོངས་ཅན་ལས་དུ་རྙེད་པ་དང༌། གཟུགས་ཀྱི་དགེ་བ་ལས་དུ་རྙེད་པ་དང༌། སློབ་པའི་སེམས་ལས་དུ་རྙེད་པ་དང༌། དེ་རྣམས་ཀྱི་ལྷག་མའི་སེམས་ལས་དུ་རྙེད་པའོ། །དང་པོ་ལ། འདོད་སེམས་ཉོན་མོངས་ཅན་ལས། གཟུགས་ཀྱི་དེ་ལས། གཟུགས་མེད་ཀྱི་དེ་ལས་དུ་རྙེད་པའོ། །
Enumeration Block 15:
གསུམ་པ་འཇིག་རྟེན་བསྟན་པའི་གནས་ཀྱི་དོན་ལ་གཉིས་ལས། དང་པོ་གནས་ཀྱི་གཞུང་བཤད་པ་ལ་གཉིས། སེམས་ཅན་གྱི་འཇིག་རྟེན་དང༌། སྣོད་ཀྱི་འཇིག་རྟེན་ནོ། །དང་པོ་ལ་ལྔ། སེམས་ཅན་སྐྱེ་བ་པོ་འགྲོ་བའི་དབྱེ་བ། སྐྱེ་ཚུལ་རྟེན་འབྲེལ་གྱི་རང་བཞིན། སྐྱེས་པ་གནས་པའི་རྐྱེན། གནས་པ་འཆི་འཕོ་བའི་སེམས། སེམས་ཅན་གྱི་ཚོགས་གསུམ་དུ་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ། ཁམས་གསུམ་དུ་དབྱེ་བ། འགྲོ་བ་ལྔར་དབྱེ་བ། སྐྱེ་གནས་བཞིར་དབྱེ་བའོ། །དང་པོ་ལ་གསུམ། འདོད་ཁམས། གཟུགས་ཁམས། གཟུགས་མེད་ཁམས་ཀྱི་དབྱེ་བའོ། །དང་པོ་ལ། སྤྱིར་དབྱེ་བ་དང༌། བྱེ་བྲག་ཏུ་དབྱེ་བའོ། །
Enumeration Block 16:
གཉིས་པ་གཟུགས་ཁམས་ཀྱི་དབྱེ་བ་ལ། སྤྱིར་དབྱེ་བ་དང༌། བྱེ་བྲག་ཏུ་དབྱེ་བའོ། །
Enumeration Block 17:
གཉིས་པ་བྱེ་བྲག་ཏུ་དབྱེ་བ་ལ། དང་པོ་གསུམ་གྱི་དབྱེ་བ་དང༌། བཞི་པའི་དབྱེ་བའོ། །
Enumeration Block 18:
གསུམ་པ་གཟུགས་མེད་ཀྱི་དབྱེ་བ་ལ། གནས་ཀྱི་སྒོ་ནས་དབྱེ་བ་མེད་པར་བསྟན། སྐྱེ་བའི་སྒོ་ནས་བཞིར་དབྱེ། སེམས་ཀྱི་རྒྱུད་འཇུག་ཚུལ་ལོ། །
Enumeration Block 19:
གཉིས་པ་འགྲོ་བ་ལྔར་དབྱེ་བ་ལ། དངོས་དང༌། ཁམས་ཀྱི་དམིགས་བསལ། དེ་ལས་འཕྲོས་པའི་དོན་ཏོ། །
Enumeration Block 20:
གསུམ་པ་འཕྲོས་དོན་ལ་བཞི། རྣམ་ཤེས་ཀྱི་གནས་པ་བདུན། སེམས་ཅན་གྱི་གནས་པ་དགུ། རྣམ་པར་ཤེས་པའི་གནས་པ་བཞི། བདུན་དང་བཞིའི་མུ་བཞི་དཔྱད་པའོ། །དང་པོ་ལ་གཉིས། དངོས་དང་དེ་མིན་པའོ། །
Enumeration Block 21:
གཉིས་པ་སེམས་ཅན་གྱི་གནས་པ་དགུ་ལ། དངོས་དང༌། དེ་མིན་པའོ། །
Enumeration Block 22:
གསུམ་པ་རྣམ་པར་ཤེས་པའི་གནས་པ་བཞི་ལ། དངོས་དང༌། དེ་མིན་པའོ། །
Enumeration Block 23:
གསུམ་པ་སྐྱེ་གནས་བཞིར་དབྱེ་བ་ལ། གང་དུ་འཇུག་པ་སྐྱེ་གནས་ཀྱི་དབྱེ་བ། གང་གིས་འཇུག་པའི་བར་སྲིད་བཤད་པ། དེས་སྐྱེ་གནས་སུ་བགྲོད་པའི་ཚུལ་ལོ། །དང་པོ་ལ། དབྱེ་བ་དངོས་དང༌། འགྲོ་བ་གང་ལ་སྐྱེ་གནས་གང་ལྡན་དཔྱད་པའོ། །
Enumeration Block 24:
གཉིས་པ་འགྲོ་བ་གང་ལ་སྐྱེ་གནས་གང་ལྡན་དཔྱད་པ་ལ་གསུམ། མི་དང་དུད་འགྲོ་ལ་གང་ལྡན་པ། དམྱལ་བ་དང་ལྷ་སོགས་ལ་གང་ལྡན་པ། ཡི་དྭགས་ལ་གང་ལྡན་པའོ། །
Enumeration Block 25:
གཉིས་པ་གང་གིས་འཇུག་པའི་བར་སྲིད་བཤད་པ་ལ། ངོ་བོ་སྒྲུབ་བྱེད་དང་བཅས་པ་དང༌། ཤ་ཚུགས་སོགས་ཀྱི་ཁྱད་པར་རོ། །དང་པོ་ལ། ངོ་བོ། དོགས་གཅོད། སྒྲུབ་བྱེད་དོ། །
