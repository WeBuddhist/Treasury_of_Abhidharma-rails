Enumeration Block 1:
གསུམ་པ་རྣམ་པར་ཤེས་པའི་གནས་པ་བཞི་ལ། དངོས་དང༌། དེ་མིན་པའོ། །
Enumeration Block 2:
གསུམ་པ་སྐྱེ་གནས་བཞིར་དབྱེ་བ་ལ། གང་དུ་འཇུག་པ་སྐྱེ་གནས་ཀྱི་དབྱེ་བ། གང་གིས་འཇུག་པའི་བར་སྲིད་བཤད་པ། དེས་སྐྱེ་གནས་སུ་བགྲོད་པའི་ཚུལ་ལོ། །དང་པོ་ལ། དབྱེ་བ་དངོས་དང༌། འགྲོ་བ་གང་ལ་སྐྱེ་གནས་གང་ལྡན་དཔྱད་པའོ། །
Enumeration Block 3:
གཉིས་པ་འགྲོ་བ་གང་ལ་སྐྱེ་གནས་གང་ལྡན་དཔྱད་པ་ལ་གསུམ། མི་དང་དུད་འགྲོ་ལ་གང་ལྡན་པ། དམྱལ་བ་དང་ལྷ་སོགས་ལ་གང་ལྡན་པ། ཡི་དྭགས་ལ་གང་ལྡན་པའོ། །
Enumeration Block 4:
གཉིས་པ་གང་གིས་འཇུག་པའི་བར་སྲིད་བཤད་པ་ལ། ངོ་བོ་སྒྲུབ་བྱེད་དང་བཅས་པ་དང༌། ཤ་ཚུགས་སོགས་ཀྱི་ཁྱད་པར་རོ། །དང་པོ་ལ། ངོ་བོ། དོགས་གཅོད། སྒྲུབ་བྱེད་དོ། །
Enumeration Block 5:
གསུམ་པ་སྒྲུབ་བྱེད་ལ། རིགས་པས་སྒྲུབ་པ། ལུང་གིས་སྒྲུབ་པའོ། །དང་པོ་ལ། སྒྲུབ་བྱེད་དངོས། དཔེ་མི་འཐད་པར་བསྟན་པ། དེའི་གཏན་ཚིགས་སྒྲུབ་པའོ། །
Enumeration Block 6:
གསུམ་པ་དེའི་གཏན་ཚིགས་སྒྲུབ་པ་ལ། ཐོགས་བཅས་ཀྱི་གཟུགས་སུ་མ་གྲུབ་པའི་སྒྲུབ་བྱེད། དཔེ་དོན་མི་འདྲ་བའི་སྒྲུབ་བྱེད་དོ། །
Enumeration Block 7:
གཉིས་པ་ཤ་ཚུགས་སོགས་ཀྱི་ཁྱད་པར་ལ། ཤ་ཚུགས་ཀྱི་ཁྱད་པར། རྫུ་འཕྲུལ་གྱི། དབང་པོའི། འགྲོ་ཚུལ་གྱི། ཟས་ཀྱི་ཁྱད་པར་རོ། །དང་པོ་ལ། དངོས་དང༌། སྔུན་དུས་ཀྱི་ངོས་འཛིན། གང་གིས་མཐོང་བའོ། །
Enumeration Block 8:
གསུམ་པ་དེས་སྐྱེ་གནས་སུ་འགྲོ་བའི་ཚུལ་ལ་གསུམ། བསམ་པ་གང་གིས་འཇུག་པ། དབྱིབས་གང་གིས་འཇུག་པ། བསམ་པའི་ཁྱད་པར་གཞན་བཤད་པའོ། །དང་པོ་ལ་གསུམ། སྐྱེ་གནས་དང་པོ་གཉིས་ཀྱི་བསམ་པ། དྲོད་གཤེར་སྐྱེས་ཀྱི་བསམ་པ། རྫུས་སྐྱེས་ཀྱི་བསམ་པའོ། །
Enumeration Block 9:
གསུམ་པ་བསམ་པའི་ཁྱད་པར་གཞན་བཤད་པ་ལ། འཁོར་ལོས་བསྒྱུར་བའི། རང་རྒྱལ་གྱི། བྱང་སེམས་ཀྱི། ཐ་མལ་པའི། སྒོང་སྐྱེས་ཀྱི་ཁྱད་པར། སྔ་མ་གསུམ་གྱི་རྒྱུ་མཚན་བཤད་པའོ། །
Enumeration Block 10:
གཉིས་པ་སྐྱེ་ཚུལ་རྟེན་འབྲེལ་གྱི་རང་བཞིན་ལ། ཕུང་པོ་ཉིང་མཚམས་སྦྱོར་ཚུལ། ཕུང་པོའི་རྒྱུན་ཐོག་མ་མེད་པ། རྟེན་འབྲེལ་གྱི་རང་བཞིན་གཏན་ལ་དབབ་པའོ། །
