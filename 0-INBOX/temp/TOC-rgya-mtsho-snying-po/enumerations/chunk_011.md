Enumeration Block 1:
གཉིས་པ་དམྱལ་བའི་གནས་བཤད་པ་ལ། ཚ་དམྱལ་ཉེ་འཁོར་དང་བཅས་པ། གྲང་དམྱལ་གྱི་གནས་བཤད་པའོ། །དང་པོ་ལ། མནར་མེད། རབ་ཚ་སོགས་བདུན། ཉེ་འཁོར་བཤད་པའོ། །
Enumeration Block 2:
གསུམ་པ་ཉེ་འཁོར་བ་ལ། ཉེ་འཁོར་བའི་གྲངས། ཕྱོགས་གང་ན་ཡོད་པ། སྡེ་ཚན་གྱི་མིང་ངོ༌། །
Enumeration Block 3:
གསུམ་པ་ལྷའི་གནས་བཤད་པ་ལ། དངོས་དང༌། ཞར་ལ་དེའི་སེམས་ཅན་གྱི་ཁྱད་པར་རོ། །དང་པོ་ལ་གཉིས། ས་དང་འབྲེལ་བ་དང༌། མ་འབྲེལ་བའོ། །དང་པོ་ལ། རྒྱལ་ཆེན་རིགས་བཞི་པ་དང༌། སུམ་ཅུ་རྩ་གསུམ་པའི་གནས་སོ། །དང་པོ་ལ། གཞལ་མེད་ཁང༌། རི་ལ་བརྟེན་པའོ། །དང་པོ་ལ་ཉི་ཟླའི་ཐག་ཚད། བྱ་བ་བྱེད་ཚུལ། དེ་ལ་བརྟེན་པའི་དུས་ཀྱི་ཁྱད་པར། ཟླ་བ་འཕེལ་འགྲིབ་ཀྱི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ། ཉི་ཟླ་མཐོ་དམན་གྱི་ཚད། ཉི་ཟླའི་རྒྱ་ཁྱོན་གྱི་ཚད་དོ། །
Enumeration Block 4:
གསུམ་པ་དེ་ལ་བརྟེན་པའི་དུས་ཚིགས་ལ། ཉིན་མཚན་རིང་ཐུང་དུ་འགྱུར་བའི་དུས། རིང་ཐུང་གི་ཚད། ཉི་མ་ཟློག་པའི་དུས་སོ། །
Enumeration Block 5:
གཉིས་པ་རི་ལ་བརྟེན་པའི་གནས་ལ། རྟེན་རི་རབ་ཀྱི་བང་རིམ་བཤད་པ་དང༌། ལྷ་གང་བརྟེན་བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལྷ་གང་བརྟེན་བཤད་པ་ལ། རི་རབ་ལ་གང་བརྟེན་པ་དང༌། གསེར་གྱི་རི་བདུན་ལ་གང་བརྟེན་པའོ། །
Enumeration Block 7:
གཉིས་པ་སུམ་ཅུ་རྩ་གསུམ་གྱི་གནས་བཤད་པ་ལ། སྤྱིར་བསྟན་པ། ལག་ན་རྡོ་རྗེའི་རིགས་ཀྱི་གནས་བཤད་པ། སུམ་ཅུ་རྩ་གསུམ་པའི་གནས་ཀྱི་རྒྱས་བཤད་དོ། །
Enumeration Block 8:
གསུམ་པ་སུམ་ཅུ་རྩ་གསུམ་གྱི་གནས་རྒྱས་པར་བཤད་པ་ལ་གྲོང་ཁྱེར་དང༌། སྐྱེད་མོས་ཚལ་ལོ། །དང་པོ་ལ། གྲོང་ཁྱེར་སྤྱི་དང༌། དབང་པོའི་ཕོ་བྲང་ངོ༌། །
Enumeration Block 9:
གཉིས་པ་སྐྱེད་ཚལ་བཤད་པ་ལ། སྐྱེད་ཚལ་དངོས། ས་གཞི། ལྗོན་ཤིང༌། འདུན་སའོ། །
Enumeration Block 10:
གཉིས་པ་ཞར་ལ་དེའི་སེམས་ཅན་གྱི་ཁྱད་པར་བཤད་པ་ལ། འདོད་པ་སྤྱོད་པ། ལྷའི་བུ་སྐྱེ་བ། འདོད་བདེ་སྐྱེ་བ། གོང་འོག་གི་བར་ཐག་གི་ཚད། གོང་མར་བགྲོད་ཚུལ་ལོ། །
Enumeration Block 11:
གཉིས་པ་ལྷའི་བུ་སྐྱེ་བ་ལ། འདོད་ལྷའི་བུ་དང༌། གཟུགས་ཀྱི་བུའོ། །
Enumeration Block 12:
གསུམ་པ་འདོད་བདེ་སྐྱེ་བ་ལ། དངོས་དང༌། ཞར་ལ་གཟུགས་བདེ་སྐྱེ་བའོ། །
Enumeration Block 13:
གསུམ་པ་སྟོང་གསུམ་ངོས་བཟུང་བ་ལ། སྟོང་སྤྱི་ཕུད། སྟོང་གཉིས་བར་མ། སྟོང་གསུམ་སྟོང་ཆེན་ངོས་བཟུང་བའོ། །
Enumeration Block 14:
གཉིས་པ་ཞར་ལ་སེམས་ཅན་གྱི་ཚད་བཤད་པ་ལ། ལུས་ཚད་དང༌། ཚེ་ཚད་དོ། །དང་པོ་ལ། མིའི་ལུས་ཚད། འདོད་ལྷའི་ལུས་ཚད། གཟུགས་ཁམས་པའི་ལུས་ཚད་དོ། །དང་པོ་ལ། འཛམ་བུ་གླིང་པ་དང༌། གླིང་གཞན་གསུམ་གྱི་ལུས་ཚད་དོ། །
Enumeration Block 15:
གཉིས་པ་ཚེ་ཚད་ལ། དངོས་དང༌། བར་དུ་འཆི་བ་ཡོད་མེད་དཔྱད་པའོ། །དང་པོ་ལ། བདེ་འགྲོ་དང༌། ངན་འགྲོའི་ཚེ་ཚད་དོ། །དང་པོ་ལ། མིའི། འདོད་ལྷའི། ཁམས་གོང་གི་ཚེ་ཚད་དོ། །དང་པོ་ལ། གླིང་གཞན་གསུམ་དང༌། འཛམ་བུ་གླིང་པའི་ཚེ་ཚད་དོ། །
Enumeration Block 16:
གཉིས་པ་འདོད་ལྷའི་ཚེ་ཚད་ལ། རྒྱལ་ཆེན་རིགས་བཞི་པ་དང༌། གཞན་ལྔའི་ཚེ་ཚད་དོ། །
Enumeration Block 17:
གསུམ་པ་ཁམས་གོང་གི་ལྷའི་ཚེ་ཚད་ལ། གཟུགས་ཁམས་པའི། གཟུགས་མེད་ཁམས་པའི། འཕྲོས་དོན་བསྐལ་པ་རིང་ཐུང་ལ་དཔྱད་པའོ། །
