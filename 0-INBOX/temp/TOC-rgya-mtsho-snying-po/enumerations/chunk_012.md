Enumeration Block 1:
གཉིས་པ་ཚེ་ཚད་ལ། དངོས་དང༌། བར་དུ་འཆི་བ་ཡོད་མེད་དཔྱད་པའོ། །དང་པོ་ལ། བདེ་འགྲོ་དང༌། ངན་འགྲོའི་ཚེ་ཚད་དོ། །དང་པོ་ལ། མིའི། འདོད་ལྷའི། ཁམས་གོང་གི་ཚེ་ཚད་དོ། །དང་པོ་ལ། གླིང་གཞན་གསུམ་དང༌། འཛམ་བུ་གླིང་པའི་ཚེ་ཚད་དོ། །
Enumeration Block 2:
གཉིས་པ་འདོད་ལྷའི་ཚེ་ཚད་ལ། རྒྱལ་ཆེན་རིགས་བཞི་པ་དང༌། གཞན་ལྔའི་ཚེ་ཚད་དོ། །
Enumeration Block 3:
གསུམ་པ་ཁམས་གོང་གི་ལྷའི་ཚེ་ཚད་ལ། གཟུགས་ཁམས་པའི། གཟུགས་མེད་ཁམས་པའི། འཕྲོས་དོན་བསྐལ་པ་རིང་ཐུང་ལ་དཔྱད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ངན་འགྲོའི་ཚེ་ཚད་ལ། ཚ་དམྱལ་གྱི། དུད་འགྲོའི། ཡི་དྭགས་ཀྱི། གྲང་དམྱལ་གྱི་ཚེ་ཚད་དོ། །དང་པོ་ལ། གོང་མ་དྲུག་གི ། རབ་ཏུ་ཚ་བའི། མནར་མེད་པའི་ཚེ་ཚད་དོ། །
Enumeration Block 5:
བཞི་པ་གྲང་དམྱལ་གྱི་ཚེ་ཚད་ལ། ཆུ་བུར་ཅན་གྱི་དང༌། གཞན་བདུན་གྱིའོ། །
Enumeration Block 6:
གསུམ་པ་དེ་དག་འཇལ་བྱེད་ཀྱི་ཚད་བཤད་པ་ལ། རྩོམ་ཚུལ་དང༌། བརྩམས་པའི་འཇལ་བྱེད་དོ། །
Enumeration Block 7:
གཉིས་པ་བརྩམས་པའི་འཇལ་བྱེད་ལ། ཡུལ་གྱི་ཚད་དང༌། དུས་ཀྱི་ཚད་དོ། །
Enumeration Block 8:
དང་པོ་ལ། ཕྲ་རབ་ནས་སོར་མོའི་བར་གྱི་འགྱུར། དེ་ནས་རྒྱང་གྲགས་ཀྱི་འགྱུར། འཇལ་བྱེད་དངོས་ཀྱི་དཔག་ཚད་ཀྱི་ཚད་དོ། །
Enumeration Block 9:
གཉིས་པ་རྒྱང་གྲགས་ཀྱི་འགྱུར་ལ། དངོས་དང༌། དགོན་པའོ། །
Enumeration Block 10:
གཉིས་པ་དུས་ཀྱི་ཚད་ལ། ལོའི་ཚད་དང༌། བསྐལ་པའི་ཚད་དོ། །དང་པོ་ལ། འཇལ་བྱེད་ཟླ་བའི་ཚད་དང༌། ལོ་དངོས་སོ། །
Enumeration Block 11:
གཉིས་པ་བསྐལ་པའི་ཚད་ལ། བསྐལ་པ་ངོས་བཟུང༌། ཡ་ཐོག་རིང་མོའི་འགྲིབ་ཚུལ། འཇིག་པའི་བསྐལ་པའི་ཚུལ་ལོ། །དང་པོ་ལ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 12:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། འཇིག་ཆགས་ཀྱི་བསྐལ་པ་བཤད་པ། གནས་པའི་བསྐལ་པ་བཤད། བསྐལ་ཆེན་བཤད་པའོ། །དང་པོ་ལ། འཇིག་པའི་བསྐལ་ཚུལ་དང༌། ཆགས་པའི་བསྐལ་ཚུལ་ལོ། །
Enumeration Block 13:
གཉིས་པ་གནས་པའི་བསྐལ་པ་བཤད་པ་ལ། བཤད་པ་དང༌། བསྡུ་བའོ། །དང་པོ་ལ། ཡ་ཐོག་རིང་མོ། །བར་ཁུག་བཅོ་བརྒྱད། མ་ཐོག་རིང་མོ། །ཡར་འཕེལ་བའི་ཚེ་ཚད་དོ། །
Enumeration Block 14:
གཉིས་པ་དོན་བསྡུ་བ་ལ། དངོས་དང༌། འཇིག་ཆགས་ཀྱང་དེ་དང་མཉམ་པར་བསྟན་པའོ། །
Enumeration Block 15:
གསུམ་པ་བསྐལ་ཆེན་བཤད་པ་ལ། དངོས་དང༌། ཞར་ལ་གང་ཟག་གསུམ་འབྱུང་ཚུལ་ལོ། །
Enumeration Block 16:
གཉིས་པ་ཞར་ལ་གང་ཟག་གསུམ་འབྱུང་ཚུལ་ལ། སངས་རྒྱས་འབྱུང་ཚུལ། རང་རྒྱལ་འབྱུང་ཚུལ། འཁོར་བསྒྱུར་འབྱུང་ཚུལ་ལོ། །དང་པོ་ལ། །སངས་རྒྱས་ཀྱི་རྒྱུ་དང༌། དེ་འབྱུང་བའི་དུས་སོ། །
Enumeration Block 17:
གཉིས་པ་རང་རྒྱལ་འབྱུང་བའི་ཚུལ་ལ། དེ་འབྱུང་བའི་དུས། དེའི་རྒྱུའོ། །
Enumeration Block 18:
གསུམ་པ་འཁོར་སྒྱུར་འབྱུང་ཚུལ་ལ། དེ་འབྱུང་བའི་དུས། རིགས་ཀྱི་དབྱེ་བ། ཡོན་ཏན་གྱི་ཁྱད་པར་རོ། །
Enumeration Block 19:
གཉིས་པ་རིགས་ཀྱི་དབྱེ་བ་ལ། དབྱེ་བ་དངོས་དང༌། གླིང་གང་ལ་དབང་བསྒྱུར་བ། འཕྲོས་པའི་དོན། རྒྱལ་བར་བྱེད་ཚུལ་ལོ། །
Enumeration Block 20:
གཉིས་པ་ཡ་ཐོག་རིང་མོའི་འགྲིབ་ཚུལ་ལ། བསྐལ་པ་དང་པོའི་ཁྱད་པར། ཇི་ལྟར་འགྲིབ་པའི་ཚུལ། འགྲིབ་པའི་མཐར་གང་འབྱུང་བའོ། །
Enumeration Block 21:
གཉིས་པ་ཇི་ལྟར་འགྲིབ་པའི་ཚུལ་ལ། གསུམ་ལྡན་བྱུང་ཚུལ། གཉིས་ལྡན་དང་རྩོད་དུས་བྱུང་བའི་ཚུལ། ཚེ་ལོ་བཅུ་པར་བྱུང་ཚུལ་ལོ། །
Enumeration Block 22:
གསུམ་པ་འགྲིབ་པའི་མཐར་གང་འབྱུང་བ་ལ། བསྐལ་ངན་གསུམ་འབྱུང་བར་བསྟན་པ་དང༌། དེ་གསུམ་གྱི་ཡུན་ནོ། །
Enumeration Block 23:
གསུམ་པ་འཇིག་པའི་བསྐལ་པའི་ཚུལ་ལ། བསམ་གཏན་གསུམ་པ་མན་འཇིག་ཚུལ། བཞི་པ་འཇིག་ཚུལ། མེ་ཆུ་རླུང་གསུམ་གྱིས་འཇིག་པའི་གྲངས་བསྟན་པའོ། །དང་པོ་ལ། གང་གིས་གང་འཇིག་པ། །མ་ཞིག་པར་ལུས་པའི་རྩེ་མོ། དེ་རྣམས་ཀྱི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 24:
གཉིས་པ་བསམ་གཏན་བཞི་པ་འཇིག་ཚུལ་ལ། མེ་ཆུ་རླུང་གསུམ་གྱིས་མི་འཇིག་པར་བསྟན་པ་དང༌། འཇིག་ཚུལ་དངོས་སོ། །
