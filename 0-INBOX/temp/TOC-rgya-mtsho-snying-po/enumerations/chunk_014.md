Enumeration Block 1:
གཉིས་པ་ལ། སྡོམ་པ་ཁྱད་པར་དུ་བཤད་པ་དང༌། ཐམས་ཅད་ཐུན་མོང་དུ་བསྟན་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། སོ་ཐར་རྒྱས་བཤད། བསམ་གཏན་ཟག་མེད་རྒྱས་བཤད། ཞར་ལས་བྱུང་བའི་དོན་ཏོ། །དང་པོ་ལ། བསྡུས་ཏེ་བསྟན་པ་དང༌། ཕྱེ་སྟེ་བཤད་པ་གཉིས་ལས། དང་པོ་ལ། མིང་གི་སྒོ་ནས་བརྒྱད་དུ་དབྱེ་བ། རྫས་ཀྱི་སྒོ་ནས་བཞིར་བསྡུ་བ། གནས་པའི་ཚུལ་ལོ། །
Enumeration Block 3:
གཉིས་པ་ཕྱེ་སྟེ་བཤད་པ་ལ། སོ་སོའི་ངོ་བོ། མིང་གི་རྣམ་གྲངས། སྒྲ་དོན། ལྡན་པའི་གང་ཟག་གོ །
Enumeration Block 4:
གཉིས་པ་བསམ་གཏན་དང་ཟག་མེད་ཀྱི་སྡོམ་པ་རྒྱས་བཤད་ལ། གང་ལ་ལྡན་པ། སེམས་ཀྱི་རྗེས་འབྲང་དུ་བསྟན་པ། སྤོང་བའི་སྡོམ་པར་བསྟན་པའོ། །
Enumeration Block 5:
གཉིས་པ་ཐམས་ཅད་ཐུན་མོང་དུ་བསྟན་པ་ལ། དུས་ཇི་སྲིད་ལྡན་པ། ཚུལ་ཇི་ལྟར་ཐོབ་པ། རྒྱུ་གང་གིས་གཏོང་བ། རྟེན་གང་དང་ལྡན་པའོ། །དང་པོ་ལ། རིག་བྱེད་མིན་པའི་ལྡན་ཚུལ། རིག་བྱེད་ཀྱི་ལྡན་ཚུལ། སྡོམ་མིན་གྱི་མིང་གི་རྣམ་གྲངས། དེ་དག་གི་མུ་བཞི་བཤད་པའོ། །དང་པོ་ལ་གསུམ། མཉམ་པར་མ་བཞག་པའི་དང༌། མཉམ་པར་བཞག་པའི་དང༌། བར་མའི་ལྡན་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། སྡོམ་པ་དང༌། སྡོམ་མིན་ནོ། །
Enumeration Block 6:
གསུམ་པ་བར་མ་ལྡན་ཚུལ་ལ་གཉིས། དངོས་དོན་དང༌། འཕྲོས་དོན་སྡོམ་སྡོམ་མིན་ཅན་ལ་ལྡན་ཚུལ་ལོ། །
Enumeration Block 7:
གཉིས་པ་ཚུལ་ཇི་ལྟར་ཐོབ་པ་ལ། སྡོམ་པའི་ཐོབ་ཚུལ་དང༌། སྡོམ་མིན་གྱི་དང༌། བར་མའི་ཐོབ་ཚུལ་ལོ། །དང་པོ་ལ། དངོས་དང༌། གང་ལས་ཐོབ་པའོ། །དང་པོ་ལ། བསམ་གཏན་གྱི་དང༌། ཟག་མེད་ཀྱི་དང༌། སོ་ཐར་སྡོམ་པའི་ཐོབ་ཚུལ་ལོ། །
Enumeration Block 8:
གསུམ་པ་སོ་ཐར་སྡོམ་པའི་ཐོབ་ཚུལ་ལ། སྤྱིར་བསྟན་པ། བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 9:
གཉིས་པ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། ལེན་པའི་དུས། སྡོམ་མིན་གྱི་དུས་ངེས་པ། བསྙེན་གནས་ཀྱི་ཁྱད་པར། དགེ་བསྙེན་གྱི་ཁྱད་པར་རོ། །
Enumeration Block 10:
གསུམ་པ་བསྙེན་གནས་ཀྱི་ཁྱད་པར་ལ། རྣམ་བཞག་སྤྱིར་བསྟན་པ། ཡན་ལག་བརྒྱད་ཀྱི་གྲངས་ངེས། སྐྱབས་འགྲོ་རྩོམ་བྱེད་དུ་དགོས་པའོ། །
Enumeration Block 11:
གཉིས་པ་ཡན་ལག་བརྒྱད་ཀྱི་གྲངས་ངེས་ལ། དངོས་དང༌། དོགས་གཅོད་དོ། །
Enumeration Block 12:
བཞི་པ་དགེ་བསྙེན་གྱི་ཁྱད་པར་ལ། ལུང་གི་དོན་བཤད་པ། མདོ་དང་འགལ་བ་སྤང་བ། སྡོམ་པ་ཆེ་ཆུང་གི་ཁྱད་པར། སྐྱབས་གནས་བཤད་པ། །ཡན་ལག་གི་ཁྱད་པར་རོ། །
Enumeration Block 13:
ལྔ་པ་ཡན་ལག་གི་ཁྱད་པར་ལ། ལོག་གཡེམ་ཡན་ལག་ཏུ་དང༌། རྫུན་ཡན་ལག་ཏུ་དང༌། མྱོས་འགྱུར་ཡན་ལག་ཏུ་འཇོག་པའི་དོན་ཏོ། །དང་པོ་ལ། དངོས་དང༌། དོགས་གཅོད་དོ། །
Enumeration Block 14:
གཉིས་པ་གང་ལས་ཐོབ་པ་ལ། སོ་སོར་བཤད་པ་དང༌། བསྡོམས་ནས་བཤད་པའོ། །དང་པོ་ལ། སོ་ཐར་གང་ལས་ཐོབ་པ། བསམ་གཏན་དང་ཟག་མེད་གང་ལས་ཐོབ་པའོ། །
Enumeration Block 15:
གཉིས་པ་སྡོམ་མིན་གྱི་ཐོབ་ཚུལ་ལ། གང་ལས་ཐོབ་པ་དང༌། ཇི་ལྟར་ཐོབ་པའོ། །
Enumeration Block 16:
གསུམ་པ་རྒྱུ་གང་གིས་གཏོང་བ་ལ། སྡོམ་པའི་གཏོང་རྒྱུ། སྡོམ་མིན་གྱི་གཏོང་རྒྱུ། བར་མའི་གཏོང་རྒྱུ། ཆོས་གཞན་གྱི་གཏོང་རྒྱུའོ། །དང་པོ་ལ་སོ་ཐར་དང༌། བསམ་གཏན་དང༌། ཟག་མེད་ཀྱི་གཏོང་རྒྱུའོ། །དང་པོ་ལ། སྤྱིར་བསྟན་པ་དང༌། འདོད་པ་མི་འདྲ་བ་བཀོད་པའོ། །
