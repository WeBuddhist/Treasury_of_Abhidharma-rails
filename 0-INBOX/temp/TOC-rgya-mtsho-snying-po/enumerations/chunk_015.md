Enumeration Block 1:
ལྔ་པ་ཡན་ལག་གི་ཁྱད་པར་ལ། ལོག་གཡེམ་ཡན་ལག་ཏུ་དང༌། རྫུན་ཡན་ལག་ཏུ་དང༌། མྱོས་འགྱུར་ཡན་ལག་ཏུ་འཇོག་པའི་དོན་ཏོ། །དང་པོ་ལ། དངོས་དང༌། དོགས་གཅོད་དོ། །
Enumeration Block 2:
གཉིས་པ་གང་ལས་ཐོབ་པ་ལ། སོ་སོར་བཤད་པ་དང༌། བསྡོམས་ནས་བཤད་པའོ། །དང་པོ་ལ། སོ་ཐར་གང་ལས་ཐོབ་པ། བསམ་གཏན་དང་ཟག་མེད་གང་ལས་ཐོབ་པའོ། །
Enumeration Block 3:
གཉིས་པ་སྡོམ་མིན་གྱི་ཐོབ་ཚུལ་ལ། གང་ལས་ཐོབ་པ་དང༌། ཇི་ལྟར་ཐོབ་པའོ། །
Enumeration Block 4:
གསུམ་པ་རྒྱུ་གང་གིས་གཏོང་བ་ལ། སྡོམ་པའི་གཏོང་རྒྱུ། སྡོམ་མིན་གྱི་གཏོང་རྒྱུ། བར་མའི་གཏོང་རྒྱུ། ཆོས་གཞན་གྱི་གཏོང་རྒྱུའོ། །དང་པོ་ལ་སོ་ཐར་དང༌། བསམ་གཏན་དང༌། ཟག་མེད་ཀྱི་གཏོང་རྒྱུའོ། །དང་པོ་ལ། སྤྱིར་བསྟན་པ་དང༌། འདོད་པ་མི་འདྲ་བ་བཀོད་པའོ། །
Enumeration Block 5:
གཉིས་པ་འདོད་པ་མི་འདྲ་བ་བཀོད་པ་ལ། རྩ་ལྟུང་གཏོང་རྒྱུར་འདོད་པ། དམ་ཆོས་ནུབ་པ་དེར་འདོད་པ། ཁ་ཆེ་བས་རྩ་ལྟུང་གཏོང་རྒྱུར་མི་འདོད་པའོ། །
Enumeration Block 6:
གཉིས་པ་བསམ་གཏན་གྱི་གཏོང་རྒྱུ་ལ། དངོས་དང༌། ཞར་བྱུང་ངོ༌། །
Enumeration Block 7:
བཞི་པ་ཆོས་གཞན་གྱི་གཏོང་རྒྱུ་ལ། གཟུགས་མིན་དགེ་བ་གཏོང་རྒྱུ། གཟུགས་མིན་ཉོན་མོངས་ཅན་གཏོང་རྒྱུའོ། །
Enumeration Block 8:
བཞི་པ་གང་ཟག་གང་ལ་ལྡན་ཚུལ་ལ། སྡོམ་མིན་ལྡན་ཚུལ་དང༌། སྡོམ་པ་ལྡན་ཚུལ་ལོ། །
Enumeration Block 9:
གཉིས་པ་ལ། སྤྱིར་བསྟན་པ་དང༌། རྟེན་གང་ལ་སྡོམ་པ་གང་ཡོད་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ། མི་དང༌། ལྷ་ལ་གང་ལྡན་པའོ། །
Enumeration Block 11:
གཉིས་པ་ལ། བསམ་གཏན་དང༌། ཟག་མེད་ལྷ་གང་ལ་ལྡན་པའོ། །
Enumeration Block 12:
གསུམ་པ་མདོ་ལས་འབྱུང་བའི་ལས་ཀྱི་དོན་ལ། ཐུན་མོང་དུ་བསྟན་པ། སོ་སོར་བཤད་པའོ། །དང་པོ་ལ། རྒྱུ་འབྲས་ཀྱི་སྒོ་ནས་དབྱེ་བ་དང༌། ལས་ཀྱི་རྣམ་གྲངས་དུ་མ་བསྟན་པ། ལས་གང་འབྲས་བུ་དུ་དང་བཅས་པ། ལས་ཀྱི་རྣམ་གཞག་གཞན་བསྟན་པའོ། །དང་པོ་ལ། འབྲས་བུའི་སྒོ་ནས་དབྱེ་བ། རྒྱུའི་སྒོ་ནས། གཉིས་ཀའི་སྒོ་ནས་དབྱེ་བའོ། །དང་པོ་ལ། དགེ་སོགས་གསུམ་དང༌། བསོད་ནམས་སོགས་གསུམ་དང༌། མྱོང་འགྱུར་གསུམ་དུ་དབྱེ་བ། ཕྱི་མ་གཉིས་ཀྱི་རྒྱས་བཤད་དོ། །
Enumeration Block 13:
བཞི་པ་ཕྱི་མ་གཉིས་ཀྱི་རྒྱས་བཤད་ལ། བསོད་ནམས་སོགས་རྒྱས་པར་བཤད། མྱོང་འགྱུར་གསུམ་ཞར་བྱུང་དང་བཅས་པའོ། །དང་པོ་ལ། བསོད་ནམས་ཀྱི་ལས། མི་གཡོ་བའི་ལས་སོ། །
Enumeration Block 14:
གཉིས་པ་མྱོང་འགྱུར་གསུམ་ཞར་བྱུང་དང་བཅས་ཏེ་བཤད་པ་ལ། མྱོང་འགྱུར་གསུམ་བཤད་པ་དངོས། ཞར་ལ་མྱོང་འགྱུར་ལྔ་བསྟན་པ། །མྱོང་འགྱུར་གྱི་ཁྱད་པར་གཏན་ལ་དབབ་པའོ། །དང་པོ་ལ། སོ་སོའི་ངོ་བོ། གཞན་འདོད་འགོད་པའོ། །དང་པོ་ལ། བདེ་བ་མྱོང་འགྱུར། བཏང་སྙོམས་མྱོང་འགྱུར། སྡུག་བསྔལ་མྱོང་འགྱུར་རོ། །
Enumeration Block 15:
གསུམ་པ་མྱོང་འགྱུར་གྱི་ཁྱད་པར་གཏན་ལ་དབབ་པ་ལ། བསྟན། བཤད་དོ། །
Enumeration Block 16:
གཉིས་པ་ལ། དབྱེ་བ་སྤྱིར་བསྟན་པ་དང༌། སོ་སོའི་ཁྱད་པར། མྱོང་ངེས་ཀྱི་ལས་བསྟན་པའོ། །དང་པོ་ལ། རང་ལུགས་དང༌། གཞན་ལུགས་སོ། །
Enumeration Block 17:
གཉིས་པ་ལ། ལྔར་འདོད་པའི་ལུགས། མུ་བཞི་བརྩི་བའི་ལུགས་སོ། །
Enumeration Block 18:
གཉིས་པ་སོ་སོའི་ཁྱད་པར་ལ། ལས་གང་གིས་རིས་མཐུན་འཕེན་པ། ཁམས་དང་འགྲོ་བ་གང་ན་ལས་འཕེན་དུ་ཡོད་པའོ། །
Enumeration Block 19:
གཉིས་པ་ལ། སྤྱིར་བཏང་བ་དང༌། དམིགས་ཀྱིས་བསལ་བའོ། །
Enumeration Block 20:
གཉིས་པ་ལ། སྐྱེ་སྲིད་ལ་དང༌། བར་སྲིད་ལ་ལས་འཕེན་དུ་ཡོད་པའོ། །དང་པོ་ལ། དམྱལ་བའི་སྐྱེ་སྲིད་ལ་དུ་ཡོད་པ་དང༌། སོ་སྐྱེ་ཁྱད་པར་བའི་སྐྱེ་སྲིད་ལ་དང༌། འཕགས་པའི་སྐྱེ་སྲིད་ལ་དུ་ཡོད་པའོ། །
Enumeration Block 21:
གཉིས་པ་བར་སྲིད་ལ་ལས་འཕེན་དུ་ཡོད་པ་ལ། དབྱེ་བ། ངེས་པ་བཅུ་གཅིག་མཐོང་ཆོས་སུ་སྒྲུབ་པའོ། །
Enumeration Block 22:
གསུམ་པ་མྱོང་ངེས་ཀྱི་ལས་བསྟན་པ་ལ། སྤྱིར་བཤད་པ། མཐོང་ཆོས་བྱེ་བྲག་ཏུ་བཤད་པ། ལས་འབྲས་མྱོང་ཚུལ་གཞན་བསྟན་པའོ། །
Enumeration Block 23:
གཉིས་པ་ལ། ལས་ཀྱི་ནུས་པ་དང༌། གཉེན་པོའི་ནུས་པས་མཐོང་ཆོས་སུ་ངེས་པ་དང༌། ཞིང་གི་ཁྱད་པར་རོ། །
Enumeration Block 24:
གསུམ་པ་ལས་འབྲས་མྱོང་ཚུལ་གཞན་བསྟན་པ་ལ། ཚོར་བ་མྱོང་ཚུལ། གཡེངས་པའི་སེམས་གང་ལ་གནས་པ། དེ་རྒྱུ་ཅི་ལས་གྱུར་པ། དེ་འགྲོ་བ་གང་ན་ཡོད་པའོ། །
Enumeration Block 25:
གསུམ་པ་རྒྱུ་འབྲས་གཉིས་ཀའི་སྒོ་ནས་དབྱེ་བ་ལ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 26:
གཉིས་པ་ལ། སྤྱིར་བསྟན་པ་དང༌། ཟད་བྱེད་བྱེ་བྲག་ཏུ་བཤད་པ། གཞན་ལུགས་འགོད་པའོ། །
Enumeration Block 27:
གཉིས་པ་ལ་གསུམ། ནག་པོ་ཟད་བྱེད་དང༌། དཀར་གནག་གཉིས་ཀ་དང༌། དཀར་པོ་ཟད་བྱེད་དོ། །
