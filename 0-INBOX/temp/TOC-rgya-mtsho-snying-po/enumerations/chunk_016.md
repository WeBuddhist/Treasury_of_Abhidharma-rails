Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། ནག་པོ་ཟད་བྱེད་དང༌། དཀར་གནག་གཉིས་ཀ་དང༌། དཀར་པོ་ཟད་བྱེད་དོ། །
Enumeration Block 2:
གཉིས་པ་ལས་ལམ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། བསྟན། བཤད་གཉིས་ཀྱི།
Enumeration Block 3:
གསུམ་པ་རྫོགས་བྱེད་གསུམ་བསྟན་པ་ལ། དངོས་དང༌། གཞི་གང་ཡིན་པ། དངོས་གཞིར་འགྱུར་བའི་ཚད་དོ། །དང་པོ་ལ། ཞེ་སྡང་གིས་རྫོགས་པ་གསུམ། འདོད་ཆགས་ཀྱིས་རྫོགས་པ་གསུམ། གཏི་མུག་གིས་རྫོགས་པ་གཅིག གསུམ་ཀས་རྫོགས་པ་གསུམ་མོ། །
Enumeration Block 4:
བཞི་པ་ལས་སོ་སོར་བསྟན་པ་ལ། ལས་སོ་སོའི་མཚན་ཉིད། སེམས་པ་གང་དང་ལྷན་ཅིག་ཏུ་འཇུག་པ། འགྲོ་བ་གང་ན་ལས་ལམ་དུ་ཡོད་པ། ལས་ལམ་གྱི་འབྲས་བུ་བསྟན་པའོ། །དང་པོ་ལ། སོ་སོར་ངོས་བཟུང་བ་དང༌། ལོག་ལྟ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ། ལུས་ཀྱི་ལས། ངག་གི་ལས། ཡིད་ཀྱི་ལས། ལས་དང་ལས་ལམ་གྱི་བྱེ་བྲག་གོ ། དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 5:
གཉིས་པ་ངག་གི་ལས་ལ་བཞི་ལས། དང་པོ་རྫུན་ལ། དངོས་དང༌། མཐོང་ཐོས་སོགས་ཀྱི་དོན་ཏོ། །
Enumeration Block 6:
གསུམ་པ་ཡིད་ཀྱི་ལས་ལ་གསུམ་ལས།
