Enumeration Block 1:
གཉིས་པ་བྱེ་བྲག་ཏུ་སྟོན་པས་མཛད་ཚུལ་ལ། ཚོགས་བསགས་ཚུལ་དང༌། ཕར་ཕྱིན་རྫོགས་ཚུལ་ལོ། །
Enumeration Block 2:
གཉིས་པ་ལ། སྦྱིན་པའི་ཕར་ཕྱིན་རྫོགས་ཚུལ། ཚུལ་ཁྲིམས་དང་བཟོད་པའི། བརྩོན་འགྲུས་ཀྱི། བསམ་གཏན་དང་ཤེས་རབ་ཀྱི་ཕར་ཕྱིན་རྫོགས་ཚུལ་ལོ། །
Enumeration Block 3:
གཉིས་པ་བསྟེན་བྱ་བསོད་ནམས་བྱ་བའི་གཞི་གསུམ་བཤད་པ་ལ། ཐུན་མོང་གི་ངེས་ཚིག དབྱེ་བ་སོ་སོའི་རང་བཞིན། ཆོས་སྦྱིན་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་དབྱེ་བ་སོ་སོའི་རང་བཞིན་ལ། སྦྱིན་པ་ལས་བྱུང་བ་བཤད། གཞན་གཉིས་བཤད་པའོ། །དང་པོ་ལ། སྦྱིན་པའི་ངོ་བོ། །དབྱེ་བ། ཁྱད་པར་རོ། །དང་པོ་ལ། དངོས་དང༌། དེའི་འབྲས་བུའོ། །
Enumeration Block 5:
གསུམ་པ་ཁྱད་པར་ལ། བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 6:
གཉིས་པ་རྒྱས་བཤད་ལ། སྦྱིན་བདག་གི་ཁྱད་པར། སྦྱིན་བྱའི་ཁྱད་པར། ཞིང་གི་ཁྱད་པར། སྦྱིན་པ་ཁྱད་པར་ཅན་ངོས་བཟུང་བ། འཕྲོས་པའི་དོན་ཏོ། །དང་པོ་ལ། དངོས་དང༌། སྦྱིན་ཚུལ་གྱི་ཁྱད་པར། དེའི་འབྲས་བུའོ། །
Enumeration Block 7:
གཉིས་པ་སྦྱིན་བྱའི་ཁྱད་པར་ལ། དངོས་དང༌། དེའི་འབྲས་བུའོ། །
Enumeration Block 8:
བཞི་པ་སྦྱིན་པ་ཁྱད་པར་ཅན་ངོས་བཟུང་བ་ལ། མཆོག་གི་སྦྱིན་པ་དང༌། གཞལ་དུ་མེད་པའི་སྦྱིན་པའོ། །དང་པོ་ལ། དངོས་དང༌། སྦྱིན་པ་བརྒྱད་ཀྱི་ནང་ནས་མཆོག་ངོས་བཟུང་བའོ། །
Enumeration Block 9:
ལྔ་པ་འཕྲོས་དོན་ལ། ཆེ་ཆུང་གི་ཁྱད་པར། བསགས་མ་བསགས་ཀྱི་ཁྱད་པར། དོགས་གཅོད་དོ། །
Enumeration Block 10:
གཉིས་པ་གཞན་གཉིས་བཤད་པ་ལ། སོ་སོའི་རང་བཞིན་དང༌། གཉིས་ཀའི་འབྲས་བུ། ཞར་བྱུང་ཚངས་པའི་བསོད་ནམས་བཞི་བཤད་པའོ། །དང་པོ་ལ། ཚུལ་ཁྲིམས་ལས་བྱུང་བ་དང༌། སྒོམ་པ་ལས་བྱུང་བའོ། །དང་པོ་ལ། སྤང་བྱ་ངོས་བཟུང་བ། དེའི་གཉེན་པོ་ཚུལ་ཁྲིམས། དེ་དག་པའི་ཡོན་ཏན་ནོ། །
Enumeration Block 11:
གསུམ་པ་ཆོས་ཀྱི་རྣམ་གྲངས་བསྟན་པས་མཇུག་བསྡུ་བ་ལ། འཇིག་རྟེན་པའི་ལས་གསུམ་གྱི་རྣམ་གྲངས། ཉོན་མོངས་ཅན་གྱི་རྣམ་གྲངས། དགེ་བའི་རྣམ་གྲངས་སོ། །
Enumeration Block 12:
ལྔ་པ་ཕྲ་རྒྱས་བསྟན་པའི་གནས་ཀྱི་དོན་ལ། གནས་ཀྱི་གཞུང་དང༌། གནས་ཀྱི་མཚན་ནོ། །དང་པོ་ལ། ཕྲ་རྒྱས་ཀྱི་རང་བཞིན། གང་གིས་སྤོང་བ། སྤངས་པའི་འབྲས་བུའོ། །དང་པོ་ལ། སྲིད་པའི་རྩ་བ་ཕྲ་རྒྱས་སུ་བསྟན་པ། དེ་གཏན་ལ་དབབ་པའོ། །
