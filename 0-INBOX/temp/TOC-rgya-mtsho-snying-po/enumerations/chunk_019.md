Enumeration Block 1:
ལྔ་པ་ཕྲ་རྒྱས་བསྟན་པའི་གནས་ཀྱི་དོན་ལ། གནས་ཀྱི་གཞུང་དང༌། གནས་ཀྱི་མཚན་ནོ། །དང་པོ་ལ། ཕྲ་རྒྱས་ཀྱི་རང་བཞིན། གང་གིས་སྤོང་བ། སྤངས་པའི་འབྲས་བུའོ། །དང་པོ་ལ། སྲིད་པའི་རྩ་བ་ཕྲ་རྒྱས་སུ་བསྟན་པ། དེ་གཏན་ལ་དབབ་པའོ། །
Enumeration Block 2:
གཉིས་པ་དེ་གཏན་ལ་དབབ་པ་ལ། དབྱེ་བ། སྐྱེ་ཚུལ། རྣམ་གྲངས་སོ། །དང་པོ་ལ། ངོ་བོའི་དབྱེ་བ། རྣམ་པའི་དབྱེ་བ། ཕྲ་རྒྱས་དང་བཅས་པའི་དབྱེ་བའོ། །དང་པོ་ལ། སྤྱིར་དབྱེ་བ་དང༌། ལྟ་བ་དང་ང་རྒྱལ་བྱེ་བྲག་ཏུ་དབྱེ་བའོ། །དང་པོ་ལ། དྲུག་ཏུ་དབྱེ་བ། བདུན་དུ་དབྱེ་བ། བཅུར་དབྱེ་བ། དགུ་བཅུ་རྩ་བརྒྱད་དུ་དབྱེ་བའོ། །
Enumeration Block 3:
གཉིས་པ་བདུན་དུ་དབྱེ་བ་ལ། དབྱེ་བ་དངོས། སྲིད་པའི་འདོད་ཆགས་ངོས་བཟུང་བའོ། །
Enumeration Block 4:
བཞི་པ་དགུ་བཅུ་རྩ་བརྒྱད་དུ་དབྱེ་བ་ལ། དངོས་དང༌། ཞར་བྱུང་ངོ༌། །དང་པོ་ལ། འདོད་པའི་སས་བསྡུས་སོ་དྲུག་བཤད་པ། ཁམས་གོང་གི་སས་བསྡུས་རེ་གཉིས་བཤད་པ། མཇུག་བསྡུ་བའོ། །དང་པོ་ལ། མཐོང་སྤང་སོ་གཉིས་དང༌། སྒོམ་སྤང་བཞི་བཤད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལྟ་བ་དང་ང་རྒྱལ་བྱེ་བྲག་ཏུ་དབྱེ་བ་ལ། ལྟ་བའི་དབྱེ་བ་དང༌། ང་རྒྱལ་གྱི་དབྱེ་བའོ། །དང་པོ་ལ། ལྟ་བ་ལྔ་པོ་སོ་སོའི་རང་བཞིན། ལྔ་པ་ཀུན་འབྱུང་མཐོང་སྤང་མ་ཡིན་པའི་རྒྱུ་མཚན། ཕྱིན་ཅི་ལོག་བཞིར་དབྱེ་བའོ། །
Enumeration Block 6:
གསུམ་པ་ཕྱིན་ཅི་ལོག་བཞིར་དབྱེ་བ་ལ། དངོས་དང༌། ཞར་བྱུང་གཉིས་ལས།
Enumeration Block 7:
གཉིས་པ་ང་རྒྱལ་གྱི་དབྱེ་བ་ལ། དབྱེ་བ་དངོས། དེ་གཉེན་པོ་གང་གིས་སྤོང་བ། མ་སྤངས་ཀྱང་འཕགས་རྒྱུད་ལ་མངོན་དུ་མི་འགྱུར་བའི་སྒོམ་སྤང་བཤད་པའོ། །
Enumeration Block 8:
གཉིས་པ་རྣམ་པའི་དབྱེ་བ་ལ། ཀུན་འགྲོ་ཡིན་མིན་གྱི་དབྱེ་བ། ཟག་མེད་ལ་དམིགས་པ་དང་མ་དམིགས་པའི་བྱེ་བྲག དམིགས་པ་དང་མཚུངས་ལྡན་གྱིས་རྒྱས་འགྱུར། མི་དགེ་བ་དང་ལུང་མ་བསྟན་གྱི་དབྱེ་བ། དུས་གསུམ་ལ་ཕྲ་རྒྱས་གང་ལྡན་པའོ། །དང་པོ་ལ། ཁམས་སྐལ་བ་མཉམ་པ་དང༌། མི་མཉམ་པ་དང༌། དེ་གཉིས་ལས་གཞན་པའི་ཀུན་འགྲོ་བཤད་པའོ། །
Enumeration Block 9:
གཉིས་པ་ཟག་མེད་ལ་དམིགས་པ་དང་མ་དམིགས་པའི་བྱེ་བྲག་ལ། ཟག་མེད་ལ་དམིགས་པ་དང༌། མ་དམིགས་པའོ། །དང་པོ་ལ། བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 10:
གསུམ་པ་དམིགས་པ་དང་མཚུངས་ལྡན་གྱིས་རྒྱས་འགྱུར་ལ། དམིགས་པའི་སྒོ་ནས་རྒྱས་འགྱུར་དང༌། མཚུངས་ལྡན་གྱི་སྒོ་ནས་རྒྱས་འགྱུར་རོ། །
