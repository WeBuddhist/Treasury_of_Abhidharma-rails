Enumeration Block 1:
གསུམ་པ་དམིགས་པ་དང་མཚུངས་ལྡན་གྱིས་རྒྱས་འགྱུར་ལ། དམིགས་པའི་སྒོ་ནས་རྒྱས་འགྱུར་དང༌། མཚུངས་ལྡན་གྱི་སྒོ་ནས་རྒྱས་འགྱུར་རོ། །
Enumeration Block 2:
བཞི་པ་མི་དགེ་བ་དང་ལུང་མ་བསྟན་གྱི་དབྱེ་བ་ལ། དངོས་དང༌། རྩ་བའི་བྱེ་བྲག་དེ་ལས་འཕྲོས་པའོ། །
Enumeration Block 3:
གཉིས་པ་རྩ་བའི་བྱེ་བྲག་ལ། མི་དགེ་བའི་རྩ་བ་དང༌། ལུང་མ་བསྟན་གྱི་རྩ་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལུང་མ་བསྟན་གྱི་རྩ་བ་ལ། ཁ་ཆེ་བའི་ལུགས་དང༌། ཉི་འོག་པའི་ལུགས་སོ། །
Enumeration Block 5:
ལྔ་པ་དུས་གསུམ་ལ་ཕྲ་རྒྱས་གང་ལྡན་པ་ལ། དངོས་པོ་གང་དང་ལྡན་པ། དུས་གསུམ་དཔྱད་པ། སྤངས་ཀྱང་ལྡན་པ། ཆོས་གང་སེམས་གང་གི་ཡུལ་ཡིན་པའོ། །དང་པོ་ལ། རང་གི་མཚན་ཉིད་པའི་ལྡན་ཚུལ་དང༌། སྤྱིའི་མཚན་ཉིད་པའི་ལྡན་ཚུལ་ལོ། །དང་པོ་ལ། དུས་གཉིས་ཀྱི་ལྡན་ཚུལ་དང༌། མ་འོངས་པའི་ལྡན་ཚུལ་ལོ། །
Enumeration Block 6:
གཉིས་པ་དུས་གསུམ་དཔྱད་པ་ལ། རང་ལུགས་བཀོད་པ་དང༌། རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། དུས་གསུམ་རྫས་སུ་གྲུབ་པར་དམ་བཅའ་བ། དེའི་སྒྲུབ་བྱེད་དགོད་པ། དེ་བྱེ་སྨྲའི་ལུགས་སུ་བསྟན་པའོ། །
Enumeration Block 7:
གཉིས་པ་སྒྲུབ་བྱེད་ལ། ལུང་གི་སྒྲུབ་བྱེད་དང༌། རིགས་པའི་སྒྲུབ་བྱེད་དོ། །
Enumeration Block 8:
གསུམ་པ་དེ་བྱེ་སྨྲའི་ལུགས་སུ་བསྟན་པ་ལ། དངོས་དང༌། གྲུབ་མཐའི་དབྱེ་བ། ལུགས་བཞི་པོ་གང་བཟང་བརྟག་པའོ། །
Enumeration Block 9:
ཐམས་ཅད་ཡོད་པར་སྨྲ་བ་དེ་དག་ཀྱང་ལུགས་རྣམ་པ་བཞི་སྟེ། དངོས་པོ་གཞན་དུ་འགྱུར་བ་དང༌། མཚན་ཉིད་གཞན་དུ་འགྱུར་བ་དང༌། གནས་སྐབས་གཞན་དུ་འགྱུར་བ་དང༌། གཞན་གཞན་དུ་འགྱུར་བ་ཞེས་བྱ་བ་བཞི་ཡོད་པ་ལས།
Enumeration Block 10:
གཉིས་པ་རྩོད་སྤང་ལ། རྩོད་པ་དང༌། ལན་གཉིས་ལས།
Enumeration Block 11:
གསུམ་པ་སྤངས་ཀྱང་ལྡན་པའམ་མ་བྲལ་བ་ལ། མཐོང་སྤང་དང༌། སྒོམ་སྤང་ངོ༌། །
Enumeration Block 12:
བཞི་པ་ཆོས་གང་སེམས་གང་གི་ཡུལ་ཡིན་པ་ལ། ཁམས་གསུམ་གྱི་ཆོས་ལྔ་ལ་སེམས་གང་གིས་དམིགས་པ་དང༌། ཟག་མེད་ལ་སེམས་གང་གིས་དམིགས་པའོ། །དང་པོ་ལ། མཐོང་སྤང་དང་པོ་གཉིས་དང་སྒོམ་སྤང་ལ་སེམས་གང་གིས་དམིགས་པ་དང༌། འགོག་ལམ་མཐོང་སྤང་ལ་སེམས་གང་གིས་དམིགས་པའོ། །དང་པོ་ལ། འདོད་པའི་སས་བསྡུས་ལ། གཟུགས་ཀྱི་སས་བསྡུས། གཟུགས་མེད་ཀྱི་སས་བསྡུས་ལ་སེམས་གང་གིས་དམིགས་པའོ། །
Enumeration Block 13:
གཉིས་པ་སྐྱེ་ཚུལ་ལ། སྐྱེ་བའི་རིམ་པ་དང༌། སྐྱེ་བའི་རྒྱུའོ། །
Enumeration Block 14:
གསུམ་པ་ཕྲ་རྒྱས་ཀྱི་རྣམ་གྲངས་ལ། ངོ་བོ་དངོས་དང༌། གང་ལ་མཚུངས་པར་ལྡན་པ་དང༌། །སྒྲིབ་པ་ལྔ་བསྟན་པའོ། །དང་པོ་ལ། མདོ་ལས་འབྱུང་བའི་དོན་དང༌། བསྟན་བཅོས་ལས་འབྱུང་བ་བསྟན་པའོ། །དང་པོ་ལ། དངོས་དང༌། ངེས་ཚིག་གོ ། དང་པོ་ལ། ཟག་པ་དང༌། ཆུ་སྦྱོར་དང༌། ཉེར་ལེན་ནོ། །དང་པོ་ལ། འདོད་པའི་ཟག་པ་དང༌། སྲིད་པའི་ཟག་པ་དང༌། མ་རིག་པའི་ཟག་པ་ལོགས་ཤིག་ཏུ་བསྟན་པའི་རྒྱུ་མཚན་ནོ། །
