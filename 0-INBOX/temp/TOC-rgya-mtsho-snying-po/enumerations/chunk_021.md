Enumeration Block 1:
གཉིས་པ་སྐྱེ་ཚུལ་ལ། སྐྱེ་བའི་རིམ་པ་དང༌། སྐྱེ་བའི་རྒྱུའོ། །
Enumeration Block 2:
གསུམ་པ་ཕྲ་རྒྱས་ཀྱི་རྣམ་གྲངས་ལ། ངོ་བོ་དངོས་དང༌། གང་ལ་མཚུངས་པར་ལྡན་པ་དང༌། །སྒྲིབ་པ་ལྔ་བསྟན་པའོ། །དང་པོ་ལ། མདོ་ལས་འབྱུང་བའི་དོན་དང༌། བསྟན་བཅོས་ལས་འབྱུང་བ་བསྟན་པའོ། །དང་པོ་ལ། དངོས་དང༌། ངེས་ཚིག་གོ ། དང་པོ་ལ། ཟག་པ་དང༌། ཆུ་སྦྱོར་དང༌། ཉེར་ལེན་ནོ། །དང་པོ་ལ། འདོད་པའི་ཟག་པ་དང༌། སྲིད་པའི་ཟག་པ་དང༌། མ་རིག་པའི་ཟག་པ་ལོགས་ཤིག་ཏུ་བསྟན་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 3:
གཉིས་པ་སྲིད་པའི་ཟག་པ་ལ། མཚན་གཞི་ངོས་བཟུང་བ་དང༌། གོང་མ་གཉིས་ཀ་དེར་ངེས་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 4:
གཉིས་པ་ངེས་ཚིག་ལ། ཕྲ་རྒྱས་ཀྱི་ངེས་ཚིག་དང༌། ཟག་པ་ལ་སོགས་པའི་ངེས་ཚིག་གོ །
Enumeration Block 5:
གཉིས་པ་བསྟན་བཅོས་ལས་འབྱུང་བ་ལ། བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 6:
གཉིས་པ་རྒྱས་བཤད་ལ། ཀུན་སྦྱོར་དང༌། འཆིང་བ་དང༌། ཉེ་ཉོན། ཀུན་དཀྲིས་སོ། །དང་པོ་ལ། ཀུན་སྦྱོར་དགུར་བཤད་པ། ཐ་མའི་ཆ་མཐུན། གོང་མའི་ཆ་མཐུན་ནོ། །དང་པོ་ལ། ཀུན་སྦྱོར་དགུ་ངོས་བཟུང་བ། ལྟ་བའི་ཀུན་སྦྱོར་ལ་གཉིས་སུ་བཤད་པའི་རྒྱུ་མཚན། ཕྲག་དོག་དང་སེར་སྣ་ལོགས་སུ་ཀུན་སྦྱོར་དུ་བཤད་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 7:
གཉིས་པ་ཐ་མའི་ཆ་མཐུན་ལ། དངོས་དང༌། དོགས་པ་བཅད་པའོ། །
Enumeration Block 8:
བཞི་པ་ཀུན་དཀྲིས་ལ། དངོས་ཀྱི་དོན་དང༌། ཞར་ལ་དྲི་མ་བཤད་པ། དེ་དག་གི་ཁྱད་པར་བཤད་པའོ། །དང་པོ་ལ། ངོ་བོ་ངོས་བཟུང་བ་དང༌། གང་གི་རྒྱུ་མཐུན་ཡིན་པའོ། །དང་པོ་ལ། རབ་ཏུ་བྱེད་པ་ལས་གསུངས་པ་དང༌། བྱེ་སྨྲའི་འདོད་པ་གཉིས་སོ། །
Enumeration Block 9:
གཉིས་པ་ཞར་ལ་དྲི་མ་བཤད་པ་ལ། དྲི་མའི་དབྱེ་བ། སོ་སོའི་རྒྱུའོ། །
Enumeration Block 10:
གསུམ་པ་དེ་དག་གི་ཁྱད་པར་བཤད་པ་ལ། མཐོང་སྤང་དང་སྒོམ་སྤང་གི་ཁྱད་པར། མི་དགེ་བ་དང་ལུང་མ་བསྟན་གྱི་ཁྱད་པར། ཁམས་དང་སའི་ཁྱད་པར་རོ། །
