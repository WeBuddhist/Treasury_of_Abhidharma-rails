Enumeration Block 1:
གཉིས་པ་ཞར་ལ་དྲི་མ་བཤད་པ་ལ། དྲི་མའི་དབྱེ་བ། སོ་སོའི་རྒྱུའོ། །
Enumeration Block 2:
གསུམ་པ་དེ་དག་གི་ཁྱད་པར་བཤད་པ་ལ། མཐོང་སྤང་དང་སྒོམ་སྤང་གི་ཁྱད་པར། མི་དགེ་བ་དང་ལུང་མ་བསྟན་གྱི་ཁྱད་པར། ཁམས་དང་སའི་ཁྱད་པར་རོ། །
Enumeration Block 3:
གཉིས་པ་དེ་རྣམས་གང་དང་མཚུངས་ལྡན་ལ། སེམས་གང་དང་མཚུངས་ལྡན། ཚོར་བ་གང་དང་མཚུངས་ལྡན་ནོ། །
Enumeration Block 4:
གཉིས་པ་ཚོར་བ་གང་དང་མཚུངས་པར་ལྡན་པ་ལ། རྩ་ཉོན་གང་དང་ལྡན་པ། ཉེ་ཉོན་གང་དང་ལྡན་པའོ། །དང་པོ་ལ། འདོད་པའི་དང༌། ཁམས་གོང་གིའོ། །
Enumeration Block 5:
གསུམ་པ་སྒྲིབ་པ་ལྔ་བསྟན་པ་ལ། ངོ་བོ་དང༌། གྲངས་ངེས་སོ། །
Enumeration Block 6:
གཉིས་པ་གྲངས་ངེས་ལ། བདུན་བཤད་པ་དང་མི་འགལ་བའི་རྒྱུ་མཚན་དང༌། ལྔར་ངེས་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 7:
གཉིས་པ་གང་གིས་སྤོང་བ་ལ། ཇི་ལྟར་སྤོང་ཚུལ། སྤོང་བྱེད་གཉེན་པོའི་དབྱེ་བ། གང་ལས་ཕྱེ་ནས་སྤོང་ཚུལ། སྤངས་པ་གང་གིས་ཐག་བསྲིང་བ། སྤངས་པའི་ཐོབ་པ་ཡང་དང་ཡང་དུ་བསྟན་པའོ། །དང་པོ་ལ། མཐོང་སྤང་དང༌། སྒོམ་སྤང་སྤོང་ཚུལ་ལོ། །
Enumeration Block 8:
མཐོང་སྤང་ཇི་ལྟར་སྤོང་ཚུལ་ནི་རྣམ་པ་གསུམ་སྟེ། དམིགས་པ་ཡོངས་སུ་ཤེས་པ་ཉིད་ཀྱིས་སྤོང་བ་དང༌། དེ་ལ་དམིགས་པ་ཡུལ་ཅན་གྱི་ཉོན་མོངས་ཡང་དག་པར་ཟད་པས་སྤོང་བ་དང༌། དམིགས་པ་སྤངས་པས་སྤོང་བ་རྣམས་སོ། །
Enumeration Block 9:
གཉེན་པོ་ནི་རྣམ་པ་བཞི་སྟེ།
Enumeration Block 10:
གསུམ་པ་སྤངས་པའི་འབྲས་བུ་ལ། འབྲས་བུའི་དབྱེ་བ། གང་གི་འབྲས་བུ་གང་ཡིན་པ། གྲངས་ངེས། གང་ཟག་གང་ལ་ལྡན་པའི་ཚུལ། །གཏོང་ཐོབ་བོ། །
Enumeration Block 11:
གཉིས་པ་གང་གི་འབྲས་བུ་གང་ཡིན་པ་ལ། ཤེས་བཟོད་དང༌། ས་དང༌། ལམ་གང་གི་འབྲས་བུ་གང་ཡིན་པའོ། །
Enumeration Block 12:
གསུམ་པ་གྲངས་ངེས་ལ། མཐོང་སྤང་སྤངས་པ་དྲུག་གི་གྲངས་ངེས། སྒོམ་སྤང་སྤངས་པ་གསུམ་གྱི་གྲངས་ངེས་སོ། །
