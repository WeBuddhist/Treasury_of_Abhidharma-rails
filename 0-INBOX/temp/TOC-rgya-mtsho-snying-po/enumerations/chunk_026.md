Enumeration Block 1:
གཉིས་པ་དགེ་སྦྱོང་ཚུལ་གྱི་འབྲས་བུ་ལ། དགེ་སྦྱོང་ཚུལ་འབྲས་ཀྱི་དབྱེ་བ། དགེ་སྦྱོང་ཚུལ་ཉིད་བཤད་པའོ། །དང་པོ་ལ། བསྡུས་ཏེ་དབྱེ་བ། རྒྱས་པར་དབྱེ་བ། འབྲས་བུ་བཞིའི་གྲངས་ངེས། མ་ཁྱབ་པ་སྤང་བའོ། །
Enumeration Block 2:
གཉིས་པ་དགེ་སྦྱོང་གི་ཚུལ་ཉིད་བཤད་པ་ལ། ལམ་གྱི་ཚངས་པའི་འཁོར་ལོ་བཤད་པ། མཐོང་ལམ་བྱེ་བྲག་ཏུ་ཆོས་འཁོར་དུ་བཤད་པ། ཁམས་གང་དུ་དགེ་སྦྱོང་ཚུལ་གྱི་འབྲས་བུ་དུ་ཐོབ་པའོ། །
Enumeration Block 3:
གསུམ་པ་ཁམས་གང་དུ་དགེ་སྦྱོང་ཚུལ་གྱི་འབྲས་བུ་དུ་ཐོབ་པ་ལ། དངོས་དང༌། དོགས་གཅོད་དོ། །
Enumeration Block 4:
གསུམ་པ་དགྲ་བཅོམ་འབྲས་གནས་ཀྱི་དབྱེ་བ་ལ། དྲུག་ཏུ་དབྱེ་བ་དང༌། དགུར་དབྱེ་བའོ། །དང་པོ་ལ། དབྱེ་བ་དངོས་དང༌། དབང་པོ་འཕོ་ཚུལ་ལོ། །དང་པོ་ལ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། གཉིས་སུ་བསྡུ་བ། རིགས་དང་འབྲས་བུ་གང་ལས་ཉམས་པ། རིགས་ཀྱི་དབྱེ་བ་དེ་གཞན་ལའང་སྦྱར་བ། ལམ་གང་ལ་དབང་པོ་འཕོ་བ། ཉམས་པའི་རབ་ཏུ་དབྱེ་བའོ། །དང་པོ་ལ། རིགས་ཅན་ལྔ་དུས་ཀྱི་རྣམ་གྲོལ་དུ་བསྟན་པ། དྲུག་པ་དུས་ལ་མི་ལྟོས་པར་བསྟན་པ། དེ་ལས་འཕྲོས་པའི་དོན་ཏོ། །
Enumeration Block 6:
ལྔ་པ་ཉམས་པའི་རབ་ཏུ་དབྱེ་བ་ལ། དངོས་དང༌། གང་ཟག་གང་ལ་ཉམས་པ་གང་ཡོད་པ། འབྲས་བུ་ལས་ཉམས་བཞིན་པར་མི་འཆི་བའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 7:
གཉིས་པ་དབང་པོ་འཕོ་ཚུལ་ལ། ལམ་དུས་དབང་པོ་འཕོ་བ། ལམ་དེའི་ངོ་བོ། རྟེན་གང་ལས་འཕོ་བ། ས་གང་ལ་བརྟེན་ནས་འཕོ་བའོ། །དང་པོ་ལ། མི་སློབ་པ་དང༌། སློབ་པའོ། །
Enumeration Block 8:
བཞི་པ་ས་གང་ལ་བརྟེན་ནས་འཕོ་བ་ལ་མི་སློབ་པ་དང༌། སློབ་པའོ། །
Enumeration Block 9:
གཉིས་པ་དགུར་དབྱེ་བ་ལ། དབྱེ་བ་དངོས་དང༌། འབྱེད་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 10:
གསུམ་པ་རྫས་དྲུག་ཏུ་བསྡུ་བ་ལ། དངོས་དང༌། འཕྲོས་དོན་ནོ། །
Enumeration Block 11:
གཉིས་པ་ལ། རྣམ་གྲོལ་གཉིས་ངོས་བཟུང༌། ཡོན་ཏན་རྫོགས་པའི་ཁྱད་པར་རོ། །
Enumeration Block 12:
གསུམ་པ་ལམ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། ལམ་གྱི་ཁྱད་པར་གྱི་ཡོན་ཏན། །བྱང་ཆུབ་ཕྱོགས་མཐུན་གྱི་རྣམ་གཞག ལམ་གྱིས་ཐོབ་པའི་རྣམ་གྲོལ་ལོ། །དང་པོ་ལ། སྦྱོར་ལམ་སོགས་བཞིའི་ཁྱད་པར། དཀའ་སླ་མྱུར་བུལ་བཞིའི་ཁྱད་པར་རོ། །
