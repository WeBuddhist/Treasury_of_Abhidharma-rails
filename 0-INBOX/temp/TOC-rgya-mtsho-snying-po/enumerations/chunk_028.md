Enumeration Block 1:
གནས་བདུན་པ་ཡེ་ཤེས་བསྟན་པའི་གནས་ཀྱི་དོན་ལ་གཉིས། དང་པོ་གནས་ཀྱི་གཞུང་བཤད་པ་ལ། ཤེས་པ་དང༌། ལྡན་པ་དང༌། ཐོབ་པ་དང༌། ཡོན་ཏན་ནོ། །དང་པོ་ལ་གསུམ། བཟོད་ཤེས་དང་ལྟ་བའི་ཁྱད་པར། ཤེས་པ་བཅུ་ངོས་བཟུང་བ། དེ་དག་གི་ཁྱད་པར་དཔྱད་པའོ། །དང་པོ་ལ། ཟག་མེད་དང༌། ཟག་བཅས་སོ། །
Enumeration Block 2:
གཉིས་པ་ཤེས་པ་བཅུ་ངོས་བཟུང་བ་ལ། དབྱེ་བ་དངོས་དང༌། སེམས་ཤེས་ཁྱད་པར་དུ་བསྟན་པའོ། །དང་པོ་ལ། བསྟན། བཤད་གཉིས་ལས། 
Enumeration Block 3:
གཉིས་པ་སེམས་ཤེས་ཁྱད་པར་དུ་བཤད་པ་ལ། སེམས་ཤེས་ཀྱི་ཁྱད་ཆོས་དང༌། ཟད་མི་སྐྱེ་ཤེས་པའི་ཁྱད་པར་རོ། །དང་པོ་ལ། སྤྱིར་བསྟན་པ་དང༌། ལམ་གྱི་གནས་སྐབས་སོ། །
Enumeration Block 4:
གསུམ་པ་དེ་དག་གི་ཁྱད་པར་དཔྱད་པ་ལ། ཤེས་བཅུའི་ཁྱད་པར། གཉེན་པོའི་ཁྱད་པར། རྣམ་པའི་ཁྱད་པར། ཁྱད་པར་གཞན་བཤད་པའོ། །
Enumeration Block 5:
གསུམ་པ་རྣམ་པའི་ཁྱད་པར་ལ། ཤེས་པ་སོ་སོའི་རྣམ་པ་དང༌། རྣམ་པ་སོ་སོའི་ངོ་བོའོ། །དང་པོ་ལ། ཆོས་ཤེས་རྗེས་ཤེས་རྣམ་པ་གང་གིས་འཇུག་པ། ཀུན་རྫོབ་ཤེས་པ། བདེན་བཞི་ཤེས་པ། ཕ་རོལ་གྱི་སེམས་ཤེས་པ། ཟད་མི་སྐྱེ་ཤེས་པ་རྣམ་པ་གང་གིས་འཇུག་པའོ། །
Enumeration Block 6:
བཞི་པ་ཕ་རོལ་གྱི་སེམས་ཤེས་པ་ལ། དྲི་མེད་དང༌། དྲི་བཅས་འཇུག་ཚུལ་ལོ། །
Enumeration Block 7:
གཉིས་པ་རྣམ་པ་སོ་སོའི་ངོ་བོ་ལ། ཟག་མེད་ལ་རང་མཚན་གྱི་རྣམ་པ་ཡོད་མེད་དཔྱད་པ། རྣམ་པ་བཅུ་དྲུག་རྫས་སུ་སྒྲུབ་པ། རྣམ་པའི་ངོ་བོ། གཟུང་འཛིན་གྱི་ཁྱད་པར་རོ། །དང་པོ་ལ། རང་ལུགས་དང༌། གཞན་ལུགས་སོ། །
Enumeration Block 8:
བཞི་པ་ཤེས་པའི་ཁྱད་པར་གཞན་བསྟན་པ་ལ། ངོ་བོའི་ཁྱད་པར། སའི་ཁྱད་པར། རྟེན་གྱི་ཁྱད་པར། དྲན་པ་ཉེར་བཞག་གི་ཁྱད་པར། དམིགས་པའི་ཁྱད་པར་རོ། །
