Enumeration Block 1:
མི་འཇིགས་པ་བཤད་པ་ལ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 2:
མཇུག་བསྡུ་བ་ལ། སངས་རྒྱས་ཀྱི་ཁྱད་པར་མཉམ་པའི་ཚུལ་དང༌། མི་མཉམ་པའི་ཚུལ་ལོ། །
Enumeration Block 3:
ཐུན་མོང་གི་ཡོན་ཏན་ལ། བསྟན། བཤད་གཉིས་ལས། དང་པོ་ལའང༌། མདོར་བསྟན་པ་དང༌། ཅུང་ཟད་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 4:
རྒྱས་བཤད་ལ། འཕགས་པ་དང་ཐུན་མོང་བ་དང༌། སྐྱེ་འཕགས་གཉིས་ཀ་དང་ཐུན་མོང་བའོ། །དང་པོ་ལ། ཡོན་ཏན་དྲུག་པོ་སོ་སོའི་ཆོས་བཤད་པ་དང༌། །ཐུན་མོང་བའི་ཆོས་བཤད་པའོ། །དང་པོ་ལ། ཉོན་མོངས་མེད་པ་དང༌། སྨོན་ནས་མཁྱེན་པ། སོ་སོ་ཡང་དག་པར་རིག་པ་བཞིའོ། །
Enumeration Block 5:
སོ་སོ་ཡང་དག་པར་རིག་པ་བཞི་བཤད་པ་ལ། དབྱེ་བའི་སྒོ་ནས་ཐུན་མོང་གི་ཆོས་བསྟན་པ། མི་འདྲ་བའི་ཁྱད་ཆོས་སོ་སོར་བཤད་པ། ཐོབ་ཚུལ་གྱི་དོན་བསྡུ་བའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། དང་པོ་གསུམ་གྱི་དམིགས་པ་དང་རང་བཞིན། བཞི་པའི་ཆོས་བཞི། གཉིས་པའི་ཆོས་གཉིས། དང་པོ་དང་གསུམ་པའི་ངོ་བོ། དང་པོའི་ས། གསུམ་པའི་སའི་ཁྱད་པར་རོ། །
Enumeration Block 7:
ཡོན་ཏན་དྲུག་པོ་ཐུན་མོང་བའི་ཆོས་བཤད་པ་ལ། སེམས་རྟེན་སྤྱིར་བསྟན་པ་དང༌། རབ་མཐའ་དངོས་ཡིན་མིན་གྱི་ཁྱད་པར། བཞི་པའི་རབ་མཐའ་ངོས་བཟུང་བ། སྦྱོར་བའི་དམིགས་བསལ་ལོ། །
Enumeration Block 8:
སྐྱེ་འཕགས་གཉིས་ཀ་དང་ཐུན་མོང་བའི་ཡོན་ཏན་བཤད་པ་ལ། ཡོན་ཏན་གྱི་ཁྱད་པར་དང༌། ཁྱད་པར་གཏན་ལ་དབབ་པའོ། །དང་པོ་ལ། དབྱེ་བ། ངོ་བོ། ཆོས་ཀྱི་ཁྱད་པར། ཐོབ་ཚུལ་ལོ། །
Enumeration Block 9:
ཆོས་ཀྱི་ཁྱད་པར་ལ། ཤེས་པ་གང་ཡིན་པ་དང༌། ས་གང་ན་ཡོད་པ་དང༌། སྤྱོད་ཡུལ་གང་ཡིན་པའོ། །
Enumeration Block 10:
ཁྱད་པར་གཏན་ལ་དབབ་པ་ལ། ཐུན་མོང་དུ་གཏན་ལ་དབབ་པ་དང༌། བྱེ་བྲག་ཏུ་གཏན་ལ་དབབ་པའོ། །དང་པོ་ལ། དྲན་པ་ཉེར་གཞག་དང་སྦྱར་བ། དགེ་སོགས་གསུམ་དང་སྦྱར་བ། རིག་པ་གསུམ་དང་སྦྱར་བ། ཆོ་འཕྲུལ་གསུམ་དང་སྦྱར་བའོ། །
Enumeration Block 11:
རིག་པ་གསུམ་དང་སྦྱར་བ་ལ། བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 12:
རྒྱས་བཤད་ལ། དོན་དམ་པའི་མི་སློབ་པའི་རིག་པ་ངོས་བཟུང་བ། གཞན་གཉིས་ལ་དེའི་སྒྲ་འཇུག་པའི་རྒྱུ་མཚན། དེ་ལས་འཕྲོས་པའི་དོན་ཏོ། །
Enumeration Block 13:
ཆོ་འཕྲུལ་གསུམ་དང་སྦྱར་བ་ལ། སྤྱིར་བསྟན་པ་དང༌། དེའི་མཆོག་ངོས་བཟུང་བ་གཉིས་ལས།
Enumeration Block 14:
བྱེ་བྲག་ཏུ་གཏན་ལ་དབབ་པ་ལ་གསུམ། རྫུ་འཕྲུལ་གྱི་མངོན་ཤེས་གཏན་ལ་དབབ་པ། མིག་རྣའི་མངོན་ཤེས་གཏན་ལ་དབབ་པ། སྐྱེས་ཐོབ་སོགས་ཀྱི་རང་བཞིན་གཏན་ལ་དབབ་པའོ། །དང་པོ་ལ། རྫུ་འཕྲུལ་གྱི་ཁྱད་པར། སྤྲུལ་སེམས་ངོས་བཟུང་བ། དེས་ཇི་ལྟར་སྤྲུལ་པ། སྤྲུལ་སེམས་ཀྱི་ངོ་བོ། རྫུ་འཕྲུལ་གྱི་དབྱེ་བའོ། །དང་པོ་ལ། རྫུ་འཕྲུལ་སྤྱིར་བཤད་པ་དང༌། ཁྱད་པར་དངོས་སོ། །
Enumeration Block 15:
གཉིས་པ་ལ། འགྲོ་བ་གསུམ་གྱི་ཁྱད་པར། སྤྲུལ་པ་གཉིས་ཀྱི་ཁྱད་པར་རོ། །
