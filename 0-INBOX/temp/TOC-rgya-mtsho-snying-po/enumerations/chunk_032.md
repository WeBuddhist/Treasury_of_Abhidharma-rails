Enumeration Block 1:
གཉིས་པ་ལ། སྤྱིའི་ངོ་བོ་དང༌། སོ་སོའི་ངོ་བོའོ། །དང་པོ་ལ། དངོས་དང༌། འཁོར་བཅས་ལས།
Enumeration Block 2:
གཉིས་པ་སོ་སོའི་ངོ་བོ་ལ། བསམ་གཏན་དང་པོའི་ངོ་བོ་དང༌། ལྷག་མ་གསུམ་གྱི་ངོ་བོའོ། །
Enumeration Block 3:
གཉིས་པ་གཟུགས་མེད་བཤད་པ་ལ། སྤྱིའི་ངོ་བོ། སོ་སོའི་ངོ་བོ། འཕྲོས་དོན་ཏོ། །དང་པོ་ལ། འདྲ་བ་ཉེར་སྦྱར་དང༌། མི་འདྲ་བའི་ཁྱད་པར་གཉིས་ལས།
Enumeration Block 4:
གསུམ་པ་འཕྲོས་དོན་ལ། འདུ་ཤེས་ཀྱི་ཁྱད་པར་དང༌། སྒྲ་བཤད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། གཟུགས་མེད་ཁམས་ཀྱི་སྒྲ་བཤད་དང༌། བཞི་པོ་སོ་སོའི་སྒྲ་བཤད་དོ། །དང་པོ་ལ། དངོས་དང༌། དོགས་གཅོད་གཉིས་ལས།
Enumeration Block 6:
གཉིས་པ་བཞི་པོ་སོ་སོའི་སྒྲ་བཤད་ལ། དང་པོ་གསུམ་གྱི་སྒྲ་དོན་དང༌། ཐ་མའི་སྒྲ་དོན་ནོ། །
Enumeration Block 7:
གཉིས་པ་ཐུན་མོང་དུ་གཏན་ལ་དབབ་པ་ལ། ངོ་བོ་རྣམ་པར་དཔྱད་པ། བསམ་གཏན་གྱི་ཡན་ལག་ངོས་བཟུང་བ། སྙོམས་འཇུག་ཐོབ་ཚུལ། རྟེན་གང་གིས་མངོན་དུ་བྱེད་པ། སྤྱོད་ཡུལ་གང་ལ་དམིགས་པ། ཉོན་མོངས་སྤོང་བྱེད་ངོས་བཟུང་བའོ། །དང་པོ་ལ། ངོ་བོའི་སྒོ་ནས་དབྱེ་བ་དང༌། དབྱེ་བ་སོ་སོའི་དོན་ཏོ། །དང་པོ་ལ། འོག་མ་བདུན་གྱི་དབྱེ་བ་དང༌། སྲིད་རྩེའི་དབྱེ་བ་གཉིས་ཀྱི།
Enumeration Block 8:
གཉིས་པ་བསམ་གཏན་གྱི་ཡན་ལག་ངོས་བཟུང་བ་ལ། ཡན་ལག་སོ་སོར་སྦྱར་བ། ཡན་ལག་གསུམ་ཁྱད་པར་དུ་བསྟན་པ། སྙོམས་འཇུག་རྣམས་ཀྱི་ཁྱད་པར་བསྟན་པའོ། །དང་པོ་ལ། མིང་གི་སྒོ་ནས་དབྱེ་བ་དང༌། རྫས་ཀྱི་སྒོ་ནས་མཇུག་བསྡུ་བའོ། །
Enumeration Block 9:
གཉིས་པ་ཡན་ལག་གསུམ་གྱི་ཁྱད་པར་བཤད་པ་ལ། བདེ་བའི་ཁྱད་པར་བཤད། ནང་རབ་དང་ཁྱད་པར་དུ་བཤད་པ། ཡིད་བདེ་བའི་ཁྱད་པར་བཤད་པའོ། །
Enumeration Block 10:
གསུམ་པ་སྙོམས་འཇུག་རྣམས་ཀྱི་ཁྱད་པར་བསྟན་པ་ལ། ཉོན་མོངས་ཅན་ཡིན་མིན་གྱི་ཁྱད་པར། བསམ་གཏན་བཞི་པའི་ཁྱད་ཆོས། རྒྱུ་འབྲས་ཀྱི་བསམ་གཏན་གཉིས་ཀྱི་ཚོར་བའི་ཁྱད་པར་རོ། །
Enumeration Block 11:
གསུམ་པ་རྒྱུ་འབྲས་ཀྱི་བསམ་གཏན་གཉིས་ཀྱི་ཚོར་བའི་ཁྱད་པར་ལ། དངོས་དང༌། དོགས་པ་གཅོད་པའོ། །
Enumeration Block 12:
གསུམ་པ་སྙོམས་འཇུག་གི་ཐོབ་ཚུལ་ལ། ཇི་ལྟར་ཐོབ་པའི་ཚུལ་དངོས། གང་གི་མཇུག་ཏུ་གང་སྐྱེ་བ། ཐོད་རྒལ་གྱི་སྙོམས་འཇུག་སྐྱེ་ཚུལ་ལོ། །དང་པོ་ལ། དག་པ་བ་ཐོབ་ཚུལ། ཟག་མེད་ཐོབ་ཚུལ། ཉོན་མོངས་ཅན་ཐོབ་ཚུལ་ལོ། །
Enumeration Block 13:
གཉིས་པ་གང་གི་མཇུག་ཏུ་གང་སྐྱེ་བ་ལ། སྤྱིར་བསྟན་པ་དང༌། ཕྱི་མ་གཉིས་ཀྱི་དམིགས་བསལ་ལོ། །དང་པོ་ལ། ཟག་མེད་ཀྱི་མཇུག་ཏུ་གང་སྐྱེ་བ། དག་པ་བའི་མཇུག་ཏུ་གང་སྐྱེ་བ། ཉོན་མོངས་ཅན་གྱི་མཇུག་ཏུ་གང་སྐྱེ་བའོ། །
Enumeration Block 14:
གཉིས་པ་ཕྱི་མ་གཉིས་ཀྱི་དམིགས་བསལ་ལ། འཆི་འཕོའི་གནས་སྐབས་དང༌། ཆ་མཐུན་བཞིའི་དམིགས་བསལ་ལོ། །དང་པོ་ལ། དག་པ་བ་དང༌། ཉོན་མོངས་ཅན་གཉིས།
Enumeration Block 15:
གཉིས་པ་ཆ་མཐུན་བཞིའི་དམིགས་བསལ་ལ། དག་པ་བ་ལ་དེ་བཞིར་དབྱེ་བ། དབྱེ་བ་སོ་སོའི་དོན། བཞི་པོ་གང་གི་མཇུག་ཏུ་གང་སྐྱེ་བའོ། །
Enumeration Block 16:
གསུམ་པ་ཐོད་བརྒལ་གྱི་སྙོམས་འཇུག་སྐྱེ་ཚུལ་ལ། སྦྱོར་བ་དང༌། དངོས་གཞིའོ། །དང་པོ་ལ། རིང་སྦྱོར་དང༌། ཉེ་སྦྱོར་ལས།
Enumeration Block 17:
བཞི་པ་རྟེན་གང་གིས་གང་མངོན་དུ་བྱེད་པ་ལ། སྤྱིར་བཏང་བ་དང༌། སྲིད་རྩེ་ལ་དམིགས་བསལ་ལོ། །
Enumeration Block 18:
ལྔ་པ་སྤྱོད་ཡུལ་གང་ལ་དམིགས་པ་ལ། བསམ་གཏན་ཉོན་མོངས་ཅན་གྱིས་གང་ལ་དམིགས་པ། བསམ་གཏན་དག་པ་བ་དང་ཟག་མེད་ཀྱིས་གང་ལ་དམིགས་པ། གཟུགས་མེད་ཀྱི་དངོས་གཞིས་གང་ལ་དམིགས་པའོ། །
Enumeration Block 19:
དྲུག་པ་ཉོན་མོངས་སྤོང་བྱེད་ངོས་བཟུང་བ་ལ། གང་གིས་གང་སྤོང་བ། སྤོང་བྱེད་གཉེན་པོའི་ཁྱད་པར་རོ། །དང་པོ་ལ། དངོས་གཞི་ཟག་མེད་ཀྱིས་གང་སྤོང་བ། ཉེར་བསྡོགས་ཀྱིས་གང་སྤོང་བའོ། །
Enumeration Block 20:
གཉིས་པ་སྤོང་བྱེད་གཉེན་པོའི་ཁྱད་པར་ལ། ཉེར་བསྡོགས་ཀྱི་ཁྱད་པར་དང༌། བསམ་གཏན་ཁྱད་པར་ཅན་ངོས་བཟུང་བའོ། །དང་པོ་ལ། དབྱེ་བ། ངོ་བོ་ཚོར་བ་དང་བཅས་པའོ། །
Enumeration Block 21:
གཉིས་པ་ལ། ངོ་བོ་སྤྱིར་བཏང་བ། ཚོར་བ་ལྡན་ཚུལ། ངོ་བོའི་དམིགས་བསལ། གཞན་འདོད་དོ། །
Enumeration Block 22:
གཉིས་པ་བསམ་གཏན་ཁྱད་པར་ཅན་ངོས་བཟུང་བ་ལ། ངོ་བོ་ངོས་བཟུང་བ། དབྱེ་བ། ཚོར་བ་གང་དང་ལྡན་པ། འབྲས་བུའོ། །
Enumeration Block 23:
གཉིས་པ་ཏིང་ངེ་འཛིན་གྱི་དབྱེ་བ་ལ། གསུམ་དུ་དབྱེ་བ། བཞིར་དབྱེ་བའོ། །དང་པོ་ལ། སའི་སྒོ་ནས། ལམ་གྱི་སྒོ་ནས། ཡུལ་ལ་འཇུག་པའི་ཚུལ་གྱི་སྒོ་ནས་དབྱེ་བའོ། །
Enumeration Block 24:
གཉིས་པ་ལ། ཏིང་ངེ་འཛིན་གསུམ་པོ་དེའི་ངོ་བོ་ངོས་བཟུང་བ། ནང་གསེས་ཀྱི་དབྱེ་བ། དངོས་བཏགས་དཔྱད་པའོ། །
Enumeration Block 25:
གསུམ་པ་ཡུལ་ལ་འཇུག་པའི་ཚུལ་གྱི་སྒོ་ནས་དབྱེ་བ་ལ། དབྱེ་བ་སྤྱིར་བསྟན་པ་དང༌། ཁྱད་ཆོས་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 26:
གཉིས་པ་ལ། དམིགས་རྣམ་གྱི་ཁྱད་པར། ངོ་བོའི་ཁྱད་པར། རྟེན་གྱི་ཁྱད་པར། གང་ཟག་གི་ཁྱད་པར། སའི་ཁྱད་པར་རོ། །
