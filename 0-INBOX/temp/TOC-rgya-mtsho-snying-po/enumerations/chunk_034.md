Enumeration Block 1:
གསུམ་པ་སྙོམས་འཇུག་ལ་བརྟེན་པའི་ཡོན་ཏན་བཤད་པ་ལ། ཚད་མེད་བསྟན་པ་དང༌། ཡོན་ཏན་གཞན་བསྟན་པའོ། །དང་པོ་ལ། དབྱེ་བ་དང༌། ཁྱད་ཆོས་སོ། །དང་པོ་ལ། དབྱེ་བ་དངོས། གྲངས་ངེས། དབྱེ་བ་སོ་སོའི་ངོ་བོའོ། །
Enumeration Block 2:
གཉིས་པ་ཁྱད་པར་གྱི་ཆོས་ལ། རྣམ་པའི་ཁྱད་པར། ཡུལ་གྱི་ཁྱད་པར། སའི། གཉེན་པོའི་བྱེད་ཚུལ་གྱི། རྟེན་གྱི། ལྡན་ཚུལ་གྱི་ཁྱད་པར་རོ། །
Enumeration Block 3:
གསུམ་པ་སའི་ཁྱད་པར་ལ། དངོས་དང༌། གཞན་འདོད་གཉིས་ལས།
Enumeration Block 4:
གཉིས་པ་ཡོན་ཏན་གཞན་བསྟན་པ་ལ། ཐོབ་བྱ་ཡོན་ཏན་གྱི་ངོ་བོ། དེ་དག་གི་ཐོབ་ཚུལ། རྟེན་གྱི་ཁྱད་པར། ཏིང་ངེ་འཛིན་གྱི་སྐྱེ་ཚུལ་ལོ། །དང་པོ་ལ། རྣམ་ཐར། ཟིལ་གནོན། ཟད་པར་རོ། །དང་པོ་ལ། རྣམ་ཐར་གྱི་དབྱེ་བ། སོ་སོའི་རང་བཞིན། སྔ་མ་བདུན་གྱི་སྤྱོད་ཡུལ་ལོ། །
Enumeration Block 5:
གཉིས་པ་ལ། རྣམ་ཐར་དང་པོ་གཉིས་བཤད་པ། གསུམ་པ། གཟུགས་མེད་ཀྱི་རྣམ་ཐར། འགོག་པའི་རྣམ་ཐར་བཤད་པའོ། །དང་པོ་ལ། དངོས་དང༌། སའི་ཁྱད་པར་རོ། །
Enumeration Block 6:
བཞི་པ་འགོག་པའི་རྣམ་ཐར་བཤད་པ་ལ། ངོ་བོ་ངོས་གཟུང༌། འཇུག་སེམས་དང༌། ལྡང་སེམས་སོ། །
Enumeration Block 7:
གསུམ་པ་སྔ་མ་བདུན་གྱི་སྤྱོད་ཡུལ་ལ། དང་པོ་གསུམ་གྱི་དང༌། གཟུགས་མེད་བཞིའི་སྤྱོད་ཡུལ་ལོ། །
Enumeration Block 8:
གཉིས་པ་ཟིལ་གནོན་ལ། དབྱེ་བ་དང༌། མཚན་ཉིད་བཤད་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ། གཟུགས་ཅན་གཟུགས་ལ་ལྟ་བའི་ཟིལ་གནོན་གཉིས་པ་བཤད་པ། གཟུགས་མེད་གཟུགས་ལ་ལྟ་བའི་ཟིལ་གནོན་གཉིས་བཤད་པ། ཁ་དོག་གི་ཟིལ་གནོན་བཞི་བཤད་པའོ། །
Enumeration Block 10:
གསུམ་པ་ཟད་པར་བཤད་པ་ལ། དབྱེ་བ་དང༌། སོ་སོའི་རང་བཞིན་ནོ།
Enumeration Block 11:
གཉིས་པ་ལ། སྔ་མ་བརྒྱད་བཤད་པ་དང༌། ཕྱི་མ་གཉིས་བཤད་པའོ། །
Enumeration Block 12:
གསུམ་པ་རྟེན་གྱི་ཁྱད་པར་ལ། དངོས་དང༌། འཕྲོས་དོན་ལས།
Enumeration Block 13:
གཉིས་པ་རྩོམ་པ་མཐར་ཕྱིན་བྱེད་ཀྱི་ཡན་ལག་བསྟན་བཅོས་ཀྱི་མཇུག་གི་དོན་བཤད་པ་ལ། བསྟན་པ་གནས་པའི་ཚད། བསྟན་བཅོས་འདི་ཉིད་ཀྱི་མཇུག་གི་དོན། བཤད་པ་མཐར་ཕྱིན་པའི་ཚུལ་ལོ། །དང་པོ་ནི་བསྟན་པ་དང༌། དེ་གནས་པའི་ཚད་དོ། །
Enumeration Block 14:
གཉིས་པ་བསྟན་བཅོས་འདི་ཉིད་ཀྱི་འཇུག་དོན་ལ། བསྟན་བཅོས་བརྩམས་པའི་ཚུལ། ནོངས་པ་བཤགས་པ། བག་ཡོད་བྱ་བར་གདམས་པའོ། །
Enumeration Block 15:
གསུམ་པ་བག་ཡོད་བྱ་བར་གདམས་པ་ལ། བག་མེད་པའི་ཉེས་པ་བསྟན་པ། བག་ཡོད་བསྟན་པར་གདམས་པའོ། །
