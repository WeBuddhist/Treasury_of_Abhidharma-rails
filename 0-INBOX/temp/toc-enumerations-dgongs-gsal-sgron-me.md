Enumeration Block 11:
རྣམ༵་པར་རིག༵་བྱེད་མིན༵་པ་ནི་རྣམ༵་པ་གསུ༵་དུ་ཤེས༵་པར་བྱ༵་སྟེ།
Enumeration Block 12:
གཉིས་པ་རྒྱས་བཤད་ལ་བཞི། སྡོམ་པ། ལྡན་ཚུལ། འཐོབ་གཏོང་། ལྡན་པའི་གང་ཟག་བཤད་པའོ། །དང་པོ་ལ་གཉིས། བསྟན། བཤད་དོ། །
Enumeration Block 13:
སྡོམ༵་པ༵་གསུམ་དུ་ཤེས་པར་བྱ་སྟེ། སོ༵་སོར༵་ཐར༵་པ་ཞེས༵་བྱ༵་བའི་སྡོམ་པ་དང་། དེ༵་བཞིན༵་དུ་ཟག༵་མེད༵་དང་བསམ༵་གཏན༵་ལས་སྐྱེས༵་པའི་སྡོམ་པ་གསུམ་དུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 14:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། སོ་ཐར་གྱི་སྡོམ་པ། བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པ། ཞར་བྱུང་ངོ། །དང་པོ་ལ་བཞི། དབྱེ་བ། ངོ་བོ། སྒྲ་དོན། ལྡན་པའི་གང་ཟག་གོ །
Enumeration Block 15:
སོ༵་སོར༵་ཐར༵་པ་ཞེས༵་བྱ༵་བའི་སྡོམ་པ་ལ་རྣམ༵་པ་བརྒྱད༵་ཡོད་དེ། དགེ་སློང་ཕ་མ་གཉིས། དགེ་སློབ་མ། དགེ་ཚུལ་ཕ་མ་གཉིས། དགེ་བསྙེན་ཕ་མ་གཉིས། བསྙེན་གནས་པའི་སྡོམ་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 16:
རྫས༵་སུ༵་བསྡུ་ན་རྣམ༵་པ༵་བཞི༵་ཡིན༵་ཏེ༵། དགེ་སློང་ཕ་མའི་སྡོམ་པ་རྫས་གཅིག ། དགེ་སློབ་མ་དང་དགེ་ཚུལ་ཕ་མའི་སྡོམ་པ་རྫས་གཅིག དགེ་བསྙེན་ཕ་མའི་སྡོམ་པ་རྫས་གཅིག ། བསྙེན་གནས་ཀྱི་སྡོམ་པ་རྫས་གཅིག་ཡིན་པའི་ཕྱིར་ཏེ།
Enumeration Block 17:
སོ༵་སོར༵་ཐར༵་པའི་སྡོམ་པ་དང༵་ལྡན༵་པའི༵་གང་ཟག་དེ་ལ་བརྒྱད༵་དུ་ཡོད་དེ། དགེ་སློང་ཕ་མ་གཉིས། དགེ་སློབ་མ། དགེ་ཚུལ་ཕ་མ་གཉིས། དགེ་བསྙེན་ཕ་མ་གཉིས། བསྙེན་གནས་པའི་གང་ཟག་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 18:
གཉིས་པ་ལྡན་ཚུལ་ལ་གསུམ། རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་ལྡན་ཚུལ་དང་། རྣམ་པར་རིག་བྱེད་ཀྱི་ལྡན་ཚུལ་དང་། ལྡན་པའི་མུ་བཞི་བཤད་པའོ། །
Enumeration Block 19:
གཉིས་པ་རྣམ་པར་རིག་བྱེད་ཀྱི་ལྡན་ཚུལ་ལ་གཉིས། དངོས་དང་། ཞར་བྱུང་ངོ་། །
Enumeration Block 20:
གསུམ་པ་འཐོབ་གཏོང་ལ་གཉིས། འཐོབ་ཚུལ་དང་། གཏོང་ཚུལ་ལོ། །དང་པོ་ལ་གསུམ། སྡོམ་པའི་འཐོབ་ཚུལ། སྡོམ་མིན་གྱི་འཐོབ་ཚུལ། བར་མའི་འཐོབ་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། ཇི་ལྟར་འཐོབ་པ་དང་། གང་ལས་འཐོབ་པའོ། །དང་པོ་ལ་གཉིས། བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པ་འཐོབ་ཚུལ། སོ་ཐར་གྱི་སྡོམ་པ་འཐོབ་ཚུལ་ལོ། །
Enumeration Block 21:
གཉིས་པ་སོ་ཐར་གྱི་སྡོམ་པ་འཐོབ་ཚུལ་ལ། དངོས་དང ་། ཞར་བྱུང་གཉིས།
Enumeration Block 22:
གཉིས་པ་ཞར་བྱུང་ལ་གསུམ། སྡོམ་པ་སྡོམ་མིན་གྱི་དུས་ཀྱི་ངེས་པ། བསྙེན་གནས་ཀྱི་སྡོམ་པའི་ཁྱད་པར། དགེ་བསྙེན་གྱི་སྡོམ་པའི་ཁྱད་པར་རོ། །
Enumeration Block 23:
གཉིས་པ་བསྙེན་གནས་ཀྱི་སྡོམ་པའི་ཁྱད་པར་ལ་གསུམ། ལེན་ཐབས། ཡན་ལག་གི་ངེས་པ། རྟེན་གྱི་ངེས་པའོ། །

Enumeration Block 1:
གཉིས་པ་རྣམ་པར་རིག་བྱེད་ཀྱི་ལྡན་ཚུལ་ལ་གཉིས། དངོས་དང་། ཞར་བྱུང་ངོ་། །
Enumeration Block 2:
གསུམ་པ་འཐོབ་གཏོང་ལ་གཉིས། འཐོབ་ཚུལ་དང་། གཏོང་ཚུལ་ལོ། །དང་པོ་ལ་གསུམ། སྡོམ་པའི་འཐོབ་ཚུལ། སྡོམ་མིན་གྱི་འཐོབ་ཚུལ། བར་མའི་འཐོབ་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། ཇི་ལྟར་འཐོབ་པ་དང་། གང་ལས་འཐོབ་པའོ། །དང་པོ་ལ་གཉིས། བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པ་འཐོབ་ཚུལ། སོ་ཐར་གྱི་སྡོམ་པ་འཐོབ་ཚུལ་ལོ། །
Enumeration Block 3:
གཉིས་པ་སོ་ཐར་གྱི་སྡོམ་པ་འཐོབ་ཚུལ་ལ། དངོས་དང ་། ཞར་བྱུང་གཉིས།
Enumeration Block 4:
གཉིས་པ་ཞར་བྱུང་ལ་གསུམ། སྡོམ་པ་སྡོམ་མིན་གྱི་དུས་ཀྱི་ངེས་པ། བསྙེན་གནས་ཀྱི་སྡོམ་པའི་ཁྱད་པར། དགེ་བསྙེན་གྱི་སྡོམ་པའི་ཁྱད་པར་རོ། །
Enumeration Block 5:
གཉིས་པ་བསྙེན་གནས་ཀྱི་སྡོམ་པའི་ཁྱད་པར་ལ་གསུམ། ལེན་ཐབས། ཡན་ལག་གི་ངེས་པ། རྟེན་གྱི་ངེས་པའོ། །
Enumeration Block 6:
གསུམ་པ་དགེ་བསྙེན་གྱི་སྡོམ་པའི་ཁྱད་པར་ལ་གསུམ། དངོས་དང་། སྐྱབས་འགྲོའི་ཡུལ་བྱེ་བྲག་ཏུ་བཤད་པ། ཡན་ལག་གི་ངེས་པའོ། །
Enumeration Block 7:
གཉིས་པ་གཏོང་ཚུལ་ལ་གསུམ། སྡོམ་པའི། སྡོམ་མིན་གྱི། བར་མའི་གཏོང་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། སོ་ཐར་གྱི་སྡོམ་པའི། བསམ་གཏན་ཟག་མེད་ཀྱི་སྡོམ་པའི་གཏོང་ཚུལ་ལོ། །
Enumeration Block 8:
གཉིས་པ་མདོ་ལས་འབྱུང་བའི་མིང་གི་རྣམ་གྲངས་ལ་བཅོ་ལྔ་ཡོད་པ་ལས།
Enumeration Block 9:
གཉིས་པ་འབྲས་བུའི་སྒོ་ནས་དབྱེ་བ་ལ་གཉིས། བསྟན། བཤད་དོ། །
Enumeration Block 10:
ལས་དེ་ལ་གསུམ་ཡོད་དེ། བསོད༵་ནམ༵ས་ཀྱི་ལས་དང་། བསོད༵་ནམ༵ས་མིན༵་པའི་ལས་དང་། མི༵་གཡོ༵་བའི་ལས་རྣམས་སུ་ཡོད་པའི་ཕྱིར། ཡང་ལས་དེ་ལ་གསུམ་ཡོད་དེ། བདེ༵་བ༵་མྱོང༵་བར༵་འགྱུར༵་བའི་ལས་ལ༵་སོགས༵་པ་གསུ༵་ཡོད་པའི་ཕྱིར། །
Enumeration Block 11:
གཉིས་པ་རྒྱས་པ་བཤད་ལ་གཉིས། བསོད་ནམས་སོགས་བཤད་པ་དང་། བདེ་སོགས་བཤད་པའོ། །
Enumeration Block 12:
གཉིས་པ་བདེ་སོགས་བཤད་པ་ལ་གསུམ། མྱོང་འགྱུར་གསུམ་པོ་སོ་སོའི་མཚན་གཞི། མྱོང་འགྱུར་གྱི་དབྱེ་བ། ལས་གང་གི་འབྲས་བུ་ཚོར་བ་གང་ཡིན་པའོ། །དང་པོ་ལ་གཉིས། རང་ལུགས་དང་། གཞན་ལུགས་སོ། །
Enumeration Block 13:
གཉིས་པ་མྱོང་འགྱུར་གྱི་དབྱེ་བ་ལ་གཉིས། ལྔར་དབྱེ་བ། རྣམ་སྨིན་མྱོང་འགྱུར་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 14:

ཡང་དེ་དག་བཅུར་ཡང་བཤད་དེ། ཇི་ལྟར་ཞེ་ན། ལྟ྄༷་བ༵་ལ༵་ལྔ༵་སྟེ༵། འཇིག༵་ཚོག༵ས་ལ་ལྟ་བ་དང༵་། སྐུར་འདེབས་ལོག༵་ལྟ་དང༵་། སྒྲོ་འདོགས་མཐར༵་འཛིན༵་པར་ལྟ྄༷་བ༵་དང༵་། ལྟ྄༷་བ༵་མཆོག་འཛིན་དང༵་ནི༵། ཚུལ༵་ཁྲིམ༵ས་དང༵་། བརྟུལ༵་ཞུག༵ས་མཆོག༵་ཏུ༵་འཛིན༵་པ་ལ་སྔར་གྱི་བསྣན་པ་དང༵་བཅུ༵་ཡིན་ནོ། །གཉིས་པ་ཁྱད་པར་གྱི་དབྱེ་བ་ནི། ཡང་ཕྲ་རྒྱས་དེ་ལ་རྣམ་པ་དང་། བྱེ་བྲག་དང་། ཁམས་ཀྱི་སྒོ་ནས་དབྱེ་ན་དགུ་བཅུ་རྩ་བརྒྱད་དུ་འདོད་དེ།
Enumeration Block 9:
གཉིས་པ་ཞར་བྱུང་ལ་ལྔ། སྤང་བྱ་ངེས་པ། ལྟ་བ་སོ་སོའི་མཚན་ཉིད། ལྟ་བ་ཐ་མ་དང་འབྲེལ་བའི་རྩོད་སྤང་། ཕྱིན་ཅི་ལོག་གི་རབ་དབྱེ། ང་རྒྱལ་གྱི་དབྱེ་བ་སྤྲོས་པ་དང་བཅས་པའོ། །
Enumeration Block 10:
ཕྱིན་ཅི་ལོག་བཞི་ཡོད་པའི་ཕྱིར་ཏེ། མི་རྟག་པ་ལ་རྟག་པར་ཕྱིན་ཅི་ལོག ། མི་གཙང་བ་ལ་གཙང་བར། སྡུག་བསྔལ་བ་ལ་བདེ་བར། བདག་མེད་པ་ལ་བདག་ཏུ་ཕྱིན་ཅི་ལོག་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 11:
ང་རྒྱལ་ལའང་བདུན་ཡོད་དེ། ང་རྒྱལ་དང་། ལྷག་པའི་ང་རྒྱལ་དང་། ང་རྒྱལ་ལས་ཀྱང་ང་རྒྱལ་དང་། ངའོ་སྙམ་པའི་ང་རྒྱལ་དང་། མངོན་པའི་ང་རྒྱལ་དང་། ཅུང་ཟད་སྙམ་པའི་ང་རྒྱལ་དང་། ལོག་པའི་ང༵་རྒྱལ༵་ཏེ་རྣམ་པ་བདུན༵་ཡོད་པའི་ཕྱིར།
Enumeration Block 12:
བསྟན་བཅོས་ཡེ་ཤེས་ལ་འཇུག་པ་ལས་དགུ་གསུངས་ཏེ། གཞན་ལ་ལྟོས་ཏེ་བདག་སྒྲུབ་པ་གསུམ། བདག་ལ་ལྟོས་ཏེ་གཞན་སྒྲུབ་པ་གསུམ། བདག་ལ་ལྟོས་ཏེ་གཞན་འགོག་པ་གསུམ་མོ། །དང་པོ་གསུམ་ཡོད་དེ། བདག་གཞན་ལས་ཁྱད་པར་དུ་འཕགས་སོ། །གཞན་དང་མཉམ་མོ། །གཞན་ལས་དམན་ནོ་ཞེས་པ་གསུམ་མོ། །གཉིས་པ་གསུམ་ཡོད་དེ། གཞན་བདག་ལས་ཁྱད་པར་དུ་འཕགས་སོ། །བདག་དང་མཉམ་མོ། །བདག་ལས་དམན་ནོ་ཞེས་པ་གསུམ་མོ། །གསུམ་པ་གསུམ་ཡོད་དེ། བདག་ལས་ཁྱད་པར་དུ་འཕགས་པ་མེད་དོ། །བདག་དང་མཉམ་པ་མེད་དོ། །བདག་ལས་དམན་པ་མེད་དོ་ཞེས་པ་གསུམ་མོ། །
Enumeration Block 13:
གཉིས་པ་རྣམ་པའི་བྱེ་བྲག་ལ་ལྔ། རྒྱུ་ལ་ལྟོས་པའི་རབ་དབྱེ། དམིགས་ཡུལ་ལ་ལྟོས་པའི་རབ་དབྱེ། ངོ་བོ་ལ་ལྟོས་པའི་རབ་དབྱེ། དུས་ལ་ལྟོས་པའི་ལྡན་ཚུལ། ཡུལ་ཡུལ་ཅན་གྱི་བྱེ་བྲག་གོ །
Enumeration Block 14:
གསུམ་པ་ངོ་བོ་ལ་ལྟོས་པའི་རབ་དབྱེ་ལ་གསུམ། དངོས་དང་། རྩ་བའི་བྱེ་བྲག ། དྲི་བ་ལུང་མ་བསྟན་གྱི་ཞར་བྱུང་ངོ་། །
Enumeration Block 15:
བཞི་ཡོད་དེ། མགོ༵་གཅིག༵་པ་དང༵་། རྣམ༵་པར་ཕྱེ༷་བ་དང༵་། དྲི༵་བ་དང༵་། གཞག༵་པར༵་ལུང༵་བསྟན༵་པ༵་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 16:
བཞི་པ་དུས་ལ་ལྟོས་པའི་ལྡན་ཚུལ་ལ་གསུམ། དངོས་དང་། ཞར་ལ་དུས་གསུམ་གྱི་རྣམ་གཞག་དཔྱད་པ། སྤངས་པ་དང་བྲལ་བའི་ཁྱད་པར་རོ། །
Enumeration Block 17:
སྤྱིར་ཉོན་མོངས་པ་ལ་ཉོན་མོངས་རང་གི་མཚན་ཉིད་པ་དང་། ཉོན་མོངས་སྤྱི་པ་གཉིས་ཡོད་ལ།

Enumeration Block 1:
གསུམ་པ་ངོ་བོ་ལ་ལྟོས་པའི་རབ་དབྱེ་ལ་གསུམ། དངོས་དང་། རྩ་བའི་བྱེ་བྲག ། དྲི་བ་ལུང་མ་བསྟན་གྱི་ཞར་བྱུང་ངོ་། །
Enumeration Block 2:
བཞི་ཡོད་དེ། མགོ༵་གཅིག༵་པ་དང༵་། རྣམ༵་པར་ཕྱེ༷་བ་དང༵་། དྲི༵་བ་དང༵་། གཞག༵་པར༵་ལུང༵་བསྟན༵་པ༵་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
བཞི་པ་དུས་ལ་ལྟོས་པའི་ལྡན་ཚུལ་ལ་གསུམ། དངོས་དང་། ཞར་ལ་དུས་གསུམ་གྱི་རྣམ་གཞག་དཔྱད་པ། སྤངས་པ་དང་བྲལ་བའི་ཁྱད་པར་རོ། །
Enumeration Block 4:
གཉིས་པ་ཞར་ལ་དུས་གསུམ་གྱི་རྣམ་གཞག་དཔྱད་པ་ལ་གསུམ། ཡུལ་དུས་གསུམ་རྫས་སུ་བསྒྲུབ་པ་དང་། དེ་ལ་རྩོད་པ་དགོད་པ་དང་། དེའི་ལན་གདབ་པའོ། །
Enumeration Block 5:
དུས་གསུམ་གྱི་འདོད་ཚུལ་ལ་རྣམ༵་པ་བཞི༵་ཡོད་དེ། དངོས༵་པོ་གཞན་དུ་འགྱུར་བར་སྨྲ་བ་དང༵་། མཚན༵་ཉིད༵་གཞན་དུ་འགྱུར་བ་དང༵་། གནས༵་སྐབ༵ས་གཞན༵་དུ་འགྱུར་བ་དང་། གཞན༵་དང་གཞན་དུ་འགྱུར༵་བར་སྨྲ་བ་ཞེས༵་བྱ༵་བ་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
སེམས་ཉོན་མོངས་པ་ཅན་དང་། དེ་མིན་པ་གཉིས་ལས།
Enumeration Block 7:
རྒྱས་པར་འགྱུར་བ་དང་། རྒྱས་པར་མི་འགྱུར་ཡང་ཕྲ྄༷་རྒྱས༵་དང་བཅས༵་པ་རྣམ༵་པ་གཉིས༵་ཡོད་དེ།
Enumeration Block 8:
ལྔ་པ་རྣམ་གྲངས་བཤད་པ་ལ་གཉིས། མདོ་ལས་འབྱུང་བའི་རྣམ་གྲངས། བསྟན་བཅོས་ལས་འབྱུང་བའི་རྣམ་གྲངས་སོ། །དངོས་ལ་བཞི། ཟག་པ། ཆུ་སྦྱོར། ཉེར་ལེན། དེ་དག་གི་ངེས་པ་བཤད་པའོ། །
Enumeration Block 9:
ཟག་པ་ནི་གསུམ་སྟེ། འདོད་པའི་ཟག་པ། སྲིད་པའི་ཟག་པ། མ་རིག་པའི་ཟག་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 10:
གཉིས་པ་བསྟན་བཅོས་ལས་འབྱུང་བའི་རྣམ་གྲངས་ལ་གཉིས། བསྟན། བཤད་དོ། །
Enumeration Block 11:
ཀུན༵་ཏུ༵་སྦྱོར་བ་དང་། སོག༵ས་ཀྱིས༵་འཆིང་བ་དང་། ཕྲ་རྒྱས་དང་། ཉེ་བའི་ཉོན་མོངས་པ་དང་། ཀུན་ནས་དཀྲིས་པ་རྣམས་ཀྱི་དབྱེ༵་བས༵་ཡང༵་རྣམ༵་པ་ལྔར༵་མདོ་དང་ཆོས་མངོན་པ་ལས་ཕྱེ་ནས་བཤད༵་དོ༵། །
Enumeration Block 12:

Enumeration Block 15:
དེ་ལ་བར་སྲིད་མེད་པས་སྐྱེས་འདའ་བ་ནས་གོང་འཕོའི་བར་རྣམ༵་པ་བཞི༵་ཡིན་ནོ། །
Enumeration Block 16:
གཉིས་པ་དོན་གྱི་ཁྱད་པར་ནི། བར་དོར་འདའ་བ་དང་། སྐྱེས་འདའ་བ་དང་། གོང་འཕོ་སྟེ་གསུ༵་པོ་རེ་རེ་ལ༵་ཡང༵་རྣམ༵་པ་གསུ༵་གསུམ་དུ་ཕྱེ༷་ནས༵་གཟུག༵ས་སུ༵་ཉེར༵་འགྲོ༵འི་ཕྱིར་མི་འོང་དགུར༵་ཡང་བཤད༵དོ༵། །འབྱེད་ཚུལ་ནི་དང་པོ་ལ་ལྕགས་ཀྱི་ཚྭ་ཚྭའི་དཔེས་མྱུར་བ་དང་། མྱུར་བ་མ་ཡིན་པ་དང་། ཆེས་རིང་མོ་ནས་འདའ་བ་གསུམ་དང་། གཉིས་པ་ལ་སྐྱེས་མ་ཐག་པ་དང་། འདུ་བྱེད་དང་བཅས་པ་དང་། བྱེད་མིན་དུ་འདའ་བའོ། །གསུམ་པ་ལ་འཕར་བ། ཕྱེད་འཕར་བ། གནས་ཐམས་ཅད་དུ་འགྲོ་བའོ། །

Enumeration Block 1:
གཉིས་པ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གསུམ། དབྱེ་བ། སྤེལ་མ་སྒོམ་པ། ལུས་མངོན་བྱེད་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དངོས་དང་། དོན་གྱི་ཁྱད་པར་རོ། །དང་པོ་ནི། ཕྱིར་མི་འོང་ལ་གཟུགས་སུ་ཉེར་འགྲོ་དང་། གཟུགས་མེད་ཉེར་འགྲོ་གཉིས་ལས། 
Enumeration Block 2:
ཕྱིར་མི་འོང་གཟུགས་སུ་ཉེར་འགྲོ་དེ༵་ནི༵་ལྔ་ཡོད་དེ།
Enumeration Block 3:
བཤད་མ་ཐག་པའི་གོང་དུ་འཕོ་བ་དེ༵་ནི༵་ལྷག་མཐོང་ལ་དགའ་བ་དང་། ཞི་གནས་ལ་དགའ་བའི་རིགས་གཉིས་ལས། 
Enumeration Block 4:
དེ༵་ལའང་འཕར༵་བ་དང་། ཕྱེད༵་དུ་འཕར༵་བ་དང་། གནས་ཐམ༵ས་ཅད༵་དུ་འཆི༵་འཕོ༵་བ་གསུམ་ཡོད་དེ།
Enumeration Block 5:
སྐྱེས་འདའ་བ་ནས་གོང་འཕོའི་བར་རྣམ༵་པ་བཞི༵་ཡིན་ནོ། །
Enumeration Block 6:
གཉིས་པ་དོན་གྱི་ཁྱད་པར་ནི། བར་དོར་འདའ་བ་དང་། སྐྱེས་འདའ་བ་དང་། གོང་འཕོ་སྟེ་གསུ༵་པོ་རེ་རེ་ལ༵་ཡང༵་རྣམ༵་པ་གསུ༵་གསུམ་དུ་ཕྱེ༷་ནས༵་གཟུག༵ས་སུ༵་ཉེར༵་འགྲོ༵འི་ཕྱིར་མི་འོང་དགུར༵་ཡང་བཤད༵དོ༵། །འབྱེད་ཚུལ་ནི་དང་པོ་ལ་ལྕགས་ཀྱི་ཚྭ་ཚྭའི་དཔེས་མྱུར་བ་དང་། མྱུར་བ་མ་ཡིན་པ་དང་། ཆེས་རིང་མོ་ནས་འདའ་བ་གསུམ་དང་། གཉིས་པ་ལ་སྐྱེས་མ་ཐག་པ་དང་། འདུ་བྱེད་དང་བཅས་པ་དང་། བྱེད་མིན་དུ་འདའ་བའོ། །གསུམ་པ་ལ་འཕར་བ། ཕྱེད་འཕར་བ། གནས་ཐམས་ཅད་དུ་འགྲོ་བའོ། །
Enumeration Block 7:
བཞི་པ་དགྲ་བཅོམ་ལ། ཞུགས་པ་དང་། གནས་པ་གཉིས། 
Enumeration Block 8:
གཉིས་པ་གནས་པ་ལ་བདུན། དངོས་དང་། ཞར་ལ་སྤང་བྱ་སྤོང་ཚུལ། ཤེས་པའི་འབྱུང་ཚུལ། དགེ་སྦྱོང་ཚུལ་གྱི་བསྡུ་བ། ཚངས་པའི་འཁོར་ལོ། དགེ་སྦྱོང་ཚུལ་གྱི་འབྲས་བུ་འཐོབ་ཚུལ། དགྲ་བཅོམ་གྱི་དབྱེ་བའོ། །
Enumeration Block 9:
གཉིས་པ་ཞར་ལ་སྤང་བྱ་སྤོང་ཚུལ་ལ་གསུམ། ལམ་གང་གིས་ས་གང་གི་སྤང་བྱ་སྤོང་། ས་གང་གིས་ས་གང་གི་སྤང་བྱ་སྤོང་། ཞར་ལ་འཇིག་རྟེན་པའི་ལམ་གྱིས་དམིགས་རྣམ་མོ། །དང་པོ་ནི། འཕགས་པ་དག་ས་དང་ས་ལས་འདོད་ཆགས་དང་བྲལ་ན་གཉེན་པོ་གང་གིས་ས་གང་ལས་འདོད་ཆགས་དང་བྲལ་ཞེ་ན། འདི་ལྟར་བསྒོམ་པའི་ལམ་ནི་འཇིག་རྟེན་དང་དེ་ལས་འདས་པ་གཉིས་ལས། 
Enumeration Block 10:
བདུན་པ་དགྲ་བཅོམ་གྱི་དབྱེ་བ་ལ་བཞི། དངོས་དང་། ཆོས་ཀྱི་ཁྱད་པར། ཉམས་པའི་དབྱེ་བ། དབང་པོའི་འཕོ་ཚུལ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 11:
ཉན་ཐོས་དགྲ྄༷་བཅོམ༵་པ་ནི་དྲུག༵་ཏུ༵་འདོད༵་དེ། རྐྱེན་ཆུང་ངུས་ཀྱང་རྟོགས་པ་ལས་ཡོངས་སུ་ཉམས་པའི་ཆོས་ཅན་དང་། ཉམས་པར་དོགས་པས་འཆི་བར་སེམས་པའི་ཆོས་ཅན་དང་། ཉམས་པར་དོགས་པས་རྗེས་སུ་བསྲུང་བའི་ཆོས་ཅན་དང་། རྐྱེན་ཆུང་ངུས་རྟོགས་པ་ལས་མི་བསྐྱོད་པའི་ཆོས་ཅན་དང ་། དབང་པོ་འཕོས་ཏེ་མི་གཡོ་བ་རྟོགས་པའི་སྐལ་པ་ཅན་དང་། དབང་པོ་རྣོ་བས་རྟོགས་པ་ལས་ཉམས་མི་སྲིད་པས་མི་གཡོ་བ་རྣམས་སོ། །
Enumeration Block 12:
ཡོང༵ས་སུ་ཉམ༵ས་པ་རྣམ༵་པ༵་གསུ༵་དུ་ཤེས༵་པར་བྱ༵་སྟེ། ཡོན་ཏན་ཐོབ་པ་ཤོར་བ་ཐོབ༵་པ་ལས་ཉམས་པ་དང༵་། ཐོབ་པར་བྱ་བ་མ༵་ཐོབ༵་པ་མ་ཐོབ་པ་ལས་ཉམས་པ་དང་། ཐོབ་པ་མངོན་དུ་མ་བྱས་པ་ཐོབ་པ་ཉེར༵་སྤྱད༵་ལས༵་ཉམས་པ་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 13:
