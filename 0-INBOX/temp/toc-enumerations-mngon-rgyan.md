Enumeration Block 1:
འདི་ཡང་བཤད་པ་ལ་འཇུག་པ་དང་། བཤད་པ་འགོད་པ་དང་། ཡོངས་སུ་རྫོགས་པའི་བྱ་བ་གསུམ་གྱིས་ངེས་པར་བྱའོ། །དང་པོ་ལའང་གསུམ་ལས་མཆོད་པར་བརྗོད་ཅིང་བཤད་པར་དམ་བཅའ་བ་ལའང་གཉིས་ཀྱི་
Enumeration Block 2:
འདི་ལ་གསུམ་ལས་དང་པོ། འདི་ཡང་དོན་གསུམ་གྱིས་ངེས་པར་བྱ་སྟེ། དགོས་པ་དང་། བསྡུས་པ་དང་། ཚིག་གི་དོན་ཏོ། དང་པོ་ལའང་གཉིས་ལས་མཆོད་པར་བརྗོད་པའི་དགོས་པའི་དོན་ནི་
Enumeration Block 3:
གནས་སྐབས་དང་མཐར་ཐུག་ཀྱི་དགོས་པ་གཉིས་ལས་དང་པོ་ལའང་གསུམ་ཡོད་དེ། སྟོན་པའི་ཆེ་བ་ཤེས་པ་དང་། བསོད་ནམས་འཕེལ་བ་དང་། དམ་པ་རྣམས་ཀྱི་སྤྱོད་པ་དང་མཐུན་པའོ། །
Enumeration Block 4:
གཉིས་པ་བཤད་པར་དམ་བཅའ་བ་ལའང་གསུམ་ལས་དང་པོ་འི་དགོས་པ་ལ་གཉིས་ལས་
Enumeration Block 5:
གསུམ་པ་ཚིག་གི་དོན་ལ་གཉིས་ལས་མཆོད་ཡུལ་ངོས་གཟུང་བ་ནི་
Enumeration Block 6:
དེ་ལ་ཇི་ལྟར་མཆོད་པར་བརྗོད་པ་ལ་བསྟོད་པ་དང་ཕྱག་གཉིས་ལས་དང་པོ་ལ་གསུམ་གྱི་རང་དོན་ལ་སྤངས་རྟོགས་གཉིས་ལས་
Enumeration Block 7:
བསྡུས་པའི་དོན་ནི་གང་གིས་གང་ཇི་ལྟར་བཤད་པར་བྱ་བ་གསུམ་གྱིས་བསྟན་ཏོ། །
Enumeration Block 8:
ཆོས་མངོན་པའི་ངོ་བོ་དང་དབྱེ་བ་དང་འཁོར་དང་བཅས་ན་ཕུང་པོ་དུ་ཡིན་པ་དང་། ངེས་ཚིག་བཞི་ལས་
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས་སུ་དབྱེ་བ་དང་། གསུམ་དུ་དབྱེ་བ་གཉིས་ཀྱི་དང་པོ་ཆོས་མངོན་པ་ནི་རྣམ་པ་གཉིས་ཏེ། དོན་དམ་པ་དང་། བརྡར་བཏགས་པའོ། །
Enumeration Block 10:
གསུམ་པ་འཁོར་དང་བཅས་ན་ཕུང་པོ་དུ་ཡིན་པ་ལ་གཉིས་ལས་
Enumeration Block 11:
གཉིས་པ་བརྡར་བཏགས་པའི་ཆོས་མངོན་པའང་རྣམ་པ་གཉིས་ཏེ། དོན་དམ་པའི་ཆོས་མངོན་པ་དེ་ཐོབ་པར་བྱ་བའི་ཕྱིར་ཞུགས་པའི་རྒྱུ་སྐྱེས་ཐོབ་དང་ཐོས་དང་བསམ་པ་དང་བསྒོམས་པ་ལས་བྱུང་བའི་ཤེས་རབ་ཟག་བཅས་རྗེས་འབྲང་དང་བཅས་པ་གང་དང་། དེ་དག་རྗོད་པར་བྱེད་པའི་བསྟན་བཅོས་ཀྱིས་བསྡུས་པའི་ཆོས་མངོན་པ་གང་ཡིན་པ་སྟེ།
Enumeration Block 12:
གསུམ་དུ་དབྱེ་བ་ནི་ཟག་མེད་ཀྱི་ཤེས་རབ་འབྲས་བུའི་ཆོས་མངོན་པ་དང་། སྐྱེས་ཐོབ་ཀྱི་ཤེས་རབ་ལ་སོགས་པ་བཞི། རྒྱུའི་ཆོས་མངོན་པ་དང་། བསྟན་བཅོས་ནི་གཞུང་གི་ཆོས་མངོན་པ་དང་གསུམ་དུ་འགྱུར་སྟེ།
Enumeration Block 13:
འདི་ལ་དགོས་པ་དང་། བསྡུས་པ་དང་། ཚིག་གི་དོན་གསུམ་གྱི་དང་པོ་ལའང་གསུམ་ལས་
Enumeration Block 14:
བསྟན་བཅོས་ཀྱི་ལུས་ལ་དགོས་པ་ལ་སོགས་པ་བཞི་ཡོད་པར་བསྟན་པ་ཡིན་ནོ། །དེ་ལ་གཉིས་ལས་

Enumeration Block 1:
འདི་ལ་དགོས་པ་དང་། བསྡུས་པ་དང་། ཚིག་གི་དོན་གསུམ་གྱི་དང་པོ་ལའང་གསུམ་ལས
Enumeration Block 2:
དེ་ལ་ཡོད་པའི་དགོས་འབྲེལ་ལ་གསུམ་ལས
Enumeration Block 3:
ད་ནི་བཤད་པ་དགོད་པ་ལ་མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས་ལས
Enumeration Block 4:
རྒྱས་བཤད་ལ་གསུམ་ལས
Enumeration Block 5:
གལ་ཏེ་དབྱེ་བ་ལ་གཉིས་ལས
Enumeration Block 6:
འགོག་པ་གཉིས་དང་འབྲེལ་བའི་མུ་བཞི་ལ་སྤྱིར་བསྟན་པ་དང་མུ་གསུམ་པ་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས་ལས
Enumeration Block 7:
འདུས་མ་བྱས་རྣམ་པ་གསུམ་པོ་ཉིད་གང་ཞེ་ན། ནམ་མཁའ་དང་ནི་སོ་སོར་བརྟགས་འགོག་དང་བརྟགས་མིན་གྱི་འགོག་པ་གཉིས་སོ།
Enumeration Block 8:
དེ་དག་གི་སྤྱིའི་དོན་ནི་གནས་བརྒྱད་ཀྱི་གྲངས་ངེས་པ་དང་རྣམ་བཞག་དང་། འབྲེལ་དང་། གོ་རིམ་ངེས་པ་དང་། གནས་གང་ནས་བརྗོད་བྱ་གང་སྟོན་པ་གསུམ་གྱིས་ངེས་པར་བྱ་བ་ལས
Enumeration Block 9:
སློབ་དཔོན་གང་སྤེལ་ནི་ཟག་བཅས་ཟག་པ་མེད་ཆོས་རྣམས་ཞེས་མདོར་བསྟན་པའི་དོན་རྒྱས་པར་འཆད་པའི་དབང་དུ་མཛད་ནས་གནས་བརྒྱད་དུ་མཛད་དོ། །དེ་ལ་ཟག་བཅས་ཟག་མེད་སྤྱིར་བསྟན་པའི་ཕྱིར་གནས་དང་པོ་གཉིས་སོ། །ཟག་བཅས་བྱེ་བྲག་ཏུ་སྟོན་པའི་དབང་དུ་མཛད་ནས་གནས་གསུམ་སྟེ། གང་ཀུན་ནས་ཉོན་མོངས་པ་སེམས་ཅན་གྱི་འཇིག་རྟེན་ཁམས་གསུམ་དང་འགྲོ་བ་ལྔ་དང་། གང་དུ་ཀུན་ནས་ཉོན་མོངས་པ་སྣོད་ཀྱི་འཇིག་རྟེན་དང་། ཇི་ལྟར་ཀུན་ནས་ཉོན་མོངས་པ་སྐྱེ་གནས་བཞི་དང་རྟེན་འབྲེལ་ཡན་ལག་བཅུ་གཉིས་སྟོན་པ་འཇིག་རྟེན་བསྟན་པའི་མཛོད་དང་། གང་གིས་ཀུན་ནས་ཉོན་མོངས་པར་བྱེད་པའི་དབང་དུ་མཛད་ནས་ལས་བསྟན་པ་དང་ཕྲ་རྒྱས་བསྟན་པའི་མཛོད་བསྟན་ཏོ།
Enumeration Block 10:
ཟག་མེད་བྱེ་བྲག་ཏུ་སྟོན་པའི་དབང་དུ་བྱས་ནས་གནས་ཕྱི་མ་གསུམ་སྟེ། གང་རྣམ་པར་བྱང་བའི་གང་ཟག་དང་། གང་དུ་རྣམ་པར་བྱང་བའི་ཁམས་གསུམ་དང་། ཇི་ལྟར་རྣམ་པར་བྱང་བའི་མངོན་པར་རྟོགས་པའི་རིམ་པ་སྟོན་པ་ལམ་དང་གང་ཟག་བསྟན་པའི་མཛོད་དང་། གང་གིས་རྣམ་པར་བྱང་བར་བྱེད་པ་ཡེ་ཤེས་བསྟན་པའི་མཛོད་དང་། ཡེ་ཤེས་ཀྱི་རྟེན་བསྟན་པའི་དབང་དུ་མཛད་ནས་སྙོམས་འཇུག་བསྟན་པའི་མཛོད་བསྟན་ཏོ་ཞེས་འཆད་དེ།
Enumeration Block 11:

ང་རྒྱལ་ཡང་ཡུལ་གྱི་སྒོ་ནས་རྣམ་པ་བདུན་ཡིན་ནོ། །གང་ཞེ་ན། སེམས་ཁེངས་པ་ནི་ང་རྒྱལ་སྤྱིའི་མཚན་ཉིད་ཡིན་ལ་རྣམ་པའམ་ཡུལ་གྱི་བྱེ་བྲག་ལས་ནི་ཆུང་ངུ་བས་བདག་ཁྱད་པར་དུ་འཕགས་པའམ་མཉམ་པ་དང་མཉམ་མོ་སྙམ་ནས་སེམས་ཁེངས་པའི་ང་རྒྱལ་དང་། མཉམ་པ་བས་བདག་ཁྱད་པར་དུ་འཕགས་པའམ་མཆོག་དང་མཉམ་མོ་སྙམ་པ་ལྷག་པའི་ང་རྒྱལ་དང་། ཁྱད་པར་དུ་འཕགས་པ་བས་ཀྱང་བདག་ཁྱད་པར་དུ་འཕགས་སོ་སྙམ་པ་ང་རྒྱལ་ལས་ཀྱང་ང་རྒྱལ་དང་། ཉེར་ལེན་གྱི་ཕུང་པོ་ལྔ་ལ་བདག་གམ་བདག་གིར་སེམས་ཁེངས་པ་ངའོ་སྙམ་པའི་ང་རྒྱལ་དང་། བསམ་གཏན་ལ་བརྟེན་པའི་ཟག་བཅས་ཟག་མེད་ཀྱི་ཡོན་ཏན་མ་ཐོབ་པ་ལ་ཐོབ་པར་རློམ་པ་མངོན་པའི་ང་རྒྱལ་དང་། ཆེས་ཁྱད་པར་དུ་འཕགས་པ་བས་བདག་ཅུང་ཟད་ཅིག་གིས་དམན་ནོ་སྙམ་དུ་སེམས་ཁེངས་པ་ཅུང་ཟད་སྙམ་པའི་ང་རྒྱལ་དང་། གསོད་པ་ལ་དཔའ་བ་ལ་སོགས་པ་ཡོན་ཏན་མ་ཡིན་པ་ལ་ཡོན་ཏན་དུ་ལྟ་བས་སེམས་ཁེངས་པ་ལོག་པའི་ང་རྒྱལ་དང་།
Enumeration Block 2:
ལུང་དུ་མ་བསྟན་པའི་རྩ་བ་ནི་གསུམ་མོ། །
Enumeration Block 3:
ལུང་དུ་མ་བསྟན་པའི་རྩ་བ་ནི་བཞི་ཡིན་ནོ་ཞེས་ཉི་འོག་པ་བྱེ་བྲག་ཏུ་སྨྲ་བ་རྣམས་འདོད་དེ། བཞི་པོ་དེ་དག་ཀྱང་གང་ཞེ་ན། ཁམས་གོང་མ་གཉིས་ཀྱི་སྲེད་པ་དང་ལྟ་བ་ཐམས་ཅད་དང་། འདོད་པ་ན་ལུང་མ་བསྟན་གྱི་ལྟ་བ་དང་པོ་གཉིས་དང་། ཁམས་གོང་མ་གཉིས་ཀྱི་ང་རྒྱལ་དང་། སྔར་བཤད་པའི་རྨོངས་པ་རྣམས་ཡིན་ནོ། །
Enumeration Block 4:
དྲིས་པ་ལུང་བསྟན་པ་ནི་རྣམ་པ་བཞི་སྟེ། བཞི་གང་ཞེ་ན། མགོ་གཅིག་ཏུ་དྲིས་པ་ལུང་བསྟན་པ་དང་། རྣམ་པར་ཕྱེ་སྟེ་དྲིས་པ་ལུང་བསྟན་པ་དང་། དྲི་བ་དྲིས་ཏེ་ལུང་བསྟན་པ་དང་། རྣམ་པར་བཞག་པ་ལུང་བསྟན་པའོ། །
Enumeration Block 5:
དུས་གསུམ་རྫས་སུ་ཡོད་པར་འདོད་པའི་ཐམས་ཅད་ཡོད་པར་སྨྲ་བ་དེ་དག་ཀྱང་དབྱེ་ན་རྣམ་པ་བཞི་ཡིན་ཏེ། དངོས་པོ་གཞན་དུ་འགྱུར་བ་དང་། མཚན་ཉིད་གཞན་དུ་འགྱུར་བ་དང་། གནས་སྐབས་གཞན་དུ་འགྱུར་བ་དང་། གཞན་དང་གཞན་དུ་འགྱུར་བ་ཞེས་བྱ་བའོ། །

Enumeration Block 1:
གང་དག་དུས་གསུམ་རྫས་སུ་ཡོད་པར་འདོད་པའི་ཐམས་ཅད་ཡོད་པར་སྨྲ་བ་དེ་དག་ཀྱང་དབྱེ་ན་རྣམ་པ་བཞི་ཡིན་ཏེ། དངོས་པོ་གཞན་དུ་འགྱུར་བ་དང་། མཚན་ཉིད་གཞན་དུ་འགྱུར་བ་དང་། གནས་སྐབས་གཞན་དུ་འགྱུར་བ་དང་། གཞན་དང་གཞན་དུ་འགྱུར་བ་ཞེས་བྱ་བའོ། །
Enumeration Block 2:
ཡུལ་ཆོས་ཐམས་ཅད་ནི་རྣམ་པ་བཅུ་དྲུག་ཏུ་འདུས་ཏེ། ཁམས་གསུམ་ན་སྤང་བྱ་རིས་ལྔ་ལྔ་དང་། ཟག་པ་མེད་པའོ། །
Enumeration Block 3:
ཡུལ་དེ་ཆོས་གང་དུ་གཏོགས་པ་དང་། དེ་སེམས་དུའི་ཡུལ་དུ་འགྱུར་བ་དང་། ཡུལ་ཅན་གྱི་སེམས་དེ་ཕྲ་རྒྱས་ཡིན་མིན་དང་། ཕྲ་རྒྱས་ཡིན་པ་དེ་ཡུལ་དེ་ལ་རྒྱས་མི་རྒྱས་དཔྱད་པ་བཞིས་
Enumeration Block 4:
རྒྱས་པ་དང་མི་རྒྱས་པའི་བཅས་པ་རྣམ་པ་གཉིས་ལས་
Enumeration Block 5:
སེམས་ཉོན་མོངས་ཅན་ཕྲ་རྒྱས་དང་བཅས་པ་དེ་ཡང་རྒྱས་པ་དང་མི་རྒྱས་པ་རྣམ་པ་གཉིས་སོ། །
Enumeration Block 6:
མདོ་ལས་གསུངས་པའི་ཟག་པ་ལ་སོགས་པའི་དབྱེ་བ་བསྟན་པ་ལ་ཟག་པ་དང་། ཆུ་བོ་དང་། སྦྱོར་བ་དང་། ཉེར་ལེན་དང་། ཕྲ་རྒྱས་ལ་སོགས་པའི་མིང་དོན་དང་། ཀུན་སྦྱོར་དང་། འཆིང་བ་དང་། ཉེ་བའི་ཉོན་མོངས་དང་། ཀུན་དཀྲིས་དང་། དྲི་མ་དང་། དེ་དག་གི་རྣམ་པའི་རབ་དབྱེ་དང་། སྒྲིབ་པ་ལྔ་བཤད་པ་དང་བཅུ་གཅིག་ལས་
Enumeration Block 7:
འདོད་པའི་ཟག་པ་དང་། སྲིད་པའི་ཟག་པ་དང་། མ་རིག་པའི་ཟག་པའོ་ཞེས་ཟག་པ་གསུམ་དུ་གསུངས་པ་ལས་
Enumeration Block 8:
ཆུ་བོ་ནི་བཞི་སྟེ། འདོད་པའི་ཆུ་བོ་དང་། སྲིད་པའི་ཆུ་བོ་དང་། ལྟ་བའི་ཆུ་བོ་དང་། མ་རིག་པའི་ཆུ་བོའོ་
Enumeration Block 9:
སྦྱོར་བ་ནི་བཞི་སྟེ། འདོད་པའི་སྦྱོར་བ་དང་། སྲིད་པའི་སྦྱོར་བ་དང་། ལྟ་བའི་སྦྱོར་བ་དང་། མ་རིག་པའི་སྦྱོར་བའོ་
Enumeration Block 10:
ཉེ་བར་ལེན་པ་ནི་བཞི་སྟེ། འདོད་པ་ཉེ་བར་ལེན་པ་དང་། ལྟ་བ་ཉེ་བར་ལེན་པ་དང་། ཚུལ་ཁྲིམས་དང་བརྟུལ་ཞུགས་མཆོག་ཏུ་འཛིན་པ་ཉེ་བར་ལེན་པ་དང་། བདག་ཏུ་སྨྲ་བ་ཉེ་བར་ལེན་པའོ་
Enumeration Block 11:
ཕྲ་རྒྱས་དེ་དག་ཉིད་ཀུན་ཏུ་སྦྱོར་བ་དང་། སོགས་པས་གཟུང་བ་འཆིང་བ་དང་། ཕྲ་རྒྱས་དང་། ཉེ་བའི་ཉོན་མོངས་པ་དང་། ཀུན་ནས་དཀྲིས་པ་རྣམས་ཀྱི་དབྱེ་བས་ཡང་རྣམ་པ་ལྔར་མདོ་དང་། ཆོས་མངོན་པ་ལས་ཕྱེ་ནས་བཤད་དོ། །
Enumeration Block 12:
ཀུན་ཏུ་སྦྱོར་བ་ནི་དགུ་སྟེ། རྗེས་སུ་ཆགས་པ་དང་། ཁོང་ཁྲོ་བ་དང་། ང་རྒྱལ་དང་། མ་རིག་པ་དང་། ལྟ་བ་དང་། མཆོག་ཏུ་འཛིན་པ་དང་། ཐེ་ཚོམ་དང་། ཕྲག་དོག་དང་། སེར་སྣའི་ཀུན་ཏུ་སྦྱོར་བ་རྣམས་སོ་
Enumeration Block 13:
ཐ་མའི་ཆ་དང་མཐུན་པའི་ཀུན་ཏུ་སྦྱོར་བ་ལྔ་སྤངས་པའི་ཕྱིར་འཕགས་པ་ཕྱིར་མི་འོང་བ་ཡིན་ཏེ། འདི་ལྟ་སྟེ་འཇིག་ཚོགས་ལ་ལྟ་བ་དང་། ཚུལ་ཁྲིམས་དང་བརྟུལ་ཞུགས་མཆོག་ཏུ་འཛིན་པ་དང་། ཐེ་ཚོམ་དང་། འདོད་པ་ལ་འདུན་པ་དང་། གནོད་སེམས་སོ་
Enumeration Block 14:
