ཁམས་ཀྱི་རྣམ་པའི་རབ་དབྱེ་ལ་བདུན། ངོ་བོ་ལ་ལྟོས་པའི་རབ་དབྱེ། གྲོགས་ལ་ལྟོས་པའི། །རྒྱུ་འབྲས་ལ་ལྟོས་པའི། མོང་དོན་ལ་ལྟོས་པའི། སྤང་བྱ་ལ་ལྟོས་པའི། བྱེད་པ་ལ་ལྟོས་པའི། རབ་དབྱེ་གཞན་བསྟན་པ། དང་པོ་ལ་བསྟན་ཡོད་བསྟན་མེད་ཀྱི་ཁྱད་པར། ཐོགས་བཅས་ཐོགས་མེད་ཀྱི་ཁྱད་པར། དགེ་མི་དགེ་ལུང་མ་བསྟན་གསུམ་གྱི་ཁྱད་པར། ཁམས་གསུམ་གང་རུང་དུ་གཏོགས་པ་དུ་ཡོད་ཀྱི་ཁྱད་པར་དང་བཞི་ཡོད་དེ།
Enumeration Block 2:
གཉིས་པ་གྲོགས་ལ་ལྟོས་བའི་རབ་དབྱེ་ལ། ཟག་བཅས་ཟག་མེད་ཀྱི་ཁྱད་པར། རྟོག་དཔྱོད་དང་བཅས་མ་བཅས་ཀྱི། དམིགས་བཅས་དམིགས་མེད་ཀྱི། ཟིན་མ་ཟིན་གྱི། འབྱུང་བ་འབྱུང་འགྱུར་གྱི། བསགས་མ་བསགས་ཀྱི། གཅོད་བྱེད་གཅད་བྱའི་ཁྱད་པར་ཏེ་བདུན་ཡོད་དེ།
Enumeration Block 3:
གསུམ་པ་ལ། བྱུང་བ་གསུམ་གྱི་ཁྱད་པར། བཏགས་རྫས་ཡིན་མིན་གྱི། ཐོབ་པའི་ཁྱད་པར་ཏེ་གསུམ་ཡོད་དེ།
Enumeration Block 4:
བཞི་པ་ལ། ཕྱི་ནང་གི་ཁྱད་པར། རྟེན་བཅས་དེ་མཚུངས་ཀྱི་ཁྱད་པར་གཉིས་ཡོད་དེ།
Enumeration Block 5:
ལྔ་པ་ལ། མཐོང་སྤང༌། སྒོམ་སྤང༌། སྤང་བྱ་མིན་པའི་ཁྱད་པར་ཏེ།
Enumeration Block 6:
དྲུག་པ་ལ། ལྟ་བ་དང་ལྟ་མིན་གྱི་ཁྱད་པར། དབང་པོས་ཡུལ་འཛིན་ཚུལ་གྱི་ཁྱད་པར། རྟེན་གྱི་ཡུལ་ངེས་པ། དབང་པོ་རྟེན་དུ་འཇོག་ཚུལ། དབང་པོ་ལྔ་ལ་རང་མིང་གི་འདོགས་པའི་རྒྱུ་མཚན། ཡུལ་དབང་རྟེན་གསུམ་གྱི་མཚུངས་པ་རྩི་བ་དང་དྲུག་ཡོད།
Enumeration Block 7:
བདུན་པ་ནི། རྣམ་པར་ཤེས་པ་གང་གིས་ཤེས་པར་བྱ་བ། རྟག་མི་རྟག་གི་ཁྱད་པར། དབང་པོ་དང་དབང་པོ་མ་ཡིན་པའི་ཁྱད་པར་དང་གསུམ་ཡོད་དེ།
Enumeration Block 8:
གཉིས་པ་དབང་པོ་སྟོན་པའི་གནས་བཤད་པ་ལ། དབང་པོའི་རྣམ་གཞགའདུས་བྱས་ཀྱི་སྐྱེ་ཚུལ། རྒྱུ་རྐྱེན་འབྲས་གསུམ་བཤད་པའོ། །དང་པོ་ལ། དབང་པོའི་རང་བཞིན། སྐབས་སུ་བབས་པའི་དབང་པོའི་ངོ་བོ། རྣམ་པའི་རབ་དབྱེ། རྙེད་གཏོང༌། དགེ་སྦྱོང་ཚུལ་གྱི་འབྲས་བུ་དབང་པོ་དུས་ཐོབ་པ། དབང་པོའི་ལྡན་ཚུལ་ལོ། །
Enumeration Block 9:
སྤྱི་དོན། གཞུང་དོན་གཉིས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། ངེས་ཚིགགང་གིས་གང་ལ་དབང་བྱེད་པ། གཞུང་དོན་དང་སྦྱར་ཏེ་བཤད་པའོ། །

Enumeration Block 1:
དབང་པོ་ལ་ཉེར་གཉིས་སུ་གྲངས་ངེས་ཏེ། ཀུན་ནས་ཉོན་མོངས་ཀྱི་ཕྱོགས་ལ་དང་པོ་བཅུ་བཞི། རྣམ་བྱང་གི་ཕྱོགས་ལ་ཕྱི་མ་བརྒྱད་དུ་གྲངས་ངེས་པའི་ཕྱིར།
Enumeration Block 2:
འདིར་ཚོར་བའི་དབང་པོ་ལྔའི་ངོ་བོ་འཆད་པ་ལ། ལུས་ཚོར་སིམ་པ་མ་ཡིན་གང༌། །ཞེས་སོགས་ཤོ་ལོ་ཀ་གཅིག་གིས་སྐབས་སུ་གཉིས་ལས།
Enumeration Block 3:
རྣམ་བྱང་གི་དབང་པོ་རྒྱས་པར་བཤད་པ་ནི། མཐོང་སྒོམ་མི་སློབ་ལམ་ལ་དགུ། གསུམ་ཡིན། ཞེས་པའི་སྐབས་སུ་གཉིས་ལས།
Enumeration Block 4:
གསུམ་པ་དབང་པོའི་རབ་དབྱེ་ལ་གྲོགས་ལ་ལྟོས་བའི་རབ་དབྱེ། རྒྱུ་འབྲས་ལ་ལྟོས་བའི། ངོ་བོ་ལ་ལྟོས་པའི། སྤང་བྱ་ལ་ལྟོས་པའི་རབ་དབྱེ་དང་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
དྲུག་པ་དབང་པོའི་ལྡན་ཚུལ་ལ། ངེས་ལྡན། སྲིད་ལྡན་གཉིས། དང་པོ་ལ། གསུམ། བཞི། ལྔ། བདུན། བཅུ་གཅིག བཅུ་གསུམ་ལྡན་ཏེ་རིམ་བཞིན་དུ་སྟོན་པ་ལ།
Enumeration Block 6:
གཉིས་པ་སྲིད་ལྡན་ལ་ཉུང་ལྡན་མང་ལྡན་གཉིས།
Enumeration Block 7:
གཉིས་པ་འདུས་བྱས་ཀྱི་སྐྱེ་ཚུལ་ལ། གཟུགས་ཅན་གྱི་སྐྱེ་ཚུལ་དང༌། གཟུགས་ཅན་མ་ཡིན་པའི་སྐྱེ་ཚུལ་གཉིས། དང་པོ་ནི། འདོད་ན་དབང་པོ་མེད་པ་དང༌། ཞེས་སོགས་རྐང་བ་བཞིའི་སྐབས་སུ། །གཉིས་ལས།
Enumeration Block 8:
རྡུལ་ལ་རྫས་ཀྱི་རྡུལ་དང༌། བསགས་པའི་རྡུལ་གཉིས་ལས།
Enumeration Block 9:
གཉིས་པ་གཟུགས་ཅན་མ་ཡིན་པའི་སྐྱེ་ཚུལ་ལ། བསྟན། བཤད་གཉིས་ལས། དང་པོ་ནི། སེམས་དང་སེམས་བྱུང་ངེས་ལྷན་ཅིག ཞེས་སོགས་རྐང་པ་ཕྱེད་དང་གསུམ་གྱི་སྐབས་སུ། གཉིས་ལས།
Enumeration Block 10:
སེམས་བྱུང་ལ་དབྱེ་ན། སྡེ་ཚན་དུ་ངེས་པའི་སེམས་བྱུང༌། སྡེ་ཚན་དུ་མ་ངེས་པའི་སེམས་བྱུང་གཉིས། དང་པོ་ལ། སེམས་ཀྱི་ས་མང༌། དགེ་བའི་ས་མང༌། ཉོན་མོངས་ཆེན་པོའི་ས་མང༌། མི་དགེ་བའི་ས་མང༌། ཉོན་མོངས་ཆུང་ངུའི་ས་མང་རྣམས་སུ་ཡོད།

Enumeration Block 1:
རྡུལ་ལ་རྫས་ཀྱི་རྡུལ་དང༌། བསགས་པའི་རྡུལ་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་གཟུགས་ཅན་མ་ཡིན་པའི་སྐྱེ་ཚུལ་ལ། བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 3:
སེམས་དང་སེམས་བྱུང་ངེས་ལྷན་ཅིག ཞེས་སོགས་རྐང་པ་ཕྱེད་དང་གསུམ་གྱི་སྐབས་སུ། གཉིས་ལས།
Enumeration Block 4:
སེམས་བྱུང་ལ་དབྱེ་ན། སྡེ་ཚན་དུ་ངེས་པའི་སེམས་བྱུང༌། སྡེ་ཚན་དུ་མ་ངེས་པའི་སེམས་བྱུང་གཉིས། དང་པོ་ལ། སེམས་ཀྱི་ས་མང༌། དགེ་བའི་ས་མང༌། ཉོན་མོངས་ཆེན་པོའི་ས་མང༌། མི་དགེ་བའི་ས་མང༌། ཉོན་མོངས་ཆུང་ངུའི་ས་མང་རྣམས་སུ་ཡོད།
Enumeration Block 5:
གཉིས་པ་སྡེ་ཚན་དུ་མ་ངེས་པའི་སེམས་བྱུང་ལ་བརྒྱད་ཡོད་དེ།
Enumeration Block 6:
སེམས་དང་ཡིད་དང་རྣམ་ཤེས་ནི། །ཞེས་སོགས་རྐང་པ་བཞིའི་སྐབས་སུ། གཉིས་ལས།
Enumeration Block 7:
མི་ལྡན་པ་ཡི་འདུ་བྱེད་རྣམས། །ཞེས་སོགས་རྐང་པ་ལྔའི་སྐབས་སུ། གཉིས་ལས།
Enumeration Block 8:

Enumeration Block 9:
བཅུ་བཞི་ཡོད་དེ། ཐོབ་པ་སོགས་དེར་ཡོད་པའི་ཕྱིར།
Enumeration Block 10:
དང་པོ་ལ། ཐོབ་པ་བཤད་པ་དང༌། མ་ཐོབ་པ་བཤད་པ་གཉིས་ལས།
Enumeration Block 11:
ཐོབ་པ་རྙེད་དང་ལྡན་པའོ། །ཞེས་པའི་སྐབས་སུ། གཉིས་ལས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། དེའི་ཁྱད་པར་གྱི་ཆོས།
Enumeration Block 12:
ཐོབ་པ་ལ་དབྱེ་ན་གསར་དུ་ཐོབ་པ། ཐོབ་པའི་ཐོབ་པ་གཉིས་ལས། རྙེད་པ་ལ་དབྱེ་ན། གསར་དུ་རྙེད་པ། ཉམས་པ་ལས་རྙེད་པ་གཉིས། ལྡན་པ་ལ་དབྱེ་ན། ཉམས་པ་ལས་ལྡན་པ། ཐོབ་ནས་ལྡན་པའི་ལྡན་པ་གཉིས། གསུམ་པ་ལ། ཐོབ་པ་རྫས་ཡོད་དུ་བཤད་པ། ཐོབ་པ་ཐོབ་པའི་ཐོབ་པ། ཐོབ་བྱའི་ཆོས་གསུམ་གྱི་ཁྱད་པར་བཤད་པ། རྒྱུད་ཀྱིས་བསྡུས་མ་བསྡུས་ཀྱི་ཁྱད་པར། དུས་གསུམ་གྱི་ཁྱད་པར། དགེ་སོགས་གསུམ་གྱི་ཁྱད་པར། ཁམས་གསུམ་གྱི་ཁྱད་པར། སློབ་མི་སློབ་ཀྱི་ཁྱད་པར། སྤང་བྱ་ཡིན་མ་ཡིན་གྱི་ཁྱད་པར། དམིགས་བསལ་བཤད་པ་དང་དགུ།

Enumeration Block 1:
མ་ཐོབ་མ་བསྒྲིབས་ལུང་མ་བསྟན། །ཞེས་སོགས་ཀྱི་སྐབས་སུ་གཉིས་ལས། དང་པོ་ནི། མཚན་ཉིད། དབྱེ་བ། ཁྱད་པར་གྱི་ཆོས་གསུམ།
Enumeration Block 2:
གཉིས་པ་ནི། དེ་ལ་རྙེད་པའི་མ་ཐོབ་པ་མ་རྙེད་པའི་མ་ཐོབ་པ། མི་ལྡན་པའི་མ་ཐོབ་པ་གསུམ་ཡོད།
Enumeration Block 3:
གཉིས་པ་སྐལ་མཉམ་བཤད་པ་ནི། སྐལ་མཉམ་སེམས་ཅན་འདྲ་བའོ། ཞེས་སོགས་ཀྱི་སྐབས་སུ། མཚན་ཉིད། དབྱེ་བ། དྭོགས་པར་གཅོད་པ་གསུམ།
Enumeration Block 4:
གཉིས་པ་ནི། ཐ་དད་མ་ཡིན་པའི་སྐལ་མཉམ་དང་ཐ་དད་པའི་སྐལ་མཉམ་གཉིས།
Enumeration Block 5:
བཞི་པ་སྙོམས་འཇུག་གཉིས་བཤད་པ་ལ་འདུ་ཤེས་མེད་པའི་སྙོམས་འཇུགའགོག་པའི་སྙོམས་འཇུག། དེ་གཉིས་ཀའི་རྟེན་ཐུན་མོང་དུ་བསྟན་པའོ། །
Enumeration Block 6:
གཉིས་པ་ནི། དེ་ལ་གཟུགས་ཅན་དུ་གྱུར་པའི་སྲོགཤེས་པར་གྱུར་པའི་སྲོག་ལྡན་མིན་འདུ་བྱེད་དུ་གྱུར་པའི་སྲོག་གསུམ་ཡོད།
Enumeration Block 7:
དྲུག་པ་མཚན་ཉིད་བཞི་སྟོན་པ་ནི། མཚན་ཉིད་དག་ནི་སྐྱེ་བ་དང༌། །ཞེས་སོགས་རྐང་པ་དྲུག་གི་སྐབས་སུ། སྐྱེ་བ། རྒ་བ། གནས་པ། མི་རྟག་པ་བཞི་ཆོས་ཅན།
Enumeration Block 8:
བདུན་པ་ཚོགས་གསུམ་བཤད་པ་ནི། མིང་གི་ཚོགས་ལ་སོགས་པ་ནི། །ཞེས་སོགས་རྐང་པ་གཉིས་ཀྱི་སྐབས་སུ། ཚོགས་གསུམ་བཞག་ཏུ་ཡོད་དེ།
Enumeration Block 9:
གསུམ་པ་རྒྱུ་རྐྱེན་འབྲས་བུ་གསུམ་བཤད་པ་ལ། རྒྱུ་བཤད་པ། འབྲས་བུ་བཤད་པ། རྐྱེན་བཤད་པའོ། །དང་པོ་ནི། བྱེད་རྒྱུ་ལྷན་ཅིག་འབྱུང་བ་དང༌། །ཞེས་སོགས་ཀྱི་སྐབས་སུ། སྤྱི་དོན་དང༌། གཞུང་དོན་གཉིས། དང་པོ་ནི། རྒྱུ་ལ་མཚན་ཉིད། དབྱེ་བ། བསྡུ་བ། སོ་སོའི་རང་བཞིན། རྒྱུ་དྲུག་གྲུབ་མཐའ་སྨྲ་བ་གང་གིས་འདོད་པ། རྒྱུ་དྲུག་འགལ་མི་འགལ་ལ་དཔྱད་པའོ། །
Enumeration Block 10:
གསུམ་པ་ནི། བསྡུ་ན། གཉིས་སུ་འདུ་སྟེ། ཐུན་མོང་མ་ཡིན་པའི་རྒྱུ་གཉིས་སུ་འདུ་བའི་ཕྱིར།
Enumeration Block 11:
གཉིས་པ་ཡང་གཉིས་སུ་འདུ་སྟེ། དུས་མཉམ་པའི་རྒྱུ། མི་མཉམ་བའི་རྒྱུ་གཉིས་སུ་འདུ་བའི་ཕྱིར་ཏེ།

Enumeration Block 1:
གསུམ་པ་རྒྱུ་རྐྱེན་འབྲས་བུ་གསུམ་བཤད་པ་ལ། རྒྱུ་བཤད་པ། འབྲས་བུ་བཤད་པ། རྐྱེན་བཤད་པའོ། །དང་པོ་ནི། བྱེད་རྒྱུ་ལྷན་ཅིག་འབྱུང་བ་དང༌། །ཞེས་སོགས་ཀྱི་སྐབས་སུ། སྤྱི་དོན་དང༌། གཞུང་དོན་གཉིས། དང་པོ་ནི། རྒྱུ་ལ་མཚན་ཉིད། དབྱེ་བ། བསྡུ་བ། སོ་སོའི་རང་བཞིན། རྒྱུ་དྲུག་གྲུབ་མཐའ་སྨྲ་བ་གང་གིས་འདོད་པ། རྒྱུ་དྲུག་འགལ་མི་འགལ་ལ་དཔྱད་པའོ། །
Enumeration Block 2:
བསྡུ་ན། གཉིས་སུ་འདུ་སྟེ། ཐུན་མོང་མ་ཡིན་པའི་རྒྱུ་གཉིས་སུ་འདུ་བའི་ཕྱིར།
Enumeration Block 3:
གཉིས་པ་ཡང་གཉིས་སུ་འདུ་སྟེ། དུས་མཉམ་པའི་རྒྱུ། མི་མཉམ་བའི་རྒྱུ་གཉིས་སུ་འདུ་བའི་ཕྱིར་ཏེ།
Enumeration Block 4:
རྒྱུ་ལ་དྲུག་ཏུ་ཡོད་དེ། བྱེད་རྒྱུ་སོགས་དྲུག་ཡོད་པའི་ཕྱིར། །གཉིས་པ་འབྲས་བུ་བཤད་པ་ནི། འདུས་བྱས་བྲལ་བཅས་འབྲས་བུ་ཡིན། །ཞེས་སོགས་ཀྱི་སྐབས་སུ། གཉིས་ལས། དང་པོ་ནི། འབྲས་བུའི་མཚན་ཉིད། དབྱེ་བ། སོ་སོའི་རང་བཞིན། འབྲས་བུ་གང་རྒྱུ་གང་གི་འབྲས་བུ་ཡིན་པ། དེ་དག་ལ་དྭོགས་པ་གཅོད་པ་དང་ལྔ།
Enumeration Block 5:
དེ་ལ་ལྔ་ཡོད་དེ་རྣམ་སྨིན་གྱི་འབྲས་བུ། རྒྱུ་མཐུན་གྱི་འབྲས་བུ། བྲལ་བའི་འབྲས་བུ། སྐྱེས་བུ་བྱེད་པའི་འབྲས་བུ། བདག་འབྲས་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
སྐྱེད་པའི་སྐྱེས་བུའི་བྱེད་འབྲས། ཐོབ་པའི་སྐྱེས་བུའི་བྱེད་འབྲས་གཉིས་ཡོད།
Enumeration Block 7:
གསུམ་པ་རྐྱེན་བཤད་པ་ལ། བསྟན་བཤད་གཉིས། དང་པོ་ནི། རྐྱེན་ནི་བཞི་པོ་དག་ཏུ་གསུངས། །ཞེས་སོགས་ཀྱི་སྐབས་སུ། གཉིས་ལས། དང་པོ་ལ། རྐྱེན་ལ་མཚན་ཉིད། དབྱེ་བ། སོ་སོའི་རང་བཞིན། རྐྱེན་གང་གི་དུས་གང་ལ་བྱ་བ་བྱེད་པ། དངོས་པོ་གང་རྐྱེན་དུས་སྐྱེད་པའོ། །
Enumeration Block 8:

ཕྲ་རྒྱས་གོ་བརྒྱད་པོ་དེ་ལ། སྐལ་མཉམ་གྱི་ཀུན་འགྲོ། སྐལ་པ་མི་མཉམ་གྱི་ཀུན་འགྲོ། དེ་ལས་གཞན་པའི་ཀུན་འགྲོ་དང་གསུམ་ཡོད་དེ།
Enumeration Block 2:
ཕྲ་རྒྱས་གོ་བརྒྱད་པོ་ལ་ཟག་བཅས་ལ་དམིགས་པ་ཟག་མེད་ལ་དམིགས་པ་གཉིས་ཡོད་དེ།
Enumeration Block 3:
སྤྱིར་དྲི་བ་བཞི་ཡོད་དེ། མགོ་གཅིག་པའི་དྲི་བ། རྣམ་པར་ཕྱེ་སྟེ་ལན་བཏབ་པའི་དྲི་བ། དྲིས་ནས་ལན་བཏབ་པའི་དྲི་བ། བཞག་པར་ལུང་མ་བསྟན་པའི་དྲི་བ་དང་བཞི་ཡོད་པའི་ཕྱིར་ཏེ།
Enumeration Block 4:
ཉོན་མོངས་ལ་རང་གི་མཚན་ཉིད་པའི་ཉོན་མོངས་དང༌། ཉོན་མོངས་སྤྱི་པ་ཞེས་བྱ་བ་གཉིས་ལས།
Enumeration Block 5:
ཁྱད་པར་དུ་འདས་མ་འོངས་རྫས་སུ་ལུང་རིགས་གཉིས་ཀྱིས་གྲུབ།
Enumeration Block 6:
གཞི་ཐམས་ཅད་ཡོད་པར་སྨྲ་བའི་སྡེ་པ་ལ་བཞི་ཡོད་དེ། དངོས་པོ་གཞན་དུ་འགྱུར་བར་སྨྲ་བ། མཚན་ཉིད་གཞན་དུ་འགྱུར་བར་སྨྲ་བ། གནས་སྐབས་གཞན་དུ་འགྱུར་བར་སྨྲ་བ། གཞན་གཞན་དུ་འགྱུར་བར་སྨྲ་བ་སྟེ་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
ལྔ་པ་ཉོན་མོངས་སྐྱེ་ཚུལ་ལ། སྐྱེ་བའི་གོ་རིམ་དང༌། སྐྱེ་བའི་རྒྱུ་གཉིས།
Enumeration Block 8:
ཟག་པ་ལ་ནི་འདོད་པའི་ཟག་པ་དང༌། སྲིད་པའི་ཟག་པ། མ་རིག་པའི་ཟག་པ་དང་གསུམ།
Enumeration Block 9:
ཉེར་ལེན་ལའང་ལྟ་བ་ཉེར་ལེན། འདོད་པ་ཉེར་ལེན། བདག་ཏུ་ལྟ་བ་ཉེ་བར་ལེན་པ། ཚུལ་ཁྲིམས་མཆོག་ཏུ་འཛིན་པ་ཉེ་བར་ལེན་པ་བཞི་ཡོད།
Enumeration Block 10:
ཀུན་སྦྱོར། འཆིང་བ། ཕྲ་རྒྱུས། ཉེ་ཉོན། ཀུན་དཀྲིས་ཞེས་ལྔ་གསུངས་ཏེ།
Enumeration Block 11:
ཀུན་སྦྱོར་ལ་དགུ་ཡོད་དེ། རྩ་ཉོན་དྲུག་གི་ཀུན་སྦྱོར། མཆོག་འཛིན་གཉིས་ཀྱི་ཀུན་སྦྱོར། ཕྲག་དོག་སེར་སྣའི་ཀུན་སྦྱོར་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 12:
དང་པོ་ལ། འཇིག་ལྟ་ཀུན་སྦྱོར། ཚུལ་ཁྲིམས་མཆོག་འཛིན། ཐེ་ཚོམ་སྟེ་གསུམ་ཡོད།
Enumeration Block 13:
ཐ་མའི་ཀུན་སྦྱོར་ལ་ལྔ་ཡོད་དེ།

Enumeration Block 1:
ཉེར་ལེན་ལའང་ལྟ་བ་ཉེར་ལེན། འདོད་པ་ཉེར་ལེན། བདག་ཏུ་ལྟ་བ་ཉེ་བར་ལེན་པ། ཚུལ་ཁྲིམས་མཆོག་ཏུ་འཛིན་པ་ཉེ་བར་ལེན་པ་བཞི་ཡོད།
Enumeration Block 2:
ཀུན་སྦྱོར་ལ་དགུ་ཡོད་དེ། རྩ་ཉོན་དྲུག་གི་ཀུན་སྦྱོར། མཆོག་འཛིན་གཉིས་ཀྱི་ཀུན་སྦྱོར། ཕྲག་དོག་སེར་སྣའི་ཀུན་སྦྱོར་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
ཀུན་སྦྱོར་ལ་མཐོང་སྤང་ཀུན་སྦྱོར། ཐ་མའི་ཀུན་སྦྱོར་རོ། །གོང་མའི་ཀུན་སྦྱོར་རོ། །
Enumeration Block 4:
དང་པོ་ལ། འཇིག་ལྟ་ཀུན་སྦྱོར། ཚུལ་ཁྲིམས་མཆོག་འཛིན། ཐེ་ཚོམ་སྟེ་གསུམ་ཡོད།
Enumeration Block 5:
ཐ་མའི་ཀུན་སྦྱོར་ལ་ལྔ་ཡོད་དེ། གསུམ་པོ་དེའི་སྟེང་དུ་འདོད་པ་ལ་འདུན་པ། གནོད་སེམས་གཉིས་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
གོང་མའི་ཀུན་སྦྱོར་ལ་ལྔ་ཡོད་དེ། གཟུགས་གཟུགས་མེད་ཀྱི་འདོད་ཆགས་གཉིས། རྒོད་པ། ང་རྒྱལ། མ་རིག་པ་གསུམ་སྟེ།
Enumeration Block 7:
གཉིས་པ་འཆིང་བ་ལ་གསུམ་ཡོད། དུག་གསུམ་གྱི་འཆིང་བ་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 8:
ཀུན་བཀྲིས་ལ་བརྒྱད་ཡོད་དེ། ཚུལ་ཁྲིམས་ཀྱི་མི་མཐུན་ཕྱོགས་ངོ་ཚ་མེད་དང་ཁྲེལ་མེད། གཞན་ལ་ཕན་འདོགས་པའི་མི་མཐུན་ཕྱོགས་ཕྲག་དོག་སེར་སྣ། ཤེས་རབ་ཀྱི་མི་མཐུན་ཕྱོགས་རྒོད་འགྱོད། ཏིང་ངེ་འཛིན་གྱི་མི་མཐུན་ཕྱོགས་གཉིད་རྨུགས་རྣམས་སུ་ཡོད་པའི་ཕྱིར་ཏེ།
Enumeration Block 9:
ཉོན་མོངས་པའི་མིང་གིས་རྣམ་གྲངས་སུ་འགྱུར་པའི་དྲི་མ་ལ་དྲུག་ཡོད་དེ།
Enumeration Block 10:
བརྒྱད་པ་སྒྲིབ་པ་ལྔ་བཤད་པ་ན། འདོད་པའི་སས་བསྡུས་ཀྱི་སྒྲིབ་པ་ལ་ལྔ་ཡོད་དེ།
Enumeration Block 11:
འདོད་པ་ལ་འདུན་པ། གནོད་སེམས་གཉིད་རྨུགས་རྒོད་འགྱོོད་ཐེ་ཚོམ་རྣམས་སོ། །
Enumeration Block 12:
དགུ་པ་སྤངས་པའི་འབྲས་བུ་ཡོངས་ཤེས་བཤད་པ་ལ། ཚུལ་ཇི་ལྟར་སྤོང་བ། སྤོང་བྱེད་གཉེན་པོའི་དབྱེ་བ། ཡོངས་ཤེས་ཀྱི་དབྱེ་བ་དངོས་བཤད་པའོ། །དང་པོ་ལ། མཐོང་སྤང་སྤོང་ཚུལ་དང༌། སྒོམ་སྤང་སྤོང་ཚུལ་ལོ། །
Enumeration Block 13:
གཉེན་པོ་ལ་བཞི་ཡོད་དེ། སྤོང་བའི་གཉེན་པོ། གཞིའི་གཉེན་པོ། ཐག་སྲིང་བའི་གཉེན་པོ། རྣམ་པར་སུན་འབྱིན་པའི་གཉེན་པོ་རྣམས་སུ་ཡོད་པའི་ཕྱིར་ཏེ།
Enumeration Block 14:
ཡོངས་ཤེས་ལ་དགུ་ཡོད་དེ། འདོད་པའི་སས་བསྡུས་ཀྱི་སྡུག་བསྔལ་ཀུན་འབྱུང་མཐོང་སྤང་སྤངས་པའི་ཡོངས་ཤེས་གཅིགའགོག་ལམ་མཐོང་སྤང་ཟད་པའི་ཡོངས་ཤེས་གཉིས་ཏེ་གསུམ། གོང་མའི་སྡུག་ཀུན་མཐོང་སྤང་ཟད་པའི་ཡོད་ཤེས་གཅིགའགོག་ལམ་མཐོང་སྤང་ཟད་པའི་ཡོངས་ཤེས་གཉིས་དེ་གསུམ། ཐ་མའི་ཆ་མཐུན་ལྔ་སྤངས་པའི་ཡོངས་ཤེས། གཟུགས་ཁམས་ཀྱི་ཟག་པ་ཟད་པའི་ཡོངས་ཤེས། གཟུགས་མེད་ཁམས་ཀྱི་ཟག་པ་ཟད་པའི་ཡོངས་ཤེས་གསུམ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 15:
ཡེ་ཤེས་ཀྱི་ཡོངས་ཤེས་དང༌། སྤངས་བའི་ཡོངས་ཤེས་གཉིས་ལས།
Enumeration Block 16:
གནས་དྲུག་པ་ལམ་དང་གང་ཟག་བསྟན་པའི་གནས་བཤད་པ་ལ་བཞི། དམིགས་ཡུལ་འཕགས་པའི་བདེན་པ། བདེན་མཐོང་མངོན་པར་རྟོགས་པའི་རིམ་པ། མངོན་རྟོགས་ལ་གནས་པའི་གང་ཟག་མངོན་པར་རྟོགས་པའི་ལམ་བསྟན་པའོ། །
Enumeration Block 17:
