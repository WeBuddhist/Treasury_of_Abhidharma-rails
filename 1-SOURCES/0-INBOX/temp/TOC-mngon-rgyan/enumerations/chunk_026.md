Enumeration Block 1:
ཕྲ་རྒྱས་ཀྱི་རྣམ་པའི་རབ་ཏུ་དབྱེ་བ་བཤད་པ་ལ་ཀུན་འགྲོ་དང་ཀུན་འགྲོ་མ་ཡིན་པ་དང་། ཟག་བཅས་ཟག་མེད་ལ་དམིགས་པ་དང་། རྒྱས་པ་དང་མི་རྒྱས་པ་དང་། མི་དགེ་བ་དང་ལུང་མ་བསྟན་གྱི་དབྱེ་བ་དང་། མི་དགེ་བ་དང་ལུང་མ་བསྟན་གྱི་རྩ་བ་བཤད་པ་དང་། ལྡན་པའི་ཚུལ་དང་། ཆོས་དུའི་ཡུལ་ཅན་ཡིན་པ་དང་། གོ་རིམ་དང་། སྐྱེ་བའི་རྒྱུ་དང་། ཟག་པ་ལ་སོགས་པ་མདོ་ལས་གསུངས་པའི་རྣམ་པའི་དབྱེ་བ་བཤད་པ་བཅུ་ལས་
Enumeration Block 2:
ང་རྒྱལ་ཡང་ཡུལ་གྱི་སྒོ་ནས་རྣམ་པ་བདུན་ཡིན་ནོ། །གང་ཞེ་ན། སེམས་ཁེངས་པ་ནི་ང་རྒྱལ་སྤྱིའི་མཚན་ཉིད་ཡིན་ལ་རྣམ་པའམ་ཡུལ་གྱི་བྱེ་བྲག་ལས་ནི་ཆུང་ངུ་བས་བདག་ཁྱད་པར་དུ་འཕགས་པའམ་མཉམ་པ་དང་མཉམ་མོ་སྙམ་ནས་སེམས་ཁེངས་པའི་ང་རྒྱལ་དང་། མཉམ་པ་བས་བདག་ཁྱད་པར་དུ་འཕགས་པའམ་མཆོག་དང་མཉམ་མོ་སྙམ་པ་ལྷག་པའི་ང་རྒྱལ་དང་། ཁྱད་པར་དུ་འཕགས་པ་བས་ཀྱང་བདག་ཁྱད་པར་དུ་འཕགས་སོ་སྙམ་པ་ང་རྒྱལ་ལས་ཀྱང་ང་རྒྱལ་དང་། ཉེར་ལེན་གྱི་ཕུང་པོ་ལྔ་ལ་བདག་གམ་བདག་གིར་སེམས་ཁེངས་པ་ངའོ་སྙམ་པའི་ང་རྒྱལ་དང་། བསམ་གཏན་ལ་བརྟེན་པའི་ཟག་བཅས་ཟག་མེད་ཀྱི་ཡོན་ཏན་མ་ཐོབ་པ་ལ་ཐོབ་པར་རློམ་པ་མངོན་པའི་ང་རྒྱལ་དང་། ཆེས་ཁྱད་པར་དུ་འཕགས་པ་བས་བདག་ཅུང་ཟད་ཅིག་གིས་དམན་ནོ་སྙམ་དུ་སེམས་ཁེངས་པ་ཅུང་ཟད་སྙམ་པའི་ང་རྒྱལ་དང་། གསོད་པ་ལ་དཔའ་བ་ལ་སོགས་པ་ཡོན་ཏན་མ་ཡིན་པ་ལ་ཡོན་ཏན་དུ་ལྟ་བས་སེམས་ཁེངས་པ་ལོག་པའི་ང་རྒྱལ་དང་།
Enumeration Block 3:
མཐོང་སྤང་སྒོམ་སྤང་དེ་དག་གི་དམིགས་པ་ནི་བསྡུ་ན་ལྔ་སྟེ། ལོག་པར་རྣམ་པར་བརྟགས་པའི་དངོས་པོ་ལ་དམིགས་པ་དང་། ལྟ་བ་ལ་དམིགས་པ་དང་། ཚུལ་ཁྲིམས་དང་བརྟུལ་ཞུགས་ལ་དམིགས་པ་དང་། རང་གིས་རྣམ་པར་བརྟགས་པའི་མིང་ལ་དམིགས་པ་དང་། རང་གི་ངང་གིས་ཡེ་ཡོད་པའི་དངོས་པོ་ལ་དམིགས་པའོ། །
Enumeration Block 4:
ཕྲ་རྒྱས་ཀུན་འགྲོ་ནི་གཉིས་ཏེ་རང་གི་ཁམས་དང་ས་ཀུན་ཏུ་འགྲོ་བ་དང་། སྐལ་བ་མི་མཉམ་པའི་ཁམས་དང་ས་ཀུན་ཏུ་འགྲོ་བའོ །
Enumeration Block 5:
ཕྲ་རྒྱས་ལ་ཀུན་འགྲོ་དང་ཀུན་འགྲོ་མ་ཡིན་པ་གཉིས་ལས་དང་པོ་ལའང་རང་གི་ཁམས་དང་ས་སྐལ་བ་མཉམ་པ་དང་མི་མཉམ་པ་གཉིས་སོ། །ཀུན་འགྲོ་མ་ཡིན་པ་ལའང་ཟག་བཅས་དང་ཟག་མེད་ལ་དམིགས་པ་གཉིས་སོ། །
Enumeration Block 6:
འཇིག་ཚོགས་ལ་ལྟ་བ་ནི་གཉིས་ཏེ། ལྷན་ཅིག་སྐྱེས་པ་དང་ཀུན་བརྟགས་པའོ། །
Enumeration Block 7:
མཐར་འཛིན་པར་ལྟ་བ་ལའང་གཉིས་ལས་
Enumeration Block 8:
དྲི་བའི་ལན་ནི་མགོ་གཅིག་ཏུ་ལུང་བསྟན་པ་དང་རྣམ་པར་ཕྱེ་སྟེ་ལུང་བསྟན་པ་དང་དྲིས་ཏེ་ལུང་བསྟན་པ་དང་། གཞག་པར་ལུང་བསྟན་པ་བཞི་ཡོད་པ་ལས།
Enumeration Block 9:
དྲིས་པ་ལུང་བསྟན་པ་ནི་རྣམ་པ་བཞི་སྟེ། བཞི་གང་ཞེ་ན། མགོ་གཅིག་ཏུ་དྲིས་པ་ལུང་བསྟན་པ་དང་། རྣམ་པར་ཕྱེ་སྟེ་དྲིས་པ་ལུང་བསྟན་པ་དང་། དྲི་བ་དྲིས་ཏེ་ལུང་བསྟན་པ་དང་། རྣམ་པར་བཞག་པ་ལུང་བསྟན་པའོ
Enumeration Block 10:
ཉོན་མོངས་པ་ལ་རང་གི་མཚན་ཉིད་པ་དང་། སྤྱིའི་མཚན་ཉིད་པ་གཉིས་ལས་
Enumeration Block 11:
གང་དག་དུས་གསུམ་རྫས་སུ་ཡོད་པར་འདོད་པའི་ཐམས་ཅད་ཡོད་པར་སྨྲ་བ་དེ་དག་ཀྱང་དབྱེ་ན་རྣམ་པ་བཞི་ཡིན་ཏེ། དངོས་པོ་གཞན་དུ་འགྱུར་བ་དང་། མཚན་ཉིད་གཞན་དུ་འགྱུར་བ་དང་། གནས་སྐབས་གཞན་དུ་འགྱུར་བ་དང་། གཞན་དང་གཞན་དུ་འགྱུར་བ་ཞེས་བྱ་བའོ། །
