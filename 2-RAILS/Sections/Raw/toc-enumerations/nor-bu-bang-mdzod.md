Enumeration Block 1:

Enumeration Block 2:

Enumeration Block 3:

Enumeration Block 4:

Enumeration Block 5:

Enumeration Block 8:

Enumeration Block 9:

Enumeration Block 10:
ཁམས་ཀྱི་རྣམ་པའི་རབ་དབྱེ་ལ་བདུན། ངོ་བོ་ལ་ལྟོས་པའི་རབ་དབྱེ། གྲོགས་ལ་ལྟོས་པའི། །རྒྱུ་འབྲས་ལ་ལྟོས་པའི། མོང་དོན་ལ་ལྟོས་པའི། སྤང་བྱ་ལ་ལྟོས་པའི། བྱེད་པ་ལ་ལྟོས་པའི། རབ་དབྱེ་གཞན་བསྟན་པ། དང་པོ་ལ་བསྟན་ཡོད་བསྟན་མེད་ཀྱི་ཁྱད་པར། ཐོགས་བཅས་ཐོགས་མེད་ཀྱི་ཁྱད་པར། དགེ་མི་དགེ་ལུང་མ་བསྟན་གསུམ་གྱི་ཁྱད་པར། ཁམས་གསུམ་གང་རུང་དུ་གཏོགས་པ་དུ་ཡོད་ཀྱི་ཁྱད་པར་དང་བཞི་ཡོད་དེ།
Enumeration Block 11:
གཉིས་པ་གྲོགས་ལ་ལྟོས་བའི་རབ་དབྱེ་ལ། ཟག་བཅས་ཟག་མེད་ཀྱི་ཁྱད་པར། རྟོག་དཔྱོད་དང་བཅས་མ་བཅས་ཀྱི། དམིགས་བཅས་དམིགས་མེད་ཀྱི། ཟིན་མ་ཟིན་གྱི། འབྱུང་བ་འབྱུང་འགྱུར་གྱི། བསགས་མ་བསགས་ཀྱི། གཅོད་བྱེད་གཅད་བྱའི་ཁྱད་པར་ཏེ་བདུན་ཡོད་དེ།
Enumeration Block 12:

Enumeration Block 13:

Enumeration Block 15:

Enumeration Block 17:

གཉིས་པ་ནི། ཐ་དད་མ་ཡིན་པའི་སྐལ་མཉམ་དང་ཐ་དད་པའི་སྐལ་མཉམ་གཉིས།
Enumeration Block 9:
དེ་ལ་གཟུགས་ཅན་དུ་གྱུར་པའི་སྲོགཤེས་པར་གྱུར་པའི་སྲོག་ལྡན་མིན་འདུ་བྱེད་དུ་གྱུར་པའི་སྲོག་གསུམ་ཡོད།
Enumeration Block 10:
གསུམ་པ་རྒྱུ་རྐྱེན་འབྲས་བུ་གསུམ་བཤད་པ་ལ། རྒྱུ་བཤད་པ། འབྲས་བུ་བཤད་པ། རྐྱེན་བཤད་པའོ། །
Enumeration Block 11:
སྤྱི་དོན་དང༌། གཞུང་དོན་གཉིས།
Enumeration Block 12:
བྱེད་རྒྱུ། ལྷན་ཅིག་འབྱུང་བའི་རྒྱུ། སྐལ་མཉམ་གྱི་རྒྱུ། མཚུངས་ལྡན་གྱི་རྒྱུ། ཀུན་འགྲོའི་རྒྱུ། རྣམ་སྨིན་གྱི་རྒྱུ་རྣམས་སུ་ཡོད་དོ། །
Enumeration Block 13:
གཉིས་ལས། དང་པོ་ནི། འབྲས་བུའི་མཚན་ཉིད། དབྱེ་བ། སོ་སོའི་རང་བཞིན། འབྲས་བུ་གང་རྒྱུ་གང་གི་འབྲས་བུ་ཡིན་པ། དེ་དག་ལ་དྭོགས་པ་གཅོད་པ་དང་ལྔ།
Enumeration Block 14:
དེ་ལ་ལྔ་ཡོད་དེ་རྣམ་སྨིན་གྱི་འབྲས་བུ། རྒྱུ་མཐུན་གྱི་འབྲས་བུ། བྲལ་བའི་འབྲས་བུ། སྐྱེས་བུ་བྱེད་པའི་འབྲས་བུ། བདག་འབྲས་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 15:
དབྱེ་ན། སྐྱེད་པའི་སྐྱེས་བུའི་བྱེད་འབྲས། ཐོབ་པའི་སྐྱེས་བུའི་བྱེད་འབྲས་གཉིས་ཡོད།
Enumeration Block 16:
གསུམ་པ་རྐྱེན་བཤད་པ་ལ། བསྟན་བཤད་གཉིས།
Enumeration Block 17:
གཉིས་ལས། དང་པོ་ལ། རྐྱེན་ལ་མཚན་ཉིད། དབྱེ་བ། སོ་སོའི་རང་བཞིན། རྐྱེན་གང་གི་དུས་གང་ལ་བྱ་བ་བྱེད་པ། དངོས་པོ་གང་རྐྱེན་དུས་སྐྱེད་པའོ། །
Enumeration Block 18:
དེ་ལ་རྒྱུ་རྐྱེན། དེ་མ་ཐག་རྐྱེན། དམིགས་རྐྱེན། བདག་རྐྱེན་དང་བཞི་ཡོད།
Enumeration Block 19:
གཉིས་ལས། དང་པོ་ནི། སྤྱིར་སེམས་ཀྱི་དབྱེ་བ་བཤད་པ། དེ་མ་ཐག་རྐྱེན་དང་སྦྱར་བ། ཁམས་གསུམ་གྱི་ཉོན་མོངས་ཅན་གྱི་སེམས་གང་མངོན་དུ་གྱུར་པ་ན་གསར་དུ་དུ་རྙེད་དཔྱད་པའོ། །དང་པོ་ལ། སེམས་བཅུ་གཉིས་སུ་དབྱེ་བ། ཉི་ཤུར་དབྱེ་བ། དེ་གཉིས་གང་ཁྱབ་ཆེ་བཤད་པའོ། །
Enumeration Block 20:
སེམས་ལ་བཅུ་གཉིས་ཡོད་དེ། འདོད་བའི་སས་བསྡུས་ཀྱི་དགེ་སེམས། །མི་དགེའི་སེམས། སྒྲིབ་ལུང་མ་བསྟན་གྱི་སེམས། མ་སྒྲིབ་ལུང་མ་བསྟན་གྱི་སེམས་ཏེ་བཞི། ཁམས་གོང་མ་གཉིས་ན་མི་དགེ་བ་གཉིས་དོར་བའི་གསུམ་གསུམ། སློབ་པའི་ཟག་མེད་ཀྱི་སེམས་མི་སློབ་པའི་ཟག་མེད་ཀྱི་སེམས་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 21:
སེམས་ཉི་ཤུ་ཡོད་དེ། ཁམས་གསུམ་གྱི་དགེ་སེམས་ལ་སྐྱེས་ཐོབ་དང་སྦྱོར་བྱུང་གི་དགེ་བ་གཉིས་གཉིས་སུ་ཕྱེ་བས་དྲུག། འདོད་པའི་མ་སྒྲིབ་ལུང་མ་བསྟན་གྱི་སེམས་ལ་རྣམ་སྨིན་སྐྱེས་གྱི། སྤྱོད་ལམ་པའི། བཟོ་གནས་པའི། སྤྲུལ་པའི་སེམས་ཏེ་བཞི། གཟུགས་ཀྱི་མ་སྒྲིབ་ལུང་མ་བསྟན་གྱི་སེམས་ལ། བཟོ་གནས་མ་གཏོགས་པའི་གསུམ། གཟུགས་མེད་ན་རྣམ་སྨིན་སྐྱེས་ཀྱི་སེམས་གཅིག་པུ་སྟེ། དེ་ལྟར་དགེ་སེམས་དྲུག་མ་སྒྲིབ་ལུང་མ་བསྟན་གྱི་སེམས་བརྒྱད། སྒྲིབ་ལུང་མ་བསྟན་གྱི་སེམས་གསུམ། མི་དགེའི་སེམས་གཅིག ཟག་མེད་ཀྱི་སེམས་གཉིས་རྣམས་སུ་ཡོད་པའི་ཕྱིར་ཏེ།
Enumeration Block 22:
ཚེའམ་གནས་སྐབས་བརྒྱད་ཀྱིས་ཤེས་པར་བྱ་སྟེ། རྒྱུན་ལྡན་གྱི་ཚེ། ས་མཚུངས་ཀྱི་ཚེ། ཉིང་མཚམས་སྦྱོར་བའི་ཚེ། སྙོམས་པར་འཇུག་པའི་ཚེ། སྙོམས་པར་འཇུག་པ་ལས་ལྡང་བའི་ཚེ། སྙོམས་འཇུག་ཉོན་མོངས་ཅན་གྱིས་གཟིར་བའི་ཚེ། སྤྲུལ་པ་ལ་འཇུག་པའི། སྤྲུལ་པ་ལས་ལྡང་པའི་ཚེ་རྣམས་སོ། །

Enumeration Block 1:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། དེ་མ་ཐག་རྐྱེན་བྱེ་བྲག་ཏུ་བཤད་པ་ནི། འདོད་ཡིད་དགེ་དང་མི་དགེ་དང༌། །ཞེས་སོགས་ཀྱི་སྐབས་སུ། གཉིས་ལས། དང་པོ་ནི། སྤྱིར་སེམས་ཀྱི་དབྱེ་བ་བཤད་པ། དེ་མ་ཐག་རྐྱེན་དང་སྦྱར་བ། ཁམས་གསུམ་གྱི་ཉོན་མོངས་ཅན་གྱི་སེམས་གང་མངོན་དུ་གྱུར་པ་ན་གསར་དུ་དུ་རྙེད་དཔྱད་པའོ། །དང་པོ་ལ། སེམས་བཅུ་གཉིས་སུ་དབྱེ་བ། ཉི་ཤུར་དབྱེ་བ། དེ་གཉིས་གང་ཁྱབ་ཆེ་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་དུས་ནམ་གྱི་ཚེ་རྐྱེན་དང་རྐྱེན་ཅན་དུ་འགྱུར་བ། སེམས་བཅུ་གཉིས་ཀྱི་རྐྱེན་དང་རྐྱེན་དུ་སྦྱར་བ། སེམས་ཉི་ཤུའི་རྐྱེན་དང་རྐྱེན་ཅན་དུ་སྦྱར་བའོ། །དང་པོ་ནི། ཚེའམ་གནས་སྐབས་བརྒྱད་ཀྱིས་ཤེས་པར་བྱ་སྟེ། རྒྱུན་ལྡན་གྱི་ཚེ། ས་མཚུངས་ཀྱི་ཚེ། ཉིང་མཚམས་སྦྱོར་བའི་ཚེ། སྙོམས་པར་འཇུག་པའི་ཚེ། སྙོམས་པར་འཇུག་པ་ལས་ལྡང་བའི་ཚེ། སྙོམས་འཇུག་ཉོན་མོངས་ཅན་གྱིས་གཟིར་བའི་ཚེ། སྤྲུལ་པ་ལ་འཇུག་པའི། སྤྲུལ་པ་ལས་ལྡང་པའི་ཚེ་རྣམས་སོ། །
Enumeration Block 3:
གནས་གསུམ་པ་འཇིག་རྟེན་བསྟན་པའི་གནས་བཤད་པ་ལ། སེམས་ཅན་གྱི་འཇིག་རྟེན། སྣོད་ཀྱི་འཇིག་རྟེན་བཤད་པའོ། །དང་པོ་ལ། སེམས་ཅན་གྱི་དབྱེ་བ། ཆོས་ཀྱི་ཁྱད་པར། རང་བཞིན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ། ཁམས་གསུམ་བཤད་པ་དང༌། འགྲོ་བ་ལྔ་བཤད་པའོ། །
Enumeration Block 4:
གསུམ་པ་རང་བཞིན་རྒྱས་པར་བཤད་པ་ལ། འཇུག་ཚུལ། གནས་ཚུལ། འགྲོ་ཚུལ་ལོ། །དང་པོ་ལ། གང་དུ་འཇུག་པའི་སྐྱེ་གནས། གང་གིས་འཇུག་པའི་བར་སྲིད་གཉིས།
Enumeration Block 5:
བར་སྲིད་ལ་མཚན་ཉིད། དབྱེ་བ། སྒྲུབ་བྱེད། ཤ་ཚུགས། ཆོས་ཀྱི་ཁྱད་པར། སྐྱེ་གནས་སུ་འཇུག་ཚུལ། འགྲོ་ཚུལ། ཁ་དོག་དང་ཉམས་སྣང་གི་ཁྱད་པར་ཏེ་བརྒྱད་དོ། །
Enumeration Block 6:

ཟད་དང་མི་སྐྱེ་ཤེས་པ་ནི། །ཞེས་སོགས་ཀྱི་སྐབས་སུ་གཉིས་ལས། དང་པོ་ལ། ངེས་ཚིགདབྱེ་བ། བསྡུ་བ། གྲངས་ངེས། གོ་རིམ། ཟག་བཅས་ཟག་མེད་ཀྱི་ཁྱད་པར། ལམ་དང་སའི་ཁྱད་པར་རོ། །
Enumeration Block 9:
སོ་བདུན་པོ་དེ་ལ་རྗེས་ཀྱི་སྒོ་ནས་བསྡུ་ན་བཅུར་འདུས་ཏེ། རྫས་སུ་བཅུ།
Enumeration Block 10:
གནས་བདུན་པ་ཡེ་ཤེས་བསྟན་པའི་གནས་བཤད་པ་ལ། ཤེས་པ། ལྡན་པ། ཐོབ་པ། ཡོན་ཏན་བཤད་པའོ། །
Enumeration Block 11:
སྐབས་འདིར་བསྟན་ཤེས་པ་ལ་དབྱེ་ན་བཅུ་ཡོད་དེ། ཆོས་ཤེས། རྗེས་ཤེས། ཀུན་རྫོབ་ཤེས་པ། གཞན་སེམས་ཤེས་པ། བདེན་བཞི་ཤེས་པ། ཟད་པ་ཤེས་པ། མི་སྐྱེ་བ་ཤེས་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར་ཏེ།
Enumeration Block 12:
བཅུ་པོ་དེ་བསྡུ་ན་གཉིས་སུ་འདུ་སྟེ། ཟག་བཅས་ཀྱི་ཤེས་པ་དང༌། ཟག་མེད་ཀྱི་ཤེས་པ་གཉིས་སུ་འདུ་བའི་ཕྱིར།
Enumeration Block 13:
གཉིས་པ་ལའང་གཉིས་སུ་འདུ་སྟེ། ཆོས་ཤེས་དང་རྗེས་ཤེས་གཉིས་སུ་འདུ་བའི་ཕྱིར།
Enumeration Block 14:
བཞི་པ་ཤེས་པས་བསྡུས་བའི་ཡོན་ཏན་ལ། ཐུན་མོང་མ་ཡིན་པའི་ཡོན་ཏན་དང༌། ཐུན་མོང་བའི་ཡོན་ཏན་གཉིས་ལས།
Enumeration Block 15:
སངས་རྒྱས་ཆོས་ནི་མ་འདྲེས་པ། །ཞེས་སོགས་རྐང་པ་གཉིས་ཀྱི་སྐབས་སུ། སྤྱི་དོན་དང༌། གཞུང་དོན་གཉིས། དང་པོ་ལ། སངས་རྒྱས་ཀྱི་ཆོས་མ་འདྲེས་པའི་ཡོན་ཏན་གྱི་མཚན་ཉིད། དབྱེ་བ། སོ་སོའི་རང་བཞིན་ནོ། །
Enumeration Block 16:
གཉིས་པ་ནི། སྟོབས་བཅུ། མི་འཇིགས་པ་བཞི། དྲན་པ་ཉེར་གཞག་གསུམ། ཐུགས་རྗེ་ཆེན་པོ་རྣམས་སུ་ཡོད་དེ།
Enumeration Block 17:
དབྱེ་ན། རང་དོན་སྤངས་རྟོགས་དམ་པ་ལ་མི་འཇིགས་པ་གཉིས། གཞན་དོན་སྤང་གཉེན་དམ་པ་ལ་མི་འཇིགས་པ་གཉིས་ཏེ་བཞི་ཡོད་དེ།
Enumeration Block 18:
དབྱེ་ན། འཁོར་གུས་པར་ཆོས་ཉན་པ་ལ་རྗེས་སུ་ཆགས་པ་སྤངས་བའི་དྲན་པ། མ་གུས་པར་ཆོས་ཉན་པ་ལ་ཁོང་ཁྲོ་སྤངས་པའི་དྲན་པ། གུས་མ་གུས་འདྲེས་མ་ལ་དེ་གཉིས་ཀར་མི་འགྱུར་བ་དྲན་ཤེས་བཞིན་བཏང་སྙོམས་སུ་གནས་པའི་དྲན་པ་གསུམ་སྟེ།
Enumeration Block 19:
གཉིས་པ་ནི། ཐུན་མོང་མ་ཡིན་པའི་སངས་རྒྱས་ཀྱི་ཡོན་ཏན་འཕགས་པ་འོག་མ་དང་མ་འདྲེས་པ་ལ་བཅོ་བརྒྱད་ཡོད་དེ། སྟོབས་བཅུ་མི་འཇིགས་པ་བཞི། དྲན་པ་ཉེར་གཞག་གསུམ། ཐུགས་རྗེ་ཆེན་པོ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 20:
དབྱེ་ན་ཆོས། དོན། ངེས་ཚིག་སྤོབས་པ་སོ་སོ་ཡང་དག་པར་རིག་པ་བཞི་ཡོད།
Enumeration Block 21:
མངོན་ཤེས་ལ་དྲུག་ཡོད་དེ། རྫུ་འཕྲུལ་ཡུལ་ཤེས་ཀྱི་མངོན་ཤེས་སོགས་དྲུག་ཡོད་པའི་ཕྱིར།
Enumeration Block 22:
དེའི་ཡུལ་ལ་སྤྲུལ་པ་དང་འགྲོ་བ་གཉིས་ཡོད་ཅིང༌། འགྲོ་བ་ལ་གསུམ་ཡོད་དེ། འདབ་ཆགས་བྱ་བཞིན་ལུས་ཕྱིན་བྱེད་ཀྱི་འགྲོ་བ། ཐག་རིང་པོ་ཡང་ཐུང་ངུར་མོས་པས་མྱུར་དུ་འགྲོ་མོས་པ་ལས་བྱུང་བའི་འགྲོ་བ་ཡིད་ལྟར་མགྱོགས་པའི་འགྲོ་བ་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 23:
སྤྲུལ་པ་ལ་གཉིས་ཡོད་དེ། འདོད་པར་གཏོགས་པའི་སྤྲུལ་པ། གཟུགས་ཁམས་སུ་གཏོགས་པའི་སྤྲུལ་པ་གཉིས་ཡོད་པའི་ཕྱིར།
Enumeration Block 24:
སྤྲུལ་པ་ཐམས་ཅད་བསྡུ་ན་གཉིས་སུ་འདུས་ཏེ། རང་ཉིད་སེང་གེ་སོགས་སུ་སྤྲུལ་པ་རང་གི་ལུས་དང་འབྲེལ་བ་དང༌། །ཕྱི་རོལ་ཏུ་སེང་གེ་སོགས་སྤྲུལ་པ་ལྟ་བུ་གཞན་གྱི་ལུས་དང་འབྲེལ་བ་གཉིས་སུ་འདུས་པའི་ཕྱིར།
Enumeration Block 25:
རྫུ་འཕྲུལ་ལ་དབྱེ་ན་ལྔ་ཡོད་དེ། སྒོམ་བྱུང་གི་རྫུ་འཕྲུལ། སྐྱེས་ཐོབ་ཀྱི། གསང་སྔགས་ཀྱིས་ནམ་མཁའ་ལ་འགྲོ་ནུས་པ་ལྟ་བུ་གསང་སྔགས་ཀྱི། རྨ་བྱའི་མདོངས་དང་རུས་སྦལ་གྱི་ཟེ་བ་ལ་སོགས་པའི་སྨན་དག་དང༌། རྒྱལ་པོ་ང་ལས་ནུས་དང་བར་སྲིད་པ་ལྟ་བུ་ལས་ལས་སྐྱེས་པའི་རྫུ་འཕྲུལ་དང་ལྔ་ཡོད་པའི་ཕྱིར།
Enumeration Block 26:
གནས་བརྒྱད་པ་སྙོམས་འཇུག་བསྟན་པའི་གནས་བཤད་པ་ལ། སྙོམས་འཇུག་དངོས་དང༌། དེ་ལ་བརྟེན་པའི་ཡོན་ཏན་ནོ། །
Enumeration Block 27:
བསམ་གཏན་དག་ནི་རྣམ་གཉིས་བཞི། །ཞེས་སོགས་ཀྱི་སྐབས་སུ་སྤྱི་དོན། གཞུང་དོན་གཉིས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། བསྡུ་བ། སོ་སོའི་རང་བཞིན། བྱེ་བྲག་ཏུ་བསམ་གཏན་གྱི་ཡན་ལག་གི་དབྱེ་བསྡུ། ཉོན་མོངས་ཅན་ལ་ཡན་ལག་རྣམ་པར་མི་འཇོག་པའི་རྒྱུ་མཚན། ཁྱད་ཆོས་བཤད་པའོ། །
Enumeration Block 28:
ངོ་བོའི་སྒོ་ནས་དབྱེ་ན། བསམ་གཏན་གྱི་དངོས་གཞི་བཞི་དང༌། གཟུགས་མེད་ཀྱི་དེ་བཞི་སྟེ་བརྒྱད་ཡོད། བརྒྱད་པོའི་དང་པོ་བདུན་ལ། ཉོན་མོངས་ཅན་དང༌། དག་པ་བ། ཟག་མེད་གསུམ་གསུམ་ཡོད།
Enumeration Block 29:
གསུམ་པ་ནི། གཉིས་སུ་འདུས་ཏེ། བསམ་གཏན་གྱི་དངོས་གཞིའི་སྙོམས་འཇུག་རྣམས་རྒྱུ་སྙོམས་འཇུག་གི་བསམ་གཏན་གྱི་དངོས་གཞི་དང༌། འབྲས་བུ་སྐྱེ་བའི་བསམ་གཏན་གྱི་དངོས་གཞི་གཉིས་སུ་འདུ།

Enumeration Block 1:
གནས་བརྒྱད་པ་སྙོམས་འཇུག་བསྟན་པའི་གནས་བཤད་པ་ལ། སྙོམས་འཇུག་དངོས་དང༌། དེ་ལ་བརྟེན་པའི་ཡོན་ཏན་ནོ། །
Enumeration Block 2:
གཞུང་དོན་གཉིས། དང་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། བསྡུ་བ། སོ་སོའི་རང་བཞིན། བྱེ་བྲག་ཏུ་བསམ་གཏན་གྱི་ཡན་ལག་གི་དབྱེ་བསྡུ། ཉོན་མོངས་ཅན་ལ་ཡན་ལག་རྣམ་པར་མི་འཇོག་པའི་རྒྱུ་མཚན། ཁྱད་ཆོས་བཤད་པའོ། །
Enumeration Block 3:
གཉིས་པ་དེ་ལ་བརྟེན་པའི་ཡོན་ཏན་ལ། ཚད་མེད། རྣམ་ཐར། ཟིལ་གནོན། ཟད་པར་དེ་དག་གི་སྤྲོས་པའོ། །
Enumeration Block 4:
