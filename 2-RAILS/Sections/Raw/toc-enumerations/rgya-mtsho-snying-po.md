Enumeration Block 1:
མཆོད་ཡུལ་གྱི་སྟོན་པ་ངོས་བཟུང༌། དེ་ཐོབ་པ་ལ་གེགས་བྱེད་ཀྱི་སྒྲིབ་པ། དེ་སྤོང་བྱེད་ཀྱི་གཉེན་པོ་དང་གསུམ་ལས།
Enumeration Block 2:
བརྗོད་བྱ་དགོས་པ་ཉིང་དགོས་འབྲེལ་བ་བཞི་ལས།
Enumeration Block 3:
བཞི་པ་བསྟན་བཅོས་ཀྱི་ལུས་དངོས་བཤད་པ་ལ་གཉིས་ཏེ། ལུས་རྣམ་པར་བཞག་པ་དང༌། ཡན་ལག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། ནམ་མཁའ། བརྟགས་འགོག བརྟགས་མིན་གྱི་འགོག་པའོ། །
Enumeration Block 5:
ཁམས་བསྟན་པའི་གནས་ཀྱི་དོན་ལ་གཉིས། གནས་ཀྱི་གཞུང་བཤད་པ་དང༌། གནས་ཀྱི་མཚན་བསྟན་པའོ། །དང་པོ་ལ་བཞི། འདུས་བྱས་ཀྱི་རྣམ་གཞག ཕུང་ཁམས་སྐྱེ་མཆེད་ཀྱི་རྣམ་གཞག ཆོས་གསུམ་གྱིས་ཐམས་ཅད་བསྡུས་པར་བསྟན་པ། ཁམས་ཀྱི་རྣམ་པའི་རབ་དབྱེའོ། །དང་པོ་ལ་གསུམ། འདུས་བྱས་ཀྱི་མཚན་གཞི། མིང་གི་རྣམ་གྲངས། ཟག་བཅས་ཀྱི་རྣམ་གྲངས་བྱེ་བྲག་ཏུ་བཤད་པའོ། །

Enumeration Block 1:
གནས་བརྒྱད་ལས་དང་པོ་ཁམས་བསྟན་པའི་གནས་ཀྱི་དོན་ལ་གཉིས། གནས་ཀྱི་གཞུང་བཤད་པ་དང༌། གནས་ཀྱི་མཚན་བསྟན་པའོ། །དང་པོ་ལ་བཞི། འདུས་བྱས་ཀྱི་རྣམ་གཞག ཕུང་ཁམས་སྐྱེ་མཆེད་ཀྱི་རྣམ་གཞག ཆོས་གསུམ་གྱིས་ཐམས་ཅད་བསྡུས་པར་བསྟན་པ། ཁམས་ཀྱི་རྣམ་པའི་རབ་དབྱེའོ། །དང་པོ་ལ་གསུམ། འདུས་བྱས་ཀྱི་མཚན་གཞི། མིང་གི་རྣམ་གྲངས། ཟག་བཅས་ཀྱི་རྣམ་གྲངས་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ཕུང་ཁམས་སྐྱེ་མཆེད་ཀྱི་རྣམ་གཞག་ལ་བཞི། ཕུང་ཁམས་སྐྱེ་མཆེད་སོ་སོའི་རང་བཞིན། སྒྲ་འཇུག་པའི་རྒྱུ་མཚན། ཆོས་གསུམ་བསྟན་པའི་དགོས་པ། ཆོས་གསུམ་གྱི་གོ་རིམ་མོ། །དང་པོ་ལ་གསུམ། རྒྱས་པར་བཤད། བསྡུས་ཏེ་བསྟན། དོགས་པ་བཅད་པའོ། །དང་པོ་ལ་གསུམ། གཟུགས་ཀྱི་ཕུང་ཁམས་སྐྱེ་མཆེད་བཤད། ཚོར་སོགས་གསུམ་གྱི། རྣམ་ཤེས་ཀྱི་དེ་བཤད་པའོ། །དང་པོ་ལ་གསུམ། བསྟན་པ་དང༌། བཤད་པ་དང༌། ཁམས་དང་སྐྱེ་མཆེད་དུ་བཞག་ཚུལ་ལོ། །
Enumeration Block 3:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་གསུམ། དབང་པོ་ལྔ་བཤད། དོན་ལྔ་བཤད། རིག་བྱེད་མ་ཡིན་པའི་གཟུགས་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་དོན་ལྔ་བཤད་པ་ལ་ལྔ་ལས།
Enumeration Block 5:
གསུམ་པ་རིག་བྱེད་མིན་པའི་གཟུགས་བཤད་པ་ལ། དངོས་དང༌། དེའི་རྒྱུ་འབྱུང་བ་བཤད་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ཚོར་སོགས་གསུམ་གྱི་ཕུང་ཁམས་སྐྱེ་མཆེད་བཤད་པ་ལ་བཞི། ཚོར་བ། འདུ་ཤེས། འདུ་བྱེད། ཆོས་ཀྱི་སྐྱེ་མཆེད་དང་ཁམས་སུ་བསྟན་པའོ། །

Enumeration Block 1:
གསུམ་པ་ཆོས་གསུམ་གྱིས་ཐམས་ཅད་བསྡུས་པར་བསྟན་པ་ལ། ཆོས་ཀྱི་ཕུང་པོ་བསྡུ་བ། ཕུང་ཁམས་སྐྱེ་མཆེད་གཞན་བསྡུ་བ། ཞར་ལ་ཁམས་གཉིས་ཀྱི་ངོ་བོ་བསྟན་པའོ། །དང་པོ་ལ། དངོས་དང༌། ཆོས་ཕུང་གི་ཚད་དོ། །
Enumeration Block 2:
གཉིས་པ་ཆོས་ཕུང་གི་ཚད་ལ། གཞན་ལུགས་དགག རང་ལུགས་བཞག་པའོ། །
Enumeration Block 3:
གསུམ་པ་ཞར་ལ་ཁམས་གཉིས་ཀྱི་ངོ་བོ་བསྟན་པ་ལ། ནམ་མཁའ་དང༌། རྣམ་ཤེས་གཉིས་ལས།
Enumeration Block 4:
བཞི་པ་ཁམས་ཀྱི་རྣམ་པའི་རབ་དབྱེ་ལ་བདུན། གཉིས་ཚན་གྱི་དབྱེ་བ་དང༌། གསུམ་ཚན། བཅས་མ་བཅས། གཟུགས་ཅན་གྱི་དབྱེ་བ། བྱུང་བ་གསུམ་དང༌། ཐོབ་པའི་ཁྱད་པར། ཕྱི་ནང་ལ་སོགས་པའི་དབྱེ་བའོ། །དང་པོ་ལ། བསྟན་དུ་ཡོད་མེད་དང༌། ཐོགས་བཅས་ཐོགས་མེད་ཀྱི་རྣམ་པའོ། །
Enumeration Block 5:
གཉིས་པ་གསུམ་ཚན་གྱི་རྣམ་པ་ལ། དགེ་སོགས་གསུམ་གྱི་རྣམ་པ་དང༌། ཁམས་གསུམ་དུ་གཏོགས་པའི་རྣམ་པའོ། །
Enumeration Block 6:
གསུམ་པ་བཅས་མ་བཅས་ཀྱི་རྣམ་པ་ལ། ཟག་པ་དང་བཅས་མ་བཅས། རྟོག་དཔྱོད་དང་བཅས་མ་བཅས། དམིགས་པ་དང་བཅས་མ་བཅས་སོ། །
Enumeration Block 7:
བཞི་པ་གཟུགས་ཅན་གྱི་དབྱེ་བ་ལ། ཟིན་མ་ཟིན་གྱི་དབྱེ་བ། འབྱུང་འབྱུང་གྱུར་གྱི་དབྱེ་བ། བསགས་མ་བསགས་ཀྱི་དབྱེ་བ། གཅད་བྱ་གཅོད་བྱེད་ཀྱི་དབྱེ་བ། སྲེག་འཇལ་གྱི་དབྱེ་བའོ། །
Enumeration Block 8:
ལྔ་པ་བྱུང་བ་གསུམ་ལ། སྤྱིར་བཏང་བ་དང༌། དམིགས་ཀྱིས་བསལ་བའོ། །
Enumeration Block 9:
བདུན་པ་ཕྱི་ནང་ལ་སོགས་པའི་དབྱེ་བ་ལ། ཕྱི་ནང་གི་རྣམ་པ། རྟེན་བཅས་དེ་མཚུངས་ཀྱི། མཐོང་སྤང་སོགས་ཀྱི། ལྟ་བ་ཡིན་མིན་གྱི། རྣམ་ཤེས་གང་གི་ཡུལ་ཡིན་པ། རྟག་མི་རྟག་གི ། དབང་པོ་ཡིན་མིན་གྱི་རྣམ་པའོ། །
Enumeration Block 10:
གཉིས་པ་རྟེན་བཅས་དེ་མཚུངས་ཀྱི་རྣམ་པ་ལ། དངོས་དང༌། དེ་མཚུངས་ཀྱི་དོན་ཏོ། །
Enumeration Block 11:
གསུམ་པ་མཐོང་སྤང་སོགས་ཀྱི་རྣམ་པ་ལ། དངོས་དང༌། གནས་མ་བུའི་འདོད་པ་དགག་པའོ། །
Enumeration Block 12:
བཞི་པ་ལྟ་བ་ཡིན་མིན་གྱི་རྣམ་པ་ལ། དངོས་དང༌། དེ་ལས་འཕྲོས་པའི་དོན་ཏོ། །
Enumeration Block 13:
གཉིས་པ་དེ་ལས་འཕྲོས་པའི་དོན་ལ། དབང་པོའི་ཤེས་རབ་ལྟ་བ་ཡིན་པ་དགག མིག་ལྟ་བ་ཡིན་པར་སྒྲུབ། །དབང་པོས་ཡུལ་འཛིན་པའི་ཁྱད་པར། རྟེན་གྱི་དུས་ངེས་པ། རྟེན་དང་བརྟེན་པའི་རྒྱུ་མཚན། དབང་ཡུལ་རྣམ་ཤེས་དང་རྟེན་གྱི་ས་པའི་ངེས་པའོ། །
Enumeration Block 14:
གཉིས་པ་མིག་ལྟ་བ་ཡིན་པར་སྒྲུབ་པ་ལ། དངོས་དང༌། དོགས་པ་གཅོད་པའོ། །
Enumeration Block 15:
གཉིས་པ་དོགས་གཅོད་ལ། ཐམས་ཅད་ཀྱིས་མཐོང་མི་མཐོང་དཔྱད། མིག་དང་མིག་ཤེས་གང་གིས་མཐོང་དཔྱད། མིག་གཉིས་ཀས་མཐོང་མི་མཐོང་དཔྱད་པའོ། །
Enumeration Block 16:

གསུམ་པ་རྒྱུ་རྐྱེན་འབྲས་བུ་དང་བཅས་པའི་རྣམ་གཞག་བཤད་པ་ལ། རྒྱུ་བཤད་པ། འབྲས་བུ་བཤད་པ། རྒྱུ་འབྲས་གཉིས་ཀྱི་ཐུན་མོང་གི་ཆོས་བཤད་པ། རྐྱེན་བཤད་པའོ། །དང་པོ་ལ། དབྱེ་བས་མདོར་བསྟན། སོ་སོའི་རང་བཞིན་རྒྱས་པར་བཤད། །དུས་ངེས་པས་མཇུག་བསྡུ་བའོ། །
Enumeration Block 6:
གཉིས་པ་སོ་སོའི་རང་བཞིན་རྒྱས་བཤད་ལ། བྱེད་རྒྱུ། ལྷན་ཅིག་བྱུང་བའི། སྐལ་མཉམ། མཚུངས་ལྡན། ཀུན་འགྲོ། རྣམ་སྨིན་གྱི་རྒྱུའོ། །
Enumeration Block 7:
གཉིས་པ་ལྷན་ཅིག་འབྱུང་བའི་རྒྱུ་ལ། ངོ་བོ་ངོས་བཟུང༌། མཚན་གཞི་དཔེར་བརྗོད། དེ་ལས་འཕྲོས་པའི་དོན་ཏོ། །
Enumeration Block 8:
གསུམ་པ་འཕྲོས་པའི་དོན་ལ། སེམས་ཀྱི་རྗེས་འཇུག་ངོས་བཟུང་བ་དང༌། དེ་སེམས་ཀྱི་རྗེས་སུ་ཇི་ལྟར་འཇུག་ཚུལ་ལོ། །
Enumeration Block 9:
གསུམ་སྐལ་མཉམ་གྱི་རྒྱུ་ལ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 10:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ། ཟག་བཅས་ཀྱི་འདྲ་བ། དུས་ཀྱི་ཁྱད་པར། ཟག་མེད་བྱེ་བྲག་ཏུ་བཤད་པ། དེ་འཇིག་རྟེན་པའི་སྦྱོར་བྱུང་ལ་མཚུངས་པར་བསྟན་པའོ། །
Enumeration Block 11:
གཉིས་པ་འབྲས་བུ་བཤད་པ་ལ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 12:
གཉིས་པ་རྒྱས་བཤད་ལ། རྒྱུ་གང་གི་འབྲས་བུ་གང་ཡིན་པ་དང༌། འབྲས་བུ་ལྔའི་ངོ་བོའོ། །
Enumeration Block 13:
གཉིས་པ་འབྲས་བུ་ལྔའི་ངོ་བོ་ལ། རྣམ་སྨིན་གྱི། རྒྱུ་མཐུན་གྱི། བྲལ་བའི། སྐྱེས་བུའི་བྱེད་པའི། བདག་པོའི་འབྲས་བུའི་ངོ་བོའོ། །
Enumeration Block 14:
གསུམ་པ་རྒྱུ་འབྲས་གཉིས་ཀྱི་ཐུན་མོང་གི་ཆོས་བཤད་པ་ལ། རྒྱུ་འབྲས་འཛིན་འབྱིན་གྱི་དུས། འབྲས་བུ་གང་རྒྱུ་དུས་བསྐྱེད་པའོ། །དང་པོ་ལ། འཛིན་པའི་དུས་དང༌། འབྱིན་པའི་དུས་སོ། །
Enumeration Block 15:
གཉིས་པ་འབྲས་བུ་གང་རྒྱུ་དུས་སྐྱེད་པ་ལ། མཚུངས་ལྡན་དང༌། མཚུངས་ལྡན་མ་ཡིན་པའི་སྐྱེད་ཚུལ་ལོ། །དང་པོ་ལ། བཤད་པ་དང༌། བསྡུ་བའོ། །
Enumeration Block 16:
བཞི་པ་རྐྱེན་བཤད་པ་ལ། མདོར་བསྟན། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 17:
གཉིས་པ་རྒྱས་བཤད་ལ། རྐྱེན་བཞི་སོ་སོའི་རང་བཞིན། རྐྱེན་གང་དུས་གང་ལ་བྱ་བ་བྱེད་པ། དངོས་པོ་གང་རྐྱེན་དུ་ལས་སྐྱེ་བ། དེ་མ་ཐག་རྐྱེན་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ། རྒྱུའི་རྐྱེན། དེ་མ་ཐག་རྐྱེན། དམིགས་རྐྱེན། བདག་རྐྱེན་ནོ། །
Enumeration Block 18:
གཉིས་པ་རྐྱེན་གང་དུས་གང་ལ་བྱ་བ་བྱེད་པ་ལ། ལྷན་འབྱུང་དང་མཚུངས་ལྡན་གྱི་རྒྱུ་དུས་གང་ལ་དང༌། སྐལ་མཉམ་སོགས་གསུམ་དང༌། དེ་མ་ཐག་རྐྱེན་དང་དམིགས་རྐྱེན་དུས་གང་ལ་བྱ་བ་བྱེད་པའོ། །
Enumeration Block 19:
གསུམ་པ་དངོས་པོ་གང་རྐྱེན་དུ་ལས་སྐྱེ་བ་ལ། སྤྱིར་བསྟན་པ་དང༌། གཟུགས་ཅན་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ། རང་ལུགས་བཞག་པ་དང༌། གཞན་ལུགས་དགག་པའོ། །དང་པོ་ལ། རྐྱེན་བཞི་ལས། གསུམ་ལས། གཉིས་ལས་སྐྱེ་བའོ། །
Enumeration Block 20:
གཉིས་པ་གཟུགས་ཅན་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། འབྱུང་བས་འབྱུང་བའི་རྐྱེན་བྱེད་ཚུལ། འབྱུང་བས་འབྱུང་གྱུར་གྱི་རྐྱེན་བྱེད་ཚུལ། འབྱུང་གྱུར་ནང་ཕན་ཚུན་རྐྱེན་བྱེད་ཚུལ། འབྱུང་གྱུར་གྱིས་འབྱུང་བའི་རྐྱེན་བྱེད་ཚུལ་ལོ། །
Enumeration Block 21:
བཞི་པ་དེ་མ་ཐག་རྐྱེན་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། སེམས་བཅུ་གཉིས་སུ་དབྱེ་བ། བཅུ་གཉིས་པོ་གང་ལས་གང་རྙེད་པ། སེམས་ཉི་ཤུར་དབྱེ་བ། སེམས་ཉོན་མོངས་ཅན་གྱི་རྙེད་ཚུལ་ལོ། །
Enumeration Block 22:
གཉིས་པ་བཅུ་གཉིས་པོ་གང་ལས་གང་རྙེད་པ་ལ། འདོད་སེམས་ལ་སྦྱར་བ། གཟུགས་ཀྱི། གཟུགས་མེད་ཀྱི། སློབ་པའི། མི་སློབ་པའི་སེམས་ལ་སྦྱར་བའོ། །དང་པོ་ལ། དགེ་སེམས་ལ། མི་དགེ་བའི་སེམས་ལ། ལུང་མ་བསྟན་གྱི་སེམས་ལ་སྦྱར་བའོ། །དང་པོ་ལ། དགེ་སེམས་ཀྱི་མཇུག་ཐོགས་སུ་སེམས་དུ་འབྱུང་བ་དང༌། སེམས་དུའི་མཇུག་ཐོགས་སུ་དགེ་སེམས་འབྱུང་བའོ། །
Enumeration Block 23:
གཉིས་པ་མི་དགེ་བའི་སེམས་ལ་སྦྱར་བ་ལ། དུའི་མཇུག་ཏུ་དེ་འབྱུང་བ་དང༌། དེའི་མཇུག་ཏུ་དུ་འབྱུང་བའོ། །
Enumeration Block 24:
གསུམ་པ་ལུང་མ་བསྟན་ལ་སྦྱར་བ་ལ། བསྒྲིབས་ལ་ལུང་མ་བསྟན་དང༌། མ་བསྒྲིབས་ལ་ལུང་མ་བསྟན་ནོ། །
Enumeration Block 25:
གཉིས་པ་མ་བསྒྲིབས་ལུང་མ་བསྟན་ལ་སྦྱར་བ་ལ། དུ་ལས་དེ་འབྱུང་བ་དང༌། དེ་ལས་དུ་འབྱུང་བའོ། །

Enumeration Block 1:
བཞི་པ་དེ་མ་ཐག་རྐྱེན་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། སེམས་བཅུ་གཉིས་སུ་དབྱེ་བ། བཅུ་གཉིས་པོ་གང་ལས་གང་རྙེད་པ། སེམས་ཉི་ཤུར་དབྱེ་བ། སེམས་ཉོན་མོངས་ཅན་གྱི་རྙེད་ཚུལ་ལོ། །
Enumeration Block 2:
གཉིས་པ་བཅུ་གཉིས་པོ་གང་ལས་གང་རྙེད་པ་ལ། འདོད་སེམས་ལ་སྦྱར་བ། གཟུགས་ཀྱི། གཟུགས་མེད་ཀྱི། སློབ་པའི། མི་སློབ་པའི་སེམས་ལ་སྦྱར་བའོ། །དང་པོ་ལ། དགེ་སེམས་ལ། མི་དགེ་བའི་སེམས་ལ། ལུང་མ་བསྟན་གྱི་སེམས་ལ་སྦྱར་བའོ། །དང་པོ་ལ། དགེ་སེམས་ཀྱི་མཇུག་ཐོགས་སུ་སེམས་དུ་འབྱུང་བ་དང༌། སེམས་དུའི་མཇུག་ཐོགས་སུ་དགེ་སེམས་འབྱུང་བའོ། །
Enumeration Block 3:
གཉིས་པ་མི་དགེ་བའི་སེམས་ལ་སྦྱར་བ་ལ། དུའི་མཇུག་ཏུ་དེ་འབྱུང་བ་དང༌། དེའི་མཇུག་ཏུ་དུ་འབྱུང་བའོ། །

Enumeration Block 1:

Enumeration Block 2:
གསུམ་པ་སྐྱེ་གནས་བཞིར་དབྱེ་བ་ལ། གང་དུ་འཇུག་པ་སྐྱེ་གནས་ཀྱི་དབྱེ་བ། གང་གིས་འཇུག་པའི་བར་སྲིད་བཤད་པ། དེས་སྐྱེ་གནས་སུ་བགྲོད་པའི་ཚུལ་ལོ། །དང་པོ་ལ། དབྱེ་བ་དངོས་དང༌། འགྲོ་བ་གང་ལ་སྐྱེ་གནས་གང་ལྡན་དཔྱད་པའོ། །
Enumeration Block 3:
གཉིས་པ་འགྲོ་བ་གང་ལ་སྐྱེ་གནས་གང་ལྡན་དཔྱད་པ་ལ་གསུམ། མི་དང་དུད་འགྲོ་ལ་གང་ལྡན་པ། དམྱལ་བ་དང་ལྷ་སོགས་ལ་གང་ལྡན་པ། ཡི་དྭགས་ལ་གང་ལྡན་པའོ། །
Enumeration Block 4:

Enumeration Block 5:

Enumeration Block 6:

Enumeration Block 2:

Enumeration Block 1:
གཉིས་པ་དམྱལ་བའི་གནས་བཤད་པ་ལ། ཚ་དམྱལ་ཉེ་འཁོར་དང་བཅས་པ། གྲང་དམྱལ་གྱི་གནས་བཤད་པའོ། །དང་པོ་ལ། མནར་མེད། རབ་ཚ་སོགས་བདུན། ཉེ་འཁོར་བཤད་པའོ། །
Enumeration Block 2:
གསུམ་པ་ཉེ་འཁོར་བ་ལ། ཉེ་འཁོར་བའི་གྲངས། ཕྱོགས་གང་ན་ཡོད་པ། སྡེ་ཚན་གྱི་མིང་ངོ༌། །
Enumeration Block 3:
གསུམ་པ་ལྷའི་གནས་བཤད་པ་ལ། དངོས་དང༌། ཞར་ལ་དེའི་སེམས་ཅན་གྱི་ཁྱད་པར་རོ། །དང་པོ་ལ་གཉིས། ས་དང་འབྲེལ་བ་དང༌། མ་འབྲེལ་བའོ། །དང་པོ་ལ། རྒྱལ་ཆེན་རིགས་བཞི་པ་དང༌། སུམ་ཅུ་རྩ་གསུམ་པའི་གནས་སོ། །དང་པོ་ལ། གཞལ་མེད་ཁང༌། རི་ལ་བརྟེན་པའོ། །དང་པོ་ལ་ཉི་ཟླའི་ཐག་ཚད། བྱ་བ་བྱེད་ཚུལ། དེ་ལ་བརྟེན་པའི་དུས་ཀྱི་ཁྱད་པར། ཟླ་བ་འཕེལ་འགྲིབ་ཀྱི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ། ཉི་ཟླ་མཐོ་དམན་གྱི་ཚད། ཉི་ཟླའི་རྒྱ་ཁྱོན་གྱི་ཚད་དོ། །
Enumeration Block 4:
གསུམ་པ་དེ་ལ་བརྟེན་པའི་དུས་ཚིགས་ལ། ཉིན་མཚན་རིང་ཐུང་དུ་འགྱུར་བའི་དུས། རིང་ཐུང་གི་ཚད། ཉི་མ་ཟློག་པའི་དུས་སོ། །
Enumeration Block 5:
གཉིས་པ་རི་ལ་བརྟེན་པའི་གནས་ལ། རྟེན་རི་རབ་ཀྱི་བང་རིམ་བཤད་པ་དང༌། ལྷ་གང་བརྟེན་བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལྷ་གང་བརྟེན་བཤད་པ་ལ། རི་རབ་ལ་གང་བརྟེན་པ་དང༌། གསེར་གྱི་རི་བདུན་ལ་གང་བརྟེན་པའོ། །
Enumeration Block 7:

Enumeration Block 8:
གསུམ་པ་སུམ་ཅུ་རྩ་གསུམ་གྱི་གནས་རྒྱས་པར་བཤད་པ་ལ་གྲོང་ཁྱེར་དང༌། སྐྱེད་མོས་ཚལ་ལོ། །དང་པོ་ལ། གྲོང་ཁྱེར་སྤྱི་དང༌། དབང་པོའི་ཕོ་བྲང་ངོ༌། །
Enumeration Block 9:
གཉིས་པ་སྐྱེད་ཚལ་བཤད་པ་ལ། སྐྱེད་ཚལ་དངོས། ས་གཞི། ལྗོན་ཤིང༌། འདུན་སའོ། །
Enumeration Block 10:
གཉིས་པ་ཞར་ལ་དེའི་སེམས་ཅན་གྱི་ཁྱད་པར་བཤད་པ་ལ། འདོད་པ་སྤྱོད་པ། ལྷའི་བུ་སྐྱེ་བ། འདོད་བདེ་སྐྱེ་བ། གོང་འོག་གི་བར་ཐག་གི་ཚད། གོང་མར་བགྲོད་ཚུལ་ལོ། །
Enumeration Block 11:
གཉིས་པ་ལྷའི་བུ་སྐྱེ་བ་ལ། འདོད་ལྷའི་བུ་དང༌། གཟུགས་ཀྱི་བུའོ། །
Enumeration Block 12:
གསུམ་པ་འདོད་བདེ་སྐྱེ་བ་ལ། དངོས་དང༌། ཞར་ལ་གཟུགས་བདེ་སྐྱེ་བའོ། །
Enumeration Block 13:
གསུམ་པ་སྟོང་གསུམ་ངོས་བཟུང་བ་ལ། སྟོང་སྤྱི་ཕུད། སྟོང་གཉིས་བར་མ། སྟོང་གསུམ་སྟོང་ཆེན་ངོས་བཟུང་བའོ། །
Enumeration Block 14:

གསུམ་པ་འཇིག་པའི་བསྐལ་པའི་ཚུལ་ལ། བསམ་གཏན་གསུམ་པ་མན་འཇིག་ཚུལ། བཞི་པ་འཇིག་ཚུལ། མེ་ཆུ་རླུང་གསུམ་གྱིས་འཇིག་པའི་གྲངས་བསྟན་པའོ། །དང་པོ་ལ། གང་གིས་གང་འཇིག་པ། །མ་ཞིག་པར་ལུས་པའི་རྩེ་མོ། དེ་རྣམས་ཀྱི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 5:
གཉིས་པ་བསམ་གཏན་བཞི་པ་འཇིག་ཚུལ་ལ། མེ་ཆུ་རླུང་གསུམ་གྱིས་མི་འཇིག་པར་བསྟན་པ་དང༌། འཇིག་ཚུལ་དངོས་སོ། །
Enumeration Block 6:
བཞི་པ་ལས་བསྟན་པའི་གནས་ཀྱི་དོན་ལ། གནས་ཀྱི་གཞུང་བཤད་པ་དང༌། གནས་ཀྱི་མཚན་བསྟན་པའོ། །དང་པོ་ལ། ཐམས་ཅད་ལས་ལས་བྱུང་བ། ལས་ཉིད་གཏན་ལ་དབབ་པ། ཆོས་ཀྱི་རྣམ་གྲངས་བསྟན་པས་མཇུག་བསྡུ་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལས་ཉིད་གཏན་ལ་དེ་དབབ་པ་ལ། ལས་ངོས་བཟུང་བ་དང༌། ལས་ཀྱི་རྣམ་གཞག་མདོ་ལས་འབྱུང་བའི་ལས་ཀྱི་དོན་ཏོ། །དང་པོ་ལ། ལས་ལ་གཉིས་སུ་དབྱེ་བ། དེ་སོ་སོའི་ངོ་བོ། རྣམ་རིག་ཡིན་མིན་ནོ། །
Enumeration Block 8:
གཉིས་པ་ལས་ཀྱི་རྣམ་གཞག་ལ། ལས་ལ་གཉིས་སུ་དབྱེ་བ། ལས་གསུམ་སྤྱིའི་ཆོས་ཀྱི་རྣམ་གཞག རིག་བྱེད་མིན་པའི་རྣམ་གཞག་གོ ། དང་པོ་ལ། རིག་བྱེད་དང༌། རིག་བྱེད་མིན་པའོ། །དང་པོ་ལ། ལུས་ཀྱི་རིག་བྱེད་དང༌། ངག་གི་རིག་བྱེད་བཤད་པའོ། །དང་པོ་ལ། བྱེ་སྨྲའི་ལུགས་ཀྱི་ངོ་བོ་ངོས་བཟུང་བ་དང༌། གནས་མ་བུ་པའི་ལུགས་ལ་དོགས་པ་བཅད་པ། མདོ་སྡེ་པའི་ལུགས་སོ། །
Enumeration Block 9:
གཉིས་པ་རིག་བྱེད་མིན་པ་ལ། རྫས་སུ་ཡོད་པའི་སྒྲུབ་བྱེད། ཁྱད་ཆོས་རྣམ་པར་བཞག་པའོ། །
Enumeration Block 10:
གཉིས་པ་ཁྱད་ཆོས་རྣམ་པར་བཞག་པ་ལ། རྒྱུའི། སའི། ངོ་བོའི། རྒྱུའི་ཁྱད་པར་གཞན་བསྟན་པའོ། །དང་པོ་ལ། སྐད་ཅིག་དང་པོ་དང༌། དེ་ཕྱིན་གྱི་རྒྱུའི་ཁྱད་པར་རོ། །
Enumeration Block 11:
གཉིས་པ་སའི་ཁྱད་པར་ལ། ཟག་བཅས་དང༌། ཟག་མེད་ཀྱི་སའི་ཁྱད་པར་རོ། །
Enumeration Block 12:
བཞི་པ་རྒྱུའི་ཁྱད་པར་གཞན་བསྟན་པ་ལ། འདོད་པའི་རིག་བྱེད་མིན་གཟུགས་ཀྱི་རྒྱུའི་ཁྱད་པར་དང༌། བསམ་གཏན་ཟག་མེད་ཀྱི་རྒྱུའི་ཁྱད་པར་རོ། །
Enumeration Block 13:
གཉིས་པ་ལས་གསུམ་སྤྱིའི་ཆོས་ཀྱི་རྣམ་གཞག་ལ། དངོས་ཀྱི་དོན་རྣམ་པར་བཞག་པ་དང༌། ཀུན་སློང་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ། དགེ་སོགས་ཀྱི་ཁྱད་པར། ཁམས་གང་ན་གང་ཡོད་པ། ཆོས་གསུམ་སོ་སོའི་དབྱེ་བའོ། །
Enumeration Block 14:
གཉིས་པ་ཁམས་གང་ན་གང་ཡོད་པ་ལ། མི་དགེ་བ་གང་ན་ཡོད་པ། རིག་བྱེད་མིན་པ་གང་ན་ཡོད་པ། རིག་བྱེད་ཙམ་གང་ན་ཡོད་པ། བསྒྲིབས་པའི་རིག་བྱེད་གང་ན་ཡོད་པའོ། །
Enumeration Block 15:
གསུམ་པ་ཆོས་གསུམ་སོ་སོའི་དབྱེ་བ་ལ། དགེ་བའི། མི་དགེ་བའི། ལུང་མ་བསྟན་གྱི་དབྱེ་བའོ། །དང་པོ་ལ། དོན་དམ་པའི་དགེ་བ་བཤད། ངོ་བོ་ཉིད་ཀྱི་དགེ་བ། མཚུངས་ལྡན་གྱི་དགེ་བ། ཀུན་སློང་གི་དགེ་བ་བཤད་པའོ། །
Enumeration Block 16:
གཉིས་པ་ཀུན་སློང་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། ཀུན་སློང་གི་དབྱེ་བ། དབྱེ་བ་སོ་སོའི་རང་བཞིན། མཚན་གཞི་ལ་མུ་བཞི་དཔྱད་པའོ། །
Enumeration Block 17:
གསུམ་པ་མཚན་གཞི་ལ་མུ་བཞི་དཔྱད་པ་ལ། རབ་ཏུ་འཇུག་བྱེད་ཁོ་ན་ཡིན་པའི་མུ། གཉིས་ཀ་ཡིན་པའི་མུ། རྗེས་སུ་འཇུག་བྱེད་ཁོ་ན་ཡིན་པའི་མུ། ཕན་ཚུན་འཇུག་ཚུལ་ལ་དཔྱད་པའི་མུ། གཉིས་ཀ་མིན་པའི་མུའོ། །
Enumeration Block 18:
བཞི་པ་ཕན་ཚུན་འཇུག་ཚུལ་ལ་དཔྱད་པའི་མུ་ལ། སྤྱིར་བཏང་དང༌། དམིགས་བསལ་ལོ། །
Enumeration Block 19:
གསུམ་པ་རིག་བྱེད་མ་ཡིན་པའི་རྣམ་གཞག་ལ། དབྱེ་བ་མདོར་བསྟན། རྣམ་གཞག་རྒྱས་བཤད་དོ། །
Enumeration Block 20:
གཉིས་པ་ལ། སྡོམ་པ་ཁྱད་པར་དུ་བཤད་པ་དང༌། ཐམས་ཅད་ཐུན་མོང་དུ་བསྟན་པའོ། །
Enumeration Block 21:
གཉིས་པ་ལ། སོ་ཐར་རྒྱས་བཤད། བསམ་གཏན་ཟག་མེད་རྒྱས་བཤད། ཞར་ལས་བྱུང་བའི་དོན་ཏོ། །དང་པོ་ལ། བསྡུས་ཏེ་བསྟན་པ་དང༌། ཕྱེ་སྟེ་བཤད་པ་གཉིས་ལས། དང་པོ་ལ། མིང་གི་སྒོ་ནས་བརྒྱད་དུ་དབྱེ་བ། རྫས་ཀྱི་སྒོ་ནས་བཞིར་བསྡུ་བ། གནས་པའི་ཚུལ་ལོ། །
Enumeration Block 22:
གཉིས་པ་ཕྱེ་སྟེ་བཤད་པ་ལ། སོ་སོའི་ངོ་བོ། མིང་གི་རྣམ་གྲངས། སྒྲ་དོན། ལྡན་པའི་གང་ཟག་གོ ། 
Enumeration Block 23:
གཉིས་པ་བསམ་གཏན་དང་ཟག་མེད་ཀྱི་སྡོམ་པ་རྒྱས་བཤད་ལ། གང་ལ་ལྡན་པ། སེམས་ཀྱི་རྗེས་འབྲང་དུ་བསྟན་པ། སྤོང་བའི་སྡོམ་པར་བསྟན་པའོ། །
Enumeration Block 24:
གཉིས་པ་ཐམས་ཅད་ཐུན་མོང་དུ་བསྟན་པ་ལ། དུས་ཇི་སྲིད་ལྡན་པ། ཚུལ་ཇི་ལྟར་ཐོབ་པ། རྒྱུ་གང་གིས་གཏོང་བ། རྟེན་གང་དང་ལྡན་པའོ། །དང་པོ་ལ། རིག་བྱེད་མིན་པའི་ལྡན་ཚུལ། རིག་བྱེད་ཀྱི་ལྡན་ཚུལ། སྡོམ་མིན་གྱི་མིང་གི་རྣམ་གྲངས། དེ་དག་གི་མུ་བཞི་བཤད་པའོ། །དང་པོ་ལ་གསུམ། མཉམ་པར་མ་བཞག་པའི་དང༌། མཉམ་པར་བཞག་པའི་དང༌། བར་མའི་ལྡན་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། སྡོམ་པ་དང༌། སྡོམ་མིན་ནོ། །

Enumeration Block 1:
གཉིས་པ་ལ། སྡོམ་པ་ཁྱད་པར་དུ་བཤད་པ་དང༌། ཐམས་ཅད་ཐུན་མོང་དུ་བསྟན་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། སོ་ཐར་རྒྱས་བཤད། བསམ་གཏན་ཟག་མེད་རྒྱས་བཤད། ཞར་ལས་བྱུང་བའི་དོན་ཏོ། །དང་པོ་ལ། བསྡུས་ཏེ་བསྟན་པ་དང༌། ཕྱེ་སྟེ་བཤད་པ་གཉིས་ལས། དང་པོ་ལ། མིང་གི་སྒོ་ནས་བརྒྱད་དུ་དབྱེ་བ། རྫས་ཀྱི་སྒོ་ནས་བཞིར་བསྡུ་བ། གནས་པའི་ཚུལ་ལོ། །
Enumeration Block 3:
གཉིས་པ་ཕྱེ་སྟེ་བཤད་པ་ལ། སོ་སོའི་ངོ་བོ། མིང་གི་རྣམ་གྲངས། སྒྲ་དོན། ལྡན་པའི་གང་ཟག་གོ །
Enumeration Block 4:
གཉིས་པ་བསམ་གཏན་དང་ཟག་མེད་ཀྱི་སྡོམ་པ་རྒྱས་བཤད་ལ། གང་ལ་ལྡན་པ། སེམས་ཀྱི་རྗེས་འབྲང་དུ་བསྟན་པ། སྤོང་བའི་སྡོམ་པར་བསྟན་པའོ། །
Enumeration Block 5:
གཉིས་པ་ཐམས་ཅད་ཐུན་མོང་དུ་བསྟན་པ་ལ། དུས་ཇི་སྲིད་ལྡན་པ། ཚུལ་ཇི་ལྟར་ཐོབ་པ། རྒྱུ་གང་གིས་གཏོང་བ། རྟེན་གང་དང་ལྡན་པའོ། །དང་པོ་ལ། རིག་བྱེད་མིན་པའི་ལྡན་ཚུལ། རིག་བྱེད་ཀྱི་ལྡན་ཚུལ། སྡོམ་མིན་གྱི་མིང་གི་རྣམ་གྲངས། དེ་དག་གི་མུ་བཞི་བཤད་པའོ། །དང་པོ་ལ་གསུམ། མཉམ་པར་མ་བཞག་པའི་དང༌། མཉམ་པར་བཞག་པའི་དང༌། བར་མའི་ལྡན་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། སྡོམ་པ་དང༌། སྡོམ་མིན་ནོ། །
Enumeration Block 6:
གསུམ་པ་བར་མ་ལྡན་ཚུལ་ལ་གཉིས། དངོས་དོན་དང༌། འཕྲོས་དོན་སྡོམ་སྡོམ་མིན་ཅན་ལ་ལྡན་ཚུལ་ལོ། །
Enumeration Block 7:
གཉིས་པ་ཚུལ་ཇི་ལྟར་ཐོབ་པ་ལ། སྡོམ་པའི་ཐོབ་ཚུལ་དང༌། སྡོམ་མིན་གྱི་དང༌། བར་མའི་ཐོབ་ཚུལ་ལོ། །དང་པོ་ལ། དངོས་དང༌། གང་ལས་ཐོབ་པའོ། །དང་པོ་ལ། བསམ་གཏན་གྱི་དང༌། ཟག་མེད་ཀྱི་དང༌། སོ་ཐར་སྡོམ་པའི་ཐོབ་ཚུལ་ལོ། །
Enumeration Block 8:
གསུམ་པ་སོ་ཐར་སྡོམ་པའི་ཐོབ་ཚུལ་ལ། སྤྱིར་བསྟན་པ། བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 9:
གཉིས་པ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། ལེན་པའི་དུས། སྡོམ་མིན་གྱི་དུས་ངེས་པ། བསྙེན་གནས་ཀྱི་ཁྱད་པར། དགེ་བསྙེན་གྱི་ཁྱད་པར་རོ། །
Enumeration Block 10:
གསུམ་པ་བསྙེན་གནས་ཀྱི་ཁྱད་པར་ལ། རྣམ་བཞག་སྤྱིར་བསྟན་པ། ཡན་ལག་བརྒྱད་ཀྱི་གྲངས་ངེས། སྐྱབས་འགྲོ་རྩོམ་བྱེད་དུ་དགོས་པའོ། །
Enumeration Block 11:
གཉིས་པ་ཡན་ལག་བརྒྱད་ཀྱི་གྲངས་ངེས་ལ། དངོས་དང༌། དོགས་གཅོད་དོ། །
Enumeration Block 12:
བཞི་པ་དགེ་བསྙེན་གྱི་ཁྱད་པར་ལ། ལུང་གི་དོན་བཤད་པ། མདོ་དང་འགལ་བ་སྤང་བ། སྡོམ་པ་ཆེ་ཆུང་གི་ཁྱད་པར། སྐྱབས་གནས་བཤད་པ། །ཡན་ལག་གི་ཁྱད་པར་རོ། །
Enumeration Block 13:
ལྔ་པ་ཡན་ལག་གི་ཁྱད་པར་ལ། ལོག་གཡེམ་ཡན་ལག་ཏུ་དང༌། རྫུན་ཡན་ལག་ཏུ་དང༌། མྱོས་འགྱུར་ཡན་ལག་ཏུ་འཇོག་པའི་དོན་ཏོ། །དང་པོ་ལ། དངོས་དང༌། དོགས་གཅོད་དོ། །
Enumeration Block 14:
གཉིས་པ་གང་ལས་ཐོབ་པ་ལ། སོ་སོར་བཤད་པ་དང༌། བསྡོམས་ནས་བཤད་པའོ། །དང་པོ་ལ། སོ་ཐར་གང་ལས་ཐོབ་པ། བསམ་གཏན་དང་ཟག་མེད་གང་ལས་ཐོབ་པའོ། །
Enumeration Block 15:
གཉིས་པ་སྡོམ་མིན་གྱི་ཐོབ་ཚུལ་ལ། གང་ལས་ཐོབ་པ་དང༌། ཇི་ལྟར་ཐོབ་པའོ། །
Enumeration Block 16:
གསུམ་པ་རྒྱུ་གང་གིས་གཏོང་བ་ལ། སྡོམ་པའི་གཏོང་རྒྱུ། སྡོམ་མིན་གྱི་གཏོང་རྒྱུ། བར་མའི་གཏོང་རྒྱུ། ཆོས་གཞན་གྱི་གཏོང་རྒྱུའོ། །དང་པོ་ལ་སོ་ཐར་དང༌། བསམ་གཏན་དང༌། ཟག་མེད་ཀྱི་གཏོང་རྒྱུའོ། །དང་པོ་ལ། སྤྱིར་བསྟན་པ་དང༌། འདོད་པ་མི་འདྲ་བ་བཀོད་པའོ། །

Enumeration Block 1:
ལྔ་པ་ཡན་ལག་གི་ཁྱད་པར་ལ། ལོག་གཡེམ་ཡན་ལག་ཏུ་དང༌། རྫུན་ཡན་ལག་ཏུ་དང༌། མྱོས་འགྱུར་ཡན་ལག་ཏུ་འཇོག་པའི་དོན་ཏོ། །དང་པོ་ལ། དངོས་དང༌། དོགས་གཅོད་དོ། །
Enumeration Block 2:
གཉིས་པ་གང་ལས་ཐོབ་པ་ལ། སོ་སོར་བཤད་པ་དང༌། བསྡོམས་ནས་བཤད་པའོ། །དང་པོ་ལ། སོ་ཐར་གང་ལས་ཐོབ་པ། བསམ་གཏན་དང་ཟག་མེད་གང་ལས་ཐོབ་པའོ། །
Enumeration Block 3:
གཉིས་པ་སྡོམ་མིན་གྱི་ཐོབ་ཚུལ་ལ། གང་ལས་ཐོབ་པ་དང༌། ཇི་ལྟར་ཐོབ་པའོ། །
Enumeration Block 4:
གསུམ་པ་རྒྱུ་གང་གིས་གཏོང་བ་ལ། སྡོམ་པའི་གཏོང་རྒྱུ། སྡོམ་མིན་གྱི་གཏོང་རྒྱུ། བར་མའི་གཏོང་རྒྱུ། ཆོས་གཞན་གྱི་གཏོང་རྒྱུའོ། །དང་པོ་ལ་སོ་ཐར་དང༌། བསམ་གཏན་དང༌། ཟག་མེད་ཀྱི་གཏོང་རྒྱུའོ། །དང་པོ་ལ། སྤྱིར་བསྟན་པ་དང༌། འདོད་པ་མི་འདྲ་བ་བཀོད་པའོ། །
Enumeration Block 5:
གཉིས་པ་འདོད་པ་མི་འདྲ་བ་བཀོད་པ་ལ། རྩ་ལྟུང་གཏོང་རྒྱུར་འདོད་པ། དམ་ཆོས་ནུབ་པ་དེར་འདོད་པ། ཁ་ཆེ་བས་རྩ་ལྟུང་གཏོང་རྒྱུར་མི་འདོད་པའོ། །
Enumeration Block 6:
གཉིས་པ་བསམ་གཏན་གྱི་གཏོང་རྒྱུ་ལ། དངོས་དང༌། ཞར་བྱུང་ངོ༌། །
Enumeration Block 7:
བཞི་པ་ཆོས་གཞན་གྱི་གཏོང་རྒྱུ་ལ། གཟུགས་མིན་དགེ་བ་གཏོང་རྒྱུ། གཟུགས་མིན་ཉོན་མོངས་ཅན་གཏོང་རྒྱུའོ། །
Enumeration Block 8:
བཞི་པ་གང་ཟག་གང་ལ་ལྡན་ཚུལ་ལ། སྡོམ་མིན་ལྡན་ཚུལ་དང༌། སྡོམ་པ་ལྡན་ཚུལ་ལོ། །
Enumeration Block 9:
གཉིས་པ་ལ། སྤྱིར་བསྟན་པ་དང༌། རྟེན་གང་ལ་སྡོམ་པ་གང་ཡོད་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ། མི་དང༌། ལྷ་ལ་གང་ལྡན་པའོ། །
Enumeration Block 11:

Enumeration Block 9:
དང་པོ་ལ། སྤོང་ལམ་འབྲས་བུ་དུ་དང་བཅས་པ། སྤོང་ལམ་ཟག་མེད། སྤོང་ལམ་མ་ཡིན་པའི་ཟག་བཅས། སྤོང་ལམ་མ་ཡིན་པའི་ཟག་མེད་དང་ལུང་མ་བསྟན་འབྲས་བུ་དུ་དང་བཅས་པའོ། །
Enumeration Block 10:
གཉིས་པ་དགེ་སོགས་ཀྱི་འབྲས་བུ་དུ་དང་བཅས་པ་ལ། དགེ་བའི། མི་དགེ་བའི། ལུང་མ་བསྟན་གྱི་འབྲས་བུ་དུ་དང་བཅས་པའོ། །
Enumeration Block 11:
གསུམ་པ་དུས་གསུམ་གྱི་འབྲས་བུ་ལ། འདས་པའི། ད་ལྟར་བའི། མ་འོངས་པའི་འབྲས་བུའོ། །
Enumeration Block 12:
ལྔ་པ་སློབ་མི་སློབ་ཀྱི་འབྲས་བུ་དུ་དང་བཅས་པ་ལ། སློབ་པའི། མི་སློབ་པའི། དེ་གཉིས་ལས་གཞན་པའི་འབྲས་བུ་དུ་དང་བཅས་པའོ། །
Enumeration Block 13:
དྲུག་པ་མཐོང་སྤང་སོགས་ཕན་ཚུན་འབྲས་བུ་དུ་དང་བཅས་པ་ལ། མཐོང་སྤང་འབྲས་བུ་དུ་དང་བཅས་པ། སྒོམ་སྤང༌། སྤང་བྱ་མ་ཡིན་པ་འབྲས་བུ་དུ་དང་བཅས་པའོ། །
Enumeration Block 14:
བཞི་པ་ལས་ཀྱི་རྣམ་གཞག་གཞན་བསྟན་པ་ལ། ལས་གང་རྒྱུ་གང་གིས་བྱེད་པ། འཕེན་རྫོགས་གཉིས་ཀྱི་ཁྱད་པར་རོ། །
Enumeration Block 15:
གཉིས་པ་འཕེན་རྫོགས་གཉིས་ཀྱི་ཁྱད་པར་ལ། འཕེན་བྱེད་ཀྱི་ཁྱད་པར། རྫོགས་བྱེད་ཀྱི་ཁྱད་པར། འཕེན་བྱེད་ལ་དོགས་པ་བཅད་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལས་སོ་སོར་བཤད་པ་ལ། སྤང་བྱ་སྒྲིབ་པ་གསུམ། བསྟེན་བྱ་བསོད་ནམས་བྱ་བའི་གཞི་གསུམ། ཆ་མཐུན་དགེ་བ་གསུམ་བཤད་པའོ། །དང་པོ་ལ། སྒྲིབ་པ་གསུམ་གྱི་ངོ་བོ། གང་ན་སྒྲིབ་པ་གང་ཡོད་པ། ལས་སྒྲིབ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལ། མཚམས་མེད་སྤྱིར་བཏང་བ། ཕ་མ་གསོད་པའི་མཚམས་མེད་ལ་དམིགས་བསལ། སྒྲིབ་པ་གཞན་གཉིས་གང་ན་ཡོད་པའོ། །
Enumeration Block 18:
གསུམ་པ་ལས་སྒྲིབ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། མཚམས་མེད་དང༌། དེ་དང་ཉེ་བའོ། །དང་པོ་ལ། མཚམས་མེད་དངོས། །དེའི་ལས་འབྲས། ལས་འབྲས་ཀྱི་ཞར་བྱུང་ངོ༌། །དང་པོ་ལ། དབྱེན་གྱི་མཚམས་མེད་རྒྱས་པར་བཤད་པ་དང༌། ལྔ་ག་བསྡོམས་ཏེ་བཤད་པའོ། །དང་པོ་ལ། ངོ་བོ་དང༌། འབྲས་བུ་དང༌། རྣམ་པའི་སྒོ་ནས་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ། འདི་དབྱེ་བའི་དབྱེན། འདིས་འབྱེད་པའི་དབྱེན་ནོ། །དང་པོ་ལ། ངོ་བོ་དང༌། གང་ལ་ལྡན་པའོ། །
Enumeration Block 19:
གཉིས་པ་འདིས་འབྱེད་པའི་དབྱེན་ལ། ངོ་བོ་དང༌། གང་ལ་ལྡན་པའོ། །
Enumeration Block 20:
གཉིས་པ་དེའི་འབྲས་བུ་ལ། དངོས་དང༌། དོགས་པ་བཅད་པའོ། །
Enumeration Block 21:
གསུམ་པ་རྣམ་པའི་སྒོ་ནས་རྒྱས་པར་བཤད་པ་ལ། འཁོར་ལོའི་དབྱེན་གྱི་རྣམ་པ་དང༌། ལས་ཀྱི་དབྱེན་བཤད་པ། འཁོར་ལོའི་དབྱེན་མི་འབྱུང་བའི་དུས་ངོས་བཟུང་བའོ། །དང་པོ་ལ། སུ་ཞིག་གིས་འབྱེད་པ། གང་དུ་འབྱེད་པ། སུ་དག་འབྱེད་པ། ཇི་ཙམ་གྱིས་བྱེ་བ། དུས་ཇི་སྲིད་དུ་འཇུག་པ། སྒྲ་དོན། གླིང་གང་ལ་ཡོད་པ། དགེ་སློང་གི་གྲངས་སོ། །
Enumeration Block 22:
གཉིས་པ་ལྔ་ཀ་བསྡོམས་ཏེ་བཤད་པ་ལ། མཚམས་མེད་ལྔའི་གྲངས་ངེས་དང༌། འཕྲོས་དོན་དོགས་པ་གཅོད་པའོ། །
Enumeration Block 23:
གཉིས་པ་ལ། མ་གསོད་པའི་དོགས་གཅོད། ངན་སེམས་ཀྱི་ཁྲག་ཕྱུང་བའི་དོགས་གཅོད། དགྲ་བཅོམ་གསོད་པའི་དོགས་གཅོད་དོ། །དང་པོ་ལ། མཚན་གྱུར་པ་ལ་དཔྱད་པ། ཟླ་མཚན་མངལ་གཞན་དུ་སྐྱེད་པའི་དོགས་གཅོད་དོ། །
Enumeration Block 24:
གཉིས་པ་དེའི་འབྲས་བུ་བཤད་པ་ལ། སྤྱིར་བསྟན་པ་དང༌། ཁྱད་པར་བཤད་པའོ། །
Enumeration Block 25:
གཉིས་པ་དེ་དང་ཉེ་བ་བཤད་པ་ལ། ངོ་བོ་དང༌། ཞར་ལ་ལམ་གསུམ་གྱི་གེགས་བཤད་པ་དང༌། ངེས་གནས་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 26:
གསུམ་པ་ངེས་གནས་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། སྤྱིར་བསྟན་པ་དང༌། བྱེ་བྲག་ཏུ་སྟོན་པས་མཛད་ཚུལ་ལོ། །དང་པོ་ལ། ས་མཚམས་དང༌། ཡོན་ཏན་གྱི་ཆོས། རྣམ་པར་རྒྱས་བཤད་དོ། །
Enumeration Block 27:
གཉིས་པ་བྱེ་བྲག་ཏུ་སྟོན་པས་མཛད་ཚུལ་ལ། ཚོགས་བསགས་ཚུལ་དང༌། ཕར་ཕྱིན་རྫོགས་ཚུལ་ལོ། །
Enumeration Block 28:
གཉིས་པ་ལ། སྦྱིན་པའི་ཕར་ཕྱིན་རྫོགས་ཚུལ། ཚུལ་ཁྲིམས་དང་བཟོད་པའི། བརྩོན་འགྲུས་ཀྱི། བསམ་གཏན་དང་ཤེས་རབ་ཀྱི་ཕར་ཕྱིན་རྫོགས་ཚུལ་ལོ། །
Enumeration Block 29:
གཉིས་པ་བསྟེན་བྱ་བསོད་ནམས་བྱ་བའི་གཞི་གསུམ་བཤད་པ་ལ། ཐུན་མོང་གི་ངེས་ཚིག དབྱེ་བ་སོ་སོའི་རང་བཞིན། ཆོས་སྦྱིན་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 30:
གཉིས་པ་དབྱེ་བ་སོ་སོའི་རང་བཞིན་ལ། སྦྱིན་པ་ལས་བྱུང་བ་བཤད། གཞན་གཉིས་བཤད་པའོ། །དང་པོ་ལ། སྦྱིན་པའི་ངོ་བོ། །དབྱེ་བ། ཁྱད་པར་རོ། །དང་པོ་ལ། དངོས་དང༌། དེའི་འབྲས་བུའོ། །

Enumeration Block 2:
གཉིས་པ་ལ། སྦྱིན་པའི་ཕར་ཕྱིན་རྫོགས་ཚུལ། ཚུལ་ཁྲིམས་དང་བཟོད་པའི། བརྩོན་འགྲུས་ཀྱི། བསམ་གཏན་དང་ཤེས་རབ་ཀྱི་ཕར་ཕྱིན་རྫོགས་ཚུལ་ལོ། །
Enumeration Block 3:

Enumeration Block 14:
གསུམ་པ་ཕྲ་རྒྱས་ཀྱི་རྣམ་གྲངས་ལ། ངོ་བོ་དངོས་དང༌། གང་ལ་མཚུངས་པར་ལྡན་པ་དང༌། །སྒྲིབ་པ་ལྔ་བསྟན་པའོ། །དང་པོ་ལ། མདོ་ལས་འབྱུང་བའི་དོན་དང༌། བསྟན་བཅོས་ལས་འབྱུང་བ་བསྟན་པའོ། །དང་པོ་ལ། དངོས་དང༌། ངེས་ཚིག་གོ ། དང་པོ་ལ། ཟག་པ་དང༌། ཆུ་སྦྱོར་དང༌། ཉེར་ལེན་ནོ། །དང་པོ་ལ། འདོད་པའི་ཟག་པ་དང༌། སྲིད་པའི་ཟག་པ་དང༌། མ་རིག་པའི་ཟག་པ་ལོགས་ཤིག་ཏུ་བསྟན་པའི་རྒྱུ་མཚན་ནོ། །

Enumeration Block 1:
གནས་བདུན་པ་ཡེ་ཤེས་བསྟན་པའི་གནས་ཀྱི་དོན་ལ་གཉིས། དང་པོ་གནས་ཀྱི་གཞུང་བཤད་པ་ལ། ཤེས་པ་དང༌། ལྡན་པ་དང༌། ཐོབ་པ་དང༌། ཡོན་ཏན་ནོ། །དང་པོ་ལ་གསུམ། བཟོད་ཤེས་དང་ལྟ་བའི་ཁྱད་པར། ཤེས་པ་བཅུ་ངོས་བཟུང་བ། དེ་དག་གི་ཁྱད་པར་དཔྱད་པའོ། །དང་པོ་ལ། ཟག་མེད་དང༌། ཟག་བཅས་སོ། །
Enumeration Block 2:
གཉིས་པ་ཤེས་པ་བཅུ་ངོས་བཟུང་བ་ལ། དབྱེ་བ་དངོས་དང༌། སེམས་ཤེས་ཁྱད་པར་དུ་བསྟན་པའོ། །དང་པོ་ལ། བསྟན། བཤད་གཉིས་ལས། 
Enumeration Block 3:
གཉིས་པ་སེམས་ཤེས་ཁྱད་པར་དུ་བཤད་པ་ལ། སེམས་ཤེས་ཀྱི་ཁྱད་ཆོས་དང༌། ཟད་མི་སྐྱེ་ཤེས་པའི་ཁྱད་པར་རོ། །དང་པོ་ལ། སྤྱིར་བསྟན་པ་དང༌། ལམ་གྱི་གནས་སྐབས་སོ། །
Enumeration Block 4:
གསུམ་པ་དེ་དག་གི་ཁྱད་པར་དཔྱད་པ་ལ། ཤེས་བཅུའི་ཁྱད་པར། གཉེན་པོའི་ཁྱད་པར། རྣམ་པའི་ཁྱད་པར། ཁྱད་པར་གཞན་བཤད་པའོ། །
Enumeration Block 5:
གསུམ་པ་རྣམ་པའི་ཁྱད་པར་ལ། ཤེས་པ་སོ་སོའི་རྣམ་པ་དང༌། རྣམ་པ་སོ་སོའི་ངོ་བོའོ། །དང་པོ་ལ། ཆོས་ཤེས་རྗེས་ཤེས་རྣམ་པ་གང་གིས་འཇུག་པ། ཀུན་རྫོབ་ཤེས་པ། བདེན་བཞི་ཤེས་པ། ཕ་རོལ་གྱི་སེམས་ཤེས་པ། ཟད་མི་སྐྱེ་ཤེས་པ་རྣམ་པ་གང་གིས་འཇུག་པའོ། །
Enumeration Block 6:
བཞི་པ་ཕ་རོལ་གྱི་སེམས་ཤེས་པ་ལ། དྲི་མེད་དང༌། དྲི་བཅས་འཇུག་ཚུལ་ལོ། །
Enumeration Block 7:
གཉིས་པ་རྣམ་པ་སོ་སོའི་ངོ་བོ་ལ། ཟག་མེད་ལ་རང་མཚན་གྱི་རྣམ་པ་ཡོད་མེད་དཔྱད་པ། རྣམ་པ་བཅུ་དྲུག་རྫས་སུ་སྒྲུབ་པ། རྣམ་པའི་ངོ་བོ། གཟུང་འཛིན་གྱི་ཁྱད་པར་རོ། །དང་པོ་ལ། རང་ལུགས་དང༌། གཞན་ལུགས་སོ། །
Enumeration Block 8:
བཞི་པ་ཤེས་པའི་ཁྱད་པར་གཞན་བསྟན་པ་ལ། ངོ་བོའི་ཁྱད་པར། སའི་ཁྱད་པར། རྟེན་གྱི་ཁྱད་པར། དྲན་པ་ཉེར་བཞག་གི་ཁྱད་པར། དམིགས་པའི་ཁྱད་པར་རོ། །

Enumeration Block 1:
མི་འཇིགས་པ་བཤད་པ་ལ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 2:
མཇུག་བསྡུ་བ་ལ། སངས་རྒྱས་ཀྱི་ཁྱད་པར་མཉམ་པའི་ཚུལ་དང༌། མི་མཉམ་པའི་ཚུལ་ལོ། །
Enumeration Block 3:
ཐུན་མོང་གི་ཡོན་ཏན་ལ། བསྟན། བཤད་གཉིས་ལས། དང་པོ་ལའང༌། མདོར་བསྟན་པ་དང༌། ཅུང་ཟད་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 4:
རྒྱས་བཤད་ལ། འཕགས་པ་དང་ཐུན་མོང་བ་དང༌། སྐྱེ་འཕགས་གཉིས་ཀ་དང་ཐུན་མོང་བའོ། །དང་པོ་ལ། ཡོན་ཏན་དྲུག་པོ་སོ་སོའི་ཆོས་བཤད་པ་དང༌། །ཐུན་མོང་བའི་ཆོས་བཤད་པའོ། །དང་པོ་ལ། ཉོན་མོངས་མེད་པ་དང༌། སྨོན་ནས་མཁྱེན་པ། སོ་སོ་ཡང་དག་པར་རིག་པ་བཞིའོ། །
Enumeration Block 5:
སོ་སོ་ཡང་དག་པར་རིག་པ་བཞི་བཤད་པ་ལ། དབྱེ་བའི་སྒོ་ནས་ཐུན་མོང་གི་ཆོས་བསྟན་པ། མི་འདྲ་བའི་ཁྱད་ཆོས་སོ་སོར་བཤད་པ། ཐོབ་ཚུལ་གྱི་དོན་བསྡུ་བའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། དང་པོ་གསུམ་གྱི་དམིགས་པ་དང་རང་བཞིན། བཞི་པའི་ཆོས་བཞི། གཉིས་པའི་ཆོས་གཉིས། དང་པོ་དང་གསུམ་པའི་ངོ་བོ། དང་པོའི་ས། གསུམ་པའི་སའི་ཁྱད་པར་རོ། །
Enumeration Block 7:
ཡོན་ཏན་དྲུག་པོ་ཐུན་མོང་བའི་ཆོས་བཤད་པ་ལ། སེམས་རྟེན་སྤྱིར་བསྟན་པ་དང༌། རབ་མཐའ་དངོས་ཡིན་མིན་གྱི་ཁྱད་པར། བཞི་པའི་རབ་མཐའ་ངོས་བཟུང་བ། སྦྱོར་བའི་དམིགས་བསལ་ལོ། །
Enumeration Block 8:
སྐྱེ་འཕགས་གཉིས་ཀ་དང་ཐུན་མོང་བའི་ཡོན་ཏན་བཤད་པ་ལ། ཡོན་ཏན་གྱི་ཁྱད་པར་དང༌། ཁྱད་པར་གཏན་ལ་དབབ་པའོ། །དང་པོ་ལ། དབྱེ་བ། ངོ་བོ། ཆོས་ཀྱི་ཁྱད་པར། ཐོབ་ཚུལ་ལོ། །
Enumeration Block 9:
ཆོས་ཀྱི་ཁྱད་པར་ལ། ཤེས་པ་གང་ཡིན་པ་དང༌། ས་གང་ན་ཡོད་པ་དང༌། སྤྱོད་ཡུལ་གང་ཡིན་པའོ། །
Enumeration Block 10:
ཁྱད་པར་གཏན་ལ་དབབ་པ་ལ། ཐུན་མོང་དུ་གཏན་ལ་དབབ་པ་དང༌། བྱེ་བྲག་ཏུ་གཏན་ལ་དབབ་པའོ། །དང་པོ་ལ། དྲན་པ་ཉེར་གཞག་དང་སྦྱར་བ། དགེ་སོགས་གསུམ་དང་སྦྱར་བ། རིག་པ་གསུམ་དང་སྦྱར་བ། ཆོ་འཕྲུལ་གསུམ་དང་སྦྱར་བའོ། །
Enumeration Block 11:
རིག་པ་གསུམ་དང་སྦྱར་བ་ལ། བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 12:
རྒྱས་བཤད་ལ། དོན་དམ་པའི་མི་སློབ་པའི་རིག་པ་ངོས་བཟུང་བ། གཞན་གཉིས་ལ་དེའི་སྒྲ་འཇུག་པའི་རྒྱུ་མཚན། དེ་ལས་འཕྲོས་པའི་དོན་ཏོ། །
Enumeration Block 13:
ཆོ་འཕྲུལ་གསུམ་དང་སྦྱར་བ་ལ། སྤྱིར་བསྟན་པ་དང༌། དེའི་མཆོག་ངོས་བཟུང་བ་གཉིས་ལས།
Enumeration Block 14:

Enumeration Block 24:

Enumeration Block 1:
གཉིས་པ་ཏིང་ངེ་འཛིན་གྱི་དབྱེ་བ་ལ། གསུམ་དུ་དབྱེ་བ། བཞིར་དབྱེ་བའོ། །དང་པོ་ལ། སའི་སྒོ་ནས། ལམ་གྱི་སྒོ་ནས། ཡུལ་ལ་འཇུག་པའི་ཚུལ་གྱི་སྒོ་ནས་དབྱེ་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། ཏིང་ངེ་འཛིན་གསུམ་པོ་དེའི་ངོ་བོ་ངོས་བཟུང་བ། ནང་གསེས་ཀྱི་དབྱེ་བ། དངོས་བཏགས་དཔྱད་པའོ། །
Enumeration Block 3:
གསུམ་པ་ཡུལ་ལ་འཇུག་པའི་ཚུལ་གྱི་སྒོ་ནས་དབྱེ་བ་ལ། དབྱེ་བ་སྤྱིར་བསྟན་པ་དང༌། ཁྱད་ཆོས་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། དམིགས་རྣམ་གྱི་ཁྱད་པར། ངོ་བོའི་ཁྱད་པར། རྟེན་གྱི་ཁྱད་པར། གང་ཟག་གི་ཁྱད་པར། སའི་ཁྱད་པར་རོ། །
Enumeration Block 5:
གསུམ་པ་སྙོམས་འཇུག་རྣམས་ཀྱི་ཁྱད་པར་བསྟན་པ་ལ། ཉོན་མོངས་ཅན་ཡིན་མིན་གྱི་ཁྱད་པར། བསམ་གཏན་བཞི་པའི་ཁྱད་ཆོས། རྒྱུ་འབྲས་ཀྱི་བསམ་གཏན་གཉིས་ཀྱི་ཚོར་བའི་ཁྱད་པར་རོ། །
Enumeration Block 6:
གསུམ་པ་རྒྱུ་འབྲས་ཀྱི་བསམ་གཏན་གཉིས་ཀྱི་ཚོར་བའི་ཁྱད་པར་ལ། དངོས་དང༌། དོགས་པ་གཅོད་པའོ། །
Enumeration Block 7:
གསུམ་པ་སྙོམས་འཇུག་གི་ཐོབ་ཚུལ་ལ། ཇི་ལྟར་ཐོབ་པའི་ཚུལ་དངོས། གང་གི་མཇུག་ཏུ་གང་སྐྱེ་བ། ཐོད་རྒལ་གྱི་སྙོམས་འཇུག་སྐྱེ་ཚུལ་ལོ། །དང་པོ་ལ། དག་པ་བ་ཐོབ་ཚུལ། ཟག་མེད་ཐོབ་ཚུལ། ཉོན་མོངས་ཅན་ཐོབ་ཚུལ་ལོ། །
Enumeration Block 8:
གཉིས་པ་གང་གི་མཇུག་ཏུ་གང་སྐྱེ་བ་ལ། སྤྱིར་བསྟན་པ་དང༌། ཕྱི་མ་གཉིས་ཀྱི་དམིགས་བསལ་ལོ། །དང་པོ་ལ། ཟག་མེད་ཀྱི་མཇུག་ཏུ་གང་སྐྱེ་བ། དག་པ་བའི་མཇུག་ཏུ་གང་སྐྱེ་བ། ཉོན་མོངས་ཅན་གྱི་མཇུག་ཏུ་གང་སྐྱེ་བའོ། །
Enumeration Block 9:
གཉིས་པ་ཕྱི་མ་གཉིས་ཀྱི་དམིགས་བསལ་ལ། འཆི་འཕོའི་གནས་སྐབས་དང༌། ཆ་མཐུན་བཞིའི་དམིགས་བསལ་ལོ། །དང་པོ་ལ། དག་པ་བ་དང༌། ཉོན་མོངས་ཅན་གཉིས། 
Enumeration Block 10:
གཉིས་པ་ཆ་མཐུན་བཞིའི་དམིགས་བསལ་ལ། དག་པ་བ་ལ་དེ་བཞིར་དབྱེ་བ། དབྱེ་བ་སོ་སོའི་དོན། བཞི་པོ་གང་གི་མཇུག་ཏུ་གང་སྐྱེ་བའོ། །
Enumeration Block 11:
གསུམ་པ་ཐོད་བརྒལ་གྱི་སྙོམས་འཇུག་སྐྱེ་ཚུལ་ལ། སྦྱོར་བ་དང༌། དངོས་གཞིའོ། །དང་པོ་ལ། རིང་སྦྱོར་དང༌། ཉེ་སྦྱོར་ལས། 
Enumeration Block 12:
བཞི་པ་རྟེན་གང་གིས་གང་མངོན་དུ་བྱེད་པ་ལ། སྤྱིར་བཏང་བ་དང༌། སྲིད་རྩེ་ལ་དམིགས་བསལ་ལོ། །
Enumeration Block 13:
ལྔ་པ་སྤྱོད་ཡུལ་གང་ལ་དམིགས་པ་ལ། བསམ་གཏན་ཉོན་མོངས་ཅན་གྱིས་གང་ལ་དམིགས་པ། བསམ་གཏན་དག་པ་བ་དང་ཟག་མེད་ཀྱིས་གང་ལ་དམིགས་པ། གཟུགས་མེད་ཀྱི་དངོས་གཞིས་གང་ལ་དམིགས་པའོ། །
Enumeration Block 14:
དྲུག་པ་ཉོན་མོངས་སྤོང་བྱེད་ངོས་བཟུང་བ་ལ། གང་གིས་གང་སྤོང་བ། སྤོང་བྱེད་གཉེན་པོའི་ཁྱད་པར་རོ། །དང་པོ་ལ། དངོས་གཞི་ཟག་མེད་ཀྱིས་གང་སྤོང་བ། ཉེར་བསྡོགས་ཀྱིས་གང་སྤོང་བའོ། །
Enumeration Block 15:
གཉིས་པ་སྤོང་བྱེད་གཉེན་པོའི་ཁྱད་པར་ལ། ཉེར་བསྡོགས་ཀྱི་ཁྱད་པར་དང༌། བསམ་གཏན་ཁྱད་པར་ཅན་ངོས་བཟུང་བའོ། །དང་པོ་ལ། དབྱེ་བ། ངོ་བོ་ཚོར་བ་དང་བཅས་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ། ངོ་བོ་སྤྱིར་བཏང་བ། ཚོར་བ་ལྡན་ཚུལ། ངོ་བོའི་དམིགས་བསལ། གཞན་འདོད་དོ། །
Enumeration Block 17:
